# Managed Object Storage

Managed Object Storage is S3-compatible storage for uploads, assets, and backups. Provisioning an `s3` addon also creates a **private bucket named `default`**. To serve files without authentication, make it public from the dashboard's S3 browser.

## Provision

```bash
lizard add s3
```

The first S3 addon is named `s3`, so `${{s3.S3_ENDPOINT}}` and friends work immediately.

## Environment variables

| Variable | Description |
|----------|-------------|
| `S3_ENDPOINT` | S3-compatible endpoint URL |
| `S3_DEFAULT_BUCKET` | The auto-created bucket name (`default`) |
| `S3_ACCESS_KEY_ID` | Access key |
| `S3_SECRET_ACCESS_KEY` | Secret key |
| `S3_REGION` | Region |

## Connect a service

```bash
lizard secrets set \
  S3_ENDPOINT='${{s3.S3_ENDPOINT}}' \
  S3_DEFAULT_BUCKET='${{s3.S3_DEFAULT_BUCKET}}' \
  S3_ACCESS_KEY_ID='${{s3.S3_ACCESS_KEY_ID}}' \
  S3_SECRET_ACCESS_KEY='${{s3.S3_SECRET_ACCESS_KEY}}' \
  S3_REGION='${{s3.S3_REGION}}' \
  --service api
lizard redeploy --service api
```

## Using an AWS SDK

The endpoint is S3-compatible. Set **path-style** addressing:

```ts
import { S3Client } from "@aws-sdk/client-s3";

const s3 = new S3Client({
  endpoint: process.env.S3_ENDPOINT,
  region: process.env.S3_REGION,
  forcePathStyle: true, // required
  credentials: {
    accessKeyId: process.env.S3_ACCESS_KEY_ID!,
    secretAccessKey: process.env.S3_SECRET_ACCESS_KEY!,
  },
});
```

## Public files

Buckets are private by default. Objects in a bucket you make **public** are served without authentication two ways:

1. **Gateway URL** (shown in the dashboard):
   ```
   https://s3-<region>.onlizard.com/<addonId>/<bucket>/<key>
   ```
   `<region>` is the value of `S3_REGION` (`eu-west-1` or `us-east-1`).
2. **Platform proxy** (the dashboard host, with long-lived immutable cache headers):
   ```
   <dashboard-host>/api/s3/<addonId>/public/<bucket>/<key>
   ```

Once you make the `default` bucket public, its objects are served at:

```
<dashboard-host>/api/s3/<addonId>/public/default/<key>
```

## Browse objects

Open the **S3 browser** in the dashboard (`lizard open`) to upload and delete objects, create folders, and make buckets public or private. From the CLI, `lizard s3 upload <file>` uploads a file and `lizard s3 list` lists objects.

> **Bucket ACL changes** (making a bucket public/private) aren't on the CLI yet — manage them from the dashboard.

## Storage limit

Each account can store up to 16 GiB of objects across its Managed Object Storage addons. You pay for stored bytes, not a reserved size; `lizard scale --storage` does not change this limit.
