# Lizard documentation

## What is Lizard?

Lizard is a cloud sandbox platform for AI agents. Lizard Sandboxes are Firecracker microVMs, each with its own kernel: an agent runs code and shell commands in them, uses a desktop and browser, opens private HTTPS URLs for its ports and keeps files on Persistent Volumes. Create sandboxes from your code with Lizard SDK for TypeScript or Python, or from a terminal with Lizard CLI. When the agent has built something, deploy it on the same platform: `lizard up` uploads the current folder, `lizard add -r owner/repo` deploys a GitHub repository, and Lizard builds the image on its servers and gives each web service an HTTPS address on `onlizard.com`. Add Managed Postgres, Managed Redis or S3-compatible Managed Object Storage with the same CLI and connect them to services through references such as `${{postgres.DATABASE_URL}}`. Lizard is not LizardFS, the distributed file system, and not `lizard`, the Python tool that measures code complexity.

## Run code in a sandbox

Create an API key and a project in the dashboard, set `LIZARD_API_KEY`, and install Lizard SDK. This code creates a sandbox, runs a command and kills the sandbox:

```bash
npm install @lizard-build/sdk
```

```ts
import { Lizard } from '@lizard-build/sdk'

const lizard = new Lizard({ project: 'my-project' })
const sandbox = await lizard.create('interpreter', { size: 'small' })

try {
  const run = await sandbox.process.exec("python -c 'print(2 ** 10)'")
  console.log(run.stdout) // 1024
} finally {
  await sandbox.kill()
}
```

The Small size (2 vCPU, 4 GB RAM) costs $0.0162 an hour, billed by the second. For Python, templates and lifetimes, see the [Sandboxes quickstart](/sandboxes/quickstart) and the [Sandboxes overview](/sandboxes).

## Deploy an app

Install Lizard CLI. The installer signs you in and offers the 7-day Pro trial: you add a card in Stripe Checkout, and nothing is charged during the trial. Then deploy a repository you can access:

```bash
curl -fsSL https://lizard.build/install.sh | bash   # then signs you in and offers the trial
lizard add -r your-org/your-app
```

On Windows or with npm, see [other ways to install](/getting-started#1-install-the-cli).

Lizard builds the image on its servers, so this path does not need local Docker. [lizardpack](/concepts/build-pipeline) detects supported projects; projects with special build needs can use explicit commands or a Dockerfile. Check the build logs and verify the application URL after deployment.

## Understand your resources

A **workspace** groups members and projects. A **project** groups services, databases, and Sandboxes; each account has a default project (`<username>'s Project` for a new account) that Lizard CLI uses in a folder you haven't linked. A **service** runs an application or worker. Managed Postgres, Managed Redis, and Managed Object Storage provide data services that applications connect to through environment references.

Apps and Sandboxes have different runtime and storage rules. Read [limits](/platform/limits) and [storage and recovery](/platform/storage-and-recovery) before depending on a resource's size, lifetime, or data retention.
