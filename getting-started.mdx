# App quickstart

Ship your first app to Lizard in a few minutes. A Lizard account is created automatically the first time you `lizard login`. You'll install Lizard CLI, log in, start the Pro trial, and deploy — either straight from a GitHub repo or from a local directory.

## 1. Install the CLI

On macOS or Linux, run the install script:

```bash
curl -fsSL https://lizard.build/install.sh | bash
```

It puts the `lizard` binary in `~/.lizard/bin`, adds that folder to your `PATH` in `~/.zshrc` or `~/.bashrc`, and links `lizard` into a folder that is already on your `PATH`, so it works in this terminal right away. The binary updates itself from then on, except in CI. If the script says `lizard` may not be found, open a new terminal. Check the version:

```bash
lizard --version
```

On Windows, run this in PowerShell:

```powershell
irm https://lizard.build/api/cli/install.ps1 | iex
```

**Or install from npm** (needs Node.js 18+):

```bash
npm install -g @lizard-build/cli
```

> **Don't use `npx`.** Always use the globally installed `lizard` binary. Running `npx @lizard-build/cli` pulls a throwaway copy whose version may drift from the platform. To upgrade an npm install later, run `npm install -g @lizard-build/cli@latest`.

> **Permission errors (EACCES)?** Don't use `sudo`. Use the install script above, which needs no admin rights, or point npm at a user-owned prefix:
> ```bash
> mkdir -p ~/.npm-global
> npm config set prefix ~/.npm-global
> echo 'export PATH=~/.npm-global/bin:$PATH' >> ~/.zshrc && source ~/.zshrc
> npm install -g @lizard-build/cli
> ```

## 2. Log in

```bash
lizard login
```

This opens your browser to authenticate, then drops back to your terminal once you confirm. In CI or other non-interactive environments, authenticate with a token instead:

```bash
export LIZARD_TOKEN=liz_xxx
# or
lizard login --token liz_xxx
```

API keys start with `liz_`. Create one with `lizard keys create <name>`. `LIZARD_API_KEY` works in place of `LIZARD_TOKEN`.

Check who you are at any time:

```bash
lizard whoami
```

## 3. Start the Pro trial

A new account has no plan, so creating anything returns HTTP 402 with a Checkout link. Start the 7-day Pro trial first:

```bash
lizard billing start
```

This opens Stripe Checkout, where you add a card. The trial includes $5 in trial credits, and nothing is charged until it ends. See [Billing](/platform/billing).

## 4. Deploy

Pick the path that matches where your code lives.

### Option A — Deploy a GitHub repo (recommended)

If your code is on GitHub, create a service straight from the repo. Lizard clones it, auto-detects the stack, builds it, and returns a live URL:

```bash
lizard add -r your-org/your-app
```

Pushes to the tracked branch will auto-redeploy from then on. For private repos, connect the GitHub App first:

```bash
lizard git connect
```

### Option B — Deploy local code

From inside your project directory, upload and deploy the current folder (respects `.gitignore`):

```bash
lizard up
```

If the directory isn't linked to a project yet, `up` will create or select one interactively. In CI, link explicitly first with `lizard init --name my-project`.

Either way, when the build finishes you'll get a generated URL like `https://your-app-x1y2z.onlizard.com`.

## 5. Watch it build and run

```bash
lizard ps          # services in the project, with status + URL
lizard logs        # last runtime log lines
lizard logs --build  # the most recent build's logs
lizard open        # open the project in the dashboard
```

## 6. Add a database (optional)

Provision Managed Postgres and reference it from your service:

```bash
lizard add postgres
lizard secrets set DATABASE_URL='${{postgres.DATABASE_PRIVATE_URL}}' --service your-app
lizard redeploy --service your-app
```

The `${{postgres.DATABASE_PRIVATE_URL}}` reference is resolved at deploy time and connects over the project's private network. It matches the addon's current name, so update the reference if you rename the addon. Credentials do not rotate on their own; a service picks up new values on its next deploy. See [Managed Addons](/addons).
