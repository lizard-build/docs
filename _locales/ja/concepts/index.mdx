# 概念

Lizard の中核モデル: コードがどのように整理され、どのようにビルドされ、リリースがどのように本番環境へ届くか。これを一度読めば、残りのドキュメントが理解しやすくなります。

Lizard とは何かを 1 段落でまとめた説明は、[ドキュメントのホーム](/) を参照してください。コンテナを実行するサービスの種類や、 PaaS、FaaS、IaaS とどう違うかについては、ブログの [container as a service](https://lizard.build/blog/container-as-a-service) を読んでください。

- [デプロイメント](/concepts/deployments)：ビルドとリリースのライフサイクル、再起動と再デプロイの違い、およびライブ設定変更。
