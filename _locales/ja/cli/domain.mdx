# lizard domain

現在のドメインを表示するか、カスタムドメインを接続します。

<span id="usage" />

## 使い方

```bash
lizard domain [hostname] [flags]
```

ホスト名は位置引数です。`add` サブコマンドはありません。引数なしで `lizard domain` を実行すると、サービスの現在のドメインが表示されます。ドメインがない場合は生成されます。エイリアス: `lizard domains`。

<span id="flags" />

## フラグ

| フラグ | 説明 |
|------|-------------|
| `-s, --service <name>` | サービス |
| `-p, --project <id>` | プロジェクト名、スラッグ、または ID |
| `--port <n>` | 公開するポート |
| `-f, --force` | ドメインが自分の別のサービスに接続されている場合、このサービスに移動する |

サブコマンドでも同じ `-s` と `-p` フラグを使います。ドメインの検証と削除は、そのドメインを接続したサービスで行ってください。

<span id="subcommands" />

## サブコマンド

### `lizard domain generate`

新しい `*.onlizard.com` サブドメインを生成します。

### `lizard domain verify <hostname>`

TXT レコードを確認してドメインを有効化します。TLS は自動的にプロビジョニングされます。

### `lizard domain delete <hostname>`

ドメインを削除します（別名: `rm`）。

| フラグ | 説明 |
|------|-------------|
| `-y, --yes` | 確認をスキップ |

<span id="examples" />

## 例

<span id="show-the-current-domain" />

### 現在のドメインを表示する

```bash
lizard domain
```

<span id="generate-a-subdomain" />

### サブドメインを生成する

```bash
lizard domain generate
```

<span id="attach-a-custom-domain" />

### カスタムドメインを接続する

```bash
lizard domain app.example.com --service web
```

Lizard は作成する DNS レコードを返します。ホスト名用の `CNAME` と、ドメインをまだ検証していない場合は `_lizard-verify.<apex domain>` の `TXT` レコードです（`app.example.com` の場合は `_lizard-verify.example.com`）。DNS プロバイダーでそれらを追加してから、同じサービスで検証します:

```bash
lizard domain verify app.example.com --service web
```

<span id="attach-a-domain-to-a-specific-port" />

### 特定のポートにドメインを接続する

```bash
lizard domain app.example.com --service web --port 8080
```

<span id="move-a-domain-from-another-of-your-services" />

### 自分の別のサービスからドメインを移動する

```bash
lizard domain app.example.com --service web --force
```

<span id="remove-a-domain" />

### ドメインを削除する

```bash
lizard domain delete app.example.com --service web
lizard domain rm app.example.com --service web --yes
```
