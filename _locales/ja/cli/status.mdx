# lizard status

現在のディレクトリについて、リンクされたワークスペース、プロジェクト、サービスを表示します。サインインは不要です。

リンクされていないディレクトリでは `Not linked` と表示します。そこでのコマンドはアカウントのデフォルトプロジェクトを使い、`lizard up` はディレクトリをそのプロジェクトにリンクします。

<span id="usage" />

## 使い方

```bash
lizard status
```

<span id="examples" />

## 例

<span id="check-the-current-directorys-link" />

### 現在のディレクトリのリンクを確認する

```bash
lizard status
```

<span id="read-the-link-from-a-script" />

### スクリプトからリンクを読み取る

```bash
lizard status --json
```

リンク済みのディレクトリでは `cwd`、`linked: true`、`workspace`、`workspaceId`、`project`、`projectId`、`service`、`serviceId` を返します。リンクされていないディレクトリでは `{"cwd": "…", "linked": false}` を返します。
