# lizard status

現在のディレクトリについて、リンクされたワークスペース、プロジェクト、サービスを表示します。

## Usage

```bash
lizard status
```

## Examples

<span id="check-the-current-directorys-link" />

### 現在のディレクトリのリンクを確認する

```bash

```
