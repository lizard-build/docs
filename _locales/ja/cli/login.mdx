# lizard login

Lizard にログインします。

## Usage

```bash
lizard login [flags]
```

デフォルトでは、OAuth で認証するためにブラウザが開き、確認が完了するとターミナルに戻ります。

## Flags

| Flag | Description |
|------|-------------|
| `--token <token>` | API token で認証 |

## Examples

<span id="log-in-via-browser" />

### ブラウザでログイン

```bash
lizard login
```

<span id="log-in-with-a-token" />

### token でログイン

```bash
lizard login --token lzd_xxx
```

<span id="log-in-non-interactively-in-ci" />

### CI で非対話的にログイン

CI またはその他の非対話環境では、`login` を実行する代わりに、環境変数に `LIZARD_TOKEN` を設定します:

```bash
export LIZARD_TOKEN=lzd_xxx
```
