# lizard login

Lizard にログインします。

<span id="usage" />

## 使い方

```bash
lizard login [flags]
```

デフォルトでは、ブラウザでサインインページを開き、その URL を表示して終了します。サインインしたら次のコマンド（例: `lizard whoami`）を実行してください。そのコマンドがログインを完了し、認証情報を保存します。`--json` を付けると、`login` は `{ "status": "pending", "authUrl": "…" }` を出力し、ブラウザは開きません。

<span id="flags" />

## フラグ

| フラグ | 説明 |
|------|-------------|
| `--token <token>` | API キー（`liz_…`）で認証 |

<span id="examples" />

## 例

<span id="log-in-via-browser" />

### ブラウザでログイン

```bash
lizard login
```

<span id="log-in-with-an-api-key" />

### API キーでログイン

[`lizard keys create <name>`](/cli/keys) でキーを作成してから、次を実行します:

```bash
lizard login --token liz_xxx
```

<span id="log-in-non-interactively-in-ci" />

### CI で非対話的にログイン

CI またはその他の非対話環境では、`login` を実行する代わりに、環境変数に `LIZARD_TOKEN`（または `LIZARD_API_KEY`）を設定します:

```bash
export LIZARD_TOKEN=liz_xxx
```
