# lizard open

ブラウザでプロジェクトを開きます。

<span id="usage" />

## 使い方

```bash
lizard open [flags]
```

<span id="flags" />

## フラグ

| フラグ | 説明 |
|------|-------------|
| `-p, --project <id>` | プロジェクトの名前、slug、または ID |

`-p` を指定しない場合、`open` はリンクされたプロジェクトを使い、リンクされていないフォルダーではデフォルトプロジェクトを使います。`--json` を付けると `{ url, opened: false }` を表示し、ブラウザは開きません。

<span id="examples" />

## 例

<span id="open-the-current-projects-dashboard" />

### 現在のプロジェクトのダッシュボードを開く

```bash
lizard open
```

<span id="print-the-dashboard-url" />

### ダッシュボードの URL を表示する

```bash
lizard open --json
```
