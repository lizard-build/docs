# lizard billing

Lizard (lizard.build) のプランを表示・管理します。対象はトライアル、Pro、今月の利用、プロモコードです。`lizard credits` は以前の名前です。今も使えますが警告が表示され、今後のリリースで削除されます。

<span id="usage" />

## 使い方

```bash
lizard billing [subcommand] [flags]
```

サブコマンドなしの `lizard billing` は `lizard billing status` と同じ内容を表示します。コマンドは、サインインしているアカウントのプランに対して動作します。Pro、トライアル、超過分の仕組みは[請求](/platform/billing)を参照してください。

請求、解約、カードの削除を行うコマンドは確認を求めます。CI やエージェントなど端末がない環境では、代わりに `-y` を渡してください。ページを開くコマンドは常にリンクを表示し、ブラウザを開くのは対話型の端末で実行したときだけです。

<span id="subcommands" />

## サブコマンド

### `lizard billing status`

プランと現在の状態を表示します。残りの日数とトライアルクレジット、毎月 $19 のクレジットのうち使った額、現時点の超過分、次回の請求額と日付、未払いの請求書があればそれも表示します。

| フラグ | 説明 |
|------|-------------|
| `-w, --workspace <id>` | このワークスペースの所有者のプランを表示します |

### `lizard billing open`

ブラウザで請求ページを開きます。未払いの請求書の支払い、カードの追加や変更、過去の請求書の確認はそこで行えます。

| フラグ | 説明 |
|------|-------------|
| `--no-open` | ブラウザを開かずにリンクを表示します |

### `lizard billing start`

Stripe Checkout で Pro を開始します。Checkout ではカードを登録します。コマンドはブラウザで Checkout を開きます。新しいアカウントには $5 のトライアルクレジット付きの 7 日間トライアルが付き、終了まで何も請求されません。アカウントまたはカードで以前にトライアルを使ったことがある場合、Pro はすぐに始まり、$19 が請求されます。

| フラグ | 説明 |
|------|-------------|
| `--return-url <path>` | Checkout のあとに戻るダッシュボードのパス。例: `/projects/abc` |
| `--no-open` | ブラウザを開かずに Checkout のリンクを表示します |

### `lizard billing start-now`

トライアルを終えて、最初の有料月をすぐに始めます。Lizard は $19 を請求し、毎月の $19 のクレジットを付与します。トライアルクレジットを使い切ったときに使ってください。銀行が支払いの確認を求めた場合、コマンドが確認用の請求書ページを示します。支払いが完了するまでトライアルは続きます。

| フラグ | 説明 |
|------|-------------|
| `-y, --yes` | 確認を省略します |
| `--no-open` | ブラウザを開かずに支払いリンクを表示します |

### `lizard billing cancel`

今月またはトライアルの終わりに解約します。それまで Pro は有効です。トライアル中の解約に費用はかかりません。

| フラグ | 説明 |
|------|-------------|
| `-y, --yes` | 確認を省略します |

### `lizard billing resume`

終了日の前に解約を取り消します。

### `lizard billing promo <code>`

プロモコードを使って、より長いトライアルとより多くのトライアルクレジットを受け取ります。トライアル開始前なら、Lizard がコードを保存しておきます。トライアル中なら、コードでトライアルが延長されます。コードは最初の支払いの前にのみ使え、1 つのアカウントにつき 1 つです。

### `lizard billing balance`

プリペイドクレジットの残高を表示します。2026 年 11 月 1 日までのプリペイドクレジットのアカウントと、Enterprise アカウントが対象です。

### `lizard billing transactions`

プリペイドクレジットのアカウントと Enterprise アカウントについて、最近の残高の取引を一覧表示します（エイリアス `ledger`）。

| フラグ | 説明 |
|------|-------------|
| `-l, --limit <n>` | 最大件数、`1`–`100`（既定値 `20`） |
| `-c, --cursor <cursor>` | 前回の呼び出しで得たページカーソル |
| `-u, --usage` | 日ごとの利用の行を含めます |

### `lizard billing payment-methods list`

保存済みのカードを一覧表示します。`pm` は `payment-methods` の短縮形です。カードの追加は請求ページで行います。

### `lizard billing payment-methods remove <id>`

保存済みのカードを削除します（エイリアス `rm`）。

| フラグ | 説明 |
|------|-------------|
| `-y, --yes` | 確認を省略します |

## 例

<span id="check-your-plan-and-usage" />

### プランと利用状況を確認する

```bash
lizard billing status
lizard billing status --json
```

<span id="start-the-trial-with-a-promo-code" />

### プロモコードでトライアルを始める

```bash
lizard billing promo YOURCODE
lizard billing start
```

<span id="cancel-then-change-your-mind" />

### 解約して、取り消す

```bash
lizard billing cancel --yes
lizard billing resume
```

<span id="payment-required" />

## 支払いが必要な場合

プランがない、トライアルクレジットを使い切った、または未払いの請求書があるときにリソースを作成しようとすると、Lizard は HTTP 402 を返します。Lizard CLI は理由と請求ページへのリンクを表示します。例:

```text
Start your 7-day Pro trial with $5 in credits to deploy. No charge today, then $19/month.
```
