# lizard ps

プロジェクト内のすべてのサービスを、ステータスと URL とともに一覧表示します。

<span id="usage" />

## 使い方

```bash
lizard ps [flags]
```

<span id="flags" />

## フラグ

| フラグ | 説明 |
|------|-------------|
| `-p, --project <id>` | プロジェクトの名前、slug、または ID |

`-p` を指定しない場合、`ps` はリンクされたプロジェクトを使い、リンクされていないフォルダーではデフォルトプロジェクトを使います。

<span id="examples" />

## 例

<span id="list-services-in-the-linked-project" />

### リンクされたプロジェクト内のサービスを一覧表示する

```bash
lizard ps
```

<span id="list-services-in-another-project" />

### 別のプロジェクトのサービスを一覧表示する

```bash
lizard ps -p my-project
```
