# lizard upgrade

CLI を最新バージョンに更新します。

<span id="usage" />

## 使い方

```bash
lizard upgrade [flags]
```

<span id="flags" />

## フラグ

| フラグ | 説明 |
|------|-------------|
| `--check` | インストールせずに新しいバージョンがあるか確認 |

<span id="examples" />

## 例

<span id="update-to-the-latest-version" />

### 最新バージョンに更新

```bash
lizard upgrade
```

<span id="check-for-updates-without-installing" />

### インストールせずに更新を確認

```bash
lizard upgrade --check
```
