# lizard sandbox

ターミナルから [Sandboxes](/sandboxes) を作成・管理します。エイリアス: `lizard sb`。

<span id="usage" />

## 使い方

```bash
lizard sandbox create [flags]
lizard sandbox list [flags]
lizard sandbox exec <id> -- <command>
lizard sandbox ssh <id>
lizard sandbox fork <id> [flags]
lizard sandbox rm <id> [flags]
```

すべての sandbox はプロジェクトに属します。`-p` で指定したプロジェクト、指定がなければ現在のディレクトリにリンクされたプロジェクト、それもなければアカウントの既定のプロジェクト（個人ワークスペースで最も古いプロジェクト）です。

<span id="subcommands" />

## サブコマンド

### `lizard sandbox create`

sandbox を作成し、その ID を表示します。

| フラグ | 説明 |
|------|-------------|
| `-t, --template <name>` | テンプレート（既定値 `base`）。有効なテンプレート: `base`、`interpreter`、`codex`、`desktop`、`desktop-camoufox`（US East のみ）、`opencode`、`pi`、`prime`、`claude`。サーバーがリージョンの一覧と照合します |
| `-s, --size <size>` | `small`、`medium`（既定値。トライアル中は `small`）、`large` のいずれか |
| `--timeout <ms>` | 有効期間（ミリ秒）。既定値は `300000`（5 分）で、`0` を指定すると期限がなくなります |
| `--region <code>` | sandbox を作成するリージョン |
| `--snapshot <id>` | 保存済みのスナップショットから起動します。`--size` とは併用できません |
| `--volume <name-or-id>` | [Persistent Volume](/cli/volume) を接続します |
| `--with-token [key]` | sandbox 内の `lizard` を、sandbox のプロジェクトに限定され sandbox と一緒に削除される新しいキーでサインインさせます。渡した `liz_` キー、または値を省略した場合は実行中の `liz_` キーは、このリクエストを許可するためだけに使います。ブラウザでログインした場合、そのキーはありません。`base` テンプレートには `lizard` がありません |
| `-p, --project <id>` | プロジェクト（既定はリンク済みのプロジェクト、それもなければ既定のプロジェクト） |

Lizard は sandbox の稼働中、アイドル時間も含めてサイズごとの定額で秒単位の課金をします。料金にはローカルディスクと、[アカウントごとに直近 30 日間で 2 TB までの送信トラフィック](/platform/limits#sandbox-egress)が含まれます。一時停止が完了すると計算料金は止まりますが、Persistent Volumes のストレージには、接続の有無にかかわらず[ボリューム料金](/cli/volume)が引き続きかかります。

| サイズ | vCPU | メモリ | ディスク | 料金 |
|------|------|--------|------|-------|
| `small` | 2 | 4 GiB | 5 GB | $0.0162/h |
| `medium` | 4 | 8 GiB | 20 GB | $0.0324/h |
| `large` | 8 | 16 GiB | 50 GB | $0.0648/h |

`--with-token` がインストールしたキーは、sandbox 内のあらゆるものから読み取れ、sandbox が削除されるまで sandbox のプロジェクトに対して使えます。

トライアルまたは Pro プランが始まるまで、`create` は Checkout へのリンク付きで HTTP 402 を返します。`lizard billing start` を実行してください。トライアル中は同時に 5 個、最初の有料の請求書の後は 100 個の sandbox を実行できます。一時停止中の sandbox は数えません。トライアル中の sandbox は `small` で US リージョンにある必要があり、ほかのサイズやリージョンでは HTTP 403 が返ります。[制限](/platform/limits#sandbox-account-limits)を参照してください。

### `lizard sandbox list`

リンク済みのプロジェクト内の sandbox を一覧表示します（エイリアス `ls`）。

| フラグ | 説明 |
|------|-------------|
| `-p, --project <id>` | 代わりにこのプロジェクトを一覧表示します |
| `--all` | すべてのワークスペースにまたがるすべての sandbox を一覧表示します |

### `lizard sandbox rm <id>`

sandbox を削除します（エイリアス `delete`、`kill`）。

| フラグ | 説明 |
|------|-------------|
| `-y, --yes` | 確認を省略します |

### `lizard sandbox timeout <id> <ms>`

現在時点から数えた新しい有効期間をミリ秒で設定します（最小 `1000`）。アイドル時間のタイマーではありません。コマンドを実行してもリセットされません。

### `lizard sandbox exec <id> -- <command>`

sandbox 内で `sh -c` を通して 1 つのコマンドを実行し、その出力をストリーミングして、そのコマンドの終了コードで終了します。

<span id="sandbox-ssh" />

### `lizard sandbox ssh <id>`

実行中の sandbox で対話型シェルを開きます（エイリアス `shell`）。Lizard のログインを使うため、SSH キーを設定する必要はありません。スコープを限定した API キーでは、そのスコープ内の sandbox にだけ接続できます。Ctrl-C、矢印キー、タブ補完は sandbox に送られます。終了するには `exit` と入力するか、Ctrl-D を押してください。

対話型の端末が必要です。スクリプトでは `lizard sandbox exec` を使ってください。SSH プロトコルではないため、SSH クライアント、`scp`、ポートフォワーディングは使えません。

### `lizard sandbox expose <id> <port>`

sandbox 内のポートに HTTPS URL を割り当てます。ポートは非公開です。リクエストには sandbox のアクセストークンが必要で、`X-Lizard-Access-Token` ヘッダーで送るか、表示される URL にすでに含まれている `lizard_token` クエリパラメーターとして渡します。トークンのないリクエストには HTTP 401 が返ります。`--json` を付けると、結果に `hostname` と `accessToken` も含まれます。

`lizard sandbox unexpose <id> <port>` は URL を削除します。

### `lizard sandbox desktop <id>`

`-t desktop` で作成した sandbox のグラフィカルなデスクトップを起動し、ブラウザ用の URL と閲覧専用の URL を表示します。どちらのリンクもパスワードと同じように扱ってください。

| フラグ | 説明 |
|------|-------------|
| `--view-only` | 閲覧専用の URL だけを表示するか開きます |
| `--resolution <WxH>` | 画面サイズ。640x480 から 3840x2160 まで |
| `--open` | ブラウザでデスクトップを開きます |
| `--status` | デスクトップを起動せずに、その状態と URL を表示します |
| `--stop` | デスクトップを停止し、その URL を削除します |

<span id="sandbox-vnc" />

### `lizard sandbox vnc <id>`

`-t desktop` で作成した sandbox のデスクトップに VNC アプリ（macOS の画面共有、TigerVNC、RealVNC）を接続します。デスクトップには公開された VNC ポートがないため、CLI が `localhost` で待ち受け、各接続を安全な WebSocket 経由で sandbox に中継します。必要に応じてデスクトップを起動し、アドレスと VNC パスワードを表示して、Ctrl-C で止めるまで動作し続けます。

| フラグ | 説明 |
|------|-------------|
| `--port <port>` | ローカルポート（既定値 `5900`。使用中の場合は次の空いているポート） |
| `--view-only` | 閲覧専用のパスワードを使います。画面は見られますが、操作はできません |
| `--open` | VNC アプリでアドレスを開きます（`vnc://`、macOS では画面共有） |

<span id="pause-resume-and-snapshots" />

### 一時停止、再開、スナップショット

| コマンド | 動作 |
|---------|--------------|
| `lizard sandbox pause <id>` | メモリとプロセスを保存して sandbox を一時停止します。完了すると計算料金は止まりますが、Persistent Volumes のストレージ料金は別途かかります |
| `lizard sandbox resume <id>` | 一時停止中の sandbox を、保存したメモリとファイルで再び起動します |
| `lizard sandbox snapshot <id> --name <name>` | 実行中の sandbox を、メモリとファイルを含めて、自分が所有するスナップショットとして保存します。`--scope` で復元できる場所を決めます: `workspace`（既定値）は sandbox のワークスペース内の任意のプロジェクト、`user` は自分のすべてのワークスペースの任意のプロジェクト、`project` は sandbox 自身のプロジェクトだけです |
| `lizard sandbox restore <snapshot-id>` | スナップショットのリージョンで、スナップショットから新しい sandbox を起動します。`-p <project>` でプロジェクトを選びます（既定はボリュームのプロジェクト、なければスナップショット自身のプロジェクト）。`--volume <name-or-id>` はボリュームを `/workspace` にマウントし、`--timeout <ms>` は有効期間を設定します（既定値 `300000`） |
| `lizard sandbox snapshots` | プロジェクトで作成したスナップショットを一覧表示します（別のプロジェクトには `-p`、自分が作成したすべてのスナップショットには `--mine`） |
| `lizard sandbox snapshot-scope <snapshot-id> <scope>` | 自分が作成したスナップショットを復元できる場所を変更します: `user`、`workspace`、`project` のいずれか |
| `lizard sandbox snapshot-rm <snapshot-id>` | スナップショットを削除します（エイリアス `snapshot-delete`。`-y` で確認を省略） |

`pause`、`resume`、`snapshot` は処理が終わるまで待機します。キューに入った時点で戻るには `--no-wait` を渡してください。各手順で何が保持されるかは、[一時停止、再開、スナップショット](/sandboxes/quickstart#pause-and-resume)を参照してください。

ボリュームを接続した sandbox のスナップショットには、作成時点のボリュームのファイルのコピーが含まれます。どの復元もそのコピーを受け取り、`--volume` は使えません。スナップショットを復元できる人は誰でもそのファイルを読めます。`--volume` はボリュームのない sandbox のスナップショットでだけ使え、ボリュームはスナップショットと同じリージョンにある必要があります。

<span id="sandbox-fork" />

### `lizard sandbox fork <id>`

実行中の sandbox のライブコピーを起動します。Lizard は sandbox を一瞬だけ一時停止し、メモリ、プロセス、ファイルを一度だけキャプチャして、そのキャプチャから各コピーを起動します。元の sandbox は同じ ID と有効期間のまま動き続けます。1 つの sandbox を準備（ツールをインストールし、アプリを読み込む）してからフォークすれば、セットアップを繰り返さずに作業をコピーに分配できます。

| フラグ | 説明 |
|------|-------------|
| `-n, --count <n>` | 起動するコピーの数。1〜100（既定値 `1`） |
| `--timeout <ms>` | 各コピーの有効期間。最小 `1000`。既定は元の sandbox の有効期間 |

各コピーは sandbox の起動として扱われます。[実行中の sandbox と起動回数の制限](/platform/limits#sandbox-account-limits)に数えられ、元の sandbox と同じサイズで動き、そのサイズの料金がかかります。`--json` を付けると、コピーごとに 1 つのエントリ（`{"sandbox": {...}}` または `{"error": "..."}`）を出力します。起動できなかったコピーが 1 つでもあるとコマンドは `1` で終了し、起動したコピーは削除するまで動き続けます。一時停止中の sandbox と、ボリュームを接続した sandbox はフォークできません（HTTP 409）。

### `lizard sandbox files`

| コマンド | 動作 |
|---------|--------------|
| `lizard sandbox files ls <id> [path]` | ディレクトリを一覧表示します（既定値 `/`） |
| `lizard sandbox files cat <id> <path>` | ファイルの内容を表示します |
| `lizard sandbox files put <id> <local> <remote>` | ローカルファイルをアップロードします |
| `lizard sandbox files get <id> <remote> <local>` | ファイルをダウンロードします |
| `lizard sandbox files rm <id> <path>` | ファイルまたはディレクトリを削除します |

<span id="coding-agents" />

### コーディングエージェント

自分の認証情報を使って、sandbox 内でコーディングエージェントを実行します。先に [`lizard agents`](/cli/agents) で認証情報を接続してください。sandbox はエージェント用のテンプレート（`codex`、`claude`、`opencode`、`pi`、`prime`）から作成します。`base` テンプレートには Node.js がないため、エージェントを実行できません。

`lizard sandbox prompt <id> <prompt...>` はプロンプトを送信し、エージェントの動作をストリーミング表示します。

| フラグ | 説明 |
|------|-------------|
| `--agent <name>` | `codex`（既定値）、`claude`、`pi`、`opencode`、`prime` のいずれか |
| `-c, --conversation <id>` | この会話を続けます |
| `--new` | 新しい会話を始めます |
| `-m, --model <model>` | 使用するモデル |
| `--effort <level>` | 推論の強さ: `minimal`、`low`、`medium`、`high`、`xhigh` のいずれか |
| `--cwd <dir>` | sandbox 内の作業ディレクトリ（既定値 `/workspace`） |
| `-v, --verbose` | コマンドの出力も表示します |
| `--no-wait` | プロンプトが受け付けられた時点で戻ります |

Ctrl-C で表示を止めても、エージェントは作業を続けます。`lizard sandbox interrupt <id> [-c <conversation>]` は実行中のターンを停止します。`lizard sandbox conversations <id>` は会話を新しい順に一覧表示します。

<span id="examples" />

## 例

<span id="create-a-sandbox-and-run-a-command" />

### sandbox を作成してコマンドを実行する

```bash
lizard sandbox create --size small --timeout 600000
lizard sandbox exec genuine-toddler-jasj -- python3 -c "print(1 + 1)"
```

<span id="open-a-shell" />

### シェルを開く

```bash
lizard sandbox ssh genuine-toddler-jasj
```

<span id="attach-a-persistent-volume" />

### Persistent Volume を接続する

```bash
lizard volume create agent-workdir --size 10
lizard sandbox create --volume agent-workdir
```

<span id="serve-a-port" />

### ポートで配信する

```bash
lizard sandbox exec genuine-toddler-jasj -- sh -c "nohup python3 -m http.server 3000 --bind 0.0.0.0 >/tmp/http.log 2>&1 &"
lizard sandbox expose genuine-toddler-jasj 3000
```

<span id="use-a-desktop-from-a-vnc-app" />

### VNC アプリからデスクトップを使う

```bash
lizard sandbox create -t desktop
lizard sandbox vnc genuine-toddler-jasj --open
```

<span id="run-codex-in-a-sandbox" />

### sandbox で Codex を実行する

```bash
lizard agents login chatgpt
lizard sandbox create -t codex
lizard sandbox prompt genuine-toddler-jasj "add a health check endpoint and test it"
```

<span id="save-and-restore-a-sandbox" />

### sandbox を保存して復元する

```bash
lizard sandbox snapshot genuine-toddler-jasj --name my-app
lizard sandbox snapshots --mine                     # find the snapshot ID
lizard sandbox restore <snapshot-id> -p other-project
```

<span id="fork-a-prepared-sandbox" />

### 準備済みの sandbox をフォークする

```bash
lizard sandbox fork genuine-toddler-jasj -n 8 --json   # 8 copies with the same memory and files
lizard sandbox rm <copy-id>                            # delete a copy when its work is done
```
