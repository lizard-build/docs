# lizard metrics

CPU / メモリ / ネットワーク / ディスクとコストを表示します。

<span id="usage" />

## 使い方

```bash
lizard metrics [flags]
```

<span id="flags" />

## フラグ

| フラグ | 説明 |
|------|-------------|
| `-s, --service <id>` | サービス (デフォルトはリンクされたサービス) |
| `-p, --project <id>` | プロジェクト名、スラッグ、または ID |
| `--all` | リンクされたサービスを無視して、プロジェクト内のすべてのサービスを対象にする。`-s` とは併用不可 |
| `-r, --range <range>` | 時間範囲: `1h` (デフォルト)、`6h`、`24h`、`7d`、`14d`、`30d` |
| `-w, --watch` | 3 秒ごとに更新されるライブ表示。`--json` とは併用不可 |
| `--cost` | 稼働中のリソース、1 時間あたりのコスト、今回の請求期間の使用量、今月の Pro 使用量。ワークスペースのオーナーのみ |

リンクされたサービスも `-s` もない場合、`metrics` はプロジェクト内のすべてのサービスの概要を表示します。

<span id="examples" />

## 例

<span id="view-metrics-for-the-current-service" />

### 現在のサービスのメトリクスを表示する

```bash
lizard metrics
```

<span id="view-metrics-for-a-specific-service" />

### 特定のサービスのメトリクスを表示する

```bash
lizard metrics --service api
```

<span id="watch-metrics-live" />

### メトリクスをライブで監視する

```bash
lizard metrics --watch
```

<span id="include-cost" />

### コストを含める

```bash
lizard metrics --cost
```
