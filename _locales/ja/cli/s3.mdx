# lizard s3

[Managed Object Storage](/addons/storage) の bucket にオブジェクトをアップロードし、一覧表示し、期限付きのダウンロードリンクを出力します。

<span id="usage" />

## 使い方

```bash
lizard s3 upload <file> [flags]
lizard s3 list [flags]
lizard s3 url <key> [flags]
```

`--addon` と `--bucket` を渡さない限り、3 つのコマンドはどれもプロジェクト内の唯一の S3 アドオンとその `default` bucket を対象にします。先に `lizard add s3` でアドオンを追加してください。

<span id="subcommands" />

## サブコマンド

### `lizard s3 upload <file>`

ローカルファイルをアップロードします。キー、ETag、サイズを表示し、bucket が公開されている場合は URL も表示します。`default` bucket は非公開です。bucket を公開するには、ダッシュボードの S3 ブラウザーを使ってください。

`upload` はファイル全体を 1 回のリクエストで Lizard API 経由で送ります。上限は 150 MB です。それより大きいファイルには、アドオンの認証情報を使う S3 クライアントを使ってください。[Managed Object Storage](/addons/storage) を参照してください。

| フラグ | 説明 |
|------|-------------|
| `--addon <name>` | S3 アドオンの名前または ID (デフォルト: プロジェクト内の唯一の S3 アドオン) |
| `--bucket <name>` | アップロード先の bucket (デフォルトは `default`) |
| `--key <key>` | オブジェクトキー (デフォルト: ファイル名) |
| `--content-type <type>` | Content-Type ヘッダー (デフォルト: ファイルの拡張子から推測) |
| `-p, --project <id>` | プロジェクト名、スラッグ、または ID |

### `lizard s3 url <key>`

オブジェクトの期限付きダウンロードリンクを出力します。リンクを持っている人は誰でも、期限が切れるまで、非公開の bucket からでも認証情報なしでオブジェクトをダウンロードできます。`--json` を付けると `url`、`key`、`bucket`、`expiresIn`、`expiresAt` を出力します。

| フラグ | 説明 |
|------|-------------|
| `--addon <name>` | S3 アドオンの名前または ID (デフォルト: プロジェクト内の唯一の S3 アドオン) |
| `--bucket <name>` | bucket (デフォルトは `default`) |
| `--expires <seconds>` | リンクが有効な秒数 (デフォルトは `3600`、最大 `604800` = 7 日) |
| `-p, --project <id>` | プロジェクト名、スラッグ、または ID |

### `lizard s3 list`

bucket 内のオブジェクトを一覧表示します (別名 `ls`)。

| フラグ | 説明 |
|------|-------------|
| `--addon <name>` | S3 アドオンの名前または ID |
| `--bucket <name>` | 一覧表示する bucket (デフォルトは `default`) |
| `--prefix <prefix>` | このプレフィックス配下のキーのみ |
| `-p, --project <id>` | プロジェクト名、スラッグ、または ID |

各アカウントは、すべてのアドオンを合わせて最大 16 GiB まで保存できます。ストレージは保存したバイト数に対して、1 GB あたり月 $0.14 で課金されます。

<span id="examples" />

## 例

<span id="upload-a-file" />

### ファイルをアップロードする

```bash
lizard s3 upload ./logo.png --key assets/logo.png
```

<span id="share-a-private-file-for-a-day" />

### 非公開ファイルを 1 日共有する

```bash
lizard s3 url assets/logo.png --expires 86400
```

<span id="list-objects-under-a-prefix" />

### プレフィックス配下のオブジェクトを一覧表示する

```bash
lizard s3 list --prefix assets/
```

<span id="use-a-second-s3-addon" />

### 2 つ目の S3 アドオンを使う

```bash
lizard s3 upload ./backup.tar.gz --addon s3-autumn-bear
```
