# lizard volume

sandbox とサービス用の [Persistent Volumes](/sandboxes/volumes) を管理します。エイリアス: `lizard vol`。

<span id="usage" />

## 使い方

```bash
lizard volume list [flags]
lizard volume create <name> [flags]
lizard volume resize <volume> --size <gb> [flags]
lizard volume rm <volume> [flags]
```

ボリュームの名前は、プロジェクト内でのキーになります。どのコマンドも名前または ID を受け付け、リンク済みのプロジェクト以外を対象にするには `-p, --project` を使います。リンクされていないフォルダーでは、コマンドはアカウントの既定のプロジェクトを使います。

<span id="subcommands" />

## サブコマンド

### `lizard volume list`

プロジェクトのボリュームを、サイズ、状態、接続先の sandbox とともに一覧表示します（エイリアス `ls`）。`--json` では生成された ID も含まれます。`-s, --service <name>` を付けると、代わりにそのサービスに接続されたボリュームを表示します。

### `lizard volume create <name>`

ボリュームを作成します。名前には小文字、数字、ダッシュを使い、先頭と末尾は文字か数字にします。最大 64 文字で、プロジェクト内で一意である必要があります。

| フラグ | 説明 |
|------|-------------|
| `--size <gb>` | サイズ（GB 単位の整数、デフォルトは 5）。sandbox のボリュームは 1～50。CLI は先にサーバーの現在の上限を読み取ります |
| `--region <code>` | ボリュームのリージョン。接続する sandbox と一致している必要があります |
| `-s, --service <name>` | ボリュームを作成し、代わりにこのサービスに接続します。1 つのサービスに接続できるボリュームは 1 つまでで、そのファイルは再起動と再デプロイの後も残ります |
| `--mount-path <path>` | `--service` と併用: サービスからボリュームが見える場所（デフォルトは `/data`） |
| `-p, --project <id>` | プロジェクト名、スラッグ、または ID |

1 つのワークスペースの sandbox ボリュームは、割り当てサイズの合計で 200 GB までです。それを超える `create` や `resize` は、HTTP 403 とコード `volume_quota_exceeded` で失敗します。

### `lizard volume resize <volume> --size <gb>`

ボリュームをその場で拡張します。データはコピーしません。ボリュームを接続している sandbox は動作を続けますが、古いサイズのままです。次にボリュームを接続する sandbox には新しいサイズが見えます。すぐに使うには、sandbox を削除し、`--volume` を付けて新しい sandbox を作成してください。ボリュームは拡張のみできます。2026 年 10 月より前に作成された一部のボリュームは、新しいサイズの 10% 以上が空いたままであれば縮小もできます。

### `lizard volume rm <volume>`

ボリュームとそのデータを削除します（エイリアス `delete`）。ボリュームが接続されている間は失敗するため、先に sandbox を削除してください。

| フラグ | 説明 |
|------|-------------|
| `-y, --yes` | 確認をスキップ |

sandbox ボリュームのストレージ料金は、使用容量 1 GB あたり月額 $0.14 です。[サイズと料金](/sandboxes/volumes#size-and-price)を参照してください。

<span id="examples" />

## 例

<span id="create-a-volume-and-attach-it" />

### ボリュームを作成して接続する

```bash
lizard volume create agent-workdir --size 10
lizard sandbox create --volume agent-workdir
```

<span id="grow-a-volume" />

### ボリュームを拡張する

```bash
lizard volume resize agent-workdir --size 20
```

<span id="delete-a-volume" />

### ボリュームを削除する

```bash
lizard volume rm agent-workdir --yes
```
