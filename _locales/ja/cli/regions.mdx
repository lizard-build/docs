# lizard regions

利用可能なリージョンを一覧表示します。

<span id="usage" />

## 使い方

```bash
lizard regions [flags]
```

<span id="flags" />

## フラグ

| フラグ | 説明 |
|------|-------------|
| `--json` | JSON として出力 |

<span id="examples" />

## 例

<span id="list-available-regions" />

### 利用可能なリージョンを一覧表示する

```bash
lizard regions
```

<span id="list-regions-as-json" />

### リージョンを JSON として一覧表示する

```bash
lizard regions --json
```

<span id="choose-a-region-when-you-create-a-resource" />

### リソースの作成時にリージョンを選択する

`--region <code>` を `lizard add`、`lizard up`、`lizard sandbox create`、または `lizard volume create` に渡します:

```bash
lizard add -r your-org/your-app --region <code>
lizard add postgres --region <code>
lizard up --region <code>
```

`--region` を指定しない場合、`lizard add` は `us-east-1` を使い、`lizard up` はプラットフォームのデフォルトリージョンを使います。`lizard up` では、`--region` は新しいサービスを作成するときにだけ適用されます。
