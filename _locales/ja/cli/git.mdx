# lizard git

Lizard アカウントを GitHub に接続し、プロジェクトのサービスがどのリポジトリからデプロイされるかを確認し、サービスを別のブランチに切り替えます。GitHub App の接続は、個々のプロジェクトではなく Lizard アカウントに属します。

`lizard git` のその他のサブコマンドは Lizard Git 用で、このページでは扱いません。

<span id="usage" />

## 使い方

```bash
lizard git connect
lizard git status [flags]
lizard git checkout <service> <branch> [flags]
```

`-p` を指定しない場合、`status` と `checkout` はリンクされたプロジェクトを使い、リンクされていないフォルダーではデフォルトプロジェクトを使います。

<span id="subcommands" />

## サブコマンド

### `lizard git connect`

GitHub App を接続してプライベートリポジトリにアクセスします。このコマンドは GitHub を開いてアプリをインストールさせ、Enter が押されるのを待ってから接続を確認します。アプリがすでに接続されている場合は、その旨を表示します。`--json` を付けた場合やターミナル外では、代わりにインストール URL を表示します: `{ installed: false, installUrl }`。

### `lizard git status`

GitHub App が接続されているかどうかと、プロジェクトの各サービスがどのリポジトリとブランチからデプロイされるかを表示します。

| フラグ | 説明 |
|------|-------------|
| `-p, --project <id>` | プロジェクトの名前、slug、または ID |

### `lizard git checkout <service> <branch>`

サービスを別のブランチに切り替えて再デプロイします。

| フラグ | 説明 |
|------|-------------|
| `--detach` | ログのストリーミングをスキップ |
| `-p, --project <id>` | プロジェクトの名前、slug、または ID |

## 例

<span id="connect-the-github-app" />

### GitHub App を接続する

```bash
lizard git connect
```

<span id="check-connection-and-repository-status" />

### 接続とリポジトリのステータスを確認する

```bash
lizard git status
```

<span id="switch-a-service-to-a-different-branch" />

### サービスを別のブランチに切り替える

```bash
lizard git checkout api staging
```

<span id="switch-branches-without-streaming-logs" />

### ログをストリーミングせずにブランチを切り替える

```bash
lizard git checkout api staging --detach
```
