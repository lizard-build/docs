# lizard events

デプロイ履歴とレプリカ状態を表示します。

<span id="usage" />

## 使い方

```bash
lizard events [flags]
```

<span id="flags" />

## フラグ

| フラグ | 説明 |
|------|-------------|
| `-n, --limit <n>` | 表示するエントリ数 (デフォルト 10) |
| `-s, --service <name>` | 特定のサービスのイベントを表示 |

<span id="examples" />

## 例

<span id="show-deploy-history-and-replica-status" />

### デプロイ履歴とレプリカ状態を表示

```bash
lizard events
```

<span id="show-events-for-a-specific-service" />

### 特定のサービスのイベントを表示

```bash
lizard events --service api
```

<span id="show-more-entries" />

### より多くのエントリを表示

```bash
lizard events --limit 25
```
