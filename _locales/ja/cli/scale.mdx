# lizard scale

サービスをスケールします（レプリカ数 / CPU / メモリ / ストレージ）。

## Usage

```bash
lizard scale [flags]
```

## Flags

| Flag | Description |
|------|-------------|
| `--replicas <n>` | レプリカ数 `1`–`10`（アプリ） |
| `--cpu <cores>` | `1`、`2`、`3`、または `4` |
| `--memory <mb>` | `128`–`8192` MB |
| `--storage <mb>` | アドオンボリュームのサイズ、拡張のみ |

## Examples

<span id="scale-replicas-horizontally" />

### レプリカ数を水平方向にスケール

```bash
lizard scale --service api --replicas 5
```

各レプリカは、ロードバランサーの背後にある独立した pod です。レプリカを相互に置き換えられるように、アプリがステートレスであることを確認してください。

<span id="scale-cpu-and-memory-vertically" />

### CPU とメモリを垂直方向にスケール

```bash
lizard scale --service api --cpu 4 --memory 8192
```

<span id="grow-addon-storage" />

### アドオンストレージを拡張

```bash
lizard scale --service postgres --storage 8192
```

アドオンのデータボリュームは拡張のみです — ストレージは増やせますが、縮小はできません。
