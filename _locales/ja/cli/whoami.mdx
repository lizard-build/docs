# lizard whoami

現在のユーザー、アクティブなワークスペース、リンクされているプロジェクトを表示します。

<span id="usage" />

## 使い方

```bash
lizard whoami
```

<span id="examples" />

## 例

<span id="check-who-youre-logged-in-as" />

### 現在どのアカウントでログインしているかを確認する

```bash
lizard whoami
```
