# lizard whoami

ログイン中のアカウントを表示します。リンク済みのフォルダーでは、リンクされているプロジェクトとそのワークスペースも表示します。

<span id="usage" />

## 使い方

```bash
lizard whoami
```

<span id="what-it-shows" />

## 表示される内容

- アカウントでサインインしている場合: ユーザー名、GitHub App が接続されているかどうか、リンクされているプロジェクトとその後ろの括弧内のワークスペース。リンクされていないフォルダーでは `Project: none` と表示されます。そのフォルダーでのコマンドは、アカウントのデフォルトプロジェクトを使います。
- スコープ付き API キーでサインインしている場合: `Scoped API key (account details are not visible)` と、キーが届く各プロジェクトまたはワークスペース。キーの背後のアカウントは表示されません。

`whoami` はアクティブなワークスペースを表示しません。ワークスペースを一覧表示するには [`lizard workspace list`](/cli/workspace) を実行してください。

`--json` を付けた場合、または出力先がターミナルでない場合は、アカウントのフィールドと `project` を出力します。スコープ付きキーの場合は `{ "scoped": true, "scopes": [...], "project": ... }` を出力します。
