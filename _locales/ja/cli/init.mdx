# lizard init

プロジェクトを作成または選択し、現在のディレクトリにリンクします。

<span id="usage" />

## 使い方

```bash
lizard init [flags]
```

<span id="flags" />

## フラグ

| フラグ | 説明 |
|------|-------------|
| `-n, --name <name>` | プロジェクト名（存在しない場合は作成） |
| `-w, --workspace <ws>` | ワークスペースの id、slug、または名前 |
| `--force` | すでにリンクされていても再リンク |

<span id="examples" />

## 例

<span id="link-the-current-directory-interactively" />

### 現在のディレクトリを対話的にリンクする

```bash
lizard init
```

<span id="link-explicitly-in-ci" />

### CI で明示的にリンクする

`lizard up` は TTY では `init` を実行しますが、非 TTY（CI）環境では、暗黙にプロジェクトを作成せずにエラーになります。まず明示的にリンクしてください:

```bash
export LIZARD_TOKEN=lzd_xxx
lizard init --name my-project
lizard up --ci --service api
```

<span id="relink-a-directory-thats-already-linked" />

### すでにリンクされているディレクトリを再リンクする

```bash
lizard init --name my-project --force
```
