# lizard init

プロジェクトを作成または選択し、現在のディレクトリにリンクします。

<span id="usage" />

## 使い方

```bash
lizard init [flags]
```

<span id="flags" />

## フラグ

| フラグ | 説明 |
|------|-------------|
| `-n, --name <name>` | プロジェクト名（存在しない場合は作成） |
| `-w, --workspace <ws>` | ワークスペースの id、slug、または名前 |
| `--force` | すでにリンクされていても再リンク |

<span id="examples" />

## 例

<span id="link-the-current-directory-interactively" />

### 現在のディレクトリを対話的にリンクする

```bash
lizard init
```

`--name` を付けないと、`init` は使うプロジェクトを尋ねます。非対話のシェルでは代わりにエラーになるため、`--name` を渡してください。

<span id="link-explicitly-in-ci" />

### CI で明示的にリンクする

リンクされていないディレクトリで `lizard up` を実行すると、アカウントのデフォルトプロジェクトにデプロイします。CI で特定のプロジェクトにデプロイするには、まずリンクしてください:

```bash
export LIZARD_TOKEN=liz_xxx
lizard init --name my-project
lizard up --ci --service api   # creates api on the first run
```

<span id="relink-a-directory-thats-already-linked" />

### すでにリンクされているディレクトリを再リンクする

```bash
lizard init --name my-project --force
```
