# lizard ssh

> **無効化されています。** Lizard ではサービスへのシェルアクセスが無効になっています。`lizard ssh` は HTTP 403 `Shell access to services is disabled` を受け取り、終了コード `1` で終了します。

コマンド自体は引き続き CLI に含まれていますが、プラットフォームはすべてのサービスでこれを拒否します。代わりに次のコマンドを使ってください:

| 確認したい内容 | コマンド |
|----------|---------|
| 空の値に解決された参照 | `lizard logs --build --service api` (ビルドログは空の `${{…}}` 参照ごとに警告を出します) |
| サービスに保存されている値 | `lizard secrets list --service api --show` |
| アドオンの実際の接続値を使ったコマンド | `lizard run --service postgres -- <cmd>` |
| アプリが実行時に出力する内容 | `lizard logs --service api` |

サンドボックスでシェルを使うには、[`lizard sandbox ssh <id>`](/cli/sandbox#sandbox-ssh) を使ってください。こちらは引き続き使えます。

## 使用量

```bash
lizard ssh --service <name> -- <command>
```

| フラグ | 説明 |
|------|-------------|
| `-s, --service <id>` | サービス名または ID |
| `-p, --project <id>` | プロジェクト名、スラッグ、または ID |
