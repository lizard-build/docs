# アプリ クイックスタート

このクイックスタートでは、数分でアプリを Lizard (lizard.build) にデプロイします。Lizard CLI をインストールすると、インストーラーがサインインを行い、7 日間の Pro トライアルを案内します。その後、GitHub リポジトリなら `lizard add -r owner/repo`、ローカルフォルダなら `lizard up` を実行します。Lizard はローカルの Docker なしで自社のサーバー上でアプリをビルドし、`onlizard.com` 上の HTTPS URL を割り当てます。アカウントは、最初にサインインしたときに作成されます。

<span id="1-install-the-cli" />

## 1. CLI をインストールする

macOS または Linux では、インストールスクリプトを実行します:

```bash
curl -fsSL https://lizard.build/install.sh | bash
```

スクリプトは `lizard` バイナリを `~/.lizard/bin` に置き、`~/.zshrc` または `~/.bashrc` でそのフォルダを `PATH` に追加します。さらに、すでに `PATH` に含まれているフォルダに `lizard` をリンクするので、このターミナルですぐに使えます。以後、バイナリは自動で更新されます（CI を除く）。`lizard` が見つからない可能性があるとスクリプトに表示された場合は、新しいターミナルを開いてください。バージョンを確認します:

```bash
lizard --version
```

Windows では、PowerShell で次を実行します:

```powershell
irm https://lizard.build/api/cli/install.ps1 | iex
```

どちらのインストールスクリプトも最後に [`lizard login`](/cli/login) を実行し、手順 2 と 3 を代わりに行います。サインインを行い、Pro トライアルを案内します。スキップするには `LIZARD_NO_LOGIN=1` を設定してください。CI ではスクリプトが自動でスキップします。

**npm からインストールすることもできます**（Node.js 20 以降が必要です）。npm でインストールした場合はサインインされないので、手順 2 に進んでください:

```bash
npm install -g @lizard-build/cli
```

> **`npx` は使わないでください。** 必ずグローバルにインストールされた `lizard` バイナリを使ってください。`npx @lizard-build/cli` を実行すると、その場限りのコピーが取得され、バージョンがプラットフォームとずれる可能性があります。npm でインストールした場合、後でアップグレードするには `npm install -g @lizard-build/cli@latest` を実行してください。

> **権限エラー (EACCES)?** `sudo` は使わないでください。管理者権限が不要な上記のインストールスクリプトを使うか、npm の保存先をユーザー所有の prefix に向けてください:
> ```bash
> mkdir -p ~/.npm-global
> npm config set prefix ~/.npm-global
> echo 'export PATH=~/.npm-global/bin:$PATH' >> ~/.zshrc && source ~/.zshrc
> npm install -g @lizard-build/cli
> ```

<span id="2-log-in" />

## 2. ログインする

インストールスクリプトでサインイン済みなら、この手順は飛ばしてください。そうでなければ次を実行します:

```bash
lizard login
```

GitHub と Google のどちらでサインインするかを尋ね、そのページをブラウザで開いて、承認されるまで待ちます。すでにアカウントがある場合は、登録したときと同じ方法を選んでください。別の方法を選ぶと、確認済みのメールアドレスが共通でない限り、空の 2 つ目のアカウントが作成されます。`--github` または `--google` を付けると質問を省略できます。すでにサインイン済みのマシンでは、`lizard login` はアカウントを表示するだけなので、何度実行しても問題ありません。

`lizard login` を省略することもできます。ターミナルで実行したコマンドは、まず同じ方法でサインインを行ってから処理を続けます。

CI やその他の非対話環境では、代わりにトークンで認証します:

```bash
export LIZARD_TOKEN=liz_xxx
# or
lizard login --token liz_xxx
```

API キーは `liz_` で始まります。`lizard keys create <name>` で作成できます。`LIZARD_TOKEN` の代わりに `LIZARD_API_KEY` も使えます。`lizard login --token-stdin` はキーをパイプから読み取るので、シェルの履歴に残りません。

現在どのアカウントであるかはいつでも確認できます:

```bash
lizard whoami
```

<span id="3-start-the-pro-trial" />

## 3. Pro トライアルを開始する

新しいアカウントにはプランがなく、デプロイにはプランが必要です。サインインが済むと、`lizard login` が 7 日間の Pro トライアルを案内します。承諾すると Stripe Checkout が開くので、カードを登録します。トライアルには $5 分の利用枠が含まれ、終了まで何も請求されません。すでにトライアルを利用したアカウントには、代わりに月額 $19 の Pro が案内されます。

断った場合は、後から開始できます:

```bash
lizard billing start
```

プランが始まるまでは、何かを作成しようとすると、Checkout へのリンク付きで HTTP 402 が返ります。[請求](/platform/billing) と [`lizard billing`](/cli/billing) を参照してください。

<span id="4-deploy" />

## 4. デプロイする

コードがどこにあるかに応じて、該当する方法を選んでください。

<span id="option-a--deploy-a-github-repo-recommended" />

### オプション A — GitHub リポジトリをデプロイする（推奨）

コードが GitHub 上にある場合は、リポジトリから直接サービスを作成します。Lizard がそれをクローンし、スタックを検出して最初のビルドを開始します:

```bash
lizard add -r your-org/your-app
```

コマンドはサービスが作成された時点で終了し、ビルドはそのまま続きます。ビルドの確認方法と URL の調べ方は [手順 5](#5-watch-it-build-and-run) を参照してください。

プライベートリポジトリをデプロイする場合や、追跡ブランチへの push でアプリを再デプロイしたい場合は、先に [`lizard git`](/cli/git) で Lizard GitHub App を接続してください:

```bash
lizard git connect
```

<span id="option-b--deploy-local-code" />

### オプション B — ローカルコードをデプロイする

プロジェクトディレクトリ内から、現在のフォルダをアップロードしてデプロイします（`.gitignore` を尊重します）:

```bash
lizard up
```

初回はサービス名を尋ねます。デフォルトはフォルダ名です。その後ビルドを追跡し、アプリが稼働すると `https://your-app-x1y2z.onlizard.com` のような URL を表示します。

フォルダがまだプロジェクトにリンクされていない場合、`lizard add` と `lizard up` はデフォルトプロジェクトを使い、そのことを表示します。デフォルトプロジェクトとは個人ワークスペースで最も古いプロジェクトで、新しいアカウントには登録時に作成されます。`lizard up` はフォルダをそのプロジェクトにリンクするので、次の `lizard up` は同じサービスを更新します。別のプロジェクトにデプロイするには、先に `lizard init --name my-project` を実行してください。デプロイ先を確実にするため、CI でも同様にしてください。

Lizard はほとんどのスタックを自動で検出します。お使いのフレームワークの正確なビルドコマンド、start コマンド、ポートについては、[Next.js](/framework-guides/nextjs)、[React](/framework-guides/react)、[Vue](/framework-guides/vue)、[Astro](/framework-guides/astro)、[SvelteKit](/framework-guides/sveltekit)、[Node.js](/framework-guides/nodejs)、[Django](/framework-guides/django)、[FastAPI](/framework-guides/fastapi)、[Rails](/framework-guides/rails)、[Go](/framework-guides/go) のガイドを参照してください。独自の Dockerfile を持つアプリは [Dockerfile でデプロイする](/deploy/dockerfile) に従ってください。

<span id="5-watch-it-build-and-run" />

## 5. ビルドと実行を確認する

```bash
lizard ps               # services in the project, with status + URL
lizard logs             # stream runtime logs (Ctrl+C to stop)
lizard logs --tail 100  # print the last 100 lines and exit
lizard logs --build     # the most recent build's logs
lizard open             # open the project in the dashboard
```

[`lizard open`](/cli/open) は同じプロジェクトを [ダッシュボード](/dashboard) で表示します。メトリクス、コスト、デプロイ履歴については [可観測性](/observability) を参照してください。

<span id="6-add-a-database-optional" />

## 6. データベースを追加する（任意）

Managed Postgres をプロビジョニングします。プロジェクト内のすべてのサービスは、次回のデプロイ時にその公開 `DATABASE_URL` を受け取ります。プライベートネットワーク経由で接続するには、サービスから参照します:

```bash
lizard add postgres
lizard secrets set DATABASE_URL='${{postgres.DATABASE_PRIVATE_URL}}' --service your-app
lizard redeploy --service your-app
```

`${{postgres.DATABASE_PRIVATE_URL}}` 参照はデプロイ時に解決され、プロジェクトのプライベートネットワーク経由で接続します。参照は addon の現在の名前と照合されるため、addon の名前を変更した場合は参照を更新してください。認証情報が自動でローテーションされることはありません。サービスは次回のデプロイ時に新しい値を取り込みます。[Managed Addons](/addons) を参照してください。

## ホスティング費用

Pro は月額 $19 で、毎月 $19 分の利用が含まれます。Pro 5x（$99）と Pro 20x（$499）には料金と同じ額の利用分が含まれ、上限も上がります。それを超えた利用は、公開料金での pay as you go です。トライアルがあるのは Pro だけで、$5 分の利用が含まれる 7 日間です。開始するにはカードを登録します。[請求](/platform/billing)と[料金](https://lizard.build/pricing)を参照し、デプロイ前に[上限](/platform/limits)を確認してください。
