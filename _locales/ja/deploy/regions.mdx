# リージョン

サービスとアドオンはリージョンにプロビジョニングされます。アカウントで利用可能なリージョンを一覧し、作成時に 1 つ選択します。

<span id="list-regions" />

## リージョンを一覧する

```bash
lizard regions
lizard regions --json
```

<span id="choose-a-region" />

## リージョンを選ぶ

サービスまたはアドオンの作成時に `--region <code>` を渡します:

```bash
lizard add -r your-org/your-app --region <code>
lizard add postgres --region <code>
lizard up --region <code>          # new services only
```

プロジェクトにはデフォルトのリージョンがありません。`--region` を指定しない場合、`lizard add` は `us-east-1` に作成し、`lizard up` はリクエストを処理した API サーバーのリージョンに新しいサービスを作成します。リージョンを選ぶには `--region` を渡してください。

> **ステートフルなリソースは同じ場所に配置してください。** サービスと、それが通信するアドオン（Managed Postgres、Managed Redis、Managed Object Storage）は、レイテンシを低く保ち、リージョン間のデータ転送料金を避けるために、**同じリージョン** に配置してください。

<span id="generated-domains" />

## 生成ドメイン

各サービスには、自動 TLS 付きの生成ドメインが割り当てられます。新しいサービスは `<name>-<suffix>.onlizard.com`、古いサービスは `<words>.<region>.onlizard.com` のままです。[Managed Object Storage](/addons/storage) はリージョンごとのゲートウェイホストを使用します。`us-east-1` では `s3-us-east-1.onlizard.com`、`eu-west-lim-a` では `s3-eu-west-1.onlizard.com` です。独自のホスト名を接続するには、[Networking](/networking) を参照してください。
