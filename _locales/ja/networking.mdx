# ネットワーキング

すべてのサービスは、リージョンに関係なく、デプロイされた瞬間に自動 TLS 付きの生成済み `*.onlizard.com` ドメインを取得します。本番公開の準備ができたら、独自のホスト名を追加してください。

<span id="generated-domains" />

## 生成されるドメイン

サービスのデフォルトドメインは `<name>-<suffix>.onlizard.com` の形式で自動的に作成されます。古いサービスでは `<words>.<region>.onlizard.com` のままです。表示するには:

```bash
lizard domain                    # show the service's current domain
lizard domain generate           # claim a *.onlizard.com subdomain if the service has none
```

`lizard domain generate` は、生成済みのドメインがあればそれを返し、サービスにカスタムドメインがある間は失敗します。[Managed Object Storage](/addons/storage) から提供されるファイルは、代わりにゲートウェイホスト `s3-eu-west-1.onlizard.com` または `s3-us-east-1.onlizard.com` を使用します。

<span id="attach-a-custom-domain" />

## カスタムドメインを追加する

ホスト名は**位置引数**です。`add` サブコマンドはありません:

```bash
lizard domain app.example.com --service web
```

Lizard は、作成すべき DNS レコード（ホスト名用の `CNAME` と、検証用の `TXT` レコード）を返します。これらを DNS プロバイダーで追加してください。

<span id="verify" />

## 検証

DNS の伝播が完了したら、ドメインを有効化します:

```bash
lizard domain verify app.example.com --service web
```

これにより `TXT` レコードが確認され、ドメインが有効化されます。TLS は自動的にプロビジョニングされます。

<span id="remove-a-domain" />

## ドメインを削除する

```bash
lizard domain delete app.example.com --service web
lizard domain rm app.example.com --service web --yes   # alias, skip confirmation
```

<span id="change-the-port-your-service-listens-on" />

## サービスが listen するポートを変更する

ドメインはサービスのコンテナポートにルーティングされます。サービスが別のポートで listen している場合は、コンテナポートを変更して再デプロイします:

```bash
lizard port 8080 --service web
lizard redeploy --service web
```

<span id="worker-services" />

## Worker サービス

[workerモードのサービス](/deploy/workers)（`containerPort=0`）では、生成されたドメインが表示されることがありますが、何も提供されません。リスナーもロードバランサーのルートもないためです。worker にカスタムドメインを追加しないでください。

<span id="private-networking" />

## プライベートネットワーク

同じプロジェクト内のサービスは、公開ドメインなしで `<service>.lizard.internal` を使って互いに接続でき、そのサービスが listen している任意のポートを使えます。ホスト名は `${{api.LIZARD_PRIVATE_DOMAIN}}` として参照します。Managed Postgres と Managed Redis は、同じネットワーク上で `DATABASE_PRIVATE_URL` と `REDIS_PRIVATE_URL` を公開します。これらの名前はプロジェクト内でのみ解決されます。

```bash
lizard secrets set API_URL='http://${{api.LIZARD_PRIVATE_DOMAIN}}:8080' --service web
```

<span id="manage-in-the-dashboard" />

## ダッシュボードで管理する

ダッシュボード（`lizard open`）でサービスを開き、**Settings → Networking** に移動します。各ドメインの検証状態と DNS 状態を確認でき、ホスト名の追加や削除も行えます。
