# アプリダッシュボード

LizardダッシュボードはLizard CLIのビジュアルな補完機能です。`lizard …` で行うことはすべてここにも反映され、さらに UI のほうが簡単なもの — ストリーミングログ、チャート、データブラウザー、Sandboxes、チーム/請求管理 — も利用できます。

端末をまったく開きたくない場合は、エージェントにコマンドを実行させて、ここで結果を確認してください — [Antigravity アプリを本番環境にデプロイする](https://lizard.build/blog/google-antigravity-how-to-deploy-your-app-to-production#deploy-from-the-antigravity-chat) の手順では、1 つのプロンプトでデプロイを進められます。

CLI から開く:

```bash
lizard open          # open the current project
lizard docs          # open this documentation
```

<span id="whats-in-the-dashboard" />

## ダッシュボードにあるもの

<span id="services" />

### サービス

サイドバーの **アプリとデータベース** には、すべてのサービスがステータスバッジ、生成されたドメイン、ログ・メトリクス・シークレット・設定へのクイックアクセスとともに一覧表示されます。サービスは **新しいサービス** から作成します。GitHub リポジトリから、コンピューター上のフォルダから、またはデータベース（Managed Postgres、Managed Redis）や Managed Object Storage として作成できます。

サービスの **設定** タブには、アイドル時にスリープさせる **Serverless**（[`lizard sleep`](/cli/sleep)）と、何も削除せずに停止する **一時停止**（[`lizard pause`](/cli/pause)）もあります。

<span id="deployments" />

### デプロイ

各サービスの **概要** タブにデプロイの一覧が表示されます。1 つを開くと、ステータス、トリガー、ソース、ビルドログ、再起動を確認できます。これは `lizard events` + `lizard logs --build` に相当するビジュアル版です。

<span id="logs" />

### ログ

検索とレベルフィルターに対応した、ランタイムログとビルドログのライブストリーミング — [`lizard logs`](/observability/logs) に対応する UI です。

<span id="metrics--usage" />

### メトリクスと使用状況

サービスごとの CPU、メモリ、ネットワーク、ディスクのチャートに加え、プロジェクト全体の消費量とコストを内訳表示する **使用状況** ページがあります。[`lizard metrics --cost`](/observability/metrics) に対応します。

<span id="variables--secrets" />

### 変数 & Secrets

サービススコープのシークレットは各サービスの **シークレット** タブで、プロジェクトスコープのシークレットは **グローバルシークレット** で管理できます。値はマスクされ、参照（`${{…}}`）も使えます。[変数 & Secrets](/variables) を参照してください。

<span id="domains" />

### ドメイン

サービスの **設定** タブで、カスタムドメインの追加、DNS レコードの表示、検証と TLS ステータスの追跡ができます。[Networking](/networking) を参照してください。

<span id="data-browsers" />

### データブラウザー

各 managed addon にはデータブラウザーが付属しています:

- **Managed Postgres** — データのクエリと編集ができる SQL/テーブルエディター。
- **Managed Redis** — キー/バリューブラウザー。
- **Managed Object Storage** — アップロード/ダウンロードとバケットのアクセス設定に対応したバケット/オブジェクトブラウザー。

<span id="sandboxes" />

### Sandboxes

サイドバーには **Sandboxes**、**ボリューム**（Persistent Volumes）、**テンプレート**、**エージェント** があります。sandbox は Sandboxes ページの **新しいサンドボックス** で作成します。その横には、使用中の vCPU と vCPU の上限が表示されます。トライアル中、このダイアログでは US リージョンの Small サイズだけを選べます。[Sandboxes クイックスタート](/sandboxes/quickstart) を参照してください。

<span id="github-integration" />

### GitHub 連携

GitHub は **新しいサービス → GitHub リポジトリ** から接続します。接続後は、リポジトリ一覧の下にある **アクセスを設定** から GitHub App の設定を開き、Lizard がビルドできるリポジトリを選べます。公開リポジトリは、接続しなくても URL を貼り付けてデプロイできます。[GitHubからデプロイする](/deploy/github) を参照してください。

<span id="settings-team--billing" />

### 設定、チーム、請求

サイドバー下部の **設定** には、プロジェクトとワークスペースの設定、メンバー招待とロール（**チーム**）、アカウント設定があります。**請求** は、アカウント設定から、またはダッシュボード上部のプランをクリックして開きます。プラン、トライアル、現在の期間の使用量、請求書、カードが表示されます。[請求](/platform/billing)を参照してください。

<span id="cli--dashboard" />

## CLI ↔ ダッシュボード

| タスク | CLI | ダッシュボードビュー |
|------|-----|----------------|
| デプロイ履歴 | `lizard events` | サービス → 概要 |
| ログをストリーミング | `lizard logs` | ログ |
| リソースチャート | `lizard metrics` | メトリクス / 使用状況 |
| シークレットを管理 | `lizard secrets` | シークレット / グローバルシークレット |
| カスタムドメイン | `lizard domain` | サービス → 設定 |
| サービスの一時停止と再開 | `lizard pause` / `lizard resume` | サービス → 設定 |
| アイドル時にスリープ | `lizard sleep` | サービス → 設定 → Serverless |
| Managed Postgres、Managed Redis、Managed Object Storage にクエリする | `lizard run --service <addon> -- <cmd>` | データブラウザー |
| チームメンバーを招待 | — | 設定 → チーム |

そのときに合うほうを使ってください — どちらも同じプロジェクトとサービスを操作します。
