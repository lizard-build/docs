# Events & History

`lizard events` は、サービスのデプロイ履歴とレプリカのライブステータス、つまりデプロイされた内容と現在実行中のもののタイムラインを表示します。

<span id="view-events" />

## イベントを表示する

```bash
lizard events                     # deploy history + replica status
lizard events --service api       # a specific service
lizard events --limit 5           # fewer entries (default and maximum 10)
```

各エントリは 1 回のデプロイで、ステータス、トリガー、コミット、再起動回数を示します。その下の Replicas テーブルには各 Pod の現在の状態が表示されるため、"何が変わったのか、そして正常か？" をひと目で確認できます。

<span id="quick-status" />

## クイックステータス

プロジェクト内のすべてのサービスのスナップショットをすばやく確認するには — ステータスと URL を含めて — 次を使用します:

```bash
lizard ps
lizard status        # the current directory's workspace/project/service link
```

<span id="dashboard" />

## ダッシュボード

ダッシュボード（`lizard open`）でサービスを開くと、そのデプロイ履歴を確認できます。デプロイをクリックすると、ビルドログ、コミット、クラッシュイベントが表示されます。サービスパネルには、稼働中のレプリカ数と目標のレプリカ数が表示されます。
