# 請求

Lizard (lizard.build) のセルフサービス向けプランは 3 つあります。月額 $19 の Pro、$99 の Pro 5x、$499 の Pro 20x です。どのプランにも、毎月料金と同じ額の利用分が含まれます。この利用分はプラットフォーム全体で使えます。対象はアプリ、Sandboxes、Managed Postgres、Managed Redis、Managed Object Storage、Persistent Volumes、送信トラフィックです。それを超えた分は、公開料金での pay as you go になります。上位のプランでは[上限](#limits)も上がります。

プラン、カード、請求書は **請求** ページで管理します。サイドバーまたはアカウントメニューから **設定** を開き、**アカウント** の下の **請求** を選びます。[`lizard billing`](/cli/billing) も使えます。プランはワークスペースの所有者に属します。あなたが所有するすべてのワークスペースの利用があなたのプランに計上され、メンバーを追加してもシート料金はかかりません。

<span id="plans" />

## プラン

| | Pro | Pro 5x | Pro 20x |
| --- | --- | --- | --- |
| 料金 | 月額 $19 | 月額 $99 | 月額 $499 |
| 含まれる利用分 | 毎月 $19 | 毎月 $99 | 毎月 $499 |
| それを超えた利用 | [リソース料金](#resource-rates)での pay as you go | 同じ | 同じ |
| 同時に実行できる Sandboxes | 40 vCPU | 220 vCPU | 1,200 vCPU |
| トライアル | 7 日間、$5 分の利用付き | なし、初日から有料 | なし、初日から有料 |
| 支払い方法 | カード、毎月請求 | カード、毎月請求 | カード、毎月請求 |

料金は税込みです。含まれる利用分はプラットフォーム全体で使えます。どのプランも解約するまで毎月更新されます。使わなかった利用分は翌月に繰り越されません。

Pro 5x や Pro 20x を始めるには、請求ページで選びます。Lizard はその日に全額を請求します。プランを切り替えるときは、[プランの変更](#changing-plans)を参照してください。

<span id="included-usage-and-overage" />

## 含まれる利用分と超過分

毎月、プランの料金と同じ額の利用分が含まれます。Pro は $19、Pro 5x は $99、Pro 20x は $499 です。それを超えた利用は超過分となり、同じ料金で請求されます。

Lizard は超過分を月末にまとめてではなく、たまるたびに請求します。未請求の超過分が $20 に達すると、Lizard はカードに請求します。請求が支払われるたびに次の段階が上がり、$100、$200、$400、$1,000 と進み、その後は $1,000 ずつになります。段階は毎月 $20 に戻ります。月末には、まだ請求していない超過分を 1 通の最終請求書にまとめます。支出の上限はありません。

請求ページには、含まれる利用分のうち今月どれだけ使ったか、現時点の超過分、次回の請求が表示されます。

<span id="resource-rates" />

## リソース料金

価格は米ドルです。

| リソース | 料金 |
| --- | ---: |
| CPU | vCPU秒あたり $0.000006948 |
| メモリ | GB秒あたり $0.000003474 |
| Persistent Volumes | GB秒あたり $0.000000054 |
| Managed Object Storage | GB月あたり $0.0135 |
| 送信トラフィック | GBあたり $0.045、最初の1バイトから |

受信トラフィックは無料です。アプリ、Managed Postgres、Managed Redis にはこの料金が適用されます。Sandboxes にはサイズごとに 1 時間あたりの固定料金があります。[Sandboxes のサイズ](/platform/limits#sandbox-sizes)を参照してください。

たとえば、1 vCPU と 1 GB のメモリを 1 時間使うと、コンピュート料金は $0.0375192 です。ストレージと送信トラフィックの料金が加わる場合があります。提供内容の全体は[料金](https://lizard.build/pricing)ページを参照してください。

<span id="trial" />

## トライアル

新しいアカウントでは画面を見て回れますが、アプリ、Sandboxes、データベース、ボリュームを作成するにはプランが必要です。トライアルがあるのは Pro だけです。Pro は $5 分の利用が含まれる 7 日間のトライアルから始まります。開始するにはカードを登録します。Apple Pay も使えます。トライアル開始時には何も請求されません。トライアルが終わると、その前に解約しない限り、月額 $19 の Pro が始まります。

トライアルは 1 つのアカウントにつき 1 回、1 枚のカードにつき 1 回です。アカウントで以前にトライアルを使ったことがある場合、Pro はすぐに始まり、その日に $19 が請求されます。カードで以前にトライアルを使ったことがある場合、トライアルは始まらず、何も請求されません。請求ページから月額 $19 の Pro を開始してください。

トライアルでは Pro のすべての機能を使えますが、最初の請求書の支払いまでは[上限](#limits)が低くなります。それまでの間、Sandboxes はダッシュボード、Lizard CLI、Lizard SDK、Lizard MCP のどれから作成しても、US リージョンの Small サイズでしか動かず、同時に実行できるのは Small 4 個（8 vCPU）までです。サイズを指定しない作成は Small になります。Medium の sandbox を名前で指定したとき、またはスナップショットや fork から作ったときは HTTP 403 が返り、`code` は `TRIAL_SANDBOX_SIZE` になります。Large の sandbox を作成、再開、fork、復元したときは、どれも HTTP 403 が返り、`code` は `SANDBOX_SIZE_NOT_ALLOWED` になります。US 以外のリージョンを指定すると HTTP 403 が返り、`code` は `TRIAL_SANDBOX_REGION` になります。**Start Pro now** で他のサイズとリージョンが使えるようになり、Pro の上限が適用されます。

トライアル中に Pro 5x や Pro 20x に移るには、まず **Start Pro now** を選び、そのあと[プランを変更](#changing-plans)します。

<span id="when-trial-usage-runs-out" />

### トライアルの利用分を使い切ったとき

- トライアルの利用分を使い切ると、実行中のリソースが一時停止し、新しいリソースを作成できなくなります。データは保持されます。[請求による一時停止で残るもの](#what-a-billing-pause-keeps)を参照してください。
- 続けるには、請求ページで **Start Pro now** を選ぶか、`lizard billing start-now` を実行します。トライアルが終わり、$19 が請求され、$19 分の利用付きで最初の有料月が始まります。一時停止していたアプリとデータベースは、支払いが完了すると再び起動します。

使わなかったトライアルの利用分はトライアルとともに失効し、有料月には移りません。

<span id="promo-codes" />

## プロモコード

プロモコードを使うと、最長 730 日の長いトライアルと、より多くのトライアル利用分を受け取れる場合があります。コードは標準の 7 日間と $5 に置き換わります。コードは請求ページか `lizard billing promo <code>` で利用します。

- トライアル開始前なら、Lizard がコードを保存し、カードを登録したときに適用します。
- トライアル中なら、期間と利用分がコードの内容まで引き上げられます。今ある分に加算されるわけではありません。
- コードは最初の支払いの前にのみ使えます。
- コードは 1 つのアカウントにつき 1 つ、1 枚のカードにつき 1 つです。

<span id="limits" />

## 上限

| | トライアル（最初の請求書の支払いまで） | Pro | Pro 5x | Pro 20x |
| --- | ---: | ---: | ---: | ---: |
| 同時に実行できる Sandboxes | 8 vCPU（Small 4 個まで） | 40 vCPU | 220 vCPU | 1,200 vCPU |
| Sandboxes のサイズ | Small のみ（2 vCPU） | Large まで（8 vCPU） | Large まで（8 vCPU） | Large まで（8 vCPU） |
| Sandboxes の 1 分あたりの起動数 | 6 | 24 | 60 | 120 |
| アプリあたりのレプリカ数 | 1 | 5 | 5 | 5 |

Sandboxes の上限は、sandbox の数ではなく、実行中の sandbox の vCPU で数えます。Small は 2 vCPU、Medium は 4、Large は 8 を使うため、40 vCPU では Small 20 個、Medium 10 個、Large 5 個のいずれかを同時に実行できます。トライアルの 8 vCPU では Small を 4 個まで実行できます。Pro の上限は最初の請求書の支払いから適用されます。**Start Pro now** による支払いも含みます。Pro 5x と Pro 20x は初日から有料なので、上限もすぐに適用されます。1 時間あたりと 1 日あたりの起動レートや、その他の上限は[制限](/platform/limits#sandbox-account-limits)を参照してください。

<span id="changing-plans" />

## プランの変更

Pro、Pro 5x、Pro 20x の切り替えは請求ページで行います。

- **アップグレード:** 料金が高いプランへの変更はすぐに始まります。Lizard は今月の残りの期間について差額を日割りで請求し、同じ額を今月の含まれる利用分に加えます。新しい上限もすぐに適用されます。たとえば、月の半ばに Pro から Pro 5x に移ると、約 $40 が請求され、含まれる利用分が約 $40 増えます。
- **ダウングレード:** 料金が低いプランへの変更は翌月から始まります。それまでは今のプランが続き、含まれる利用分と上限も今のままです。請求ページには次に始まるプランが表示されます。ダウングレードを取り消すには、今のプランをもう一度選びます。新しい上限が始まったときに実行中の sandbox がその上限より多くの vCPU を使っていても、sandbox は動き続けます。ただし、新しい上限に収まるまで、Lizard は新しい起動と再開を受け付けません。
- トライアル中はプランを変更できません。まず Start Pro now を選んでください。
- 未払いの請求書がある間はプランを変更できません。先に支払ってください。

アップグレードの支払いについて銀行から確認を求められた場合は、請求ページに、確認するための請求書ページへのリンクが表示されます。

<span id="payment-failures" />

## 支払いに失敗した場合

毎月のプラン料金でも、アップグレードでも、超過分の請求でも、支払いに失敗すると次のようになります。

- 失敗した時点から、新しいリソースを作成できなくなります。
- 実行中のリソースは 72 時間動いたあと、一時停止します。
- 一時停止したリソースのデータは保持されます。[請求による一時停止で残るもの](#what-a-billing-pause-keeps)を参照してください。

請求ページで未払いの請求書を支払ってください。支払いが済むと、Lizard は制限を解除し、一時停止していたアプリとデータベースを再び起動します。一時停止した Sandboxes はご自身で再開してください。Stripe は失敗した請求を再試行します。最後の再試行も失敗すると、プランは終了します。

<span id="cancelling" />

## 解約

解約はいつでも、請求ページ、Stripe のカスタマーポータル、または `lizard billing cancel` で行えます。プランは今月またはトライアルの終わりまで有効です。その日までの超過分は最終請求書に含まれます。トライアル中の解約に費用はかかりません。

終了日までなら、請求ページか `lizard billing resume` で解約を取り消せます。

プランが終了すると、リソースを作成できなくなり、実行中のリソースは一時停止します。データは下記のとおり保持されます。再び使うには、請求ページでプランを開始してください。2 回目のトライアルはないため、Pro はすぐに $19 で始まります。

<span id="what-a-billing-pause-keeps" />

## 請求による一時停止で残るもの

アプリとデータベースは、一時停止中もデータを保持します。実行中のサンドボックスは、ファイルとメモリを保ったまま一時停止します。その時点で一時停止できないサンドボックスや、クラッシュしたサンドボックスは、ファイルごと削除されます。必要なファイルは [Persistent Volume](/sandboxes/volumes) に保存してください。

<span id="enterprise" />

## Enterprise

Enterprise アカウントは pay as you go で、毎月、前月分の請求書を受け取ります。料金、上限、支払い条件は契約に従います。Pro 20x の上限を超える規模が必要な場合は、[料金](https://lizard.build/pricing)ページから Enterprise についてお問い合わせください。

<span id="idle-apps-and-stored-data" />

## アイドル状態のアプリと保存データ

アプリはリクエストがなくてもメモリと CPU を使うことがあります。コンピュートの利用を止めるには、アプリを[一時停止](/cli/pause)するか、アイドル時に[スリープ](/cli/sleep)させて次のリクエストで起動するようにします。Persistent Volumes と Managed Object Storage は、データを保存している間は料金がかかります。アプリを一時停止していても同じです。

データを削除する前に[ストレージと復旧](/platform/storage-and-recovery)を確認してください。設定した上限と実際の利用量の比較には[メトリクス](/observability/metrics)を参照してください。
