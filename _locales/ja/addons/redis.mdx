# Managed Redis

Lizard (lizard.build) の Managed Redis は、キャッシュ、キュー、レート制限、pub/sub のための Redis サーバーです。新しいインスタンスはデフォルトで Redis 8 で動作します。`lizard add redis` で追加すると、サービスは `${{redis.REDIS_PRIVATE_URL}}` のような参照を通じて `REDIS_PRIVATE_URL` または `REDIS_URL` を読み取ります。エビクションポリシーも追記専用ファイルもないため、再構築できるデータだけを保存してください。概要と料金については、[Managed Redis のページ](https://lizard.build/redis) を参照してください。

<span id="provision" />

## プロビジョニング

```bash
lizard add redis
```

最初の Redis アドオンの名前は `redis` なので、`${{redis.REDIS_URL}}` はすぐに使えます。

<span id="environment-variables" />

## 環境変数

| 変数 | 説明 |
|----------|-------------|
| `REDIS_URL` | パブリックエンドポイント経由の完全な接続文字列 (`redis://…`) |
| `REDIS_PRIVATE_URL` | プロジェクトのプライベートネットワーク経由の接続文字列 (`<name>.lizard.internal:6379`) |

どちらの文字列も `redis://default:<password>@<host>:<port>` という形式です。プライベートな文字列は、同じプロジェクト内のサービスからのみ使えます。[プライベートネットワーク](/networking#private-networking) を参照してください。

<span id="connect-a-service" />

## サービスを接続する

```bash
lizard secrets set REDIS_URL='${{redis.REDIS_PRIVATE_URL}}' --service api
lizard redeploy --service api
```

参照はデプロイ時に解決されます。利用側のサービスは、次のデプロイでアドオンの現在の値を取得します。プロジェクト外のクライアントには `REDIS_URL` を使ってください。プロジェクト内のすべてのサービスには、アドオンのパブリックな `REDIS_URL` も最も低い優先度で渡されます。明示的な参照はこれを上書きします。

<span id="does-managed-redis-keep-data" />

## Managed Redis はデータを保持しますか?

すべての書き込みが保持されるわけではありません。Managed Redis にはエビクションポリシーも追記専用ファイル (AOF) もありません。メモリが不足するとインスタンスが再起動し、直近の書き込みが失われることがあります。再構築できるデータに使い、失えないデータは [Managed Postgres](/addons/postgres) に保存してください。

<span id="common-uses" />

## 一般的な用途

- **キャッシュ**：リクエストをキーにして計算結果を保存します。
- **キュー / ワーカー**：Redis を、ジョブを消費する [workerモードのサービス](/deploy/workers) と組み合わせます。redis-worker サンプルの手順は [キューコンシューマーを実行する](/deploy/workers#run-a-queue-consumer) で説明しています。
- **レート制限 / セッション**：[replicas](/deploy/scaling) 間で高速に共有状態を扱います。

```bash
# A worker that drains a Redis queue
lizard add -r your-org/worker -n jobs --no-deploy
lizard service set jobs --set containerPort=0
lizard secrets set REDIS_URL='${{redis.REDIS_PRIVATE_URL}}' --service jobs
lizard redeploy --service jobs
```

<span id="browse-keys" />

## キーを参照する

ダッシュボードの **Redis browser** (`lizard open`) を開いて、キーと値を確認します。アドオンの接続値を使ってローカルからアクセスするには:

```bash
lizard run --service redis -- sh -c 'exec redis-cli -u "$REDIS_URL"'
```

<span id="grow-storage" />

## ストレージを拡張する

```bash
lizard scale --service redis --storage 4096
```
