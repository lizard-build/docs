# Lizard ドキュメント

<span id="what-is-lizard" />

## Lizard とは?

Lizard (lizard.build) は、AI エージェント向けのクラウドサンドボックスプラットフォームです。Lizard Sandboxes は、それぞれ独自のカーネルを持つ Firecracker microVM です。エージェントはその中でコードやシェルコマンドを実行し、デスクトップとブラウザを使い、ポートにプライベートな HTTPS URL を開き、Persistent Volumes にファイルを保存します。サンドボックスは、コードからは TypeScript または Python 向けの Lizard SDK で、ターミナルからは Lizard CLI で作成します。エージェントが何かを作ったら、同じプラットフォームでデプロイできます。`lizard up` は現在のフォルダをアップロードし、`lizard add -r owner/repo` は GitHub リポジトリをデプロイします。Lizard は自社のサーバーでイメージをビルドし、各 Web サービスに `onlizard.com` 上の HTTPS アドレスを割り当てます。同じ CLI で Managed Postgres、Managed Redis、S3 互換の Managed Object Storage を追加し、`${{postgres.DATABASE_URL}}` のような参照でサービスに接続します。Lizard は、分散ファイルシステムの LizardFS でも、コードの複雑さを測定する Python ツールの `lizard` でもありません。

## サンドボックスでコードを実行する

ダッシュボードで API キーとプロジェクトを作成し、`LIZARD_API_KEY` を設定して Lizard SDK をインストールします。次のコードはサンドボックスを作成し、コマンドを実行して、サンドボックスを削除します:

```bash
npm install @lizard-build/sdk
```

```ts
import { Lizard } from '@lizard-build/sdk'

const lizard = new Lizard({ project: 'my-project' })
const sandbox = await lizard.create('interpreter', { size: 'small' })

try {
  const run = await sandbox.process.exec("python -c 'print(2 ** 10)'")
  console.log(run.stdout) // 1024
} finally {
  await sandbox.kill()
}
```

Small サイズ（2 vCPU、4 GB RAM）は 1 時間 $0.0162 で、秒単位で課金されます。Python、テンプレート、有効期間については [Sandboxes クイックスタート](/sandboxes/quickstart) と [Sandboxes の概要](/sandboxes) を参照してください。

## アプリをデプロイする

Lizard CLI をインストールします。インストーラーがサインインを行い、7 日間の Pro トライアルを案内します。Stripe Checkout でカードを登録し、トライアル中は何も請求されません。その後、アクセス可能なリポジトリをデプロイします:

```bash
curl -fsSL https://lizard.build/install.sh | bash   # then signs you in and offers the trial
lizard add -r your-org/your-app
```

Windows の場合や npm を使う場合は、[その他のインストール方法](/getting-started#1-install-the-cli) を参照してください。

Lizard はサーバー上でイメージをビルドするため、この方法ではローカルの Docker は不要です。[lizardpack](/concepts/build-pipeline) がサポート対象のプロジェクトを検出します。特別なビルド要件があるプロジェクトでは、明示的なコマンドまたは Dockerfile を使用できます。ビルドログを確認し、デプロイ後にアプリケーション URL を検証してください。

## リソースを理解する

**workspace** はメンバーとプロジェクトをまとめる単位です。**project** はサービス、データベース、Sandboxes をまとめる単位です。各アカウントにはデフォルトプロジェクト（新しいアカウントでは `<username>'s Project`）があり、リンクしていないフォルダでは Lizard CLI がこれを使います。**service** はアプリケーションまたはワーカーを実行します。Managed Postgres、Managed Redis、Managed Object Storage は、アプリケーションが環境参照を通じて接続するデータサービスを提供します。

アプリと Sandboxes では、ランタイムとストレージのルールが異なります。リソースのサイズ、有効期間、またはデータ保持に依存する前に、[limits](/platform/limits) と [ストレージとリカバリ](/platform/storage-and-recovery) を確認してください。
