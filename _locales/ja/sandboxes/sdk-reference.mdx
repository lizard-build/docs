Lizard SDK をインストールし、Settings → API keys で API キーを作成します。`LIZARD_API_KEY` に保存してください。各 sandbox にはプロジェクトが必要です。`projectId`（Python では `project_id`）、または `project` に ID、slug、名前を渡します。

## 作成オプション

| TypeScript | Python |
|---|---|
| `projectId / project` | `project_id / project` |
| `timeoutMs` | `timeout_ms` |
| `region` | `region` |
| `volumeName / volumeId` | `volume_name / volume_id` |
| `size` | `size` |
| `snapshotId` | `snapshot_id` |
| `envs` | `envs` |
| `metadata` | `metadata` |
| `lizardToken` | `lizard_token` |
| `apiKey` | `api_key` |

現在のカタログからテンプレートを選びます: `base`、`interpreter`、`codex`、`claude`、`opencode`、`pi`、`prime`、`desktop`。利用可否はリージョンとプールの空き容量によって変わります。`interpreter` には Python と一般的なデータ処理ライブラリが含まれます。`desktop` はグラフィカルなデスクトップを実行し、`sandbox.desktop` または `lizard sandbox desktop` で操作します。ツールのバージョンは sandbox 内で確認してください。公開 CLI には独自テンプレートのアップロード機能はありません。

SDK と CLI の既定の有効期間は 5 分です。API の直接呼び出しとダッシュボードでは、既定で期限を設けません。有効期間を明示してください。作成時の `timeoutMs: 0` は期限を無効にし、正の値は期限を設定します。`setTimeout` は 1000～2147483647 ミリ秒を受け付け、0 は指定できません。コマンド実行で期限は延長されません。アイドル時間のタイマーではありません。

## メソッド

| API (TypeScript) | メソッド |
|---|---|
| `Sandbox.create(template, options)` | カタログのテンプレートからプロジェクト内に作成。 |
| `Sandbox.connect(sandboxId)` | 既存の sandbox に接続。自動再開はしません。 |
| `Sandbox.list()` | アクセスできる Sandboxes を一覧表示。状態を確認してください。 |
| `sandbox.getInfo()` | 状態とメタデータを取得。 |
| `sandbox.process.exec(cmd)` | シェルコマンドを実行し、stdout、stderr、exitCode を返す。 |
| `sandbox.fs.write(path, data)` | テキストまたはバイトを書き込み、親ディレクトリを作成。 |
| `sandbox.fs.read(path)` | UTF-8 テキストを読み取る。 |
| `sandbox.fs.readBytes(path)` | ファイルのバイトを読み取る。 |
| `sandbox.fs.list(path)` | ディレクトリの項目を一覧表示。 |
| `sandbox.fs.makeDir(path)` | ディレクトリと不足する親を作成。 |
| `sandbox.fs.remove(path)` | ファイルまたはディレクトリを削除。 |
| `sandbox.exposePort(port)` | ポートを公開し、`url`、`hostname`、`accessToken` を返す。 |
| `sandbox.getHost(port)` | ポートを公開してホスト名を返す。リクエストには `sandbox.accessToken` が必要。 |
| `sandbox.setTimeout(ms)` | 残りの有効期間を設定。最小 1000 ミリ秒。 |
| `sandbox.pause()` / `sandbox.resume()` | 一時停止または再開をキューに入れ、すぐに戻る。 |
| `sandbox.waitForStatus(status)` | `paused` または `running` を待つ。一時停止に失敗した場合はエラーを投げる。 |
| `sandbox.fork({ count })` | 実行中の sandbox を、メモリとプロセスを含めてコピー。 |
| `sandbox.snapshot(name, { poolSize })` | メモリと `/workspace` のファイルを非公開スナップショットとして保存。 |
| `Sandbox.waitForSnapshot(snapshotId)` | スナップショットの準備完了を待つ。 |
| `Sandbox.restore(snapshotId)` | 待機中のコピーから新しい sandbox を起動。 |
| `sandbox.kill()` | sandbox を停止し、ボリュームを切り離す。 |

Python: `exec_`, `get_info`, `expose_port`, `get_host`, `access_token`, `set_timeout`, `sandbox_id`, `read_bytes`, `make_dir`, `wait_for_status`, `wait_for_snapshot`, `pool_size`.

## 現在のランタイムの制限

コマンドの結果には stdout、stderr、終了コードが含まれます。タイムアウトは 1～600 秒です。`process.exec` は `envs`、`workdir`、`user` を受け付けます。作成時の `envs` は、Firecracker の sandbox ではすべてのコマンドに渡されます。pod の sandbox では無視されるため、コマンドごとに渡してください。`getInfo()` と `list()` は作成時の `metadata` を返します。

`fs.write` はテキストまたはバイトを書き込み、`fs.read` はテキストを読み取ります。バイナリファイルはバイトとして書き込み、`fs.readBytes`（Python では `read_bytes`）で読み戻します。

`size` (`'small'`、`'medium'`、`'large'`) で 2 vCPU / 4 GB、4 vCPU / 8 GB (既定)、8 vCPU / 16 GB を選べます。[サイズと料金](/platform/limits#sandbox-sizes)を参照してください。スナップショットから復元した sandbox には `size` は適用されず、元の sandbox のサイズで動作します。必要に応じてリージョンを指定してください。カタログへの掲載は空き容量を保証しません。

## 状態を保持してコードを実行する

`CodeSandbox` は `interpreter` テンプレートを起動し、`runCode`（Python では `run_code`）でコードを実行します。このテンプレートでは、Python はコンテキストごとに永続的な Jupyter カーネルで実行されるため、変数は呼び出し間で引き継がれ、結果に `image/png` のグラフを含めることができます。JavaScript と bash は、呼び出しごとに新しいプロセスとして実行されます。[Python の実行](/sandboxes/code-interpreter)を参照してください。

## 未対応の API

ファイル監視はまだ利用できません。`sandbox.fork()` は、ボリュームが接続されている場合は 409 を、pod として実行される sandbox では 501 を返します。`Sandbox.connect` は一時停止中や停止済みの sandbox を再開しません。一時停止中の sandbox には `resume()` を呼び出してください。SSH プロトコルでのアクセスはできません。`lizard sandbox ssh` は CLI の認証情報で対話型シェルを開きます。

## 保存と課金

sandbox の実行中はファイルとプロセスを維持します。停止後、別の sandbox で使えるのは、接続した Persistent Volume の `/workspace` に保存したファイルだけです。ボリュームがなければ `/workspace` は一時領域です。各ボリュームは同時に 1 つの sandbox に接続し、単一ノードに保存します。ノード障害後も必要なファイルは別の場所へ書き出してください。

各サイズは固定の時間単価で、sandbox の実行中は秒単位で課金されます。アイドル時間も含みます。送信トラフィックはアカウントごとに直近 30 日間で [2 TB まで](/platform/limits#sandbox-egress)料金に含まれます。スナップショットから復元した sandbox は、元の sandbox と同じサイズと料金で動作します。pod スナップショットから復元した sandbox は実測使用量で課金されます。一時停止中の sandbox は課金されません。Persistent Volumes はデータを保存している間、別途課金されます。タスクが終わったら sandbox を一時停止するか停止してください。
