# ダッシュボード

プロジェクトを開き、Sandboxes を選びます。作成時にテンプレートとリージョンを選択してください。既定のリージョンが最寄りとは限りません。リソース上限は固定です。ダッシュボードで作成した Sandboxes は、API で有効期間を設定しない限り期限なしで動作します。

## インストールと認証

Lizard SDK をインストールし、Settings → API keys で API キーを作成します。`LIZARD_API_KEY` に保存してください。各 sandbox にはプロジェクトが必要です。`projectId`（Python では `project_id`）、または `project` に ID、slug、名前を渡します。

## 確認と停止

詳細画面には状態、テンプレート、リージョン、実測使用量、公開ポートが表示されます。現在の Kubernetes ランタイムは SSH 認証情報を提供しないため、SSH ベースのターミナルは利用できません。SDK または CLI でコマンドを実行してください。

CPU、メモリ、ストレージ、送信トラフィックの実測使用量に応じて課金します。アイドル状態でもメモリやストレージを使う場合があります。タスク終了後は停止してください。データを保存している間はストレージ料金が続きます。

## テンプレートとボリューム

Templates タブには新しい Sandboxes 用のプラットフォームテンプレートが表示されます。実行中のセッションのスナップショットではありません。独自スナップショット、一時停止、再開には対応していません。Kill Sandbox は sandbox を停止し、ボリュームを切り離します。

Persistent Volumes タブで名前付きボリュームと接続を管理します。sandbox の作成時にボリュームを接続し、`/workspace` に書き込んでください。別の sandbox に接続する前に、現在の sandbox を停止します。
