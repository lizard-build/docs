ダッシュボードを使うと、コードを書かずに Sandboxes を作成して管理できます。プロジェクトを開き、Sandboxes を選びます。作成時にテンプレート、リージョン、サイズ (Small、Medium (既定)、Large) を選択してください。既定のリージョンが最寄りとは限りません。**Delete after** で有効期間を選びます: 15 分、1 時間、4 時間、1 日、7 日、Never (既定)。

<span id="api-keys" />

## API キー

コードから sandbox を作成するには、Settings → API keys で API キーを作成し、`LIZARD_API_KEY` に保存します。Lizard SDK と [HTTP API](/sandboxes/sdk-reference#http-api) はこのキーを読み取ります。[クイックスタート](/sandboxes/quickstart) を参照してください。

<span id="inspect-and-stop" />

## 確認と停止

詳細画面には状態、テンプレート、リージョン、実測使用量、公開ポートが表示されます。ヘッダーには Pause と Resume のボタンがあり、Terminal タブでは実行中の sandbox のシェルを開けます。

実行中の sandbox は、サイズごとの時間単価で秒単位で課金されます。アイドル時間も含みます。一時停止中の sandbox は課金されないため、タスクが終わったら一時停止するか停止してください。[保存と課金](/sandboxes#storage-and-billing) を参照してください。

<span id="templates-and-volumes" />

## テンプレートとボリューム

Templates タブには、プラットフォームのテンプレートとプロジェクトの非公開スナップショットが表示され、どちらからでも新しい sandbox を起動できます。スナップショットは SDK または CLI で作成します。Kill Sandbox は sandbox を停止し、ボリュームを切り離します。

ボリュームの作成と接続は SDK または CLI で行います。作成フォームにはボリュームの項目がありません。Persistent Volumes タブは、プロジェクトにボリュームができると表示されます。各ボリュームのサイズと接続先の sandbox が表示され、ファイルの閲覧、サイズ変更、削除ができます。別の sandbox に接続する前に、現在の sandbox を停止します。
