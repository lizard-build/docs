プロジェクトを開き、Sandboxes を選びます。作成時にテンプレート、リージョン、サイズ (Small、Medium (既定)、Large) を選択してください。既定のリージョンが最寄りとは限りません。**Delete after** で有効期間を選びます: 15 分、1 時間、4 時間、1 日、7 日、Never (既定)。

## インストールと認証

Lizard SDK をインストールし、Settings → API keys で API キーを作成します。`LIZARD_API_KEY` に保存してください。各 sandbox にはプロジェクトが必要です。`projectId`（Python では `project_id`）、または `project` に ID、slug、名前を渡します。

## 確認と停止

詳細画面には状態、テンプレート、リージョン、実測使用量、公開ポートが表示されます。ヘッダーには Pause と Resume のボタンがあり、Terminal タブでは実行中の sandbox のシェルを開けます。

各サイズは固定の時間単価で、sandbox の実行中は秒単位で課金されます。アイドル時間も含みます。送信トラフィックはアカウントごとに直近 30 日間で [2 TB まで](/platform/limits#sandbox-egress)料金に含まれます。スナップショットから復元した sandbox は、元の sandbox と同じサイズと料金で動作します。pod スナップショットから復元した sandbox は実測使用量で課金されます。一時停止中の sandbox は課金されません。Persistent Volumes はデータを保存している間、別途課金されます。タスクが終わったら sandbox を一時停止するか停止してください。

## テンプレートとボリューム

Templates タブには、プラットフォームのテンプレートとプロジェクトの非公開スナップショットが表示され、どちらからでも新しい sandbox を起動できます。スナップショットは SDK または CLI で作成します。Kill Sandbox は sandbox を停止し、ボリュームを切り離します。

ボリュームの作成と接続は SDK または CLI で行います。作成フォームにはボリュームの項目がありません。Persistent Volumes タブは、プロジェクトにボリュームができると表示されます。各ボリュームのサイズと接続先の sandbox が表示され、ファイルの閲覧、サイズ変更、削除ができます。別の sandbox に接続する前に、現在の sandbox を停止します。
