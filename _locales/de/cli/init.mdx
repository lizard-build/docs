# lizard init

Erstellen oder wählen Sie ein Projekt aus und verknüpfen Sie es mit dem aktuellen Verzeichnis.

<span id="usage" />

## Verwendung

```bash
lizard init [flags]
```

## Flags

| Flag | Beschreibung |
|------|-------------|
| `-n, --name <name>` | Projektname (wird erstellt, falls nicht vorhanden) |
| `-w, --workspace <ws>` | Workspace-ID, Slug oder Name |
| `--force` | Erneut verknüpfen, auch wenn bereits verknüpft |

<span id="examples" />

## Beispiele

<span id="link-the-current-directory-interactively" />

### Das aktuelle Verzeichnis interaktiv verknüpfen

```bash
lizard init
```

Ohne `--name` fragt `init`, welches Projekt verwendet werden soll. In einer nicht interaktiven Shell scheitert der Befehl stattdessen; übergeben Sie dort `--name`.

<span id="link-explicitly-in-ci" />

### In CI explizit verknüpfen

Ein `lizard up` in einem nicht verknüpften Verzeichnis deployt in das Standardprojekt Ihres Kontos. Um in CI in ein bestimmtes Projekt zu deployen, verknüpfen Sie es zuerst:

```bash
export LIZARD_TOKEN=liz_xxx
lizard init --name my-project
lizard up --ci --service api   # creates api on the first run
```

<span id="relink-a-directory-thats-already-linked" />

### Ein Verzeichnis erneut verknüpfen, das bereits verknüpft ist

```bash
lizard init --name my-project --force
```
