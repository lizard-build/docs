# lizard status

Zeigt den verknüpften Workspace, das Projekt und den Service für das aktuelle Verzeichnis an. Eine Anmeldung ist nicht nötig.

In einem nicht verknüpften Verzeichnis gibt der Befehl `Not linked` aus. Befehle dort nutzen das Standardprojekt deines Kontos, und `lizard up` verknüpft das Verzeichnis damit.

<span id="usage" />

## Verwendung

```bash
lizard status
```

<span id="examples" />

## Beispiele

<span id="check-the-current-directorys-link" />

### Verknüpfung des aktuellen Verzeichnisses prüfen

```bash
lizard status
```

<span id="read-the-link-from-a-script" />

### Verknüpfung in einem Skript auslesen

```bash
lizard status --json
```

Ein verknüpftes Verzeichnis liefert `cwd`, `linked: true`, `workspace`, `workspaceId`, `project`, `projectId`, `service` und `serviceId`. Ein nicht verknüpftes liefert `{"cwd": "…", "linked": false}`.
