# lizard status

Zeigt den verknüpften Workspace, das Projekt und den Service für das aktuelle Verzeichnis an.

<span id="usage" />

## Verwendung

```bash
lizard status
```

<span id="examples" />

## Beispiele

<span id="check-the-current-directorys-link" />

### Verknüpfung des aktuellen Verzeichnisses prüfen

```bash
lizard status
```
