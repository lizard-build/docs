# lizard skills

Lies die eingebetteten Agenten-Skills, die mit dieser CLI-Version ausgeliefert werden.

## Usage

```bash
lizard skills list
lizard skills get core
lizard skills path
```

## Subcommands

### `lizard skills list`

Liste die verfügbaren eingebetteten Skills auf.

### `lizard skills get core`

Lies den Core-Guide — den maßgeblichen Nutzungsleitfaden für die Plattform, versioniert mit der CLI. Er gibt `{ name, frontmatter, content, … }` zurück, wobei `content` der vollständige Leitfaden ist (Build-Pipeline, env-Priorität, Add-ons, Discovery, Exit-Codes).

### `lizard skills path`

Zeige an, wo Skills auf dem Datenträger gespeichert sind.
