# lizard skills

Lies die eingebetteten Agenten-Skills, die mit dieser CLI-Version ausgeliefert werden. Alias: `lizard skill`.

<span id="usage" />

## Verwendung

```bash
lizard skills list
lizard skills get core
lizard skills path
```

<span id="subcommands" />

## Unterbefehle

### `lizard skills list`

Liste die verfügbaren eingebetteten Skills auf.

### `lizard skills get core`

Lies den Core-Anleitung — den maßgeblichen Nutzungsleitfaden für die Plattform, versioniert mit der CLI. Mit `--json` gibt er `{ name, path, frontmatter, content }` zurück, wobei `content` der vollständige Leitfaden ist (Build-Pipeline, env-Priorität, Add-ons, Discovery, Exit-Codes).

### `lizard skills path [name]`

Gib aus, woher ein Skill stammt. Skills sind in die CLI eingebaut, daher gibt dieser Befehl `embedded://skills` aus, es sei denn, `LIZARD_SKILLS_DIR` verweist die CLI auf ein Verzeichnis auf dem Datenträger.
