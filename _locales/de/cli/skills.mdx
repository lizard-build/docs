# lizard skills

Lies die eingebetteten Agenten-Skills, die mit dieser CLI-Version ausgeliefert werden.

<span id="usage" />

## Verwendung

```bash
lizard skills list
lizard skills get core
lizard skills path
```

<span id="subcommands" />

## Unterbefehle

### `lizard skills list`

Liste die verfügbaren eingebetteten Skills auf.

### `lizard skills get core`

Lies den Core-Anleitung — den maßgeblichen Nutzungsleitfaden für die Plattform, versioniert mit der CLI. Er gibt `{ name, frontmatter, content, … }` zurück, wobei `content` der vollständige Leitfaden ist (Build-Pipeline, env-Priorität, Add-ons, Discovery, Exit-Codes).

### `lizard skills path`

Zeige an, wo Skills auf dem Datenträger gespeichert sind.

<span id="examples" />

## Beispiele

<span id="load-the-core-guide-as-an-agent" />

### Den Core-Anleitung als Agent laden


### Verfügbare eingebettete Skills auflisten
