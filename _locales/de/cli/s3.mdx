# lizard s3

Lade Objekte in einen [Managed Object Storage](/addons/storage) Bucket hoch, liste sie auf und gib befristete Download-Links aus.

<span id="usage" />

## Verwendung

```bash
lizard s3 upload <file> [flags]
lizard s3 list [flags]
lizard s3 url <key> [flags]
```

Alle drei Befehle arbeiten mit dem einzigen S3-Addon des Projekts und dessen `default`-Bucket, sofern du nicht `--addon` und `--bucket` angibst. Füge das Addon zuerst mit `lizard add s3` hinzu.

<span id="subcommands" />

## Unterbefehle

### `lizard s3 upload <file>`

Lädt eine lokale Datei hoch. Gibt den Key, den ETag, die Größe und eine URL aus, wenn der Bucket öffentlich ist. Der `default`-Bucket ist privat; mach einen Bucket über den S3-Browser im Dashboard öffentlich.

`upload` sendet die ganze Datei in einer Anfrage über die Lizard API, bis zu 150 MB. Für größere Dateien nutze einen S3-Client mit den Zugangsdaten des Addons; siehe [Managed Object Storage](/addons/storage).

| Flag | Beschreibung |
|------|-------------|
| `--addon <name>` | Name oder ID des S3-Addons (Standard: das einzige S3-Addon des Projekts) |
| `--bucket <name>` | Ziel-Bucket (Standard `default`) |
| `--key <key>` | Objekt-Key (Standard: der Dateiname) |
| `--content-type <type>` | Content-Type-Header (Standard: aus der Dateiendung abgeleitet) |
| `-p, --project <id>` | Projektname, Slug oder ID |

### `lizard s3 url <key>`

Gibt einen befristeten Download-Link für ein Objekt aus. Wer den Link hat, kann das Objekt bis zum Ablauf herunterladen, auch aus einem privaten Bucket und ohne Zugangsdaten. Mit `--json` gibt der Befehl `url`, `key`, `bucket`, `expiresIn` und `expiresAt` aus.

| Flag | Beschreibung |
|------|-------------|
| `--addon <name>` | Name oder ID des S3-Addons (Standard: das einzige S3-Addon des Projekts) |
| `--bucket <name>` | Bucket (Standard `default`) |
| `--expires <seconds>` | Wie lange der Link gilt, in Sekunden (Standard `3600`, höchstens `604800` = 7 Tage) |
| `-p, --project <id>` | Projektname, Slug oder ID |

### `lizard s3 list`

Listet Objekte in einem Bucket auf (Alias `ls`).

| Flag | Beschreibung |
|------|-------------|
| `--addon <name>` | Name oder ID des S3-Addons |
| `--bucket <name>` | Aufzulistender Bucket (Standard `default`) |
| `--prefix <prefix>` | Nur Keys unter diesem Präfix |
| `-p, --project <id>` | Projektname, Slug oder ID |

Jedes Konto kann über seine Addons hinweg bis zu 16 GiB speichern. Der Speicher wird nach gespeicherten Bytes abgerechnet, zu 0,14 $ pro GB-Monat.

## Beispiele

<span id="upload-a-file" />

### Eine Datei hochladen

```bash
lizard s3 upload ./logo.png --key assets/logo.png
```

<span id="share-a-private-file-for-a-day" />

### Eine private Datei für einen Tag teilen

```bash
lizard s3 url assets/logo.png --expires 86400
```

<span id="list-objects-under-a-prefix" />

### Objekte unter einem Präfix auflisten

```bash
lizard s3 list --prefix assets/
```

<span id="use-a-second-s3-addon" />

### Ein zweites S3-Addon verwenden

```bash
lizard s3 upload ./backup.tar.gz --addon s3-autumn-bear
```
