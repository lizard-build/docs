# lizard git

Verbinde dein Lizard-Konto mit GitHub, sieh nach, aus welchen Repositories die Services eines Projekts bereitgestellt werden, und wechsle einen Service auf einen anderen Branch. Die Verbindung zur GitHub App gehört zu deinem Lizard-Konto, nicht zu einem einzelnen Projekt.

Die übrigen Unterbefehle von `lizard git` gehören zu Lizard Git, das diese Seite nicht behandelt.

<span id="usage" />

## Verwendung

```bash
lizard git connect
lizard git status [flags]
lizard git checkout <service> <branch> [flags]
```

Ohne `-p` verwenden `status` und `checkout` das verknüpfte Projekt oder in einem nicht verknüpften Ordner dein Standardprojekt.

<span id="subcommands" />

## Unterbefehle

### `lizard git connect`

Verbinde die GitHub App, um auf private Repositories zuzugreifen. Der Befehl öffnet GitHub, um die App zu installieren, wartet, bis du Enter drückst, und prüft dann die Verbindung. Ist die App schon verbunden, meldet er das. Mit `--json` oder ohne Terminal gibt er stattdessen die Installations-URL aus: `{ installed: false, installUrl }`.

### `lizard git status`

Zeige, ob die GitHub App verbunden ist und aus welchem Repository und Branch jeder Service im Projekt bereitgestellt wird.

| Flag | Beschreibung |
|------|-------------|
| `-p, --project <id>` | Name, Slug oder ID des Projekts |

### `lizard git checkout <service> <branch>`

Wechsle einen Service auf einen anderen Branch und stelle ihn erneut bereit.

| Flag | Beschreibung |
|------|-------------|
| `--detach` | Log-Streaming überspringen |
| `-p, --project <id>` | Name, Slug oder ID des Projekts |

## Beispiele

<span id="connect-the-github-app" />

### GitHub App verbinden

```bash
lizard git connect
```

<span id="check-connection-and-repository-status" />

### Verbindungs- und Repository-Status prüfen

```bash
lizard git status
```

<span id="switch-a-service-to-a-different-branch" />

### Einen Service auf einen anderen Branch umstellen

```bash
lizard git checkout api staging
```

<span id="switch-branches-without-streaming-logs" />

### Branches wechseln, ohne Logs zu streamen

```bash
lizard git checkout api staging --detach
```
