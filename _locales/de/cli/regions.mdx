# lizard regions

Verfügbare Regionen auflisten.

<span id="usage" />

## Verwendung

```bash
lizard regions [flags]
```

## Flags

| Flag | Beschreibung |
|------|-------------|
| `--json` | Als JSON ausgeben |

<span id="examples" />

## Beispiele

<span id="list-available-regions" />

### Verfügbare Regionen auflisten

```bash
lizard regions
```

<span id="list-regions-as-json" />

### Regionen als JSON auflisten

```bash
lizard regions --json
```

<span id="choose-a-region-when-you-create-a-resource" />

### Beim Erstellen einer Ressource eine Region auswählen

Übergeben Sie `--region <code>` an `lizard add`, `lizard up`, `lizard sandbox create` oder `lizard volume create`:

```bash
lizard add -r your-org/your-app --region <code>
lizard add postgres --region <code>
lizard up --region <code>
```

Ohne `--region` verwendet `lizard add` `us-east-1` und `lizard up` die Standardregion der Plattform. Bei `lizard up` gilt `--region` nur, wenn dabei ein neuer Service erstellt wird.
