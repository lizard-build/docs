# lizard billing

Zeigt und verwaltet deinen Plan bei Lizard (lizard.build): Testphase, Pro, die Nutzung in diesem Monat und Promo-Codes. `lizard credits` ist der alte Name. Er funktioniert noch, gibt aber eine Warnung aus, und ein späteres Release entfernt ihn.

<span id="usage" />

## Verwendung

```bash
lizard billing [subcommand] [flags]
```

Ohne Unterbefehl zeigt `lizard billing` dasselbe wie `lizard billing status`. Die Befehle wirken auf den Plan des Kontos, mit dem du angemeldet bist. Wie Pro, die Testphase und Mehrnutzung funktionieren, steht unter [Abrechnung](/platform/billing).

Befehle, die belasten, kündigen oder eine Karte entfernen, fragen nach einer Bestätigung. Ohne Terminal, etwa in CI oder bei einem Agenten, übergibst du stattdessen `-y`. Befehle, die eine Seite öffnen, geben immer ihren Link aus und öffnen den Browser nur in einem interaktiven Terminal.

<span id="subcommands" />

## Unterbefehle

### `lizard billing status`

Zeigt deinen Plan und seinen Stand: verbleibende Tage und Testguthaben, wie viel der $19 monatlichen Guthabens du genutzt hast, die bisherige Mehrnutzung, Betrag und Datum der nächsten Belastung und eine offene Rechnung, falls es eine gibt.

| Flag | Beschreibung |
|------|-------------|
| `-w, --workspace <id>` | Plan des Eigentümers dieses Workspace anzeigen |

### `lizard billing open`

Öffnet die Seite „Abrechnung“ im Browser. Dort bezahlst du eine offene Rechnung, fügst eine Karte hinzu oder änderst sie und siehst frühere Rechnungen.

| Flag | Beschreibung |
|------|-------------|
| `--no-open` | Link ausgeben, statt den Browser zu öffnen |

### `lizard billing start`

Startet Pro in Stripe Checkout, wo du eine Karte hinterlegst. Der Befehl öffnet Checkout in deinem Browser. Ein neues Konto bekommt die 7-tägige Testphase mit $5 Testguthaben, und bis zu ihrem Ende wird nichts berechnet. Hatte das Konto schon eine Testphase, beginnt Pro sofort, und $19 werden belastet. Hatte die Karte schon eine, startet die Testphase nicht, und es wird nichts berechnet; starte Pro für $19 auf der Seite „Abrechnung“.

| Flag | Beschreibung |
|------|-------------|
| `--return-url <path>` | Pfad im Dashboard, zu dem du nach Checkout zurückkehrst, zum Beispiel `/projects/abc` |
| `--no-open` | Checkout-Link ausgeben, statt den Browser zu öffnen |

### `lizard billing start-now`

Beendet die Testphase und beginnt sofort deinen ersten bezahlten Monat. Lizard belastet $19 und gibt $19 monatliches Guthaben. Nutze den Befehl, wenn das Testguthaben aufgebraucht ist. Verlangt deine Bank eine Bestätigung der Zahlung, gibt der Befehl dir die Rechnungsseite dafür; die Testphase läuft weiter, bis die Zahlung durch ist.

| Flag | Beschreibung |
|------|-------------|
| `-y, --yes` | Bestätigung überspringen |
| `--no-open` | Zahlungslink ausgeben, statt den Browser zu öffnen |

### `lizard billing cancel`

Kündigt zum Ende des laufenden Monats oder der Testphase. Bis dahin bleibt Pro aktiv. Eine Kündigung während der Testphase kostet nichts.

| Flag | Beschreibung |
|------|-------------|
| `-y, --yes` | Bestätigung überspringen |

### `lizard billing resume`

Nimmt eine Kündigung vor dem Enddatum zurück.

### `lizard billing promo <code>`

Löst einen Promo-Code für eine längere Testphase und mehr Testguthaben ein. Vor dem Start der Testphase speichert Lizard den Code dafür. Während der Testphase verlängert der Code sie. Codes gelten nur vor deiner ersten Zahlung, einer pro Konto.

### `lizard billing balance`

Zeigt das Guthaben eines Enterprise-Kontos.

### `lizard billing transactions`

Listet die letzten Buchungen auf dem Guthaben eines Enterprise-Kontos auf (Alias `ledger`).

| Flag | Beschreibung |
|------|-------------|
| `-l, --limit <n>` | Maximale Anzahl, `1`–`100` (Standard `20`) |
| `-c, --cursor <cursor>` | Seiten-Cursor aus einem früheren Aufruf |
| `-u, --usage` | Tägliche Nutzungszeilen einschließen |

### `lizard billing payment-methods list`

Listet gespeicherte Karten auf. `pm` ist die Kurzform von `payment-methods`. Eine Pro-Karte fügst du auf der Seite „Abrechnung“ hinzu, änderst oder entfernst sie dort.

### `lizard billing payment-methods remove <id>`

Entfernt eine gespeicherte Karte (Alias `rm`). Das funktioniert nur für Enterprise-Konten; ein Pro-Konto erhält HTTP 409 und entfernt seine Karte auf der Seite „Abrechnung“.

| Flag | Beschreibung |
|------|-------------|
| `-y, --yes` | Bestätigung überspringen |

## Beispiele

<span id="check-your-plan-and-usage" />

### Plan und Nutzung prüfen

```bash
lizard billing status
lizard billing status --json
```

<span id="start-the-trial-with-a-promo-code" />

### Testphase mit einem Promo-Code starten

```bash
lizard billing promo YOURCODE
lizard billing start
```

<span id="cancel-then-change-your-mind" />

### Kündigen und es sich anders überlegen

```bash
lizard billing cancel --yes
lizard billing resume
```

<span id="payment-required" />

## Zahlung erforderlich

Wenn du eine Ressource erstellst, während das Konto keinen Plan hat, das Testguthaben aufgebraucht ist oder eine Rechnung offen ist, antwortet Lizard mit HTTP 402. Lizard CLI gibt den Grund und einen Link zur Seite „Abrechnung“ aus, zum Beispiel:

```text
Start your 7-day Pro trial with $5 in credits to deploy. No charge today, then $19/month.
```
