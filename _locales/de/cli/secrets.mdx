# lizard secrets

Verwalte die Secrets (Umgebungsvariablen) eines Projekts oder Services.

## Usage

```bash
lizard secrets <subcommand> [args] [flags]
```

<span id="subcommands" />

## Unterbefehle

### `lizard secrets set <K=V>...`

Setzt ein oder mehrere Secrets (variadisch). Der Standardbereich ist der Service; `--global` zielt auf das Projekt.

| Flag | Beschreibung |
|------|-------------|
| `--global` | Projektbereich |
| `-s, --service <name>` | Servicebereich |

### `lizard secrets list`

Listet Secrets im Bereich auf.

| Flag | Beschreibung |
|------|-------------|
| `--show` | Werte anzeigen |
| `--ref` | Referenzen anzeigen |

### `lizard secrets delete <K>...`

Löscht ein oder mehrere Secrets (variadisch).

### `lizard secrets import`

Importiert eine dotenv-Datei von stdin.

<span id="examples" />

## Beispiele

<span id="set-secrets-on-the-linked-service" />

### Secrets für den verknüpften Service setzen

```bash
lizard secrets set DATABASE_URL=postgres://… LOG_LEVEL=info
lizard secrets set API_KEY=sk_live_… --service api
```

<span id="set-a-project-wide-secret" />

### Ein projektweites Secret setzen

```bash
lizard secrets set NODE_ENV=production --global
```

<span id="list-and-reveal-secrets" />

### Secrets auflisten und anzeigen

```bash
lizard secrets list
lizard secrets list --show
```

<span id="delete-secrets" />

### Secrets löschen

```bash
lizard secrets delete OLD_KEY ANOTHER_KEY
```

<span id="import-a-dotenv-file" />

### Eine dotenv-Datei importieren

```bash
cat .env | lizard secrets import
```
