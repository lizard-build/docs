# lizard whoami

Zeigt das Konto an, mit dem Sie angemeldet sind, und in einem verknüpften Ordner das verknüpfte Projekt samt Workspace.

<span id="usage" />

## Verwendung

```bash
lizard whoami
```

<span id="what-it-shows" />

## Was angezeigt wird

- Mit einem Konto angemeldet: Ihr Benutzername, ob die GitHub App verbunden ist, und das verknüpfte Projekt mit seinem Workspace in Klammern. In einem nicht verknüpften Ordner steht dort `Project: none`; Befehle dort verwenden das Standardprojekt Ihres Kontos.
- Mit einem eingeschränkten API-Schlüssel angemeldet: `Scoped API key (account details are not visible)`, danach jedes Projekt und jeder Workspace, den der Schlüssel erreicht. Das Konto hinter dem Schlüssel zeigt der Befehl nie.

`whoami` zeigt keinen aktiven Workspace. Ihre Workspaces listet [`lizard workspace list`](/cli/workspace) auf.

Mit `--json` oder wenn die Ausgabe kein Terminal ist, gibt der Befehl die Felder Ihres Kontos und `project` aus. Für einen eingeschränkten Schlüssel gibt er `{ "scoped": true, "scopes": [...], "project": ... }` aus.
