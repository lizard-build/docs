# lizard domain

Zeigt die aktuelle Domain an oder hängt eine benutzerdefinierte an.

<span id="usage" />

## Verwendung

```bash
lizard domain [hostname] [flags]
```

Der Hostname ist ein Positionsargument — es gibt kein Subcommand `add`. Wenn du `lizard domain` ohne Argumente ausführst, wird die aktuelle Domain des Dienstes angezeigt oder eine erzeugt, falls der Dienst noch keine hat. Alias: `lizard domains`.

## Flags

| Flag | Beschreibung |
|------|-------------|
| `-s, --service <name>` | Dienst |
| `-p, --project <id>` | Projektname, Slug oder ID |
| `--port <n>` | Freizugebender Port |
| `-f, --force` | Verschiebt die Domain hierher, falls sie an einen anderen deiner Dienste angehängt ist |

Die Unterbefehle verwenden dieselben Flags `-s` und `-p`. Verifiziere und entferne eine Domain bei dem Dienst, an den du sie angehängt hast.

<span id="subcommands" />

## Unterbefehle

### `lizard domain generate`

Erzeugt eine neue `*.onlizard.com`-Subdomain.

### `lizard domain verify <hostname>`

Prüft den TXT-Record und aktiviert die Domain. TLS wird automatisch bereitgestellt.

### `lizard domain delete <hostname>`

Entfernt eine Domain (Alias `rm`).

| Flag | Beschreibung |
|------|-------------|
| `-y, --yes` | Bestätigung überspringen |

<span id="examples" />

## Beispiele

<span id="show-the-current-domain" />

### Aktuelle Domain anzeigen

```bash
lizard domain
```

<span id="generate-a-subdomain" />

### Eine Subdomain erzeugen

```bash
lizard domain generate
```

<span id="attach-a-custom-domain" />

### Eine benutzerdefinierte Domain anhängen

```bash
lizard domain app.example.com --service web
```

Lizard gibt die zu erstellenden DNS-Records zurück: einen `CNAME` für den Hostnamen und, sofern du die Domain nicht bereits verifiziert hast, einen `TXT`-Record unter `_lizard-verify.<apex domain>` (für `app.example.com` ist das `_lizard-verify.example.com`). Füge sie bei deinem DNS-Anbieter hinzu und verifiziere dann beim selben Dienst:

```bash
lizard domain verify app.example.com --service web
```

<span id="attach-a-domain-to-a-specific-port" />

### Eine Domain an einen bestimmten Port anhängen

```bash
lizard domain app.example.com --service web --port 8080
```

<span id="move-a-domain-from-another-of-your-services" />

### Eine Domain von einem anderen deiner Dienste verschieben

```bash
lizard domain app.example.com --service web --force
```

<span id="remove-a-domain" />

### Eine Domain entfernen

```bash
lizard domain delete app.example.com --service web
lizard domain rm app.example.com --service web --yes
```
