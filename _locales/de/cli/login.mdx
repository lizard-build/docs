# lizard login

Bei Lizard anmelden.

<span id="usage" />

## Verwendung

```bash
lizard login [flags]
```

Standardmäßig öffnet dies die Anmeldeseite in deinem Browser, gibt deren URL aus und beendet sich. Nachdem du dich angemeldet hast, führe deinen nächsten Befehl aus (zum Beispiel `lizard whoami`); er schließt die Anmeldung ab und speichert deine Zugangsdaten. Mit `--json` gibt `login` `{ "status": "pending", "authUrl": "…" }` aus und öffnet keinen Browser.

## Flags

| Flag | Beschreibung |
|------|-------------|
| `--token <token>` | Mit einem API-Key (`liz_…`) authentifizieren |

<span id="examples" />

## Beispiele

<span id="log-in-via-browser" />

### Über den Browser anmelden

```bash
lizard login
```

<span id="log-in-with-a-token" />

<span id="log-in-with-an-api-key" />

### Mit einem API-Key anmelden

Erstelle einen Key mit [`lizard keys create <name>`](/cli/keys) und führe dann aus:

```bash
lizard login --token liz_xxx
```

<span id="log-in-non-interactively-in-ci" />

### In CI nicht-interaktiv anmelden

In CI oder anderen nicht-interaktiven Umgebungen setze `LIZARD_TOKEN` (oder `LIZARD_API_KEY`) als Umgebungsvariable, statt `login` auszuführen:

```bash
export LIZARD_TOKEN=liz_xxx
```
