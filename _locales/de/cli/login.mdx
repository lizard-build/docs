# lizard login

Bei Lizard anmelden.

## Usage

```bash
lizard login [flags]
```

Standardmäßig öffnet dies deinen Browser für die Authentifizierung per OAuth und kehrt nach der Bestätigung in dein Terminal zurück.

## Flags

| Flag | Description |
|------|-------------|
| `--token <token>` | Mit einem API-Token authentifizieren |

## Examples

<span id="log-in-via-browser" />

### Über den Browser anmelden

```bash
lizard login
```

<span id="log-in-with-a-token" />

### Mit einem Token anmelden

```bash
lizard login --token lzd_xxx
```

<span id="log-in-non-interactively-in-ci" />

### In CI nicht-interaktiv anmelden

In CI oder anderen nicht-interaktiven Umgebungen setze `LIZARD_TOKEN` als Umgebungsvariable, statt `login` auszuführen:

```bash
export LIZARD_TOKEN=lzd_xxx
```
