# lizard ps

Alle Services im Projekt mit Status und URL auflisten.

<span id="usage" />

## Verwendung

```bash
lizard ps [flags]
```

## Flags

| Flag | Beschreibung |
|------|-------------|
| `-p, --project <id>` | Name, Slug oder ID des Projekts |

Ohne `-p` verwendet `ps` das verknüpfte Projekt oder in einem nicht verknüpften Ordner dein Standardprojekt.

<span id="examples" />

## Beispiele

<span id="list-services-in-the-linked-project" />

### Services im verknüpften Projekt auflisten

```bash
lizard ps
```

<span id="list-services-in-another-project" />

### Services in einem anderen Projekt auflisten

```bash
lizard ps -p my-project
```
