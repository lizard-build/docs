# lizard metrics

CPU / Arbeitsspeicher / Netzwerk / Festplatte und Kosten anzeigen.

<span id="usage" />

## Verwendung

```bash
lizard metrics [flags]
```

## Flags

| Flag | Beschreibung |
|------|-------------|
| `-s, --service <id>` | Service (Standard: der verknüpfte Service) |
| `-p, --project <id>` | Projektname, Slug oder ID |
| `--all` | Alle Services im Projekt, der verknüpfte Service wird ignoriert; kann nicht mit `-s` kombiniert werden |
| `-r, --range <range>` | Zeitfenster: `1h` (Standard), `6h`, `24h`, `7d`, `14d` oder `30d` |
| `-w, --watch` | Live-Ansicht, wird alle 3 Sekunden aktualisiert; kann nicht mit `--json` kombiniert werden |
| `--cost` | Laufende Ressourcen, Kosten pro Stunde, Nutzung im aktuellen Abrechnungszeitraum und Pro-Nutzung in diesem Monat. Nur für Workspace-Owner |

Ohne verknüpften Service oder `-s` zeigt `metrics` eine Übersicht über alle Services im Projekt an.

<span id="examples" />

## Beispiele

<span id="view-metrics-for-the-current-service" />

### Metriken für den aktuellen Service anzeigen

```bash
lizard metrics
```

<span id="view-metrics-for-a-specific-service" />

### Metriken für einen bestimmten Service anzeigen

```bash
lizard metrics --service api
```

<span id="watch-metrics-live" />

### Metriken live beobachten

```bash
lizard metrics --watch
```

<span id="include-cost" />

### Kosten einschließen

```bash
lizard metrics --cost
```
