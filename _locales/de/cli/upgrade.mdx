# lizard upgrade

Aktualisiere die CLI auf die neueste Version.

<span id="usage" />

## Verwendung

```bash
lizard upgrade [flags]
```

Wie die Aktualisierung abläuft, hängt davon ab, wie du die CLI installiert hast:

- **Installationsskript auf macOS oder Linux:** lädt das neueste Release herunter und ersetzt das Binary.
- **npm:** führt `npm install -g @lizard-build/cli@<version>` für dich aus. Scheitert npm, etwa weil ihm Schreibrechte für den globalen Ordner fehlen, gibt die CLI `npm install -g @lizard-build/cli@latest` aus, damit du den Befehl mit den nötigen Rechten selbst ausführst.
- **Windows:** Das Binary kann sich nicht selbst ersetzen. Führe den Installer erneut aus: `irm https://lizard.build/api/cli/install.ps1 | iex`.

Das Binary aus dem Installationsskript auf macOS und Linux aktualisiert sich außerdem im Hintergrund: nur in einem interaktiven Terminal, höchstens alle 6 Stunden und nie, wenn `CI` oder `LIZARD_NO_UPDATE` gesetzt ist. Der nächste Befehl gibt dann `lizard auto-updated: v<old> → v<new>` aus. npm-Installationen und das Windows-Binary aktualisieren sich nicht im Hintergrund.

## Flags

| Flag | Beschreibung |
|------|-------------|
| `--check` | Auf eine neuere Version prüfen, ohne sie zu installieren |

Mit `--json` gibt `lizard upgrade --check` `{ currentVersion, latestVersion, updateAvailable }` zurück.

## Beispiele

<span id="update-to-the-latest-version" />

### Auf die neueste Version aktualisieren

```bash
lizard upgrade
```

<span id="check-for-updates-without-installing" />

### Ohne Installation auf Updates prüfen

```bash
lizard upgrade --check
```
