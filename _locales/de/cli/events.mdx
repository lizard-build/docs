# lizard events

Bereitstellen-Verlauf und Replikat-Status anzeigen.

<span id="usage" />

## Verwendung

```bash
lizard events [flags]
```

## Flags

| Flag | Beschreibung |
|------|-------------|
| `-n, --limit <n>` | Anzahl der anzuzeigenden Einträge (Standard: 10) |
| `-s, --service <name>` | Ereignisse für einen bestimmten Service anzeigen |

<span id="examples" />

## Beispiele

<span id="show-deploy-history-and-replica-status" />

### Bereitstellen-Verlauf und Replikat-Status anzeigen

```bash
lizard events
```

<span id="show-events-for-a-specific-service" />

### Ereignisse für einen bestimmten Service anzeigen

```bash
lizard events --service api
```

<span id="show-more-entries" />

### Mehr Einträge anzeigen

```bash
lizard events --limit 25
```
