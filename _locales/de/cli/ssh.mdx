# lizard ssh

> **Abgeschaltet.** Der Shell-Zugriff auf Services ist bei Lizard deaktiviert. `lizard ssh` erhält HTTP 403 `Shell access to services is disabled` und beendet sich mit Exit-Code `1`.

Der Befehl ist weiterhin Teil der CLI, aber die Plattform lehnt ihn für jeden Service ab. Verwende stattdessen diese Befehle:

| Zu prüfen | Befehl |
|----------|---------|
| Referenzen, die zu einem leeren Wert aufgelöst wurden | `lizard logs --build --service api` (das Build-Log warnt bei jeder leeren `${{…}}`-Referenz) |
| Die auf einem Service gespeicherten Werte | `lizard secrets list --service api --show` |
| Ein Befehl mit den echten Verbindungswerten eines Addons | `lizard run --service postgres -- <cmd>` |
| Was die App zur Laufzeit ausgibt | `lizard logs --service api` |

Für eine Shell in einer Sandbox verwende [`lizard sandbox ssh <id>`](/cli/sandbox#sandbox-ssh). Das funktioniert weiterhin.

<span id="usage" />

## Verwendung

```bash
lizard ssh --service <name> -- <command>
```

| Flag | Beschreibung |
|------|-------------|
| `-s, --service <id>` | Service-Name oder ID |
| `-p, --project <id>` | Projektname, Slug oder ID |
