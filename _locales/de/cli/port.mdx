# lizard port

Zeigt den Container-Port eines Service an oder ändert ihn. Ohne Argument wird der aktuelle Port ausgegeben (`worker mode`, wenn er `0` ist). Ein neuer Port wird beim nächsten Deploy wirksam; führe [`lizard redeploy`](/cli/redeploy) aus, um ihn anzuwenden.

<span id="usage" />

## Verwendung

```bash
lizard port [value] [flags]
```

## Flags

| Flag | Beschreibung |
|------|-------------|
| `-s, --service <name>` | Ziel-Service |
| `-p, --project <id>` | Projektname, Slug oder ID |

<span id="examples" />

## Beispiele

<span id="show-the-current-port" />

### Den aktuellen Port anzeigen

```bash
lizard port
```

<span id="set-the-port-for-a-specific-service" />

### Den Port für einen bestimmten Service festlegen

```bash
lizard port 0 -s worker
```

<span id="check-the-port-on-a-worker-service" />

### Den Port eines Worker-Service prüfen

```bash
lizard port --service worker
```
