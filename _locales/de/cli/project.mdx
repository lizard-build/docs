# lizard project

Projekte in einem Workspace auflisten oder erstellen.

## Usage

```bash
lizard project list
lizard project create
```

## Subcommands

### `lizard project list`

Alle Projekte im Workspace auflisten.

### `lizard project create`

Ein neues Projekt erstellen.
