# lizard project

Projekte auflisten, erstellen, pausieren, fortsetzen oder löschen.

<span id="usage" />

## Verwendung

```bash
lizard project list [flags]
lizard project create <name> [flags]
lizard project pause [project]
lizard project resume [project]
lizard project delete <project> [flags]
```

<span id="subcommands" />

## Unterbefehle

### `lizard project list`

Listet Ihre Projekte über alle Workspaces hinweg auf, oder mit `-w` nur in einem Workspace.

| Flag | Beschreibung |
|------|-------------|
| `-w, --workspace <ws>` | Nur dieser Workspace (ID, Slug oder Name) |

### `lizard project create <name>`

Ein Projekt erstellen. Es verknüpft nicht das aktuelle Verzeichnis; verwenden Sie dafür [`lizard init`](/cli/init).

| Flag | Beschreibung |
|------|-------------|
| `-w, --workspace <ws>` | Workspace, in dem das Projekt erstellt wird |

### `lizard project pause [project]`

Pausiert jede App und jede Datenbank im Projekt sowie seine laufenden Sandboxes. Services behalten ihre URLs, Passwörter, Einstellungen und Daten. Siehe [`lizard pause`](/cli/pause).

### `lizard project resume [project]`

Setzt die Apps und Datenbanken fort, die Sie im Projekt pausiert haben, sowie die Sandboxes, die `project pause` pausiert hat.

### `lizard project delete <project>`

Ein Projekt in den Papierkorb verschieben (Alias `rm`). Nur der Besitzer des Projekts kann es löschen. Seine Services und Datenbanken werden gestoppt; Sie können sie 3 Tage lang im Dashboard aus dem Papierkorb wiederherstellen, danach löscht Lizard sie endgültig.

> **Achtung:** Sandboxes haben keinen Papierkorb. `project delete` löscht die Sandboxes des Projekts, ihre Volumes und ihre Snapshots sofort, und Sie können sie nicht zurückholen.

`delete` braucht den Projektnamen. Es greift nie auf das mit dem Verzeichnis verknüpfte Projekt oder das Standardprojekt Ihres Kontos zurück. Ohne Argument verwenden `pause` und `resume` das mit diesem Verzeichnis verknüpfte Projekt oder, in einem nicht verknüpften Verzeichnis, das Standardprojekt Ihres Kontos.

| Flag | Beschreibung |
|------|-------------|
| `-y, --yes` | Bestätigung überspringen (ohne TTY erforderlich) |

## Beispiele

<span id="list-projects-in-the-workspace" />

<span id="list-projects" />

### Projekte auflisten

```bash
lizard project list
lizard project list --workspace my-team
```

<span id="create-a-new-project" />

### Ein neues Projekt erstellen

```bash
lizard project create my-project
lizard project create my-project --workspace my-team
```

<span id="pause-and-resume-a-project" />

### Ein Projekt pausieren und fortsetzen

```bash
lizard project pause my-project
lizard project resume my-project
```

<span id="delete-a-project" />

### Ein Projekt löschen

```bash
lizard project delete my-project --yes
```
