# lizard run

Führe einen Befehl lokal mit eingefügten Projekt- und Service-Geheimnissen aus.

<span id="what-run-injects" />

## Was `run` einfügt

`lizard run` lädt die Geheimnisse des Projekts, legt die Geheimnisse des Service darüber und führt deinen Befehl auf deinem Rechner mit diesen in seiner Umgebung aus.

- Bei einem App-Service fügt es die gespeicherten Werte ein. Referenzen wie `${{postgres.DATABASE_URL}}` kommen als dieser literale Text an, nicht als aufgelöster Wert. Plattformvariablen wie `PORT` und `LIZARD_*` werden nicht eingefügt.
- Bei einem Addon (`--service postgres`, `--service redis`, `--service s3`) fügt es die echten Verbindungswerte des Addons ein, etwa `DATABASE_URL`.

Um also eine Migration oder einen Datenbank-Client lokal auszuführen, richte `--service` auf das Addon, nicht auf die App, die darauf verweist.

`lizard ssh` in einen laufenden Service ist deaktiviert (die API antwortet mit 403 „Shell access to services is disabled"). Um zu prüfen, was die laufende App erhält, verwende:

| Prüfung | Befehl |
|-------|---------|
| Leere Referenzen | `lizard logs --build --service api` (das Build-Log warnt vor jeder `${{…}}`-Referenz, die zu einem leeren Wert aufgelöst wurde) |
| Gespeicherte Werte | `lizard secrets list --service api --show` |
| Die echten Verbindungswerte eines Addons | `lizard run --service postgres -- printenv DATABASE_URL` |

<span id="usage" />

## Verwendung

```bash
lizard run [flags] -- <command>
```

## Flags

| Flag | Beschreibung |
|------|-------------|
| `-s, --service <name>` | Service, dessen env eingefügt werden soll (standardmäßig der verknüpfte Service) |
| `--no-service` | Service-env nicht einfügen, nur Projekt-Geheimnisse |
| `-p, --project <id>` | Projekt (standardmäßig das verknüpfte) |

<span id="examples" />

## Beispiele

<span id="run-a-migration-with-service-secrets-injected" />

<span id="run-a-migration-against-managed-postgres" />

### Eine Migration gegen Managed Postgres ausführen

```bash
lizard run --service postgres -- node scripts/migrate.js
```

<span id="print-an-injected-environment-variable" />

### Eine eingefügte Umgebungsvariable ausgeben

```bash
lizard run --service postgres -- printenv DATABASE_URL
```

<span id="run-a-local-tool-with-an-apps-stored-secrets" />

### Ein lokales Tool mit den gespeicherten Geheimnissen einer App ausführen

```bash
lizard run --service api -- node scripts/report.js
```
