# lizard unlink

Löst die Zuordnung des aktuellen Verzeichnisses zu jedem Projekt. Das Projekt selbst ändert sich nicht. Danach nutzen Befehle in diesem Verzeichnis das Standardprojekt Ihres Kontos, und `lizard up` verknüpft das Verzeichnis wieder damit.

<span id="usage" />

## Verwendung

```bash
lizard unlink
```

<span id="examples" />

## Beispiele

<span id="unlink-the-current-directory" />

### Verknüpfung des aktuellen Verzeichnisses aufheben

```bash
lizard unlink
```
