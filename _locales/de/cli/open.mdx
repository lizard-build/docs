# lizard open

Projekt im Browser öffnen.

<span id="usage" />

## Verwendung

```bash
lizard open [flags]
```

## Flags

| Flag | Beschreibung |
|------|-------------|
| `-p, --project <id>` | Name, Slug oder ID des Projekts |

Ohne `-p` verwendet `open` das verknüpfte Projekt oder in einem nicht verknüpften Ordner dein Standardprojekt. Mit `--json` gibt es `{ url, opened: false }` aus und öffnet keinen Browser.

<span id="examples" />

## Beispiele

<span id="open-the-current-projects-dashboard" />

### Dashboard des aktuellen Projekts öffnen

```bash
lizard open
```

<span id="print-the-dashboard-url" />

### Dashboard-URL ausgeben

```bash
lizard open --json
```
