# App-Dashboard

Das Lizard-Dashboard ist die visuelle Ergänzung zu Lizard CLI. Alles, was Sie mit `lizard …` tun, wird hier angezeigt, plus Dinge, die sich mit einer UI einfacher erledigen lassen — Live-Logs, Diagramme, die Datenbrowser, Sandboxes und die Team-/Abrechnungsverwaltung.

Wenn Sie lieber gar kein Terminal öffnen möchten, lassen Sie den Agenten die Befehle ausführen und verfolgen Sie das Ergebnis hier — die Anleitung unter [Bereitstellen einer Antigravity-App in der Produktion](https://lizard.build/blog/google-antigravity-how-to-deploy-your-app-to-production#deploy-from-the-antigravity-chat), bei der ein einziger Prompt das Deployment steuert.

Öffnen Sie es aus der CLI:

```bash
lizard open          # open the current project
lizard docs          # open this documentation
```

## Was im Dashboard enthalten ist

### Services

Die Startansicht des Projekts listet jeden Service mit seinem Status-Badge, der generierten Domain und einem schnellen Zugriff auf Logs, Metriken, Secrets und Einstellungen auf. Erstellen Sie neue Services (aus einem GitHub-Repository oder leer) direkt von hier aus.

<span id="deployments" />

### Bereitstellungen

Eine Zeitleiste aller Deploys mit Build-Logs pro Bereitstellen und einer Detailansicht (Commit, Status, Replikate). Das ist das visuelle Gegenstück zu `lizard events` + `lizard logs --build`.

### Logs

Live-Streaming von Laufzeit- und Build-Logs mit Such- und Level-Filtern — das UI-Gegenstück zu [`lizard logs`](/observability/logs).

<span id="metrics--usage" />

### Metriken & Nutzung

CPU-, Speicher-, Netzwerk- und Datenträgerdiagramme pro Service sowie eine **Nutzungs**-Ansicht, die Verbrauch und Kosten im gesamten Projekt aufschlüsselt. Entspricht [`lizard metrics --cost`](/observability/metrics).

<span id="variables--secrets" />

### Variablen & Secrets

Verwalten Sie Secrets auf Service- und Projektebene mit maskierten Werten und Unterstützung für Referenzen (`${{…}}`). Siehe [Variablen & Secrets](/variables).

### Domains

Fügen Sie benutzerdefinierte Domains hinzu, sehen Sie DNS-Einträge ein und verfolgen Sie den Verifizierungs- und TLS-Status. Siehe [Networking](/networking).

<span id="data-browsers" />

### Datenbrowser

Jedes Managed Addon enthält einen Datenbrowser:

- **Managed Postgres** — ein SQL-/Tabelleneditor zum Abfragen und Bearbeiten von Daten.
- **Managed Redis** — ein Key/Wert-Browser.
- **Managed Object Storage** — ein Bucket- und Objektbrowser mit Upload/Download und Einstellungen für den Bucket-Zugriff.

### Sandboxes

Die Seite **Sandboxes** enthält Tabs für Sandboxes, Persistent Volumes, Vorlagen und Agenten. Erstellen Sie eine Sandbox mit **New Sandbox**; die Zahl daneben zeigt, wie viele Sandboxes im Verhältnis zu Ihrem Limit laufen. Siehe [Sandboxes quickstart](/sandboxes/quickstart).

### GitHub-Integration

Verbinden Sie die GitHub-App, wählen Sie Repositories aus und verwalten Sie, welche Repos Lizard bauen darf. Siehe [Von GitHub bereitstellen](/deploy/github).

<span id="settings-team--billing" />

### Einstellungen, Team & Abrechnung

Projekt- und Workspace-Einstellungen, Einladungen und Rollen für Mitglieder sowie die Ressourcennutzung. Die Seite **Abrechnung** in den Kontoeinstellungen zeigt Ihren Plan, die Testphase, das in diesem Monat genutzte Guthaben, Rechnungen und Ihre Karte. Siehe [Abrechnung](/platform/billing).

## CLI ↔ Dashboard

| Aufgabe | CLI | Dashboard-Ansicht |
|------|-----|----------------|
| Bereitstellen-Verlauf | `lizard events` | Bereitstellungen |
| Logs streamen | `lizard logs` | Logs |
| Ressourcendiagramme | `lizard metrics` | Metriken / Nutzung |
| Secrets verwalten | `lizard secrets` | Variablen |
| Benutzerdefinierte Domains | `lizard domain` | Domains |
| Managed Postgres, Managed Redis oder Managed Object Storage abfragen | `lizard run --service <addon> -- <cmd>` | Datenbrowser |
| Teammitglieder einladen | — | Team / Einstellungen |

Verwenden Sie einfach das, was gerade am besten passt — beide arbeiten mit denselben Projekten und Services.
