Führen Sie Python mit der Vorlage `interpreter` aus. `CodeSandbox` behält den Zustand zwischen Aufrufen: Python läuft pro Kontext in einem persistenten Jupyter-Kernel, und die Ergebnisse können den Wert des letzten Ausdrucks sowie Diagramme als `image/png` enthalten.

```ts
import { CodeSandbox } from '@lizard-build/sdk';

const sandbox = await CodeSandbox.create({ projectId: 'proj_123', timeoutMs: 300_000 });
try {
  await sandbox.runCode('x = 21');
  const run = await sandbox.runCode('x * 2');
  console.log(run.results[0]?.data, run.stdout, run.error);
} finally {
  await sandbox.kill();
}
```

```python
from lizard import CodeSandbox

sandbox = CodeSandbox.create(project_id="proj_123", timeout_ms=300_000)
try:
    sandbox.run_code("x = 21")
    run = sandbox.run_code("x * 2")
    print(run.results[0].data, run.stdout, run.error)
finally:
    sandbox.kill()
```

`createContext()` (Python: `create_context()`) startet einen separaten Kernel mit eigenen Variablen. JavaScript und Bash laufen bei jedem Aufruf als neuer Prozess.

## Befehle ausführen

`process.exec` startet für jeden Befehl einen eigenen Prozess; Python-Variablen bleiben daher zwischen Aufrufen nicht erhalten. Speichern Sie Zwischenergebnisse in Dateien. Der Aufruf liefert stdout, stderr und einen Exit-Code.

```ts
import { Sandbox } from '@lizard-build/sdk';

const sandbox = await Sandbox.create('interpreter', {
  projectId: 'proj_123', timeoutMs: 300_000,
});
try {
  const result = await sandbox.process.exec("python -c 'print(2 ** 10)'");
  console.log(result.stdout, result.stderr, result.exitCode);
} finally {
  await sandbox.kill();
}
```

```python
from lizard import Sandbox

sandbox = Sandbox.create("interpreter", project_id="proj_123", timeout_ms=300_000)
try:
    result = sandbox.process.exec_("python -c 'print(2 ** 10)'")
    print(result.stdout, result.stderr, result.exit_code)
finally:
    sandbox.kill()
```

## Speicher und Abrechnung

Dateien und laufende Prozesse bleiben verfügbar, solange die Sandbox läuft. Nach dem Stopp kann eine spätere Sandbox nur Dateien auf einem angehängten Persistent Volume unter `/workspace` wiederverwenden. Ohne Volume ist `/workspace` temporär. Ein Volume hängt jeweils an einer Sandbox und liegt auf einem einzelnen Knoten. Exportieren Sie Dateien, die einen Knotenausfall überstehen müssen.
