Im Dashboard erstellen und verwalten Sie Sandboxes ohne Code. Öffnen Sie ein Projekt und wählen Sie **Sandboxes** in der Seitenleiste. Erstellen Sie eine Sandbox mit **New Sandbox**: Wählen Sie eine Vorlage aus dem Katalog, eine Region und eine Größe: Small, Medium (Standard) oder Large. Die Standardregion ist nicht zwingend die nächste. Wählen Sie unter **Delete after** eine Laufzeit: 15 Minuten, 1 Stunde, 4 Stunden, 1 Tag, 7 Tage oder Never (Standard). In der Testphase bietet der Dialog nur Small in US-Regionen an. Die Zahl neben **New Sandbox** zeigt, wie viele Sandboxes im Verhältnis zu Ihrem Limit laufen.

<span id="api-keys" />

## API-Schlüssel

Für den Zugriff aus Code erstellen Sie unter Settings → API keys einen API-Schlüssel und speichern ihn in `LIZARD_API_KEY`. Lizard SDK und die [HTTP-API](/sandboxes/sdk-reference#http-api) lesen ihn; siehe den [Schnellstart](/sandboxes/quickstart).

<span id="inspect-and-stop" />

## Prüfen und stoppen

Die Detailansicht zeigt Status, Vorlage, Region, gemessene Nutzung und offene Ports. Im Kopfbereich stehen die Schaltflächen Pause und Resume, und der Reiter Terminal öffnet eine Shell in einer laufenden Sandbox.

Eine laufende Sandbox wird sekundengenau zum Stundenpreis ihrer Größe abgerechnet, Leerlauf eingeschlossen; eine pausierte nicht. Pausieren oder beenden Sie sie daher, wenn die Aufgabe erledigt ist. Siehe [Speicher und Abrechnung](/sandboxes#storage-and-billing).

<span id="templates-and-volumes" />

## Vorlagen und Volumes

Die Seitenleiste enthält außerdem **Volumes** (Persistent Volumes), **Templates** und **Agents**. **Templates** zeigt Plattformvorlagen und die im aktuellen Projekt erstellten Snapshots; aus beiden können Sie eine neue Sandbox starten. Snapshots erstellen Sie mit dem SDK oder der CLI. Kill Sandbox stoppt die Sandbox und trennt ihr Volume.

Volumes erstellen und hängen Sie mit dem SDK oder der CLI an; das Erstellungsformular bietet keine Volume-Option. **Volumes** zeigt Größe und angehängte Sandbox jedes Volumes und erlaubt es, Dateien zu durchsuchen, die Größe zu ändern oder das Volume zu löschen. Stoppen Sie die aktuelle Sandbox, bevor Sie das Volume an eine andere hängen.

**Agents** verbindet die Zugangsdaten, die Coding-Agents in Sandboxes nutzen, wie [`lizard agents`](/cli/agents).
