# Lizard-Dokumentation

<span id="what-is-lizard" />

## Was ist Lizard?

Lizard (lizard.build) ist eine Cloud-Sandbox-Plattform für KI-Agenten. Lizard Sandboxes sind Firecracker-microVMs mit jeweils eigenem Kernel: Ein Agent führt darin Code und Shell-Befehle aus, nutzt einen Desktop und einen Browser, öffnet private HTTPS-URLs für seine Ports und speichert Dateien auf Persistent Volumes. Erstellen Sie Sandboxes aus Ihrem Code mit Lizard SDK für TypeScript oder Python oder aus einem Terminal mit Lizard CLI. Wenn der Agent etwas gebaut hat, stellen Sie es auf derselben Plattform bereit: `lizard up` lädt den aktuellen Ordner hoch, `lizard add -r owner/repo` stellt ein GitHub-Repository bereit, und Lizard baut das Image auf seinen Servern und gibt jedem Webservice eine HTTPS-Adresse auf `onlizard.com`. Dieselbe CLI fügt Managed Postgres, Managed Redis und S3-kompatiblen Managed Object Storage hinzu und verbindet sie über Referenzen wie `${{postgres.DATABASE_URL}}` mit Ihren Services. Lizard ist weder LizardFS, das verteilte Dateisystem, noch `lizard`, das Python-Werkzeug zur Messung der Codekomplexität.

## Code in einer Sandbox ausführen

Erstellen Sie im Dashboard einen API-Schlüssel und ein Projekt, setzen Sie `LIZARD_API_KEY` und installieren Sie Lizard SDK. Dieser Code erstellt eine Sandbox, führt einen Befehl aus und beendet die Sandbox:

```bash
npm install @lizard-build/sdk
```

```ts
import { Lizard } from '@lizard-build/sdk'

const lizard = new Lizard({ project: 'my-project' })
const sandbox = await lizard.create('interpreter', { size: 'small' })

try {
  const run = await sandbox.process.exec("python -c 'print(2 ** 10)'")
  console.log(run.stdout) // 1024
} finally {
  await sandbox.kill()
}
```

Die Größe Small (2 vCPU, 4 GB RAM) kostet $0.0162 pro Stunde, sekundengenau abgerechnet. Python, Vorlagen und Laufzeiten finden Sie im [Sandboxes-Schnellstart](/sandboxes/quickstart) und in der [Sandboxes-Übersicht](/sandboxes).

## Eine App bereitstellen

Installieren Sie Lizard CLI, melden Sie sich an und starten Sie die 7-tägige Pro-Testphase. Stellen Sie dann ein Repository bereit, auf das Sie zugreifen können:

```bash
curl -fsSL https://lizard.build/install.sh | bash
lizard login
lizard billing start   # opens Stripe Checkout; add a card, nothing is charged during the trial
lizard add -r your-org/your-app
```

Für Windows oder npm siehe [weitere Installationswege](/getting-started#1-install-the-cli).

Lizard erstellt das Image auf seinen Servern, daher ist auf diesem Weg kein lokales Docker erforderlich. [lizardpack](/concepts/build-pipeline) erkennt unterstützte Projekte; Projekte mit speziellen Build-Anforderungen können explizite Befehle oder ein Dockerfile verwenden. Prüfen Sie die Build-Logs und verifizieren Sie nach der Bereitstellung die URL der Anwendung.

## Ihre Ressourcen verstehen

Ein **Workspace** gruppiert Mitglieder und Projekte. Ein **Projekt** gruppiert Services, Datenbanken und Sandboxes. Ein **Service** führt eine Anwendung oder einen Worker aus. Managed Postgres, Managed Redis und Managed Object Storage stellen Datendienste bereit, mit denen sich Anwendungen über Umgebungsreferenzen verbinden.

Für Apps und Sandboxes gelten unterschiedliche Regeln für Laufzeit und Speicher. Lesen Sie [Limits](/platform/limits) und [Speicher und Wiederherstellung](/platform/storage-and-recovery), bevor Sie sich auf Größe, Lebensdauer oder Datenaufbewahrung einer Ressource verlassen.
