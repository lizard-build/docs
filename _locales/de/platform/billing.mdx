# Abrechnung

Lizard (lizard.build) hat einen Plan zum Selbstbuchen: Pro. Er kostet $19 im Monat und enthält $19 monatliches Guthaben. Das Guthaben bezahlt die Nutzung auf der ganzen Plattform: Apps, Sandboxes, Managed Postgres, Managed Redis, Managed Object Storage, Persistent Volumes und ausgehenden Traffic. Ist das Guthaben aufgebraucht, zahlen Sie pay as you go zu den veröffentlichten Preisen.

Verwalten Sie Ihren Plan auf der Seite **Abrechnung** in den Kontoeinstellungen oder mit [`lizard billing`](/cli/billing). Der Plan gehört dem Eigentümer des Workspace. Die Nutzung in allen Workspaces, die Ihnen gehören, zählt zu Ihrem Plan, und für Mitglieder fällt keine Sitzplatzgebühr an.

## Pro

| | Pro |
| --- | --- |
| Preis | $19 im Monat |
| Monatliches Guthaben | $19 für die Nutzung auf der ganzen Plattform |
| Nutzung über das Guthaben hinaus | Pay as you go zu den [Ressourcenpreisen](#resource-rates) |
| Testphase | 7 Tage mit $5 Testguthaben |
| Zahlung | Karte, monatlich abgerechnet |

Pro verlängert sich jeden Monat, bis Sie kündigen. Nicht genutztes monatliches Guthaben wird nicht in den nächsten Monat übertragen.

<span id="monthly-credits-and-overage" />

## Monatliches Guthaben und Mehrnutzung

Jeder Monat beginnt mit $19 Guthaben, und die Nutzung wird zuerst davon abgezogen. Nutzung über $19 ist Mehrnutzung und kostet dieselben Preise.

Lizard belastet die Mehrnutzung, während sie anfällt, nicht in einer Rechnung am Monatsende. Erreicht die noch nicht berechnete Mehrnutzung $20, belastet Lizard Ihre Karte. Jede bezahlte Belastung hebt die nächste Stufe an: $100, dann $200, $400 und $1,000, danach jeweils $1,000. Jeden Monat beginnen die Stufen wieder bei $20. Am Monatsende kommt die noch nicht belastete Mehrnutzung auf eine letzte Rechnung. Es gibt keine Ausgabenobergrenze.

Die Seite „Abrechnung“ zeigt, wie viel Ihrer $19 Sie in diesem Monat genutzt haben, die bisherige Mehrnutzung und die nächste Belastung.

<span id="resource-rates" />

## Ressourcenpreise

Die Preise sind in US-Dollar.

| Ressource | Preis |
| --- | ---: |
| CPU | $0.000006948 pro vCPU-Sekunde |
| Arbeitsspeicher | $0.000003474 pro GB-Sekunde |
| Persistent Volumes | $0.000000054 pro GB-Sekunde |
| Managed Object Storage | $0.0135 pro GB-Monat |
| Ausgehender Traffic | $0.045 pro GB, ab dem ersten Byte |

Eingehender Traffic ist kostenlos. Apps, Managed Postgres und Managed Redis nutzen diese Preise. Sandboxes haben für jede Größe einen festen Stundenpreis; siehe [Sandbox-Größen](/platform/limits#sandbox-sizes).

Zum Beispiel kosten eine vCPU und 1 GB Arbeitsspeicher eine Stunde lang $0.0375192 an Rechenleistung. Speicher und ausgehender Traffic können hinzukommen. Das vollständige Angebot finden Sie unter [Preise](https://lizard.build/pricing).

<span id="trial" />

## Testphase

Mit einem neuen Konto können Sie sich umsehen, aber um Apps, Sandboxes, Datenbanken oder Volumes zu erstellen, brauchen Sie Pro. Pro beginnt mit einer 7-tägigen Testphase und $5 Testguthaben. Zum Start hinterlegen Sie eine Karte; Apple Pay funktioniert auch. Beim Start der Testphase wird nichts berechnet. Endet sie, beginnt Pro für $19 im Monat, sofern Sie nicht vorher kündigen.

Jedes Konto und jede Karte bekommt eine Testphase. Hatte das Konto schon eine, beginnt Pro sofort, und $19 werden am selben Tag belastet. Hatte die Karte schon eine, startet die Testphase nicht, und es wird nichts belastet; starten Sie Pro für $19 auf der Seite „Abrechnung“.

Die Testphase enthält alle Funktionen von Pro, mit niedrigeren [Limits](#limits) bis zur ersten bezahlten Rechnung.

<span id="when-trial-credits-run-out" />

### Wenn das Testguthaben aufgebraucht ist

- Ist Ihr Testguthaben aufgebraucht, pausieren laufende Ressourcen, und Sie können keine neuen erstellen. Ihre Daten bleiben erhalten.
- Um weiterzumachen, wählen Sie **Start Pro now** auf der Seite „Abrechnung“ oder führen `lizard billing start-now` aus. Damit endet die Testphase, $19 werden belastet, und Ihr erster bezahlter Monat beginnt mit $19 Guthaben. Pausierte Apps und Datenbanken starten wieder, sobald die Zahlung durch ist.

Nicht genutztes Testguthaben endet mit der Testphase. Es geht nicht in den bezahlten Monat über.

<span id="promo-codes" />

## Promo-Codes

Ein Promo-Code kann eine längere Testphase geben, bis zu 730 Tage, und mehr Testguthaben. Er ersetzt die üblichen 7 Tage und $5. Lösen Sie einen Code auf der Seite „Abrechnung“ oder mit `lizard billing promo <code>` ein.

- Vor dem Start der Testphase speichert Lizard den Code und wendet ihn an, wenn Sie Ihre Karte hinterlegen.
- Während der Testphase hebt ein Code Dauer und Guthaben auf das an, was der Code gibt. Er wird nicht zu dem addiert, was Sie schon haben.
- Codes gelten nur vor Ihrer ersten Zahlung.
- Jedes Konto und jede Karte kann einen Code nutzen.

## Limits

| | Testphase, bis zur ersten bezahlten Rechnung | Pro |
| --- | ---: | ---: |
| Gleichzeitig laufende Sandboxes | 5 | 100 |
| Replikas pro App | 1 | 5 |

Die Limits von Pro gelten ab Ihrer ersten bezahlten Rechnung, auch nach einer Zahlung über **Start Pro now**. Startraten für Sandboxes und weitere Limits finden Sie unter [Limits](/platform/limits#sandbox-account-limits).

<span id="payment-failures" />

## Fehlgeschlagene Zahlungen

Schlägt eine Belastung fehl, ob die monatlichen $19 oder eine Belastung für Mehrnutzung:

- Ab diesem Moment können Sie keine neuen Ressourcen erstellen.
- Laufende Ressourcen laufen noch 72 Stunden weiter und pausieren dann.
- Pausierte Ressourcen behalten ihre Daten.

Bezahlen Sie die offene Rechnung auf der Seite „Abrechnung“. Sobald sie bezahlt ist, hebt Lizard die Sperre auf und startet pausierte Apps und Datenbanken wieder. Pausierte Sandboxes setzen Sie selbst fort. Stripe versucht eine fehlgeschlagene Belastung erneut; schlägt auch der letzte Versuch fehl, endet Pro.

<span id="cancelling" />

## Kündigung

Sie können jederzeit kündigen: auf der Seite „Abrechnung“, im Kundenportal von Stripe oder mit `lizard billing cancel`. Pro bleibt bis zum Ende des laufenden Monats oder der Testphase aktiv. Die Mehrnutzung bis zu diesem Datum kommt auf eine letzte Rechnung. Eine Kündigung während der Testphase kostet nichts.

Bis zum Enddatum können Sie die Kündigung auf der Seite „Abrechnung“ oder mit `lizard billing resume` zurücknehmen.

Endet Pro, können Sie keine Ressourcen mehr erstellen, und laufende pausieren. Ihre Daten bleiben erhalten. Um sie wieder zu nutzen, starten Sie Pro auf der Seite „Abrechnung“. Eine zweite Testphase gibt es nicht, daher beginnt Pro sofort für $19.

## Enterprise

Enterprise-Konten zahlen pay as you go und erhalten jeden Monat eine Rechnung für den Vormonat. Preise, Limits und Zahlungsbedingungen richten sich nach Ihrem Vertrag. Wenn Sie mehr brauchen, als die Limits von Pro erlauben, fragen Sie uns auf der Seite [Preise](https://lizard.build/pricing) nach Enterprise.

<span id="idle-apps-and-stored-data" />

## Inaktive Apps und gespeicherte Daten

Eine App kann auch ohne Anfragen Arbeitsspeicher und CPU nutzen. Stoppen Sie die App, um die Rechennutzung zu beenden. Für Persistent Volumes und Managed Object Storage zahlen Sie, solange Sie Daten darin behalten, auch wenn die App gestoppt ist.

Lesen Sie [Speicher und Wiederherstellung](/platform/storage-and-recovery), bevor Sie Daten löschen. Unter [Metriken](/observability/metrics) vergleichen Sie konfigurierte Limits mit der gemessenen Nutzung.
