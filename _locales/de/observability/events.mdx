# Events & Verlauf

`lizard events` zeigt den Bereitstellen-Verlauf eines Service und den Live-Status seiner Replikate — die Zeitleiste dessen, was ausgeliefert wurde und was gerade läuft.

<span id="view-events" />

## Events anzeigen

```bash
lizard events                     # deploy history + replica status
lizard events --service api       # a specific service
lizard events --limit 5           # fewer entries (default and maximum 10)
```

Jeder Eintrag ist eine Bereitstellung: Status, Auslöser, Commit und Anzahl der Neustarts. Eine Tabelle Replicas über den Bereitstellungen zeigt den aktuellen Zustand jedes Pods; sie fehlt, solange der Service keine Pods hat, zum Beispiel während er pausiert ist oder schläft. Zusammen beantworten sie die Frage "Was hat sich geändert, und ist es gesund?" Eine Änderung der Replikate durch `lizard scale` erzeugt keine Bereitstellung und taucht daher nicht auf.

<span id="quick-status" />

## Schnellstatus

Für eine schnelle Übersicht aller Services im Projekt — Status und URL — verwende:

```bash
lizard ps
lizard status        # the current directory's workspace/project/service link
```

## Dashboard

Öffne einen Service im Dashboard (`lizard open`), um seinen Bereitstellen-Verlauf zu sehen. Jede Zeile einer Bereitstellung zeigt ihren Branch und ihre Commit-Nachricht; klicke auf eine, um ihre Build-Logs und Neustarts zu sehen. Das Service-Panel zeigt die laufenden und gewünschten Replikate.
