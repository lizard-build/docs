# lizard run

Запускает команду локально с внедрением секретов проекта и сервиса.

<span id="what-run-injects" />

## Что внедряет `run`

`lizard run` загружает секреты проекта, затем поверх них секреты сервиса и запускает вашу команду на вашем компьютере с этими секретами в окружении.

- Для сервиса-приложения внедряются сохранённые значения. Ссылки вида `${{postgres.DATABASE_URL}}` приходят как этот буквальный текст, а не как разрешённое значение. Платформенные переменные, такие как `PORT` и `LIZARD_*`, не внедряются.
- Для аддона (`--service postgres`, `--service redis`, `--service s3`) внедряются его реальные значения подключения, например `DATABASE_URL`.

Поэтому, чтобы запустить миграцию или клиент базы данных локально, указывайте в `--service` аддон, а не приложение, которое на него ссылается.

`lizard ssh` в запущенный сервис отключён (API отвечает 403 "Shell access to services is disabled"). Чтобы проверить, что получает запущенное приложение, используйте:

| Проверка | Команда |
|----------|---------|
| Пустые ссылки | `lizard logs --build --service api` (лог сборки предупреждает о каждой ссылке `${{…}}`, которая разрешилась в пустое значение) |
| Сохранённые значения | `lizard secrets list --service api --show` |
| Реальные значения подключения аддона | `lizard run --service postgres -- printenv DATABASE_URL` |

<span id="usage" />

## Использование

```bash
lizard run [flags] -- <command>
```

<span id="flags" />

## Флаги

| Флаг | Описание |
|------|----------|
| `-s, --service <name>` | Сервис, чьё окружение внедрять (по умолчанию — привязанный сервис) |
| `--no-service` | Не внедрять окружение сервиса, только секреты проекта |
| `-p, --project <id>` | Проект (по умолчанию — привязанный) |

<span id="examples" />

## Примеры

<span id="run-a-migration-against-managed-postgres" />

### Запуск миграции для Managed Postgres

```bash
lizard run --service postgres -- node scripts/migrate.js
```

<span id="print-an-injected-environment-variable" />

### Вывод внедрённой переменной окружения

```bash
lizard run --service postgres -- printenv DATABASE_URL
```

<span id="run-a-local-tool-with-an-apps-stored-secrets" />

### Запуск локального инструмента с сохранёнными секретами приложения

```bash
lizard run --service api -- node scripts/report.js
```
