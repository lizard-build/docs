# lizard run

Запускает команду локально с внедрением секретов проекта и сервиса.

## run vs. ssh

Две команды позволяют выполнять команды в контексте сервиса. Они выполняются в разных местах — важно понимать, какая вам нужна.

| Команда | Где выполняется | Для чего нужна |
|---------|----------------|----------------|
| `lizard run` | Локально, с внедрением секретов проекта и сервиса | Миграции, скрипты наполнения базы, локальные инструменты, требующие продакшн-конфигурацию |
| `lizard ssh` | Внутри запущенного контейнера сервиса | Инспекция живого контейнера, разовые удалённые команды, отладка |

`lizard run` показывает вашу локальную копию окружения с внедрёнными секретами, которая обычно совпадает с тем, что видит запущенное приложение — но `lizard ssh` является авторитетным источником для живого контейнера. Чтобы узнать, что на самом деле видит запущенное приложение, используйте `lizard ssh`.

<span id="usage" />

## Использование

```bash
lizard run [flags] -- <command>
```

<span id="flags" />

## Флаги

| Флаг | Описание |
|------|----------|
| `-s, --service <name>` | Сервис, чьё окружение внедрять |
| `--no-service` | Не внедрять окружение сервиса |

<span id="examples" />

## Примеры

<span id="run-a-migration-with-service-secrets-injected" />

### Запуск миграции с внедрением секретов сервиса

```bash
lizard run --service api -- node scripts/migrate.js
```

<span id="print-an-injected-environment-variable" />

### Вывод внедрённой переменной окружения

```bash
lizard run --service api -- printenv DATABASE_URL
```
