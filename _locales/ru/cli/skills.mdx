# lizard skills

Чтение встроенных навыков агентов, поставляемых с данной версией CLI. Псевдоним: `lizard skill`.

<span id="usage" />

## Использование

```bash
lizard skills list
lizard skills get core
lizard skills path
```

<span id="subcommands" />

## Подкоманды

### `lizard skills list`

Выводит список доступных встроенных навыков.

### `lizard skills get core`

Читает основное руководство — авторитетное руководство по использованию платформы, версионируемое вместе с CLI. С флагом `--json` возвращает `{ name, path, frontmatter, content }`, где `content` — это полное руководство (конвейер сборки, приоритет переменных окружения, аддоны, обнаружение, коды выхода).

### `lizard skills path [name]`

Выводит, откуда берётся навык. Навыки встроены в CLI, поэтому команда выводит `embedded://skills`, если только `LIZARD_SKILLS_DIR` не указывает CLI на каталог на диске.
