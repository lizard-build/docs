# lizard status

Показывает связанное рабочее пространство, проект и сервис для текущей директории. Вход не нужен.

В несвязанной директории команда выводит `Not linked`. Команды там используют проект по умолчанию вашего аккаунта, а `lizard up` привязывает к нему директорию.

<span id="usage" />

## Использование

```bash
lizard status
```

<span id="examples" />

## Примеры

<span id="check-the-current-directorys-link" />

### Проверить привязку текущей директории

```bash
lizard status
```

<span id="read-the-link-from-a-script" />

### Прочитать привязку из скрипта

```bash
lizard status --json
```

Для связанной директории выводятся `cwd`, `linked: true`, `workspace`, `workspaceId`, `project`, `projectId`, `service` и `serviceId`. Для несвязанной — `{"cwd": "…", "linked": false}`.
