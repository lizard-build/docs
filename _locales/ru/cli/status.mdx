# lizard status

Показывает связанное рабочее пространство, проект и сервис для текущей директории.

<span id="usage" />

## Использование

```bash
lizard status
```

<span id="examples" />

## Примеры

<span id="check-the-current-directorys-link" />

### Проверить привязку текущей директории

```bash
lizard status
```
