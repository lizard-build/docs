# lizard unlink

Отвязывает текущую директорию от любого проекта. Сам проект не меняется. После этого команды в этой директории используют проект по умолчанию вашего аккаунта, а `lizard up` снова привязывает к нему директорию.

<span id="usage" />

## Использование

```bash
lizard unlink
```

<span id="examples" />

## Примеры

<span id="unlink-the-current-directory" />

### Отвязать текущую директорию

```bash
lizard unlink
```
