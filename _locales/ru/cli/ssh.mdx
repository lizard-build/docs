# lizard ssh

> **Отключено.** Доступ к шеллу сервисов на Lizard отключён. `lizard ssh` получает HTTP 403 `Shell access to services is disabled` и завершается с кодом `1`.

Команда по-прежнему входит в состав CLI, но платформа отклоняет её для любого сервиса. Используйте вместо неё:

| Что проверить | Команда |
|---------------|---------|
| Ссылки, которые разрешились в пустое значение | `lizard logs --build --service api` (лог сборки предупреждает о каждой пустой ссылке `${{…}}`) |
| Значения, сохранённые в сервисе | `lizard secrets list --service api --show` |
| Команда с реальными значениями подключения аддона | `lizard run --service postgres -- <cmd>` |
| Что приложение выводит во время работы | `lizard logs --service api` |

Для шелла в sandbox используйте [`lizard sandbox ssh <id>`](/cli/sandbox#sandbox-ssh). Он по-прежнему работает.

## Использование

```bash
lizard ssh --service <name> -- <command>
```

| Флаг | Описание |
|------|----------|
| `-s, --service <id>` | Имя или ID сервиса |
| `-p, --project <id>` | Имя, slug или ID проекта |
