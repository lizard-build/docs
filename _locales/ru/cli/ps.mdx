# lizard ps

Выводит список всех сервисов в проекте с их статусом и URL.

<span id="usage" />

## Использование

```bash
lizard ps [flags]
```

<span id="flags" />

## Флаги

| Флаг | Описание |
|------|-------------|
| `-p, --project <id>` | Имя, slug или ID проекта |

Без `-p` команда `ps` использует связанный проект, а в несвязанной папке — ваш проект по умолчанию.

<span id="examples" />

## Примеры

<span id="list-services-in-the-linked-project" />

### Список сервисов в связанном проекте

```bash
lizard ps
```

<span id="list-services-in-another-project" />

### Список сервисов в другом проекте

```bash
lizard ps -p my-project
```
