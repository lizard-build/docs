# lizard volume

Управляйте [Persistent Volumes](/sandboxes/volumes) для sandboxes и сервисов. Псевдоним: `lizard vol`.

<span id="usage" />

## Использование

```bash
lizard volume list [flags]
lizard volume create <name> [flags]
lizard volume resize <volume> --size <gb> [flags]
lizard volume rm <volume> [flags]
```

Имя тома — его ключ в рамках проекта. Каждая команда принимает имя или ID, а также `-p, --project`, чтобы указать проект, отличный от связанного. В несвязанной папке команды используют проект по умолчанию вашего аккаунта.

<span id="subcommands" />

## Подкоманды

### `lizard volume list`

Выводит список томов проекта с размером, статусом и sandbox, к которому они подключены (псевдоним `ls`). `--json` дополнительно включает сгенерированные ID. `-s, --service <name>` вместо этого показывает том, подключённый к этому сервису.

### `lizard volume create <name>`

Создаёт том. Имена состоят из строчных букв, цифр и дефисов, начинаются и заканчиваются буквой или цифрой, содержат не более 64 символов и уникальны в рамках проекта.

| Флаг | Описание |
|------|-------------|
| `--size <gb>` | Размер в целых ГБ (по умолчанию 5); том для sandbox занимает от 1 до 50. Сначала CLI считывает текущие лимиты сервера |
| `--region <code>` | Регион тома; он должен совпадать с регионом sandbox, который его подключит |
| `-s, --service <name>` | Создать том и подключить его к этому сервису. У сервиса может быть не больше одного тома, и его файлы сохраняются при перезапусках и повторных деплоях |
| `--mount-path <path>` | С `--service`: где сервис видит том (по умолчанию `/data`) |
| `-p, --project <id>` | Имя проекта, slug или ID |

Тома sandbox одного рабочего пространства могут занимать в сумме до 200 ГБ выделенного размера. `create` или `resize` сверх этого завершается ошибкой HTTP 403 с кодом `volume_quota_exceeded`.

### `lizard volume resize <volume> --size <gb>`

Увеличивает том на месте; данные не копируются. Sandbox, к которому подключён том, продолжает работать, но видит прежний размер. Новый размер видит следующий sandbox, который подключит том, поэтому, чтобы получить его сразу, удалите sandbox и создайте новый с `--volume`. Том можно только увеличить. Некоторые тома, созданные до октября 2026 года, можно и уменьшить, если после этого свободными остаются не менее 10% нового размера.

### `lizard volume rm <volume>`

Удаляет том и его данные (псевдоним `delete`). Команда завершается ошибкой, пока том подключён; сначала удалите sandbox.

| Флаг | Описание |
|------|-------------|
| `-y, --yes` | Пропустить подтверждение |

Хранение тома для sandbox стоит $0.14 за ГБ-месяц используемого пространства. См. [Размер и цена](/sandboxes/volumes#size-and-price).

## Примеры

<span id="create-a-volume-and-attach-it" />

### Создание тома и его подключение

```bash
lizard volume create agent-workdir --size 10
lizard sandbox create --volume agent-workdir
```

<span id="grow-a-volume" />

### Увеличение тома

```bash
lizard volume resize agent-workdir --size 20
```

<span id="delete-a-volume" />

### Удаление тома

```bash
lizard volume rm agent-workdir --yes
```
