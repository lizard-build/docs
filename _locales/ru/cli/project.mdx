# lizard project

Вывод списка или создание проектов в рабочей области.

<span id="usage" />

## Использование

```bash
lizard project list
lizard project create
```

<span id="subcommands" />

## Подкоманды

### `lizard project list`

Выводит все проекты в рабочей области.

### `lizard project create`

Создаёт новый проект.
