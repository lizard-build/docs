# lizard project

Вывод списка, создание, пауза, возобновление или удаление проектов.

<span id="usage" />

## Использование

```bash
lizard project list [flags]
lizard project create <name> [flags]
lizard project pause [project]
lizard project resume [project]
lizard project delete <project> [flags]
```

<span id="subcommands" />

## Подкоманды

### `lizard project list`

Выводит ваши проекты из всех рабочих областей или из одной рабочей области, если указан флаг `-w`.

| Флаг | Описание |
|------|----------|
| `-w, --workspace <ws>` | Только эта рабочая область (id, slug или имя) |

### `lizard project create <name>`

Создаёт проект. Текущая директория при этом не связывается с проектом; для этого используйте [`lizard init`](/cli/init).

| Флаг | Описание |
|------|----------|
| `-w, --workspace <ws>` | Рабочая область, в которой нужно создать проект |

### `lizard project pause [project]`

Ставит на паузу все приложения и базы данных проекта, а также его запущенные sandbox. Сервисы сохраняют URL, пароли, настройки и данные. См. [`lizard pause`](/cli/pause).

### `lizard project resume [project]`

Возобновляет приложения и базы данных, которые вы поставили на паузу в проекте, и sandbox, которые поставила на паузу команда `project pause`.

### `lizard project delete <project>`

Перемещает проект в корзину (псевдоним `rm`). Удалить проект может только его владелец. Сервисы и базы данных проекта останавливаются; их можно восстановить из корзины в дашборде в течение 3 дней, после этого Lizard удаляет их безвозвратно.

> **Внимание:** у sandbox нет корзины. `project delete` сразу удаляет sandbox проекта, их тома и снимки, и вернуть их нельзя.

`delete` требует имя проекта. Он никогда не берёт проект, привязанный к директории, или проект по умолчанию вашего аккаунта. Без аргумента `pause` и `resume` используют проект, привязанный к этой директории, а в несвязанной директории — проект по умолчанию вашего аккаунта.

| Флаг | Описание |
|------|----------|
| `-y, --yes` | Пропустить подтверждение (обязателен без TTY) |

## Примеры

<span id="list-projects-in-the-workspace" />

<span id="list-projects" />

### Вывод списка проектов

```bash
lizard project list
lizard project list --workspace my-team
```

<span id="create-a-new-project" />

### Создание нового проекта

```bash
lizard project create my-project
lizard project create my-project --workspace my-team
```

<span id="pause-and-resume-a-project" />

### Пауза и возобновление проекта

```bash
lizard project pause my-project
lizard project resume my-project
```

<span id="delete-a-project" />

### Удаление проекта

```bash
lizard project delete my-project --yes
```
