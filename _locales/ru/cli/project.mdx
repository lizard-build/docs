# lizard project

Вывод списка, создание или удаление проектов.

<span id="usage" />

## Использование

```bash
lizard project list [flags]
lizard project create <name> [flags]
lizard project delete [project] [flags]
```

<span id="subcommands" />

## Подкоманды

### `lizard project list`

Выводит ваши проекты из всех рабочих областей или из одной рабочей области, если указан флаг `-w`.

| Флаг | Описание |
|------|----------|
| `-w, --workspace <ws>` | Только эта рабочая область (id, slug или имя) |

### `lizard project create <name>`

Создаёт проект. Текущая директория при этом не связывается с проектом; для этого используйте [`lizard init`](/cli/init).

| Флаг | Описание |
|------|----------|
| `-w, --workspace <ws>` | Рабочая область, в которой нужно создать проект |

### `lizard project delete [project]`

Перемещает проект в корзину (псевдоним `rm`). Его сервисы останавливаются. Проект можно восстановить в течение 3 дней, после этого Lizard удаляет его безвозвратно. Без аргумента удаляет проект, связанный с этой директорией.

| Флаг | Описание |
|------|----------|
| `-y, --yes` | Пропустить подтверждение (обязателен без TTY) |

## Примеры

<span id="list-projects-in-the-workspace" />

<span id="list-projects" />

### Вывод списка проектов

```bash
lizard project list
lizard project list --workspace my-team
```

<span id="create-a-new-project" />

### Создание нового проекта

```bash
lizard project create my-project
lizard project create my-project --workspace my-team
```

<span id="delete-a-project" />

### Удаление проекта

```bash
lizard project delete my-project --yes
```
