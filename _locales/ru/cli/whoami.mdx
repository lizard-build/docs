# lizard whoami

Показывает аккаунт, в который вы вошли, а в привязанной папке — привязанный проект и его рабочее пространство.

<span id="usage" />

## Использование

```bash
lizard whoami
```

<span id="what-it-shows" />

## Что показывает команда

- Если вы вошли в аккаунт: имя пользователя, подключено ли GitHub App, и привязанный проект с его рабочим пространством в скобках. В непривязанной папке выводится `Project: none`; команды там используют проект по умолчанию вашего аккаунта.
- Если вы вошли с API-ключом с ограниченной областью: `Scoped API key (account details are not visible)`, а затем каждый проект или рабочее пространство, к которым у ключа есть доступ. Аккаунт, которому принадлежит ключ, команда не показывает.

`whoami` не показывает активное рабочее пространство. Список рабочих пространств выводит [`lizard workspace list`](/cli/workspace).

С `--json` или когда вывод идёт не в терминал, команда печатает поля вашего аккаунта и `project`. Для ключа с ограниченной областью она печатает `{ "scoped": true, "scopes": [...], "project": ... }`.
