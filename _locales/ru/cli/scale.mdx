# lizard scale

Масштабирование сервиса (реплики / CPU / память / хранилище).

<span id="usage" />

## Использование

```bash
lizard scale [flags]
```

<span id="flags" />

## Флаги

| Флаг | Описание |
|------|-------------|
| `--replicas <n>` | Реплики `1`–`10` (приложения) |
| `--cpu <cores>` | `1`, `2`, `3` или `4` |
| `--memory <mb>` | `128`–`8192` МБ |
| `--storage <mb>` | Размер тома аддона, только увеличение |

<span id="examples" />

## Примеры

<span id="scale-replicas-horizontally" />

### Горизонтальное масштабирование реплик

```bash
lizard scale --service api --replicas 5
```

Каждая реплика — это отдельный под за балансировщиком нагрузки. Убедитесь, что ваше приложение stateless, чтобы реплики были взаимозаменяемы.

<span id="scale-cpu-and-memory-vertically" />

### Вертикальное масштабирование CPU и памяти

```bash
lizard scale --service api --cpu 4 --memory 8192
```

<span id="grow-addon-storage" />

### Увеличение хранилища аддона

```bash
lizard scale --service postgres --storage 8192
```

Тома данных аддонов поддерживают только увеличение — вы можете расширить хранилище, но не уменьшить его.
