# lizard open

Открыть проект в браузере.

<span id="usage" />

## Использование

```bash
lizard open [flags]
```

<span id="flags" />

## Флаги

| Флаг | Описание |
|------|-------------|
| `-p, --project <id>` | Имя, slug или ID проекта |

Без `-p` команда `open` использует связанный проект, а в несвязанной папке — ваш проект по умолчанию. С `--json` она выводит `{ url, opened: false }` и не открывает браузер.

<span id="examples" />

## Примеры

<span id="open-the-current-projects-dashboard" />

### Открыть панель управления текущего проекта

```bash
lizard open
```

<span id="print-the-dashboard-url" />

### Вывести URL панели управления

```bash
lizard open --json
```
