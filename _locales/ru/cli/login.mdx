# lizard login

Выполните вход в Lizard и подключите тариф, если у аккаунта его нет.

<span id="usage" />

## Использование

```bash
lizard login [flags]
```

В терминале `login` спрашивает, как вы входите, через GitHub или Google, открывает эту страницу в браузере и ждет подтверждения. Если аккаунт у вас уже есть, выберите способ, которым регистрировались: другой способ создаст второй, пустой аккаунт, если у них нет общего подтвержденного email. Ссылка действует 5 минут.

После входа `login` проверяет тариф. Аккаунту без тарифа предлагается 7-дневный пробный период Pro, а если пробный период уже был, то Pro за $19 в месяц. Если согласиться, откроется Stripe Checkout. В конце команда перечисляет, что можно запустить дальше.

На машине, где вход уже выполнен, `login` показывает аккаунт и сразу переходит к тарифу, поэтому команду можно запускать повторно. Чтобы сменить аккаунт, сначала выполните [`lizard logout`](/cli/logout).

Скрипты установки запускают `lizard login` последним шагом. Задайте `LIZARD_NO_LOGIN=1`, чтобы пропустить его; в CI скрипты пропускают его сами.

Запускать `login` перед другими командами обычно не нужно: любая команда, запущенная в терминале на машине без входа, сначала выполнит вход, а потом продолжит работу.

<span id="flags" />

## Флаги

| Флаг | Описание |
|------|-------------|
| `--github` | Вход через GitHub, без вопроса |
| `--google` | Вход через Google, без вопроса |
| `--token <token>` | Вход по API-ключу (`liz_…`) |
| `--token-stdin` | Прочитать API-ключ из stdin, чтобы он не попал в список процессов и историю команд |

<span id="output-for-agents" />

## Вывод для агентов

С флагом `--json` или когда stdout не терминал, `login` выводит один JSON-объект. Браузер при этом не открывается, и команда ничего не ждет.

- До входа выводятся `status: "pending"`, `authUrls` со ссылкой для каждого способа, `authUrl`, `expiresAt` и `instruction`. Передайте ссылку пользователю и запустите команду снова, когда браузер покажет «CLI authorized».
- После входа выводятся `status: "complete"`, имя пользователя, `account.state` с `instruction` о тарифе и список команд `next`.

Тариф команда сама не подключает. Чтобы подключить его, выполните [`lizard billing start --json`](/cli/billing) и передайте пользователю ссылку на Checkout из `url`.

Другие команды без терминала ведут себя так же: они завершаются с кодом выхода `2` и кодом ошибки `NOT_AUTHENTICATED`, а тело ошибки содержит те же ссылки в поле `login`.

<span id="examples" />

## Примеры

<span id="log-in-via-browser" />

### Вход через браузер

```bash
lizard login
lizard login --google   # skip the question
```

<span id="log-in-with-a-token" />

<span id="log-in-with-an-api-key" />

### Вход с API-ключом

Создайте ключ с помощью [`lizard keys create <name>`](/cli/keys), затем выполните:

```bash
lizard login --token liz_xxx
# or, to keep the key out of shell history
printf '%s' "$LIZARD_TOKEN" | lizard login --token-stdin
```

<span id="log-in-non-interactively-in-ci" />

### Неинтерактивный вход в CI

В CI или других неинтерактивных средах задайте `LIZARD_TOKEN` (или `LIZARD_API_KEY`) в переменных окружения вместо запуска `login`:

```bash
export LIZARD_TOKEN=liz_xxx
```
