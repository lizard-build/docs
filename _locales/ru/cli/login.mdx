# lizard login

Выполните вход в Lizard.

<span id="usage" />

## Использование

```bash
lizard login [flags]
```

По умолчанию открывается страница входа в браузере, её URL выводится в терминал, и команда завершается. После входа выполните следующую команду (например, `lizard whoami`): она завершит вход и сохранит ваши учётные данные. С флагом `--json` команда `login` выводит `{ "status": "pending", "authUrl": "…" }` и не открывает браузер.

<span id="flags" />

## Флаги

| Флаг | Описание |
|------|-------------|
| `--token <token>` | Аутентификация с помощью API-ключа (`liz_…`) |

<span id="examples" />

## Примеры

<span id="log-in-via-browser" />

### Вход через браузер

```bash
lizard login
```

<span id="log-in-with-a-token" />

<span id="log-in-with-an-api-key" />

### Вход с API-ключом

Создайте ключ с помощью [`lizard keys create <name>`](/cli/keys), затем выполните:

```bash
lizard login --token liz_xxx
```

<span id="log-in-non-interactively-in-ci" />

### Неинтерактивный вход в CI

В CI или других неинтерактивных средах задайте `LIZARD_TOKEN` (или `LIZARD_API_KEY`) в переменных окружения вместо запуска `login`:

```bash
export LIZARD_TOKEN=liz_xxx
```
