# lizard regions

Выводит список доступных регионов.

<span id="usage" />

## Использование

```bash
lizard regions [flags]
```

<span id="flags" />

## Флаги

| Флаг | Описание |
|------|-------------|
| `--json` | Вывод в формате JSON |

<span id="examples" />

## Примеры

<span id="list-available-regions" />

### Список доступных регионов

```bash
lizard regions
```

<span id="list-regions-as-json" />

### Список регионов в формате JSON

```bash
lizard regions --json
```

<span id="choose-a-region-when-creating-a-service-or-addon" />

<span id="choose-a-region-when-you-create-a-resource" />

### Выбор региона при создании ресурса

Передайте `--region <code>` в `lizard add`, `lizard up`, `lizard sandbox create` или `lizard volume create`:

```bash
lizard add -r your-org/your-app --region <code>
lizard add postgres --region <code>
lizard up --region <code>
```

Без `--region` команда `lizard add` использует `us-east-1`, а `lizard up` — регион платформы по умолчанию. В `lizard up` флаг `--region` действует только при создании нового сервиса.
