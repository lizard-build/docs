# lizard git

Подключите аккаунт Lizard к GitHub, посмотрите, из каких репозиториев разворачиваются сервисы проекта, и переключите сервис на другую ветку. Подключение GitHub App относится к вашему аккаунту Lizard, а не к отдельному проекту.

Остальные подкоманды `lizard git` относятся к Lizard Git, и эта страница их не описывает.

<span id="usage" />

## Использование

```bash
lizard git connect
lizard git status [flags]
lizard git checkout <service> <branch> [flags]
```

Без `-p` команды `status` и `checkout` используют связанный проект, а в несвязанной папке — ваш проект по умолчанию.

<span id="subcommands" />

## Подкоманды

### `lizard git connect`

Подключить GitHub App для доступа к приватным репозиториям. Команда открывает GitHub для установки приложения, ждёт, пока вы нажмёте Enter, и проверяет подключение. Если приложение уже подключено, она сообщает об этом. С `--json` или без терминала она вместо этого выводит URL установки: `{ installed: false, installUrl }`.

### `lizard git status`

Показать, подключено ли GitHub App, и из какого репозитория и ветки разворачивается каждый сервис проекта.

| Флаг | Описание |
|------|-------------|
| `-p, --project <id>` | Имя, slug или ID проекта |

### `lizard git checkout <service> <branch>`

Переключить сервис на другую ветку и выполнить повторный деплой.

| Флаг | Описание |
|------|-------------|
| `--detach` | Пропустить стриминг логов |
| `-p, --project <id>` | Имя, slug или ID проекта |

## Примеры

<span id="connect-the-github-app" />

### Подключить GitHub App

```bash
lizard git connect
```

<span id="check-connection-and-repository-status" />

### Проверить подключение и статус репозитория

```bash
lizard git status
```

<span id="switch-a-service-to-a-different-branch" />

### Переключить сервис на другую ветку

```bash
lizard git checkout api staging
```

<span id="switch-branches-without-streaming-logs" />

### Переключить ветки без стриминга логов

```bash
lizard git checkout api staging --detach
```
