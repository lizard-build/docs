# lizard events

Показать историю развёртываний и статус реплик.

<span id="usage" />

## Использование

```bash
lizard events [flags]
```

<span id="flags" />

## Флаги

| Флаг | Описание |
|------|-------------|
| `-n, --limit <n>` | Количество записей для показа (по умолчанию 10) |
| `-s, --service <name>` | Показать события для конкретного сервиса |

<span id="examples" />

## Примеры

<span id="show-deploy-history-and-replica-status" />

### Показать историю развёртываний и статус реплик

```bash
lizard events
```

<span id="show-events-for-a-specific-service" />

### Показать события для конкретного сервиса

```bash
lizard events --service api
```

<span id="show-more-entries" />

### Показать больше записей

```bash
lizard events --limit 25
```
