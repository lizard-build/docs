# lizard domain

Показывает текущий домен или привязывает пользовательский.

<span id="usage" />

## Использование

```bash
lizard domain [hostname] [flags]
```

Имя хоста — позиционный аргумент, отдельного `add` подкоманды нет. Запуск `lizard domain` без аргументов показывает текущий домен сервиса или создаёт его, если домена ещё нет. Алиас: `lizard domains`.

<span id="flags" />

## Флаги

| Флаг | Описание |
|------|-------------|
| `-s, --service <name>` | Сервис |
| `-p, --project <id>` | Название, slug или ID проекта |
| `--port <n>` | Порт для публикации |
| `-f, --force` | Перенести домен сюда, если он привязан к другому вашему сервису |

Подкоманды используют те же флаги `-s` и `-p`. Проверяйте и удаляйте домен на том сервисе, к которому вы его привязали.

<span id="subcommands" />

## Подкоманды

### `lizard domain generate`

Создаёт новый поддомен `*.onlizard.com`.

### `lizard domain verify <hostname>`

Проверяет TXT-запись и активирует домен. TLS выпускается автоматически.

### `lizard domain delete <hostname>`

Удаляет домен (алиас `rm`).

| Флаг | Описание |
|------|-------------|
| `-y, --yes` | Пропустить подтверждение |

<span id="examples" />

## Примеры

<span id="show-the-current-domain" />

### Показать текущий домен

```bash
lizard domain
```

<span id="generate-a-subdomain" />

### Создать поддомен

```bash
lizard domain generate
```

<span id="attach-a-custom-domain" />

### Привязать пользовательский домен

```bash
lizard domain app.example.com --service web
```

Lizard возвращает DNS-записи для создания: `CNAME` для имени хоста и, если вы ещё не проверили домен, `TXT`-запись в `_lizard-verify.<apex domain>` (для `app.example.com` это `_lizard-verify.example.com`). Добавьте их у вашего DNS-провайдера, затем выполните проверку на том же сервисе:

```bash
lizard domain verify app.example.com --service web
```

<span id="attach-a-domain-to-a-specific-port" />

### Привязать домен к конкретному порту

```bash
lizard domain app.example.com --service web --port 8080
```

<span id="move-a-domain-from-another-of-your-services" />

### Перенести домен с другого вашего сервиса

```bash
lizard domain app.example.com --service web --force
```

<span id="remove-a-domain" />

### Удалить домен

```bash
lizard domain delete app.example.com --service web
lizard domain rm app.example.com --service web --yes
```
