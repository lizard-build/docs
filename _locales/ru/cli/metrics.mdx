# lizard metrics

Показывает CPU / память / сеть / диск и стоимость.

<span id="usage" />

## Использование

```bash
lizard metrics [flags]
```

<span id="flags" />

## Флаги

| Флаг | Описание |
|------|-------------|
| `-s, --service <id>` | Сервис (по умолчанию — связанный сервис) |
| `-p, --project <id>` | Название, slug или ID проекта |
| `--all` | Все сервисы проекта, без учёта связанного сервиса; нельзя использовать вместе с `-s` |
| `-r, --range <range>` | Временное окно: `1h` (по умолчанию), `6h`, `24h`, `7d`, `14d` или `30d` |
| `-w, --watch` | Живой режим с обновлением каждые 3 секунды; нельзя использовать вместе с `--json` |
| `--cost` | Запущенные ресурсы, стоимость в час, использование за текущий расчётный период и использование Pro в этом месяце. Только для владельца рабочего пространства |

Без связанного сервиса или `-s` команда `metrics` показывает обзор всех сервисов проекта.

<span id="examples" />

## Примеры

<span id="view-metrics-for-the-current-service" />

### Просмотр метрик для текущего сервиса

```bash
lizard metrics
```

<span id="view-metrics-for-a-specific-service" />

### Просмотр метрик для конкретного сервиса

```bash
lizard metrics --service api
```

<span id="watch-metrics-live" />

### Живой просмотр метрик

```bash
lizard metrics --watch
```

<span id="include-cost" />

### С включением стоимости

```bash
lizard metrics --cost
```
