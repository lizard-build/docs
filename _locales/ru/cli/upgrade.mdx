# lizard upgrade

Обновите CLI до последней версии.

<span id="usage" />

## Использование

```bash
lizard upgrade [flags]
```

Способ обновления зависит от того, как вы установили CLI:

- **Установочный скрипт на macOS или Linux:** загружает последний релиз и заменяет бинарный файл.
- **npm:** выводит команду, которую нужно выполнить, `npm install -g @lizard-build/cli@latest`.
- **Windows:** бинарный файл не может заменить сам себя. Запустите установщик ещё раз: `irm https://lizard.build/api/cli/install.ps1 | iex`.

<span id="flags" />

## Флаги

| Флаг | Описание |
|------|-------------|
| `--check` | Проверить наличие новой версии без установки |

<span id="examples" />

## Примеры

<span id="update-to-the-latest-version" />

### Обновление до последней версии

```bash
lizard upgrade
```

<span id="check-for-updates-without-installing" />

### Проверка обновлений без установки

```bash
lizard upgrade --check
```
