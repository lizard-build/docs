# lizard secrets

Управляйте секретами (переменными окружения) проекта или сервиса.

<span id="usage" />

## Использование

```bash
lizard secrets <subcommand> [args] [flags]
```

<span id="subcommands" />

## Подкоманды

### `lizard secrets set <K=V>...`

Устанавливает один или несколько секретов (вариадический). По умолчанию область — сервис; `--global` задаёт проект.

| Флаг | Описание |
|------|-------------|
| `--global` | Область проекта |
| `-s, --service <name>` | Область сервиса |

### `lizard secrets list`

Выводит список секретов в области.

| Флаг | Описание |
|------|-------------|
| `--show` | Показать значения |
| `--ref` | Показать ссылки |

### `lizard secrets delete <K>...`

Удаляет один или несколько секретов (вариадический).

### `lizard secrets import`

Импортирует dotenv-файл из stdin.

<span id="examples" />

## Примеры

<span id="set-secrets-on-the-linked-service" />

### Установка секретов на связанном сервисе

```bash
lizard secrets set DATABASE_URL=postgres://… LOG_LEVEL=info
lizard secrets set API_KEY=sk_live_… --service api
```

<span id="set-a-project-wide-secret" />

### Установка секрета на уровне проекта

```bash
lizard secrets set NODE_ENV=production --global
```

<span id="list-and-reveal-secrets" />

### Вывод списка секретов с раскрытием значений

```bash
lizard secrets list
lizard secrets list --show
```

<span id="delete-secrets" />

### Удаление секретов

```bash
lizard secrets delete OLD_KEY ANOTHER_KEY
```

<span id="import-a-dotenv-file" />

### Импорт dotenv-файла

```bash
cat .env | lizard secrets import
```
