# lizard port

Показать или изменить контейнерный порт для сервиса. Без аргументов выводит текущий порт (`worker mode`, когда он `0`). Новый порт вступает в силу при следующем деплое; выполните [`lizard redeploy`](/cli/redeploy), чтобы применить его.

<span id="usage" />

## Использование

```bash
lizard port [value] [flags]
```

<span id="flags" />

## Флаги

| Флаг | Описание |
|------|-------------|
| `-s, --service <name>` | Сервис для управления |
| `-p, --project <id>` | Имя проекта, slug или ID |

<span id="examples" />

## Примеры

<span id="show-the-current-port" />

### Показать текущий порт

```bash
lizard port
```

<span id="set-the-port-for-a-specific-service" />

### Установить порт для конкретного сервиса

```bash
lizard port 0 -s worker
```

<span id="check-the-port-on-a-worker-service" />

### Проверить порт рабочего сервиса

```bash
lizard port --service worker
```
