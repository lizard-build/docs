# lizard port

Показать или изменить контейнерный порт для сервиса. Без аргументов выводит текущий порт (`worker mode`, когда он `0`).

<span id="usage" />

## Использование

```bash
lizard port [value] [flags]
```

<span id="flags" />

## Флаги

| Флаг | Описание |
|------|-------------|
| `-s, --service <name>` | Сервис для управления |

<span id="examples" />

## Примеры

<span id="show-the-current-port" />

### Показать текущий порт

```bash
lizard port
```

<span id="set-the-port-for-a-specific-service" />

### Установить порт для конкретного сервиса

```bash
lizard port 0 -s worker
```

<span id="check-the-port-on-a-worker-service" />

### Проверить порт рабочего сервиса

```bash
lizard port --service worker
```
