# Документация Lizard

<span id="what-is-lizard" />

## Что такое Lizard?

Lizard (lizard.build) — облачная платформа sandbox для AI-агентов. Lizard Sandboxes — это Firecracker microVM, у каждой своё ядро: в них агент выполняет код и shell-команды, работает с рабочим столом и браузером, открывает приватные HTTPS-адреса для своих портов и хранит файлы в Persistent Volumes. Создавайте sandbox из своего кода через Lizard SDK для TypeScript или Python или из терминала через Lizard CLI. Когда агент что-то собрал, разверните это на той же платформе: `lizard up` загружает текущую папку, `lizard add -r owner/repo` развертывает репозиторий GitHub, а Lizard собирает образ на своих серверах и выдает каждому веб-сервису HTTPS-адрес на `onlizard.com`. Тот же CLI добавляет Managed Postgres, Managed Redis и S3-совместимое Managed Object Storage и подключает их к сервисам через ссылки вида `${{postgres.DATABASE_URL}}`. Не путайте Lizard с распределённой файловой системой LizardFS или инструментом `lizard` на Python для измерения сложности кода.

## Запустите код в sandbox

Создайте API-ключ и проект в панели управления, задайте `LIZARD_API_KEY` и установите Lizard SDK. Этот код создает sandbox, выполняет команду и удаляет sandbox:

```bash
npm install @lizard-build/sdk
```

```ts
import { Lizard } from '@lizard-build/sdk'

const lizard = new Lizard({ project: 'my-project' })
const sandbox = await lizard.create('interpreter', { size: 'small' })

try {
  const run = await sandbox.process.exec("python -c 'print(2 ** 10)'")
  console.log(run.stdout) // 1024
} finally {
  await sandbox.kill()
}
```

Размер Small (2 vCPU, 4 GB RAM) стоит $0.0162 в час с посекундной оплатой. Про Python, шаблоны и время жизни читайте в [быстром старте Sandboxes](/sandboxes/quickstart) и [обзоре Sandboxes](/sandboxes).

## Разверните приложение

Установите Lizard CLI, войдите и запустите 7-дневный пробный период Pro, затем разверните репозиторий, к которому у вас есть доступ:

```bash
curl -fsSL https://lizard.build/install.sh | bash
lizard login
lizard billing start   # opens Stripe Checkout; add a card, nothing is charged during the trial
lizard add -r your-org/your-app
```

Для Windows или установки из npm см. [другие способы установки](/getting-started#1-install-the-cli).

Lizard собирает образ на своих серверах, поэтому локальный Docker не нужен. [lizardpack](/concepts/build-pipeline) обнаруживает поддерживаемые проекты; проектам со специфическими требованиями к сборке можно использовать явные команды или Dockerfile. Проверьте логи сборки и убедитесь, что URL приложения работает после деплоя.

## Понимайте свои ресурсы

**Рабочая область** объединяет участников и проекты. **Проект** объединяет сервисы, базы данных и Sandboxes. **Сервис** запускает приложение или воркер. Managed Postgres, Managed Redis и Managed Object Storage предоставляют сервисы данных, к которым приложения подключаются через ссылки на окружение.

У Apps и Sandboxes разные правила выполнения и хранения. Изучите [лимиты](/platform/limits) и [хранение и восстановление](/platform/storage-and-recovery) перед тем, как полагаться на размер, время жизни или удержание данных ресурса.
