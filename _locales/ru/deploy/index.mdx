# Деплой

Всё о запуске сервиса на Lizard и его поддержке — от первого пуша до масштабирования и размещения по регионам.

Сравниваете с другим хостингом? В блоге объясняется, чем отличаются платформы [container as a service](https://lizard.build/blog/container-as-a-service) и как оценить их стоимость.

<span id="in-this-section" />

## В этом разделе

- [Деплой из GitHub](/deploy/github) — подключите репозиторий, чтобы пуши в отслеживаемую ветку автоматически перезапускали деплой.
- [Деплой из локального кода](/deploy/upload) — отправьте текущую директорию с помощью `lizard up`, Git не требуется.
- [Деплой из Dockerfile](/deploy/dockerfile) — соберите и запустите свой Docker-контейнер или оберните публичный образ.
- [Версии рантайма](/deploy/runtime-versions) — задайте версию Node.js, Python, Go или Ruby через `.nvmrc`, `.python-version`, `go.mod` или `.ruby-version`.
- [Фоновые воркеры](/deploy/workers) — запускайте потребители очередей, поллинг-циклы и ботов, например [Discord-бота](/guides/discord-bot), с `containerPort=0`.
- [Масштабирование](/deploy/scaling) — настраивайте реплики, ресурсы и хранилище.
- [Регионы](/deploy/regions) — где запускаются ваши сервисы.
- [Устранение неполадок](/deploy/troubleshooting/incomplete-dockerfile) — решения для самых частых проблем при сборке и деплое.
