# Регионы

Сервисы и аддоны создаются в конкретном регионе. Посмотрите список регионов, доступных вашему аккаунту, и выберите нужный при создании.

<span id="list-regions" />

## Список регионов

```bash
lizard regions
lizard regions --json
```

<span id="choose-a-region" />

## Выбор региона

Передайте `--region <code>` при создании сервиса или аддона:

```bash
lizard add -r your-org/your-app --region <code>
lizard add postgres --region <code>
lizard up --region <code>
```

Если регион не указан, платформа использует регион проекта по умолчанию.

> **Размещайте состояние в одном регионе.** Размещайте сервис и аддоны, с которыми он общается (Postgres, Redis, S3), в **одном регионе**, чтобы сохранить низкую задержку и избежать платы за межрегиональный трафик.

<span id="generated-domains" />

## Генерируемые домены

Каждый сервис получает генерируемый домен на `*.onlizard.com` с автоматическим TLS, независимо от региона. Объектное хранилище от [S3-аддона](/addons/storage) использует шлюз с учётом региона (`s3-<region>.onlizard.com`). Чтобы подключить свой хостнейм, см. [Networking](/networking).
