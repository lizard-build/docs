# Быстрый старт

<a id="authenticate" />


## Установка и вход

Установите Lizard SDK и создайте API-ключ в Settings → API keys. Сохраните его в `LIZARD_API_KEY`. Каждому sandbox нужен проект: передайте `projectId` (в Python — `project_id`) или ID, slug либо имя через `project`.

```sh
npm install @lizard-build/sdk
pip install lizard-sdk
export LIZARD_API_KEY="<your-api-key>"
```

## Запуск команды

```ts
import { Sandbox } from '@lizard-build/sdk';

const sandbox = await Sandbox.create('interpreter', {
  projectId: 'proj_123', timeoutMs: 300_000,
});
try {
  const result = await sandbox.process.exec("python -c 'print(2 ** 10)'");
  console.log(result.stdout, result.stderr, result.exitCode);
} finally {
  await sandbox.kill();
}
```

```python
from lizard import Sandbox

sandbox = Sandbox.create("interpreter", project_id="proj_123", timeout_ms=300_000)
try:
    result = sandbox.process.exec_("python -c 'print(2 ** 10)'")
    print(result.stdout, result.stderr, result.exit_code)
finally:
    sandbox.kill()
```

## Файлы

`fs.write` записывает текст или корректные байты UTF-8, а `fs.read` читает текст. Текущий метод записи не поддерживает загрузку двоичных файлов. Для скачивания двоичного файла используйте `fs.readBytes` (в Python — `read_bytes`).

Файлы и процессы доступны, пока sandbox работает. После остановки следующий sandbox может получить только файлы, записанные на подключённый Persistent Volume в `/workspace`. Без тома `/workspace` — временная папка. Том подключается только к одному sandbox и хранится на одном узле; отдельно сохраняйте файлы, которые должны пережить потерю узла.

```ts
await sandbox.fs.write("/tmp/task.py", "print(42)\n");
const result = await sandbox.process.exec("python /tmp/task.py");
console.log(result.stdout);
```

## Публичные порты

Запустите сервер на `0.0.0.0`, затем вызовите `getHost(port)`, чтобы получить публичное HTTPS-имя хоста. Порт доступен извне; при необходимости добавьте вход по ключу или паролю. После остановки sandbox порт больше не обслуживается.

```ts
await sandbox.process.exec(
  "nohup python -m http.server 3000 --bind 0.0.0.0 --directory /tmp >/tmp/http.log 2>&1 </dev/null &",
);
const host = await sandbox.getHost(3000);
console.log(`https://${host}`);
```

## Подключение к работающему sandbox

Создайте sandbox, выполните команды и вызовите `kill`. `connect` подключается к существующему sandbox, но не возобновляет остановленный. Пауза, возобновление, fork, snapshot, restore и наблюдение за файлами сейчас возвращают HTTP 501. SSH в текущем runtime недоступен.

```ts
const connected = await Sandbox.connect(sandbox.sandboxId);
console.log(await connected.getInfo());
```

## Текущие ограничения runtime

SDK и CLI по умолчанию задают срок жизни пять минут. Прямой API и кабинет по умолчанию не задают срок. Укажите его явно: `timeoutMs: 0` при создании отключает истечение срока; положительное значение задаёт срок жизни. `setTimeout` принимает 1000–2147483647 мс, но не ноль. Команды не продлевают срок. Это не таймер простоя.

Результат команды содержит stdout, stderr и код завершения. Таймаут команды ограничен 1–600 секундами. Текущий runtime не применяет параметры SDK `envs`, `workdir` и `user`; задавайте папку и переменные среды в самой shell-команде. Параметры `envs` и `metadata` при создании также не применяются.
