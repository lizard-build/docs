# Кабинет

Откройте проект и выберите Sandboxes. При создании выберите шаблон из каталога и регион. Регион по умолчанию не обязательно ближайший. Лимиты ресурсов фиксированы. Созданные в кабинете Sandboxes не имеют срока жизни, пока вы не зададите его через API.

## Установка и вход

Установите Lizard SDK и создайте API-ключ в Settings → API keys. Сохраните его в `LIZARD_API_KEY`. Каждому sandbox нужен проект: передайте `projectId` (в Python — `project_id`) или ID, slug либо имя через `project`.

## Просмотр и остановка

Карточка показывает статус, шаблон, регион, измеренный расход ресурсов и открытые порты. Текущий runtime Kubernetes не выдаёт данные для SSH, поэтому терминал через SSH недоступен. Выполняйте команды через SDK или CLI.

Оплата зависит от измеренного расхода CPU, памяти, хранилища и исходящего трафика. Sandbox может расходовать память и место даже без команд. Останавливайте его после задачи; плата за хранилище продолжается, пока вы храните данные.

## Шаблоны и тома

Вкладка Templates показывает шаблоны платформы для новых Sandboxes, а не снимки ваших работающих сессий. Создание снимков, пауза и возобновление недоступны. Kill Sandbox останавливает sandbox и отключает его том.

Вкладка Persistent Volumes позволяет управлять именованными томами и их подключениями. Подключите том при создании sandbox и записывайте файлы в `/workspace`. Остановите текущий sandbox перед подключением тома к другому.
