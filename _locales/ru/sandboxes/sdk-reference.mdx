Установите Lizard SDK и создайте API-ключ в Settings → API keys. Сохраните его в `LIZARD_API_KEY`. Каждому sandbox нужен проект: передайте `projectId` (в Python — `project_id`) или ID, slug либо имя через `project`.

## Параметры создания

| TypeScript | Python |
|---|---|
| `projectId / project` | `project_id / project` |
| `timeoutMs` | `timeout_ms` |
| `region` | `region` |
| `volumeName / volumeId` | `volume_name / volume_id` |
| `size` | `size` |
| `snapshotId` | `snapshot_id` |
| `apiKey` | `api_key` |

Выбирайте шаблон из текущего каталога. В нём доступны `base`, `codex` и `interpreter`; наличие зависит от региона и свободных ресурсов пула. `interpreter` содержит Python и основные библиотеки для работы с данными. Проверяйте версии программ внутри sandbox. Публичный CLI не поддерживает загрузку своих шаблонов.

SDK и CLI по умолчанию задают срок жизни пять минут. Прямой API и кабинет по умолчанию не задают срок. Укажите его явно: `timeoutMs: 0` при создании отключает истечение срока; положительное значение задаёт срок жизни. `setTimeout` принимает 1000–2147483647 мс, но не ноль. Команды не продлевают срок. Это не таймер простоя.

## Методы

| API (TypeScript) | Методы |
|---|---|
| `Sandbox.create(template, options)` | Создать в проекте из шаблона каталога. |
| `Sandbox.connect(sandboxId)` | Подключиться к существующему sandbox без возобновления. |
| `Sandbox.list()` | Получить список доступных Sandboxes; проверяйте их статус. |
| `sandbox.getInfo()` | Получить статус и сведения. |
| `sandbox.process.exec(cmd)` | Выполнить shell-команду; вернуть stdout, stderr и exitCode. |
| `sandbox.fs.write(path, data)` | Записать текст или UTF-8; создать родительские папки. |
| `sandbox.fs.read(path)` | Прочитать текст UTF-8. |
| `sandbox.fs.readBytes(path)` | Прочитать байты файла. |
| `sandbox.fs.list(path)` | Получить список файлов и папок. |
| `sandbox.fs.makeDir(path)` | Создать папку и её родителей. |
| `sandbox.fs.remove(path)` | Удалить файл или папку. |
| `sandbox.getHost(port)` | Зарегистрировать публичное HTTPS-имя для порта. |
| `sandbox.setTimeout(ms)` | Задать оставшийся срок жизни, минимум 1000 мс. |
| `sandbox.pause()` / `sandbox.resume()` | Поставить паузу или возобновление в очередь и сразу вернуть ответ. |
| `sandbox.waitForStatus(status)` | Дождаться `paused` или `running`; выбросить ошибку, если пауза не удалась. |
| `sandbox.snapshot(name, { poolSize })` | Сохранить память и файлы `/workspace` в приватный снимок. |
| `Sandbox.waitForSnapshot(snapshotId)` | Дождаться готовности снимка. |
| `Sandbox.restore(snapshotId)` | Запустить новый sandbox из готовой копии. |
| `sandbox.kill()` | Остановить sandbox и отключить том. |

Python: `exec_`, `get_info`, `get_host`, `set_timeout`, `sandbox_id`, `read_bytes`, `make_dir`, `wait_for_status`, `wait_for_snapshot`, `pool_size`.

## Текущие ограничения runtime

Результат команды содержит stdout, stderr и код завершения. Таймаут команды ограничен 1–600 секундами. Текущий runtime не применяет параметры SDK `envs`, `workdir` и `user`; задавайте папку и переменные среды в самой shell-команде. Параметры `envs` и `metadata` при создании также не применяются.

`fs.write` записывает текст или корректные байты UTF-8, а `fs.read` читает текст. Текущий метод записи не поддерживает загрузку двоичных файлов. Для скачивания двоичного файла используйте `fs.readBytes` (в Python — `read_bytes`).

Передайте `size` (`'small'`, `'medium'` или `'large'`), чтобы выбрать 2 vCPU / 4 GB, 4 vCPU / 8 GB (по умолчанию) или 8 vCPU / 16 GB; см. [размеры и цены](/platform/limits#sandbox-sizes). Для sandbox, восстановленного из снимка, `size` не действует. При необходимости укажите регион явно; наличие региона в каталоге не гарантирует свободные ресурсы.

## Недоступные API

`sandbox.fork()` и наблюдение за файлами возвращают HTTP 501. `Sandbox.connect` не возобновляет приостановленный или остановленный sandbox; для приостановленного вызовите `resume()`. Доступа по протоколу SSH нет; `lizard sandbox ssh` открывает интерактивную оболочку с учётными данными CLI.

`CodeSandbox`, `runCode` / `run_code` и методы контекста исполнения остаются в SDK, но в каталоге нет шаблона с нужным им сервером исполнения. Старый шаблон по умолчанию `code-interpreter-v1` недоступен. Замена имени на `interpreter` не включает этот API. Используйте `Sandbox.create("interpreter")` и команды процессов, как в примере ниже.

## Хранение и оплата

Файлы и процессы доступны, пока sandbox работает. После остановки следующий sandbox может получить только файлы, записанные на подключённый Persistent Volume в `/workspace`. Без тома `/workspace` — временная папка. Том подключается только к одному sandbox и хранится на одном узле; отдельно сохраняйте файлы, которые должны пережить потерю узла.

У каждого размера фиксированная почасовая цена; оплата идёт посекундно, пока sandbox работает, включая простой. Исходящий трафик входит в цену до [2 TB на аккаунт](/platform/limits#sandbox-egress) за скользящие 30 дней. Sandbox, восстановленный из снимка, оплачивается по измеренному расходу. За приостановленный sandbox плата не берётся; Persistent Volumes оплачиваются отдельно, пока вы храните данные. Ставьте sandbox на паузу или останавливайте его, когда задача завершена.
