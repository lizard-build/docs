# Events & History

`lizard events` показывает историю развёртываний сервиса и текущий статус его реплик — хронологию того, что было выпущено, и что работает прямо сейчас.

<span id="view-events" />

## Просмотреть события

```bash
lizard events                     # deploy history + replica status
lizard events --service api       # a specific service
lizard events --limit 5           # fewer entries (default and maximum 10)
```

Каждая запись — это развёртывание: статус, триггер, коммит и количество перезапусков. Таблица Replicas над развёртываниями показывает текущее состояние каждого пода; её нет, пока у сервиса нет подов, например пока он на паузе или спит. Вместе они отвечают на вопрос «что изменилось и всё ли исправно?». Изменение числа реплик через `lizard scale` не создаёт развёртывание, поэтому в списке его нет.

<span id="quick-status" />

## Быстрый статус

Для быстрого обзора всех сервисов в проекте — статус и URL — используйте:

```bash
lizard ps
lizard status        # the current directory's workspace/project/service link
```

<span id="dashboard" />

## Панель управления

Откройте сервис в дашборде (`lizard open`), чтобы увидеть историю его развёртываний. В каждой строке развёртывания видны ветка и сообщение коммита; нажмите на строку, чтобы увидеть логи сборки и перезапуски. Панель сервиса показывает запущенные и желаемые реплики.
