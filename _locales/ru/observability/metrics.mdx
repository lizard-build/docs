# Метрики и стоимость

Отслеживайте CPU, память, сеть и диск для сервиса — и узнавайте, во что это обходится — из CLI или дашборда.

<span id="view-metrics" />

## Просмотр метрик

```bash
lizard metrics                    # CPU / memory / network / disk
lizard metrics --service api      # a specific service
lizard metrics --range 24h        # time window: 1h (default), 6h, 24h, 7d, 14d, 30d
lizard metrics --watch            # live-updating view
```

<span id="include-cost" />

## Включить стоимость

```bash
lizard metrics --cost
```

Показывает представление со стоимостью вместо метрик: цену за час для каждого запущенного ресурса, использование за текущий расчётный период (включая исходящий трафик) и сколько из включённых в Pro $19 вы использовали в этом месяце. Оно охватывает весь проект, игнорирует `--service` и `--range`, и увидеть его может только владелец рабочего пространства.

<span id="dashboard" />

## Дашборд

На дашборде (`lizard open`) эти данные отображаются в виде графиков в разделе **Metrics**, а в разделе **Использование** представлен разбор потребления и биллинга по проекту. Откройте его командой:

```bash
lizard open
```

<span id="acting-on-what-you-see" />

## Действия на основе метрик

- Высокая нагрузка на CPU/память → увеличьте масштаб: `lizard scale --service api --cpu 2 --memory 2048`.
- Постоянная нагрузка → добавьте реплики: `lizard scale --service api --replicas 3`. Pro допускает 1 реплику на сервис во время пробного периода и 5 после первого оплаченного счёта.
- Нехватка диска на аддоне → увеличьте хранилище: `lizard scale --service postgres --storage 8192`.

См. [Scaling](/deploy/scaling).
