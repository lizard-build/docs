# Managed Redis

Управляемый экземпляр Redis для кэширования, очередей, ограничения частоты запросов и pub/sub.

<span id="provision" />

## Создание

```bash
lizard add redis
```

Первое дополнение Redis называется `redis`, поэтому `${{redis.REDIS_URL}}` работает сразу.

<span id="environment-variables" />

## Переменные окружения

| Переменная | Описание |
|----------|-------------|
| `REDIS_URL` | Полная строка подключения через публичную конечную точку (`redis://…`) |
| `REDIS_PRIVATE_URL` | Строка подключения через приватную сеть проекта (`<name>.lizard.internal:6379`) |

<span id="connect-a-service" />

## Подключение сервиса

```bash
lizard secrets set REDIS_URL='${{redis.REDIS_PRIVATE_URL}}' --service api
lizard redeploy --service api
```

Ссылка разрешается при развёртывании; потребители получают актуальные значения дополнения при следующем развёртывании. Используйте `REDIS_URL` для клиентов вне проекта. Каждый сервис в проекте также получает публичный `REDIS_URL` дополнения с самым низким приоритетом; явная ссылка переопределяет его.

<span id="memory-and-durability" />

## Память и сохранность данных

В Managed Redis нет политики вытеснения и append-only файла. Если память заканчивается, экземпляр перезапускается, и последние записи могут быть потеряны. Используйте его для данных, которые можно восстановить, а данные, которые нельзя потерять, храните в [Managed Postgres](/addons/postgres).

<span id="common-uses" />

## Типовые варианты использования

- **Кэширование** — сохраняйте вычисленные результаты с ключом запроса.
- **Очередь / воркер** — используйте Redis вместе с [сервисом в режиме воркера](/deploy/workers), который обрабатывает задания.
- **Ограничение частоты запросов / сессии** — быстрое разделяемое состояние для [реплик](/deploy/scaling).

```bash
# A worker that drains a Redis queue
lizard add -r your-org/worker -n jobs --no-deploy
lizard service set jobs --set containerPort=0
lizard secrets set REDIS_URL='${{redis.REDIS_PRIVATE_URL}}' --service jobs
lizard redeploy --service jobs
```

<span id="browse-keys" />

## Просмотр ключей

Откройте **Браузер Redis** в панели управления (`lizard open`), чтобы просмотреть ключи и значения. Для локального доступа со значениями подключения дополнения:

```bash
lizard run --service redis -- sh -c 'exec redis-cli -u "$REDIS_URL"'
```

<span id="grow-storage" />

## Расширение хранилища

```bash
lizard scale --service redis --storage 4096
```
