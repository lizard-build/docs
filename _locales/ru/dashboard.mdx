# Дашборд приложения

Дашборд Lizard — это визуальный спутник Lizard CLI. Все, что вы делаете с `lizard …`, отображается здесь, плюс то, что удобнее делать через UI — логи в реальном времени, графики, браузеры данных, Sandboxes, управление командой и биллингом.

Если вы не хотите открывать терминал вообще, пусть агент выполняет команды, а вы следите за результатом здесь — путь в [деплое Antigravity-приложения в прод](https://lizard.build/blog/google-antigravity-how-to-deploy-your-app-to-production#deploy-from-the-antigravity-chat), где деплой выполняется одним промптом.

Открыть из CLI:

```bash
lizard open          # open the current project
lizard docs          # open this documentation
```

<span id="whats-in-the-dashboard" />

## Что есть в дашборде

<span id="services" />

### Сервисы

**Приложения и базы данных** в боковой панели показывает каждый сервис с бейджем статуса, сгенерированным доменом и быстрыми переходами к логам, метрикам, секретам и настройкам. Создайте сервис кнопкой **Новый сервис**: из GitHub-репозитория, из папки на вашем компьютере, или как базу данных (Managed Postgres, Managed Redis) или Managed Object Storage.

На вкладке **Настройки** сервиса также есть **Serverless**, чтобы он засыпал без трафика ([`lizard sleep`](/cli/sleep)), и **Приостановить**, чтобы остановить его, ничего не удаляя ([`lizard pause`](/cli/pause)).

<span id="deployments" />

### Деплои

Вкладка **Обзор** каждого сервиса показывает его деплои. Откройте любой, чтобы увидеть статус, триггер, источник, логи сборки и перезапуски. Это визуальный аналог `lizard events` + `lizard logs --build`.

<span id="logs" />

### Логи

Стриминг логов рантайма и сборки в реальном времени с поиском и фильтрами по уровню — UI-аналог [`lizard logs`](/observability/logs).

<span id="metrics--usage" />

### Метрики и использование

Графики CPU, памяти, сети и диска на сервис, а также страница **Использование**, которая разбивает потребление и стоимость по проекту. Зеркалит [`lizard metrics --cost`](/observability/metrics).

<span id="variables--secrets" />

### Переменные и секреты

Секреты уровня сервиса находятся на вкладке **Секреты** сервиса, секреты уровня проекта — в **Глобальные секреты**; значения маскируются, ссылки (`${{…}}`) поддерживаются. См. [Переменные и секреты](/variables).

<span id="domains" />

### Домены

На вкладке **Настройки** сервиса добавляйте собственные домены, просматривайте DNS-записи и отслеживайте статус верификации и TLS. См. [Сеть](/networking).

<span id="data-browsers" />

### Браузеры данных

У каждого управляемого аддона свой браузер данных:

- **Managed Postgres** — SQL/табличный редактор для запросов и редактирования данных.
- **Managed Redis** — браузер ключ/значение.
- **Managed Object Storage** — браузер бакетов и объектов с загрузкой/скачиванием и настройками доступа к бакетам.

<span id="sandboxes" />

### Sandboxes

В боковой панели есть **Sandboxes**, **Volumes** (Persistent Volumes), **Шаблоны** и **Агенты**. Создайте песочницу кнопкой **Новая песочница** на странице Sandboxes; число рядом показывает, сколько песочниц запущено относительно вашего лимита. В пробный период диалог предлагает только размер Small в регионах US. См. [Быстрый старт Sandboxes](/sandboxes/quickstart).

<span id="github-integration" />

### Интеграция с GitHub

Подключите GitHub в **Новый сервис → Репозиторий GitHub**. После подключения ссылка **Настроить доступ** под списком репозиториев открывает настройки GitHub App, где вы выбираете, какие репозитории может собирать Lizard. Публичный репозиторий можно задеплоить и без подключения, вставив его URL. См. [Деплой из GitHub](/deploy/github).

<span id="settings-team--billing" />

### Настройки, команда и биллинг

**Настройки** внизу боковой панели содержат настройки проекта и рабочего пространства, приглашения участников и роли (**Команда**), а также настройки аккаунта. Откройте **Биллинг** из настроек аккаунта или нажав на свой тариф в верхней части дашборда. Там видны тариф, пробный период, расход за текущий период, счета и карта. См. [Оплата](/platform/billing).

## CLI ↔ Дашборд

| Задача | CLI | Представление в дашборде |
|--------|-----|------------------------|
| История деплоев | `lizard events` | Сервис → Обзор |
| Стриминг логов | `lizard logs` | Логи |
| Графики ресурсов | `lizard metrics` | Метрики / Использование |
| Управление секретами | `lizard secrets` | Секреты / Глобальные секреты |
| Собственные домены | `lizard domain` | Сервис → Настройки |
| Приостановить или возобновить сервис | `lizard pause` / `lizard resume` | Сервис → Настройки |
| Засыпать без трафика | `lizard sleep` | Сервис → Настройки → Serverless |
| Запросы к Managed Postgres, Managed Redis или Managed Object Storage | `lizard run --service <addon> -- <cmd>` | Браузеры данных |
| Пригласить коллег | — | Настройки → Команда |

Используйте то, что удобнее в момент — они работают с одними и теми же проектами и сервисами.
