# Дашборд приложения

Дашборд Lizard — это визуальный спутник Lizard CLI. Все, что вы делаете с `lizard …`, отображается здесь, плюс то, что удобнее делать через UI — логи в реальном времени, графики, браузеры данных, Sandboxes, управление командой и биллингом.

Если вы не хотите открывать терминал вообще, пусть агент выполняет команды, а вы следите за результатом здесь — путь в [деплое Antigravity-приложения в прод](https://lizard.build/blog/google-antigravity-how-to-deploy-your-app-to-production#deploy-from-the-antigravity-chat), где деплой выполняется одним промптом.

Открыть из CLI:

```bash
lizard open          # open the current project
lizard docs          # open this documentation
```

## Что есть в дашборде

<span id="services" />

### Сервисы

Домашняя страница проекта показывает каждый сервис с бейджем статуса, сгенерированным доменом и быстрыми переходами к логам, метрикам, секретам и настройкам. Создавайте новые сервисы (из GitHub-репозитория или пустые) прямо отсюда.

<span id="deployments" />

### Деплои

Хронология каждого деплоя с логами сборки на уровне деплоя и детальной панелью (коммит, статус, реплики). Это визуальный аналог `lizard events` + `lizard logs --build`.

<span id="logs" />

### Логи

Стриминг логов рантайма и сборки в реальном времени с поиском и фильтрами по уровню — UI-аналог [`lizard logs`](/observability/logs).

<span id="metrics--usage" />

### Метрики и использование

Графики CPU, памяти, сети и диска на сервис, а также представление **Использование**, которое разбивает потребление и стоимость по проекту. Зеркалит [`lizard metrics --cost`](/observability/metrics).

<span id="variables--secrets" />

### Переменные и секреты

Управление секретами уровня сервиса и проекта, с маскированными значениями и поддержкой ссылок (`${{…}}`). См. [Переменные и секреты](/variables).

<span id="domains" />

### Домены

Добавляйте собственные домены, просматривайте DNS-записи и отслеживайте статус верификации и TLS. См. [Сеть](/networking).

<span id="data-browsers" />

### Браузеры данных

У каждого управляемого аддона свой браузер данных:

- **Managed Postgres** — SQL/табличный редактор для запросов и редактирования данных.
- **Managed Redis** — браузер ключ/значение.
- **Managed Object Storage** — браузер бакетов и объектов с загрузкой/скачиванием и настройками доступа к бакетам.

<span id="sandboxes" />

### Sandboxes

На странице **Sandboxes** есть вкладки для песочниц, Persistent Volumes, шаблонов и агентов. Создайте песочницу кнопкой **New Sandbox**; число рядом показывает, сколько песочниц запущено относительно вашего лимита. См. [Быстрый старт Sandboxes](/sandboxes/quickstart).

<span id="github-integration" />

### Интеграция с GitHub

Подключите GitHub App, выберите репозитории и управляйте тем, какие репозитории может собирать Lizard. См. [Деплой из GitHub](/deploy/github).

<span id="settings-team--billing" />

### Настройки, команда и биллинг

Настройки проекта и рабочего пространства, приглашения участников и роли, расход ресурсов. Страница **Биллинг** в настройках аккаунта показывает ваш тариф, пробный период, кредиты, израсходованные в этом месяце, счета и карту. См. [Оплата](/platform/billing).

## CLI ↔ Дашборд

| Задача | CLI | Представление в дашборде |
|--------|-----|------------------------|
| История деплоев | `lizard events` | Деплои |
| Стриминг логов | `lizard logs` | Логи |
| Графики ресурсов | `lizard metrics` | Метрики / Использование |
| Управление секретами | `lizard secrets` | Переменные |
| Собственные домены | `lizard domain` | Домены |
| Запросы к Managed Postgres, Managed Redis или Managed Object Storage | `lizard run --service <addon> -- <cmd>` | Браузеры данных |
| Пригласить коллег | — | Команда / Настройки |

Используйте то, что удобнее в момент — они работают с одними и теми же проектами и сервисами.
