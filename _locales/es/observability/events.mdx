# Eventos e historial

`lizard events` muestra el historial de despliegues de un servicio y el estado en vivo de sus réplicas: la línea de tiempo de lo que se desplegó y de lo que se está ejecutando ahora mismo.

<span id="view-events" />

## Ver eventos

```bash
lizard events                     # deploy history + replica status
lizard events --service api       # a specific service
lizard events --limit 5           # fewer entries (default and maximum 10)
```

Cada entrada es un despliegue: estado, desencadenante, commit y número de reinicios. La tabla Replicas de abajo muestra el estado actual de cada pod, para que puedas responder de un vistazo "qué cambió y si está saludable".

<span id="quick-status" />

## Estado rápido

Para una vista rápida de todos los servicios del proyecto — estado y URL — usa:

```bash
lizard ps
lizard status        # the current directory's workspace/project/service link
```

<span id="dashboard" />

## Panel

Abre un servicio en el dashboard (`lizard open`) para ver su historial de despliegues. Haz clic en un despliegue para ver sus logs de compilación, su commit y sus eventos de fallo. El panel del servicio muestra las réplicas en marcha y las deseadas.
