# Eventos e historial

`lizard events` muestra el historial de despliegues de un servicio y el estado en vivo de sus réplicas: la línea de tiempo de lo que se desplegó y de lo que se está ejecutando ahora mismo.

<span id="view-events" />

## Ver eventos

```bash
lizard events                     # deploy history + replica status
lizard events --service api       # a specific service
lizard events --limit 25          # show more entries (default 10)
```

Cada entrada cubre una acción de despliegue o escalado y el estado resultante de las réplicas, para que puedas responder de un vistazo "qué cambió y si está saludable".

<span id="quick-status" />

## Estado rápido

Para una vista rápida de todos los servicios del proyecto — estado y URL — usa:

```bash
lizard ps
lizard status        # the current directory's workspace/project/service link
```

<span id="dashboard" />

## Panel

La vista **Despliegues** del dashboard (`lizard open`) muestra el mismo historial como una línea de tiempo, con un panel de detalles por despliegue (logs de compilación, commit, estado) y el estado de salud de cada réplica.
