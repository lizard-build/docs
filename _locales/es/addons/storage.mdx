# Managed Object Storage

Managed Object Storage en Lizard (lizard.build) es almacenamiento compatible con S3 para cargas, recursos y copias de seguridad. `lizard add s3` lo crea con un **bucket privado llamado `default`** y cinco variables, de `S3_ENDPOINT` a `S3_REGION`, que cualquier AWS SDK puede usar con direccionamiento de estilo ruta (path-style). Cada addon de Managed Object Storage puede almacenar hasta 16 GiB, y pagas por los bytes que almacenas. Para servir archivos sin autenticación, haz público el bucket desde el navegador S3 del panel. Para ver un resumen y los precios, consulta la [página de Managed Object Storage](https://lizard.build/object-storage).

<span id="provision" />

## Aprovisionar

```bash
lizard add s3
```

El primer addon de S3 se llama `s3`, así que `${{s3.S3_ENDPOINT}}` y similares funcionan de inmediato.

<span id="environment-variables" />

## Variables de entorno

| Variable | Descripción |
|----------|-------------|
| `S3_ENDPOINT` | URL del endpoint compatible con S3 |
| `S3_DEFAULT_BUCKET` | El nombre del bucket creado automáticamente (`default`) |
| `S3_ACCESS_KEY_ID` | Clave de acceso |
| `S3_SECRET_ACCESS_KEY` | Clave secreta |
| `S3_REGION` | Región |

<span id="connect-a-service" />

## Conectar un servicio

```bash
lizard secrets set \
  S3_ENDPOINT='${{s3.S3_ENDPOINT}}' \
  S3_DEFAULT_BUCKET='${{s3.S3_DEFAULT_BUCKET}}' \
  S3_ACCESS_KEY_ID='${{s3.S3_ACCESS_KEY_ID}}' \
  S3_SECRET_ACCESS_KEY='${{s3.S3_SECRET_ACCESS_KEY}}' \
  S3_REGION='${{s3.S3_REGION}}' \
  --service api
lizard redeploy --service api
```

<span id="using-an-aws-sdk" />

## Usar un AWS SDK

El endpoint es compatible con S3. Configura el direccionamiento **path-style**:

```ts
import { S3Client } from "@aws-sdk/client-s3";

const s3 = new S3Client({
  endpoint: process.env.S3_ENDPOINT,
  region: process.env.S3_REGION,
  forcePathStyle: true, // required
  credentials: {
    accessKeyId: process.env.S3_ACCESS_KEY_ID!,
    secretAccessKey: process.env.S3_SECRET_ACCESS_KEY!,
  },
});
```

<span id="public-files" />

## Archivos públicos

Los buckets son privados de forma predeterminada. Los objetos de un bucket que hagas **público** se sirven sin autenticación de dos maneras:

1. **URL del gateway** (se muestra en el panel):
   ```
   https://s3-<region>.onlizard.com/<addonId>/<bucket>/<key>
   ```
   `<region>` es el valor de `S3_REGION` (`eu-west-1` o `us-east-1`).
2. **Proxy de la plataforma** (el host del panel, con encabezados de caché inmutables de larga duración):
   ```
   <dashboard-host>/api/s3/<addonId>/public/<bucket>/<key>
   ```

Una vez que hagas público el bucket `default`, sus objetos se sirven en:

```
<dashboard-host>/api/s3/<addonId>/public/default/<key>
```

El navegador S3 tiene dos interruptores para cada bucket. **Vista pública** (Public view) permite que cualquiera lea sus objetos. **Edición pública** (Public edit) permite que cualquiera los suba o los borre, así que actívalo solo en un bucket que cualquiera pueda cambiar.

Para compartir un objeto de un bucket privado durante un tiempo, genera un enlace temporal. Funciona sin credenciales hasta que caduca (una hora por defecto, hasta 7 días como máximo):

```bash
lizard s3 url report.pdf --expires 86400
```

Las URL prefirmadas (presigned) de un AWS SDK también funcionan.

<span id="browse-objects" />

## Explorar objetos

Abre el **navegador S3** en el panel (`lizard open`) para cargar y eliminar objetos, crear carpetas y hacer buckets públicos o privados. Desde la CLI, `lizard s3 upload <file>` carga un archivo, `lizard s3 list` lista los objetos y `lizard s3 url <key>` imprime un enlace temporal; consulta [`lizard s3`](/cli/s3).

> **Los cambios de ACL del bucket** (hacer un bucket público/privado) todavía no están en la CLI; gestiónalos desde el panel.

<span id="storage-limit" />

## Límite de almacenamiento

Cada addon de Managed Object Storage puede almacenar hasta 16 GiB de objetos, sumando su bucket `default` y los demás que crees. Otro addon (`lizard add s3`) tiene sus propios 16 GiB. Pagas por los bytes almacenados, no por un tamaño reservado; `lizard scale --storage` no cambia este límite.
