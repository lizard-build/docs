# lizard events

Muestra el historial de despliegues y el estado de las réplicas.

## Usage

```bash
lizard events [flags]
```

## Flags

| Flag | Description |
|------|-------------|
| `-n, --limit <n>` | Número de entradas que se mostrarán (por defecto 10) |
| `-s, --service <name>` | Muestra los eventos de un servicio específico |

## Examples

<span id="show-deploy-history-and-replica-status" />

### Mostrar el historial de despliegues y el estado de las réplicas

```bash
lizard events
```

<span id="show-events-for-a-specific-service" />

### Mostrar eventos de un servicio específico

```bash
lizard events --service api
```

<span id="show-more-entries" />

### Mostrar más entradas

```bash
lizard events --limit 25
```
