# lizard run

Ejecuta un comando localmente con los secretos del proyecto y del servicio inyectados.

<span id="what-run-injects" />

## Qué inyecta `run`

`lizard run` carga los secretos del proyecto, luego los secretos del servicio por encima, y ejecuta tu comando en tu máquina con ellos en su entorno.

- Para un servicio de app, inyecta los valores almacenados. Las referencias como `${{postgres.DATABASE_URL}}` llegan como ese texto literal, no como el valor resuelto. Las variables de la plataforma como `PORT` y `LIZARD_*` no se inyectan.
- Para un addon (`--service postgres`, `--service redis`, `--service s3`), inyecta los valores de conexión reales del addon, como `DATABASE_URL`.

Así que para ejecutar una migración o un cliente de base de datos localmente, apunta `--service` al addon, no a la app que lo referencia.

`lizard ssh` hacia un servicio en ejecución está desactivado (la API responde 403 "Shell access to services is disabled"). Para comprobar lo que recibe la app en ejecución, usa:

| Comprobación | Comando |
|-------|---------|
| Referencias vacías | `lizard logs --build --service api` (el log de build avisa de cada referencia `${{…}}` que se resolvió a un valor vacío) |
| Valores almacenados | `lizard secrets list --service api --show` |
| Valores de conexión reales de un addon | `lizard run --service postgres -- printenv DATABASE_URL` |

<span id="usage" />

## Uso

```bash
lizard run [flags] -- <command>
```

<span id="flags" />

## Banderas

| Bandera | Descripción |
|------|-------------|
| `-s, --service <name>` | Servicio cuyo env se debe inyectar (por defecto, el servicio vinculado) |
| `--no-service` | No inyectar el env del servicio, solo los secretos del proyecto |
| `-p, --project <id>` | Proyecto (por defecto, el vinculado) |

<span id="examples" />

## Ejemplos

<span id="run-a-migration-with-service-secrets-injected" />

<span id="run-a-migration-against-managed-postgres" />

### Ejecutar una migración contra Managed Postgres

```bash
lizard run --service postgres -- node scripts/migrate.js
```

<span id="print-an-injected-environment-variable" />

### Imprimir una variable de entorno inyectada

```bash
lizard run --service postgres -- printenv DATABASE_URL
```

<span id="run-a-local-tool-with-an-apps-stored-secrets" />

### Ejecutar una herramienta local con los secretos almacenados de una app

```bash
lizard run --service api -- node scripts/report.js
```
