# lizard login

Inicia sesión en Lizard.

<span id="usage" />

## Uso

```bash
lizard login [flags]
```

De forma predeterminada, esto abre la página de inicio de sesión en tu navegador, imprime su URL y termina. Después de iniciar sesión, ejecuta tu siguiente comando (por ejemplo `lizard whoami`); este completa el inicio de sesión y guarda tus credenciales. Con `--json`, `login` imprime `{ "status": "pending", "authUrl": "…" }` y no abre un navegador.

<span id="flags" />

## Banderas

| Bandera | Descripción |
|------|-------------|
| `--token <token>` | Autenticar con una clave de API (`liz_…`) |

<span id="examples" />

## Ejemplos

<span id="log-in-via-browser" />

### Iniciar sesión mediante el navegador

```bash
lizard login
```

<span id="log-in-with-a-token" />

<span id="log-in-with-an-api-key" />

### Iniciar sesión con una clave de API

Crea una clave con [`lizard keys create <name>`](/cli/keys) y luego:

```bash
lizard login --token liz_xxx
```

<span id="log-in-non-interactively-in-ci" />

### Iniciar sesión de forma no interactiva en CI

En CI u otros entornos no interactivos, configura `LIZARD_TOKEN` (o `LIZARD_API_KEY`) en el entorno en lugar de ejecutar `login`:

```bash
export LIZARD_TOKEN=liz_xxx
```
