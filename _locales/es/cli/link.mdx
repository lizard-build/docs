# lizard link

Asocia el directorio actual con un proyecto existente (y opcionalmente con un servicio).

<span id="usage" />

## Uso

```bash
lizard link [service] [flags]
```

<span id="flags" />

## Indicadores

| Flag | Description |
|------|-------------|
| `-p, --project <id>` | Nombre del proyecto, slug o ID |
| `-s, --service <name>` | Servicio para vincular |
| `-w, --workspace <ws>` | Espacio de trabajo |

<span id="examples" />

## Ejemplos

<span id="link-to-an-existing-project" />

### Vincular a un proyecto existente

```bash
lizard link --project my-project
```

<span id="link-to-a-project-and-a-specific-service" />

### Vincular a un proyecto y a un servicio específico

```bash
lizard link my-service --project my-project
```

<span id="link-within-a-specific-workspace" />

### Vincular dentro de un espacio de trabajo específico

```bash
lizard link --project my-project --workspace my-workspace
```
