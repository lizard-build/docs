# lizard project

Muestra, crea o elimina proyectos.

<span id="usage" />

## Uso

```bash
lizard project list [flags]
lizard project create <name> [flags]
lizard project delete [project] [flags]
```

<span id="subcommands" />

## Subcomandos

### `lizard project list`

Muestra tus proyectos de todos los espacios de trabajo, o de un solo espacio de trabajo con `-w`.

| Flag | Descripción |
|------|-------------|
| `-w, --workspace <ws>` | Solo este espacio de trabajo (id, slug o nombre) |

### `lizard project create <name>`

Crea un proyecto. No vincula el directorio actual; usa [`lizard init`](/cli/init) para eso.

| Flag | Descripción |
|------|-------------|
| `-w, --workspace <ws>` | Espacio de trabajo en el que crear el proyecto |

### `lizard project delete [project]`

Mueve un proyecto a la papelera (alias `rm`). Sus servicios se detienen. Puedes recuperarlo durante 3 días; pasado ese plazo, Lizard lo elimina definitivamente. Sin argumento, elimina el proyecto vinculado a este directorio.

| Flag | Descripción |
|------|-------------|
| `-y, --yes` | Omite la confirmación (obligatorio sin TTY) |

## Ejemplos

<span id="list-projects-in-the-workspace" />

<span id="list-projects" />

### Mostrar proyectos

```bash
lizard project list
lizard project list --workspace my-team
```

<span id="create-a-new-project" />

### Crear un nuevo proyecto

```bash
lizard project create my-project
lizard project create my-project --workspace my-team
```

<span id="delete-a-project" />

### Eliminar un proyecto

```bash
lizard project delete my-project --yes
```
