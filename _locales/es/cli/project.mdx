# lizard project

Muestra, crea, pausa, reanuda o elimina proyectos.

<span id="usage" />

## Uso

```bash
lizard project list [flags]
lizard project create <name> [flags]
lizard project pause [project]
lizard project resume [project]
lizard project delete [project] [flags]
```

<span id="subcommands" />

## Subcomandos

### `lizard project list`

Muestra tus proyectos de todos los espacios de trabajo, o de un solo espacio de trabajo con `-w`.

| Flag | Descripción |
|------|-------------|
| `-w, --workspace <ws>` | Solo este espacio de trabajo (id, slug o nombre) |

### `lizard project create <name>`

Crea un proyecto. No vincula el directorio actual; usa [`lizard init`](/cli/init) para eso.

| Flag | Descripción |
|------|-------------|
| `-w, --workspace <ws>` | Espacio de trabajo en el que crear el proyecto |

### `lizard project pause [project]`

Pausa todas las apps y bases de datos del proyecto, y sus sandboxes en ejecución. Los servicios conservan sus URL, contraseñas, ajustes y datos. Consulta [`lizard pause`](/cli/pause).

### `lizard project resume [project]`

Reanuda las apps y bases de datos que pausaste en el proyecto, y los sandboxes que pausó `project pause`.

### `lizard project delete [project]`

Mueve un proyecto a la papelera (alias `rm`). Solo el propietario del proyecto puede eliminarlo. Sus servicios y bases de datos se detienen; puedes restaurarlos desde la papelera en el panel durante 3 días, y pasado ese plazo Lizard los elimina definitivamente.

> **Advertencia:** los sandboxes no tienen papelera. `project delete` elimina al instante los sandboxes del proyecto, sus volúmenes y sus snapshots, y no puedes recuperarlos.

Sin argumento, `pause`, `resume` y `delete` usan el proyecto vinculado a este directorio o, en un directorio sin vincular, el proyecto predeterminado de tu cuenta. Indica el nombre del proyecto al eliminarlo, para saber cuál se elimina.

| Flag | Descripción |
|------|-------------|
| `-y, --yes` | Omite la confirmación (obligatorio sin TTY) |

<span id="examples" />

## Ejemplos

<span id="list-projects-in-the-workspace" />

<span id="list-projects" />

### Mostrar proyectos

```bash
lizard project list
lizard project list --workspace my-team
```

<span id="create-a-new-project" />

### Crear un nuevo proyecto

```bash
lizard project create my-project
lizard project create my-project --workspace my-team
```

<span id="pause-and-resume-a-project" />

### Pausar y reanudar un proyecto

```bash
lizard project pause my-project
lizard project resume my-project
```

<span id="delete-a-project" />

### Eliminar un proyecto

```bash
lizard project delete my-project --yes
```
