# lizard metrics

Muestra CPU / memoria / red / disco y costo.

<span id="usage" />

## Uso

```bash
lizard metrics [flags]
```

<span id="flags" />

## Banderas

| Bandera | Descripción |
|------|-------------|
| `-s, --service <id>` | Servicio (por defecto, el servicio vinculado) |
| `-p, --project <id>` | Nombre, slug o ID del proyecto |
| `--all` | Todos los servicios del proyecto, ignorando el servicio vinculado; no se puede combinar con `-s` |
| `-r, --range <range>` | Ventana de tiempo: `1h` (por defecto), `6h`, `24h`, `7d`, `14d` o `30d` |
| `-w, --watch` | Vista en vivo, actualizada cada 3 segundos; no se puede combinar con `--json` |
| `--cost` | Recursos en ejecución, costo por hora, uso del período de facturación actual y uso de Pro de este mes. Solo para el propietario del workspace |

Sin un servicio vinculado ni `-s`, `metrics` muestra un resumen de todos los servicios del proyecto.

<span id="examples" />

## Ejemplos

<span id="view-metrics-for-the-current-service" />

### Ver métricas del servicio actual

```bash
lizard metrics
```

<span id="view-metrics-for-a-specific-service" />

### Ver métricas de un servicio específico

```bash
lizard metrics --service api
```

<span id="watch-metrics-live" />

### Ver métricas en vivo

```bash
lizard metrics --watch
```

<span id="include-cost" />

### Incluir costo

```bash
lizard metrics --cost
```
