# lizard metrics

Muestra CPU / memoria / red / disco y costo.

<span id="usage" />

## Uso

```bash
lizard metrics [flags]
```

<span id="flags" />

## Banderas

| Bandera | Descripción |
|------|-------------|
| `-r, --range <range>` | Ventana de tiempo |
| `-w, --watch` | Actualización en vivo |
| `--cost` | Incluir costo |

<span id="examples" />

## Ejemplos

<span id="view-metrics-for-the-current-service" />

### Ver métricas del servicio actual

```bash
lizard metrics
```

<span id="view-metrics-for-a-specific-service" />

### Ver métricas de un servicio específico

```bash
lizard metrics --service api
```

<span id="watch-metrics-live" />

### Ver métricas en vivo

```bash
lizard metrics --watch
```

<span id="include-cost" />

### Incluir costo

```bash
lizard metrics --cost
```
