# lizard config

Aplica un archivo `lizard-config.json` al proyecto.

<span id="usage" />

## Uso

```bash
lizard config apply [flags]
```

<span id="subcommands" />

## Subcomandos

### `lizard config apply`

Aplica un archivo `lizard-config.json` al proyecto.

| Bandera | Descripción |
|------|-------------|
| `-f, --file <path>` | Archivo de configuración (por defecto `lizard-config.json`) |
| `--dry-run` | Muestra qué cambiaría sin aplicar |

<span id="examples" />

## Ejemplos

<span id="apply-the-default-config-file" />

### Aplicar el archivo de configuración predeterminado

```bash
lizard config apply
```

<span id="apply-a-config-file-from-a-custom-path" />

### Aplicar un archivo de configuración desde una ruta personalizada

```bash
lizard config apply -f ./configs/prod.json
```

<span id="preview-changes-without-applying-them" />

### Previsualizar cambios sin aplicarlos

```bash
lizard config apply --dry-run
```
