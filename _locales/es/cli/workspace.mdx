# lizard workspace

Crea, lista y elimina workspaces.

<span id="usage" />

## Uso

```bash
lizard workspace list
lizard workspace create <name>
lizard workspace rm <name-or-id> [flags]
```

<span id="subcommands" />

## Subcomandos

<span id="lizard-workspace-list" />

### `lizard workspace list`

Lista los workspaces a los que perteneces, con tu rol y el número de proyectos (alias `ls`).

<span id="lizard-workspace-create-name" />

### `lizard workspace create <name>`

Crea un workspace. Añade proyectos con `lizard project create <name> --workspace <slug>`.

<span id="lizard-workspace-rm-name-or-id" />

### `lizard workspace rm <name-or-id>`

Elimina un workspace (alias `delete`). Solo el propietario puede eliminarlo, y solo cuando ya no tiene proyectos ni sandboxes. No puedes eliminar tu workspace personal.

| Flag | Descripción |
|------|-------------|
| `-y, --yes` | Omite la confirmación |

<span id="examples" />

## Ejemplos

<span id="list-your-workspaces" />

### Lista tus workspaces

```bash
lizard workspace list
```

<span id="create-a-workspace" />

### Crea un workspace

```bash
lizard workspace create my-team
```

<span id="delete-an-empty-workspace" />

### Elimina un workspace vacío

```bash
lizard workspace rm my-team --yes
```
