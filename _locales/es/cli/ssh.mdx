# lizard ssh

> **Desactivado.** El acceso a shell en los servicios está deshabilitado en Lizard. `lizard ssh` recibe HTTP 403 `Shell access to services is disabled` y termina con el código `1`.

El comando sigue incluido en la CLI, pero la plataforma lo rechaza para todos los servicios. Usa estas alternativas:

| Para comprobar | Comando |
|----------|---------|
| Referencias que se resolvieron a un valor vacío | `lizard logs --build --service api` (el log de build avisa de cada referencia `${{…}}` vacía) |
| Los valores almacenados en un servicio | `lizard secrets list --service api --show` |
| Un comando con los valores de conexión reales de un addon | `lizard run --service postgres -- <cmd>` |
| Lo que imprime la app en tiempo de ejecución | `lizard logs --service api` |

Para obtener una shell en un sandbox, usa [`lizard sandbox ssh <id>`](/cli/sandbox#sandbox-ssh). Sigue funcionando.

<span id="usage" />

## Uso

```bash
lizard ssh --service <name> -- <command>
```

| Flag | Descripción |
|------|-------------|
| `-s, --service <id>` | Nombre o ID del servicio |
| `-p, --project <id>` | Nombre, slug o ID del proyecto |
