# lizard port

Muestra o cambia el puerto del contenedor de un servicio. Sin argumentos, imprime el puerto actual (`worker mode` cuando es `0`).

<span id="usage" />

## Uso

```bash
lizard port [value] [flags]
```

<span id="flags" />

## Banderas

| Bandera | Descripción |
|------|-------------|
| `-s, --service <name>` | Servicio de destino |

<span id="examples" />

## Ejemplos

<span id="show-the-current-port" />

### Mostrar el puerto actual

```bash
lizard port
```

<span id="set-the-port-for-a-specific-service" />

### Establecer el puerto para un servicio específico

```bash
lizard port 0 -s worker
```

<span id="check-the-port-on-a-worker-service" />

### Comprobar el puerto en un servicio worker

```bash
lizard port --service worker
```
