# lizard upgrade

Actualiza la CLI a la versión más reciente.

<span id="usage" />

## Uso

```bash
lizard upgrade [flags]
```

Cómo se actualiza depende de cómo instalaste la CLI:

- **Script de instalación en macOS o Linux:** descarga la última versión y reemplaza el binario.
- **npm:** muestra el comando que debes ejecutar, `npm install -g @lizard-build/cli@latest`.
- **Windows:** el binario no puede reemplazarse a sí mismo. Vuelve a ejecutar el instalador: `irm https://lizard.build/api/cli/install.ps1 | iex`.

<span id="flags" />

## Banderas

| Bandera | Descripción |
|------|-------------|
| `--check` | Comprueba si hay una versión más reciente sin instalarla |

<span id="examples" />

## Ejemplos

<span id="update-to-the-latest-version" />

### Actualizar a la versión más reciente

```bash
lizard upgrade
```

<span id="check-for-updates-without-installing" />

### Comprobar actualizaciones sin instalar

```bash
lizard upgrade --check
```
