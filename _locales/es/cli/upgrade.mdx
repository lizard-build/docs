# lizard upgrade

Actualiza la CLI a la versión más reciente.

<span id="usage" />

## Uso

```bash
lizard upgrade [flags]
```

<span id="flags" />

## Banderas

| Bandera | Descripción |
|------|-------------|
| `--check` | Comprueba si hay una versión más reciente sin instalarla |

<span id="examples" />

## Ejemplos

<span id="update-to-the-latest-version" />

### Actualizar a la versión más reciente

```bash
lizard upgrade
```

<span id="check-for-updates-without-installing" />

### Comprobar actualizaciones sin instalar

```bash
lizard upgrade --check
```
