# lizard status

Muestra el espacio de trabajo, proyecto y servicio vinculados al directorio actual.

<span id="usage" />

## Uso

```bash
lizard status
```

<span id="examples" />

## Ejemplos

<span id="check-the-current-directorys-link" />

### Verificar el vínculo del directorio actual

```bash
lizard status
```
