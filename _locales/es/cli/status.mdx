# lizard status

Muestra el espacio de trabajo, proyecto y servicio vinculados al directorio actual. No necesita una sesión iniciada.

En un directorio sin vincular imprime `Not linked`. Los comandos ahí usan el proyecto predeterminado de tu cuenta, y `lizard up` vincula el directorio a él.

<span id="usage" />

## Uso

```bash
lizard status
```

<span id="examples" />

## Ejemplos

<span id="check-the-current-directorys-link" />

### Verificar el vínculo del directorio actual

```bash
lizard status
```

<span id="read-the-link-from-a-script" />

### Leer el vínculo desde un script

```bash
lizard status --json
```

Un directorio vinculado devuelve `cwd`, `linked: true`, `workspace`, `workspaceId`, `project`, `projectId`, `service` y `serviceId`. Uno sin vincular devuelve `{"cwd": "…", "linked": false}`.
