# lizard init

Crea o selecciona un proyecto y lo vincula al directorio actual.

<span id="usage" />

## Uso

```bash
lizard init [flags]
```

<span id="flags" />

## Banderas

| Bandera | Descripción |
|------|-------------|
| `-n, --name <name>` | Nombre del proyecto (créalo si no existe) |
| `-w, --workspace <ws>` | ID, slug o nombre del workspace |
| `--force` | Volver a vincular aunque ya esté vinculado |

<span id="examples" />

## Ejemplos

<span id="link-the-current-directory-interactively" />

### Vincular el directorio actual de forma interactiva

```bash
lizard init
```

Sin `--name`, `init` pregunta qué proyecto usar. En una shell no interactiva falla en su lugar, así que pasa `--name`.

<span id="link-explicitly-in-ci" />

### Vincular explícitamente en CI

Un `lizard up` en un directorio sin vincular despliega en el proyecto predeterminado de tu cuenta. Para desplegar en CI en un proyecto concreto, vincúlalo primero:

```bash
export LIZARD_TOKEN=liz_xxx
lizard init --name my-project
lizard up --ci --service api   # creates api on the first run
```

<span id="relink-a-directory-thats-already-linked" />

### Volver a vincular un directorio que ya está vinculado

```bash
lizard init --name my-project --force
```
