# lizard ps

Enumera todos los servicios del proyecto con su estado y URL.

<span id="usage" />

## Uso

```bash
lizard ps [flags]
```

<span id="flags" />

## Banderas

| Bandera | Descripción |
|------|-------------|
| `-p, --project <id>` | Nombre, slug o ID del proyecto |

Sin `-p`, `ps` usa el proyecto vinculado o, en una carpeta sin vincular, tu proyecto predeterminado.

<span id="examples" />

## Ejemplos

<span id="list-services-in-the-linked-project" />

### Enumerar servicios en el proyecto vinculado

```bash
lizard ps
```

<span id="list-services-in-another-project" />

### Enumerar servicios en otro proyecto

```bash
lizard ps -p my-project
```
