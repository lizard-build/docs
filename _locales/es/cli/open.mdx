# lizard open

Abre el proyecto en el navegador.

<span id="usage" />

## Uso

```bash
lizard open [flags]
```

<span id="flags" />

## Banderas

| Bandera | Descripción |
|------|-------------|
| `-p, --project <id>` | Nombre, slug o ID del proyecto |

Sin `-p`, `open` usa el proyecto vinculado o, en una carpeta sin vincular, tu proyecto predeterminado. Con `--json` imprime `{ url, opened: false }` y no abre el navegador.

<span id="examples" />

## Ejemplos

<span id="open-the-current-projects-dashboard" />

### Abrir el panel del proyecto actual

```bash
lizard open
```

<span id="print-the-dashboard-url" />

### Imprimir la URL del panel

```bash
lizard open --json
```
