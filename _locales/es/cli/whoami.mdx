# lizard whoami

Muestra la cuenta con la que has iniciado sesión y, en una carpeta vinculada, el proyecto vinculado y su espacio de trabajo.

<span id="usage" />

## Uso

```bash
lizard whoami
```

<span id="what-it-shows" />

## Qué muestra

- Con sesión iniciada en una cuenta: tu nombre de usuario, si la GitHub App está conectada y el proyecto vinculado con su espacio de trabajo entre paréntesis. En una carpeta sin vincular muestra `Project: none`; los comandos que ejecutes ahí usan el proyecto predeterminado de tu cuenta.
- Con una clave de API con ámbito: `Scoped API key (account details are not visible)` y después cada proyecto o espacio de trabajo al que llega la clave. Nunca muestra la cuenta que hay detrás de la clave.

`whoami` no muestra un espacio de trabajo activo. Para listar tus espacios de trabajo, ejecuta [`lizard workspace list`](/cli/workspace).

Con `--json`, o cuando la salida no es una terminal, imprime los campos de tu cuenta más `project`. Para una clave con ámbito imprime `{ "scoped": true, "scopes": [...], "project": ... }`.
