# lizard regions

Lista las regiones disponibles.

<span id="usage" />

## Uso

```bash
lizard regions [flags]
```

<span id="flags" />

## Banderas

| Bandera | Descripción |
|------|-------------|
| `--json` | Salida en JSON |

<span id="examples" />

## Ejemplos

<span id="list-available-regions" />

### Listar regiones disponibles

```bash
lizard regions
```

<span id="list-regions-as-json" />

### Listar regiones como JSON

```bash
lizard regions --json
```

<span id="choose-a-region-when-creating-a-service-or-addon" />

<span id="choose-a-region-when-you-create-a-resource" />

### Elegir una región al crear un recurso

Pasa `--region <code>` a `lizard add`, `lizard up`, `lizard sandbox create` o `lizard volume create`:

```bash
lizard add -r your-org/your-app --region <code>
lizard add postgres --region <code>
lizard up --region <code>
```

Sin `--region`, `lizard add` usa `us-east-1` y `lizard up` usa la región predeterminada de la plataforma. En `lizard up`, `--region` solo se aplica cuando crea un nuevo servicio.
