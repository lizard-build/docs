# lizard skills

Lee las skills para agentes integradas que se incluyen con esta versión de CLI. Alias: `lizard skill`.

<span id="usage" />

## Uso

```bash
lizard skills list
lizard skills get core [flags]
lizard skills path [name] [flags]
```

<span id="subcommands" />

## Subcomandos

### `lizard skills list`

Lista las skills integradas disponibles con sus descripciones y referencias.

### `lizard skills get core`

Lee la guía principal: la visión general de la plataforma para agentes, versionada junto con la CLI. Cubre sandboxes, despliegues, bases de datos, secretos, dominios, logs y códigos de salida. Los detalles están en tres referencias: `deploys`, `sandboxes` y `sdk`.

Con `--json` devuelve `{ name, path, frontmatter, content, references }`. `content` es la guía principal, y `references` lista para cada referencia su `name`, su `path` y el `command` que la imprime.

| Bandera | Descripción |
|------|-------------|
| `--ref <name>` | Imprime en su lugar una referencia: `deploys`, `sandboxes` o `sdk`. Con `--json` devuelve `{ name, ref, path, content }` |
| `--full` | Añade todas las referencias después de la guía principal |

### `lizard skills path [name]`

Imprime de dónde proviene una skill. Las skills están integradas en la CLI, por lo que `lizard skills path` imprime `embedded://skills` y `lizard skills path core` imprime `embedded://skills/core/SKILL.md`, a menos que `LIZARD_SKILLS_DIR` apunte la CLI a un directorio en el disco. `--ref <name>` imprime la ruta de una referencia.

<span id="examples" />

## Ejemplos

<span id="load-the-core-guide-as-an-agent" />

### Cargar la guía principal como agente

```bash
lizard skills get core --json
```

<span id="load-one-reference" />

### Cargar una referencia

```bash
lizard skills get core --ref deploys --json
```

<span id="print-the-core-guide-with-every-reference" />

### Imprimir la guía principal con todas las referencias

```bash
lizard skills get core --full
```

<span id="list-available-embedded-skills" />

### Listar las skills integradas disponibles

```bash
lizard skills list
```
