# lizard skills

Lee las skills para agentes integradas que se incluyen con esta versión de CLI. Alias: `lizard skill`.

<span id="usage" />

## Uso

```bash
lizard skills list
lizard skills get core
lizard skills path
```

<span id="subcommands" />

## Subcomandos

### `lizard skills list`

Lista las skills integradas disponibles.

### `lizard skills get core`

Lee la guía principal — la guía de uso autorizada para la plataforma, versionada junto con la CLI. Con `--json` devuelve `{ name, path, frontmatter, content }`, donde `content` es la guía completa (pipeline de build, precedencia de env, addons, discovery, códigos de salida).

### `lizard skills path [name]`

Imprime de dónde proviene una skill. Las skills están integradas en la CLI, por lo que esto imprime `embedded://skills` a menos que `LIZARD_SKILLS_DIR` apunte la CLI a un directorio en el disco.

<span id="examples" />

## Ejemplos

<span id="load-the-core-guide-as-an-agent" />

### Cargar la guía principal como agente

```bash
lizard skills get core --json
```

<span id="list-available-embedded-skills" />

### Listar las skills integradas disponibles

```bash
lizard skills list
```
