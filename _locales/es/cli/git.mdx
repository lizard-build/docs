# lizard git

Conecta tu cuenta de Lizard a GitHub, consulta desde qué repositorios se despliegan los servicios de un proyecto y cambia un servicio a otra rama. La conexión de la GitHub App pertenece a tu cuenta de Lizard, no a un proyecto concreto.

Los demás subcomandos de `lizard git` pertenecen a Lizard Git, que esta página no cubre.

<span id="usage" />

## Uso

```bash
lizard git connect
lizard git status [flags]
lizard git checkout <service> <branch> [flags]
```

Sin `-p`, `status` y `checkout` usan el proyecto vinculado o, en una carpeta sin vincular, tu proyecto predeterminado.

<span id="subcommands" />

## Subcomandos

### `lizard git connect`

Conecta la GitHub App para acceder a repositorios privados. El comando abre GitHub para instalar la app, espera a que pulses Enter y luego comprueba la conexión. Si la app ya está conectada, lo indica. Con `--json` o sin terminal, imprime en su lugar la URL de instalación: `{ installed: false, installUrl }`.

### `lizard git status`

Muestra si la GitHub App está conectada y desde qué repositorio y rama se despliega cada servicio del proyecto.

| Bandera | Descripción |
|------|-------------|
| `-p, --project <id>` | Nombre, slug o ID del proyecto |

### `lizard git checkout <service> <branch>`

Cambia un servicio a una rama diferente y vuelve a desplegarlo.

| Bandera | Descripción |
|------|-------------|
| `--detach` | Omitir la transmisión de logs |
| `-p, --project <id>` | Nombre, slug o ID del proyecto |

<span id="examples" />

## Ejemplos

<span id="connect-the-github-app" />

### Conectar la GitHub App

```bash
lizard git connect
```

<span id="check-connection-and-repository-status" />

### Comprobar la conexión y el estado del repositorio

```bash
lizard git status
```

<span id="switch-a-service-to-a-different-branch" />

### Cambiar un servicio a una rama diferente

```bash
lizard git checkout api staging
```

<span id="switch-branches-without-streaming-logs" />

### Cambiar de rama sin transmitir logs

```bash
lizard git checkout api staging --detach
```
