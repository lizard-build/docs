# lizard secrets

Gestiona los secretos (variables de entorno) de un proyecto o servicio.

## Usage

```bash
lizard secrets <subcommand> [args] [flags]
```

## Subcommands

### `lizard secrets set <K=V>...`

Establece uno o más secretos (variádico). El ámbito predeterminado es el servicio; `--global` apunta al proyecto.

| Flag | Description |
|------|-------------|
| `--global` | Ámbito del proyecto |
| `-s, --service <name>` | Ámbito del servicio |

### `lizard secrets list`

Lista los secretos del ámbito.

| Flag | Description |
|------|-------------|
| `--show` | Mostrar valores |
| `--ref` | Mostrar referencias |

### `lizard secrets delete <K>...`

Elimina uno o más secretos (variádico).

### `lizard secrets import`

Importa un archivo dotenv desde stdin.

## Examples

<span id="set-secrets-on-the-linked-service" />

### Establecer secretos en el servicio vinculado

```bash
lizard secrets set DATABASE_URL=postgres://… LOG_LEVEL=info
lizard secrets set API_KEY=sk_live_… --service api
```

<span id="set-a-project-wide-secret" />

### Establecer un secreto para todo el proyecto

```bash
lizard secrets set NODE_ENV=production --global
```

<span id="list-and-reveal-secrets" />

### Listar y mostrar secretos

```bash
lizard secrets list
lizard secrets list --show
```

<span id="delete-secrets" />

### Eliminar secretos

```bash
lizard secrets delete OLD_KEY ANOTHER_KEY
```

<span id="import-a-dotenv-file" />

### Importar un archivo dotenv

```bash
cat .env | lizard secrets import
```
