# Agentes de programación

Lizard está diseñado para ser manejado por agentes de programación con IA tan fácilmente como por humanos. Lizard CLI incluye una **skill integrada** que le enseña a un agente toda la plataforma, y cada comando es **autodescriptivo** mediante `--json` para que los agentes nunca tengan que adivinar.

<span id="the-embedded-skill" />

## La skill integrada

La guía de uso autoritativa vive dentro de la CLI y está versionada con ella, por lo que siempre coincide con la versión instalada. Un agente la lee con:

```bash
lizard skills get core --json
```

Esto devuelve `{ name, frontmatter, content, … }` — `content` es la guía completa (pipeline de build, precedencia de env, addons, descubrimiento, códigos de salida). Subcomandos relacionados:

```bash
lizard skills list        # available embedded skills
lizard skills get core    # the core guide
lizard skills path        # where skills are stored
```

Como la guía viene incluida con el binario, `lizard upgrade` también actualiza las instrucciones del agente.

<span id="self-describing-commands" />

## Comandos autodescriptivos

Los agentes descubren la forma exacta de los flags en tiempo de ejecución en lugar de depender de una sintaxis memorizada:

```bash
lizard --help --json                # full command tree + exit codes
lizard <cmd> --help --json          # a specific command's schema
```

Consulta [JSON y automatización](/cli/json).

<span id="bootstrapping-in-an-agent" />

## Inicialización dentro de un agente

Un flujo típico de un agente:

1. **Cargar la guía:** `lizard skills get core --json` → leer `content`.
2. **Verificar la autenticación de forma optimista:** ejecuta la tarea del usuario; con el código de salida `2`, ejecuta `lizard login`, entrega al usuario la URL impresa y luego reintenta.
3. **Iniciar la prueba si se solicita:** una cuenta nueva no tiene plan, así que su primera creación falla con HTTP 402 (`code: "PAYMENT_REQUIRED"`, código de salida `1`). Ejecuta `lizard billing start --json`, entrega al usuario la `url` de Checkout y reintenta cuando haya añadido una tarjeta.
4. **Resolver el contexto antes de modificar:** `lizard status` (enlace cwd) y `lizard ps --json` (servicios).
5. **Actuar** usando la guía — `add`, `up`, `secrets`, `domain`, etc., siempre con `--json`.

Si el binario `lizard` no está presente, instálalo primero. En macOS o Linux, usa el script de instalación:

```bash
curl -fsSL https://lizard.build/install.sh | bash
```

No necesita Node.js ni `sudo`, y enlaza `lizard` en una carpeta que ya está en el `PATH`, así que el agente puede llamarlo en la misma sesión. Si el script avisa de que quizá no se encuentre `lizard`, llama a `~/.lizard/bin/lizard`. En Windows, ejecuta esto en PowerShell:

```powershell
irm https://lizard.build/api/cli/install.ps1 | iex
```

O instala desde npm en cualquier sistema:

```bash
npm install -g @lizard-build/cli
```

<span id="conventions-agents-should-follow" />

## Convenciones que los agentes deben seguir

- **Pasa siempre `--json`** en llamadas no interactivas.
- **Confirma las acciones destructivas** (eliminar servicio, quitar addon, sobrescribir un secreto de todo el proyecto, reinicio de prod) con el usuario — los propios prompts de la CLI solo se activan en un TTY.
- **Limita los secretos al servicio que los consume** por defecto; reserva `--global` para valores demostrablemente públicos. Consulta [Variables y secretos](/variables#scoping).
- **No escribas Dockerfiles sin que se soliciten** — lizardpack detecta automáticamente la mayoría de los stacks. Prueba primero un despliegue. Consulta [Pipeline de build](/concepts/build-pipeline).
- **No uses `lizard up` para cambiar un servicio respaldado por git a upload** — usa `service set` + `redeploy`.

<span id="editor-integrations" />

## Integraciones con editores

Lizard Skill se distribuye como un bootstrap público para que los agentes en editores y asistentes puedan instalarla y cargarla bajo demanda, y luego manejar la misma CLI descrita a lo largo de esta documentación. Instálala una sola vez para todos tus agentes:

```bash
npx skills add lizard-build/skill -g
```

Funciona con Claude Code, Cursor, Codex, Copilot, Gemini CLI y otros agentes que leen el formato Agent Skills. Para los clientes que usan MCP en lugar de ejecutar comandos de shell, usa [Lizard MCP](#lizard-mcp).

Eso también cubre los IDE con IA: escriben y prueban una app, pero no la alojan. Consulta [desplegar una app creada en Google Antigravity](https://lizard.build/blog/google-antigravity-how-to-deploy-your-app-to-production#deploy-from-the-antigravity-chat), donde un solo prompt impulsa todo el despliegue.

<span id="lizard-mcp" />

## Lizard MCP

Lizard MCP permite que ChatGPT, Claude y otros clientes MCP gestionen tus proyectos de Lizard: crear servicios y addons, redesplegar, leer logs y métricas, definir secretos, escalar réplicas y asociar dominios. Es un servidor alojado que habla Streamable HTTP en:

```text
https://employ-woman-g1q2.us-east-1.onlizard.com/mcp
```

Un cliente que admita OAuth te hace iniciar sesión en el primer uso. Otros clientes envían una clave de API `liz_` en la cabecera `Authorization: Bearer`; crea una con `lizard keys create <name>`.

Añádelo a Claude Code:

```bash
claude mcp add --transport http lizard https://employ-woman-g1q2.us-east-1.onlizard.com/mcp
```

Para Cursor y otros clientes configurados mediante JSON:

```json
{
  "mcpServers": {
    "lizard": {
      "url": "https://employ-woman-g1q2.us-east-1.onlizard.com/mcp",
      "headers": { "Authorization": "Bearer liz_your_key" }
    }
  }
}
```

Iniciar la prueba, pagar y cancelar Pro se hace en la página de Billing. Cuando la cuenta tiene que pagar antes de poder crear algo, el error de la herramienta incluye `PAYMENT_REQUIRED` y el enlace que hay que abrir.

<span id="hosting-your-own-mcp-server" />

## Alojar tu propio servidor MCP

Un agente que usa Lizard CLI y una aplicación que expone MCP son flujos de trabajo separados. Los comandos de CLI anteriores no proporcionan un transporte MCP. Para desplegar tu propio servidor con Streamable HTTP, sigue la [guía de MCP remoto](/guides/deploy-mcp-server).
