# Documentación de Lizard

<span id="what-is-lizard" />

## ¿Qué es Lizard?

Lizard (lizard.build) es una plataforma de sandboxes en la nube para agentes de IA. Lizard Sandboxes son microVM de Firecracker, cada una con su propio kernel: en ellas un agente ejecuta código y comandos de shell, usa un escritorio y un navegador, abre URL HTTPS privadas para sus puertos y guarda archivos en Persistent Volumes. Crea sandboxes desde tu código con Lizard SDK para TypeScript o Python, o desde una terminal con Lizard CLI. Cuando el agente haya construido algo, despliégalo en la misma plataforma: `lizard up` sube la carpeta actual, `lizard add -r owner/repo` despliega un repositorio de GitHub, y Lizard compila la imagen en sus servidores y da a cada servicio web una dirección HTTPS en `onlizard.com`. La misma CLI añade Managed Postgres, Managed Redis y Managed Object Storage compatible con S3, y los conecta a tus servicios mediante referencias como `${{postgres.DATABASE_URL}}`. Lizard no es LizardFS, el sistema de archivos distribuido, ni `lizard`, la herramienta de Python que mide la complejidad del código.

## Ejecuta código en un sandbox

Crea una clave de API y un proyecto en el panel, define `LIZARD_API_KEY` e instala Lizard SDK. Este código crea un sandbox, ejecuta un comando y elimina el sandbox:

```bash
npm install @lizard-build/sdk
```

```ts
import { Lizard } from '@lizard-build/sdk'

const lizard = new Lizard({ project: 'my-project' })
const sandbox = await lizard.create('interpreter', { size: 'small' })

try {
  const run = await sandbox.process.exec("python -c 'print(2 ** 10)'")
  console.log(run.stdout) // 1024
} finally {
  await sandbox.kill()
}
```

El tamaño Small (2 vCPU, 4 GB RAM) cuesta $0.0162 por hora, con facturación por segundo. Para Python, plantillas y tiempos de vida, consulta la [guía rápida de Sandboxes](/sandboxes/quickstart) y la [descripción general de Sandboxes](/sandboxes).

## Despliega una app

Instala Lizard CLI. El instalador inicia tu sesión y te ofrece la prueba de Pro de 7 días: añades una tarjeta en Stripe Checkout y no se cobra nada durante la prueba. Luego despliega un repositorio al que tengas acceso:

```bash
curl -fsSL https://lizard.build/install.sh | bash   # then signs you in and offers the trial
lizard add -r your-org/your-app
```

En Windows o con npm, consulta [otras formas de instalación](/getting-started#1-install-the-cli).

Lizard compila la imagen en sus servidores, así que esta ruta no necesita Docker local. [lizardpack](/concepts/build-pipeline) detecta los proyectos compatibles; los proyectos con necesidades de compilación especiales pueden usar comandos explícitos o un Dockerfile. Revisa los logs de compilación y verifica la URL de la aplicación después del despliegue.

<span id="understand-your-resources" />

## Entiende tus recursos

Un **workspace** agrupa miembros y proyectos. Un **project** agrupa servicios, bases de datos y Sandboxes. Un **service** ejecuta una aplicación o un worker. Managed Postgres, Managed Redis y Managed Object Storage proporcionan servicios de datos a los que las aplicaciones se conectan mediante referencias de entorno.

Las apps y Sandboxes tienen reglas distintas de ejecución y almacenamiento. Lee [límites](/platform/limits) y [almacenamiento y recuperación](/platform/storage-and-recovery) antes de depender del tamaño, la duración o la retención de datos de un recurso.
