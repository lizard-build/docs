# Panel de la app

El panel de Lizard es el complemento visual de Lizard CLI. Todo lo que haces con `lizard …` se refleja aquí, además de lo que es más fácil con una interfaz — logs en streaming, gráficos, los exploradores de datos, Sandboxes y la gestión de equipo/facturación.

Si prefieres no abrir un terminal en absoluto, deja que el agente ejecute los comandos y observa el resultado aquí — la ruta de [desplegar una app Antigravity en producción](https://lizard.build/blog/google-antigravity-how-to-deploy-your-app-to-production#deploy-from-the-antigravity-chat), donde un solo prompt dirige el despliegue.

Ábrelo desde el CLI:

```bash
lizard open          # open the current project
lizard docs          # open this documentation
```

## Qué hay en el panel

<span id="services" />

### Servicios

**Apps y bases de datos**, en la barra lateral, muestra cada servicio con su indicador de estado, dominio generado y un acceso rápido a logs, métricas, secretos y ajustes. Crea un servicio con **Nuevo servicio**: desde un repositorio de GitHub, desde una carpeta de tu equipo o como base de datos (Managed Postgres, Managed Redis) o Managed Object Storage.

La pestaña **Configuración** de un servicio también tiene **Serverless**, que lo deja dormir cuando está inactivo ([`lizard sleep`](/cli/sleep)), y **Pausar**, que lo detiene sin borrar nada ([`lizard pause`](/cli/pause)).

<span id="deployments" />

### Despliegues

La pestaña **Resumen** de cada servicio lista sus despliegues. Abre uno para ver su estado, desencadenante, origen, logs de compilación y reinicios. Este es el equivalente visual de `lizard events` + `lizard logs --build`.

### Logs

Streaming en vivo de logs de ejecución y compilación con búsqueda y filtros por nivel — la contraparte en la interfaz de [`lizard logs`](/observability/logs).

<span id="metrics--usage" />

### Métricas y uso

Gráficos de CPU, memoria, red y disco por servicio, además de la página **Uso**, que desglosa el consumo y el coste en todo el proyecto. Refleja [`lizard metrics --cost`](/observability/metrics).

<span id="variables--secrets" />

### Variables y secretos

Gestiona los secretos con alcance de servicio en la pestaña **Secrets** de cada servicio y los de proyecto en **Secretos globales**, con valores ocultos y compatibilidad con referencias (`${{…}}`). Consulta [Variables y secretos](/variables).

<span id="domains" />

### Dominios

En la pestaña **Configuración** de un servicio, añade dominios personalizados, consulta registros DNS y sigue el estado de verificación y TLS. Consulta [Redes](/networking).

<span id="managed-addon-browsers" />

<span id="data-browsers" />

### Exploradores de datos

Cada addon gestionado incluye un explorador de datos:

- **Managed Postgres** — un editor SQL/de tablas para consultar y editar datos.
- **Managed Redis** — un explorador de clave/valor.
- **Managed Object Storage** — un explorador de buckets y objetos con subida/descarga y ajustes de acceso a los buckets.

<span id="sandboxes" />

### Sandboxes

La barra lateral tiene **Sandboxes**, **Volúmenes** (Persistent Volumes), **Plantillas** y **Agentes**. Crea un sandbox con **Nuevo Sandbox** en la página Sandboxes; junto al botón, el panel muestra las vCPU en uso y tu límite de vCPU. Durante la prueba, el diálogo solo ofrece el tamaño Small en regiones de US. Consulta [Guía rápida de Sandboxes](/sandboxes/quickstart).

<span id="github-integration" />

### Integración con GitHub

Conecta GitHub desde **Nuevo servicio → Repositorio de GitHub**. Una vez conectado, **Configurar acceso**, bajo la lista de repositorios, abre los ajustes de la GitHub App, donde eliges qué repositorios puede compilar Lizard. Un repositorio público también se despliega pegando su URL, sin conectar GitHub. Consulta [Desplegar desde GitHub](/deploy/github).

<span id="settings-team--billing" />

### Ajustes, equipo y facturación

**Configuración**, al pie de la barra lateral, reúne los ajustes del proyecto y del workspace, las invitaciones de miembros y los roles (**Equipo**), y los ajustes de tu cuenta. Abre **Facturación** desde los ajustes de la cuenta o haciendo clic en tu plan en la parte superior del panel. Muestra tu plan, la prueba, el uso del periodo actual, las facturas y la tarjeta. Consulta [Facturación](/platform/billing).

## CLI ↔ Panel

| Tarea | CLI | Vista del panel |
|------|-----|----------------|
| Historial de despliegues | `lizard events` | Servicio → Resumen |
| Streaming de logs | `lizard logs` | Logs |
| Gráficos de recursos | `lizard metrics` | Métricas / Uso |
| Gestionar secretos | `lizard secrets` | Secrets / Secretos globales |
| Dominios personalizados | `lizard domain` | Servicio → Configuración |
| Pausar o reanudar un servicio | `lizard pause` / `lizard resume` | Servicio → Configuración |
| Dormir cuando está inactivo | `lizard sleep` | Servicio → Configuración → Serverless |
| Consultar Managed Postgres, Managed Redis o Managed Object Storage | `lizard run --service <addon> -- <cmd>` | Exploradores de datos |
| Invitar a compañeros de equipo | — | Configuración → Equipo |

Usa lo que mejor se adapte al momento — operan sobre los mismos proyectos y servicios.
