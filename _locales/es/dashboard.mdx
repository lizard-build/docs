# Panel de la app

El panel de Lizard es el complemento visual de Lizard CLI. Todo lo que haces con `lizard …` se refleja aquí, además de lo que es más fácil con una interfaz — logs en streaming, gráficos, los exploradores de datos, Sandboxes y la gestión de equipo/facturación.

Si prefieres no abrir un terminal en absoluto, deja que el agente ejecute los comandos y observa el resultado aquí — la ruta de [desplegar una app Antigravity en producción](https://lizard.build/blog/google-antigravity-how-to-deploy-your-app-to-production#deploy-from-the-antigravity-chat), donde un solo prompt dirige el despliegue.

Ábrelo desde el CLI:

```bash
lizard open          # open the current project
lizard docs          # open this documentation
```

## Qué hay en el panel

<span id="services" />

### Servicios

La vista principal del proyecto muestra cada servicio con su indicador de estado, dominio generado y un acceso rápido a logs, métricas, secretos y ajustes. Crea nuevos servicios (desde un repositorio de GitHub o vacío) directamente desde aquí.

<span id="deployments" />

### Despliegues

Una cronología de cada despliegue, con logs de compilación por despliegue y un panel de detalles (commit, estado, réplicas). Este es el equivalente visual de `lizard events` + `lizard logs --build`.

### Logs

Streaming en vivo de logs de ejecución y compilación con búsqueda y filtros por nivel — la contraparte en la interfaz de [`lizard logs`](/observability/logs).

<span id="metrics--usage" />

### Métricas y uso

Gráficos de CPU, memoria, red y disco por servicio, además de una vista de **Uso** que desglosa el consumo y el coste en todo el proyecto. Refleja [`lizard metrics --cost`](/observability/metrics).

<span id="variables--secrets" />

### Variables y secretos

Gestiona secretos con alcance de servicio y de proyecto, con valores ocultos y compatibilidad con referencias (`${{…}}`). Consulta [Variables y secretos](/variables).

<span id="domains" />

### Dominios

Añade dominios personalizados, consulta registros DNS y sigue el estado de verificación y TLS. Consulta [Redes](/networking).

<span id="managed-addon-browsers" />

<span id="data-browsers" />

### Exploradores de datos

Cada addon gestionado incluye un explorador de datos:

- **Managed Postgres** — un editor SQL/de tablas para consultar y editar datos.
- **Managed Redis** — un explorador de clave/valor.
- **Managed Object Storage** — un explorador de buckets y objetos con subida/descarga y ajustes de acceso a los buckets.

<span id="sandboxes" />

### Sandboxes

La página **Sandboxes** tiene pestañas para sandboxes, Persistent Volumes, plantillas y agentes. Crea un sandbox con **New Sandbox**; el contador junto a él muestra cuántos se están ejecutando respecto a tu límite. Consulta [Guía rápida de Sandboxes](/sandboxes/quickstart).

<span id="github-integration" />

### Integración con GitHub

Conecta la GitHub App, elige repositorios y gestiona qué repositorios puede compilar Lizard. Consulta [Desplegar desde GitHub](/deploy/github).

<span id="settings-team--billing" />

### Ajustes, equipo y facturación

Ajustes del proyecto y del workspace, invitaciones de miembros y roles, y uso de recursos. La página **Facturación** de la configuración de la cuenta muestra tu plan, la prueba, los créditos usados este mes, las facturas y la tarjeta. Consulta [Facturación](/platform/billing).

## CLI ↔ Panel

| Tarea | CLI | Vista del panel |
|------|-----|----------------|
| Historial de despliegues | `lizard events` | Despliegues |
| Streaming de logs | `lizard logs` | Logs |
| Gráficos de recursos | `lizard metrics` | Métricas / Uso |
| Gestionar secretos | `lizard secrets` | Variables |
| Dominios personalizados | `lizard domain` | Dominios |
| Consultar Managed Postgres, Managed Redis o Managed Object Storage | `lizard run --service <addon> -- <cmd>` | Exploradores de datos |
| Invitar a compañeros de equipo | — | Equipo / Ajustes |

Usa lo que mejor se adapte al momento — operan sobre los mismos proyectos y servicios.
