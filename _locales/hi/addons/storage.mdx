# Managed Object Storage

Lizard पर Managed Object Storage अपलोड, एसेट्स और बैकअप के लिए S3-संगत स्टोरेज है। `lizard add s3` `default` नाम का एक प्राइवेट बकेट और पांच कनेक्शन वैरिएबल, `S3_ENDPOINT` से `S3_REGION` तक बनाता है। उन्हें किसी भी AWS SDK और पाथ-स्टाइल एड्रेसिंग के साथ उपयोग करें। प्रत्येक Managed Object Storage एडऑन 16 GiB तक स्टोर कर सकता है, और आप स्टोर किए गए बाइट्स के लिए भुगतान करते हैं। बिना प्रमाणीकरण के फ़ाइलें सर्व करने के लिए, डैशबोर्ड के S3 ब्राउज़र से बकेट को पब्लिक बनाएं। अवलोकन और कीमतों के लिए, [Managed Object Storage पेज](https://lizard.build/object-storage) देखें।

<span id="provision" />

## प्रोविज़न

```bash
lizard add s3
```

पहला Managed Object Storage एडऑन `s3` नाम का है, इसलिए `${{s3.S3_ENDPOINT}}` जैसे रेफरेंस तुरंत काम करते हैं।

<span id="environment-variables" />

## एनवायरनमेंट वेरिएबल्स

| वेरिएबल | विवरण |
|----------|-------------|
| `S3_ENDPOINT` | S3-संगत एंडपॉइंट URL |
| `S3_DEFAULT_BUCKET` | ऑटो-क्रिएटेड बकेट का नाम (`default`) |
| `S3_ACCESS_KEY_ID` | एक्सेस की |
| `S3_SECRET_ACCESS_KEY` | सीक्रेट की |
| `S3_REGION` | रीजन |

<span id="connect-a-service" />

## एक सेवा कनेक्ट करें

```bash
lizard secrets set \
  S3_ENDPOINT='${{s3.S3_ENDPOINT}}' \
  S3_DEFAULT_BUCKET='${{s3.S3_DEFAULT_BUCKET}}' \
  S3_ACCESS_KEY_ID='${{s3.S3_ACCESS_KEY_ID}}' \
  S3_SECRET_ACCESS_KEY='${{s3.S3_SECRET_ACCESS_KEY}}' \
  S3_REGION='${{s3.S3_REGION}}' \
  --service api
lizard redeploy --service api
```

<span id="using-an-aws-sdk" />

## AWS SDK का उपयोग करना

एंडपॉइंट S3-संगत है। **पाथ-स्टाइल** एड्रेसिंग सेट करें:

```ts
import { S3Client } from "@aws-sdk/client-s3";

const s3 = new S3Client({
  endpoint: process.env.S3_ENDPOINT,
  region: process.env.S3_REGION,
  forcePathStyle: true, // required
  credentials: {
    accessKeyId: process.env.S3_ACCESS_KEY_ID!,
    secretAccessKey: process.env.S3_SECRET_ACCESS_KEY!,
  },
});
```

## पब्लिक फ़ाइलें

बकेट डिफ़ॉल्ट रूप से प्राइवेट होते हैं। एक बार जब आप किसी बकेट को पब्लिक बना देते हैं, तो कोई भी दोनों एड्रेस के माध्यम से उसके ऑब्जेक्ट पढ़ सकता है:

1. **गेटवे URL** (डैशबोर्ड में दिखाया गया है):
   ```
   https://s3-<region>.onlizard.com/<addonId>/<bucket>/<key>
   ```
   `<region>` `S3_REGION` (`eu-west-1` या `us-east-1`) का मान है।
2. **प्लेटफ़ॉर्म प्रॉक्सी** (डैशबोर्ड होस्ट, लंबे समय तक चलने वाले अपरिवर्तनीय कैश हेडर के साथ):
   ```
   <dashboard-host>/api/s3/<addonId>/public/<bucket>/<key>
   ```

एक बार जब आप `default` बकेट को पब्लिक बना देते हैं, तो कोई भी इसके ऑब्जेक्ट्स को यहाँ पढ़ सकता है:

```
<dashboard-host>/api/s3/<addonId>/public/default/<key>
```

S3 ब्राउज़र में प्रत्येक बकेट के लिए दो स्विच होते हैं। **पब्लिक व्यू** किसी को भी इसके ऑब्जेक्ट्स को पढ़ने देता है। **पब्लिक एडिट** किसी को भी उन्हें अपलोड या डिलीट करने देता है, इसलिए इसे केवल उस बकेट के लिए चालू करें जिसे कोई भी बदल सकता है।

एक प्राइवेट बकेट से एक ऑब्जेक्ट को कुछ समय के लिए साझा करने के लिए, एक अस्थायी लिंक प्रिंट करें। यह समाप्त होने तक (डिफ़ॉल्ट रूप से एक घंटा, 7 दिनों तक) क्रेडेंशियल्स के बिना काम करता है:

```bash
lizard s3 url report.pdf --expires 86400
```

AWS SDK से प्रीसाइन्ड यूआरएल भी काम करते हैं।

<span id="browse-objects" />

## ऑब्जेक्ट ब्राउज़ करें

ऑब्जेक्ट्स अपलोड और डिलीट करने, फ़ोल्डर बनाने और बकेट को पब्लिक या प्राइवेट बनाने के लिए डैशबोर्ड (`lizard open`) में **S3 ब्राउज़र** खोलें। CLI से, `lizard s3 upload <file>` एक फ़ाइल अपलोड करता है, `lizard s3 list` ऑब्जेक्ट्स सूचीबद्ध करता है, और `lizard s3 url <key>` एक अस्थायी लिंक प्रिंट करता है; [`lizard s3`](/cli/s3) देखें।

> **बकेट ACL परिवर्तन** (बकेट को पब्लिक/प्राइवेट बनाना) के लिए डैशबोर्ड की आवश्यकता होती है; CLI अभी तक उनका समर्थन नहीं करता है।

<span id="storage-limit" />

## स्टोरेज सीमा

प्रत्येक Managed Object Storage एडऑन 16 GiB तक ऑब्जेक्ट्स स्टोर कर सकता है, जिसमें इसका `default` बकेट और आपके द्वारा बनाए गए कोई अन्य बकेट शामिल हैं। एक अन्य एडऑन (`lizard add s3`) को अपना 16 GiB मिलता है। आप स्टोर किए गए बाइट्स के लिए भुगतान करते हैं, न कि आरक्षित आकार के लिए; `lizard scale --storage` इस सीमा को नहीं बदलता है।
