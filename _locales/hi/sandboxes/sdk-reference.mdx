Lizard SDK, Sandboxes के लिए Lizard का क्लाइंट है: TypeScript और JavaScript के लिए npm पर `@lizard-build/sdk`, और Python के लिए `lizard-sdk`, जिसे `lizard` के रूप में इम्पोर्ट किया गया है। दोनों एक ही [HTTP API](#http-api) को कॉल करते हैं। नीचे प्रत्येक सैंडबॉक्स कॉल को उसके TypeScript और Python नामों के साथ, दोनों भाषाओं में उदाहरणों के साथ पाएं। एक गाइडेड फर्स्ट रन के लिए, [क्विकस्टार्ट](/sandboxes/quickstart) का उपयोग करें; Sandboxes क्या हैं, यह जानने के लिए [ओवरव्यू](/sandboxes) पढ़ें।

<span id="install-and-authenticate" />

## इंस्टॉल और प्रमाणित करें

```sh
npm install @lizard-build/sdk
pip install lizard-sdk
export LIZARD_API_KEY="<your-api-key>"
```

Settings → API keys में या [`lizard keys create <name>`](/cli/keys) के साथ एक API कुंजी बनाएं। SDK `LIZARD_API_KEY` को पढ़ता है; एक अलग कुंजी का उपयोग करने के लिए `apiKey` (Python: `api_key`) पास करें। प्रत्येक सैंडबॉक्स को एक प्रोजेक्ट की आवश्यकता होती है: `projectId` (Python: `project_id`) पास करें या `project` के साथ एक ID, स्लग, या नाम को रिजोल्व करें।

## विकल्प बनाएं

| TypeScript | Python |
|---|---|
| `projectId / project` | `project_id / project` |
| `timeoutMs` | `timeout_ms` |
| `region` | `region` |
| `volumeName / volumeId` | `volume_name / volume_id` |
| `size` | `size` |
| `snapshotId` | `snapshot_id` |
| `envs` | `envs` |
| `metadata` | `metadata` |
| `lizardToken` | `lizard_token` |
| `apiKey` | `api_key` |

```ts
import { Sandbox } from '@lizard-build/sdk';

const sandbox = await Sandbox.create('base', {
  projectId: 'proj_123',
  size: 'small',
  timeoutMs: 10 * 60 * 1000,
  envs: { MODE: 'test' },
  metadata: { task: 'report-42' },
});
```

```python
from lizard import Sandbox

sandbox = Sandbox.create(
    "base",
    project_id="proj_123",
    size="small",
    timeout_ms=10 * 60 * 1000,
    envs={"MODE": "test"},
    metadata={"task": "report-42"},
)
```

- पहला आर्गुमेंट [रनटाइम और टेम्प्लेट](/sandboxes#runtime-and-templates) में कैटलॉग से एक टेम्प्लेट है। इसके बिना, SDK `base` को बूट करता है।
- `size`, `'small'`, `'medium'`, या `'large'` है: 2 vCPU / 4 GB, 4 vCPU / 8 GB (डिफ़ॉल्ट), या 8 vCPU / 16 GB; [आकार और कीमतें](/platform/limits#sandbox-sizes) देखें। ट्रायल के दौरान, `'small'` डिफ़ॉल्ट और एकमात्र आकार है, और केवल US क्षेत्र काम करते हैं; एक अलग आकार या क्षेत्र `AuthenticationError` को HTTP 403. के साथ फेंकता है। `size` स्नैपशॉट से पुनर्स्थापित सैंडबॉक्स पर लागू नहीं होता है; यह उसके स्रोत के आकार पर चलता है।
- `timeoutMs` डिफ़ॉल्ट रूप से 300000, पांच मिनट है। `0` समाप्ति को अक्षम करता है। [संसाधन और टाइमआउट](/sandboxes#resources-and-timeouts) देखें।
- आवश्यकता पड़ने पर स्पष्ट रूप से एक क्षेत्र चुनें; कैटलॉग प्रविष्टि मुफ्त क्षमता की गारंटी नहीं देती है। जब आप वॉल्यूम संलग्न करते हैं तो `region` को अनसेट छोड़ दें: सैंडबॉक्स वहीं चलता है जहां वॉल्यूम है।
- `metadata` आपके अपने लेबल हैं; `getInfo()` इसे लौटाता है, `list()` नहीं।
- `lizardToken` आपकी `liz_` API कुंजियों में से एक लेता है और सैंडबॉक्स के अंदर `lizard` में साइन इन करता है। आपकी कुंजी केवल अनुरोध को अधिकृत करती है: सैंडबॉक्स को अपनी एक नई कुंजी मिलती है, जो सैंडबॉक्स के प्रोजेक्ट तक सीमित होती है और सैंडबॉक्स के साथ हटा दी जाती है, इसलिए `lizard` केवल उस प्रोजेक्ट पर कार्य कर सकता है। `base` टेम्प्लेट में कोई `lizard` नहीं है।

| `Sandbox.setSnapshotScope(snapshotId, scope)` | `Sandbox.set_snapshot_scope(snapshot_id, scope)` | बदलें कि आपके द्वारा लिया गया स्नैपशॉट कहाँ से पुनर्स्थापित किया जा सकता है। |
| `Sandbox.deleteSnapshot(snapshotId)` | `Sandbox.delete_snapshot(snapshot_id)` | एक स्नैपशॉट हटाएं; इससे पुनर्स्थापित सैंडबॉक्स चलते रहेंगे। |
| `sandbox.kill()` | `sandbox.kill()` | सैंडबॉक्स को रोकें और उसके वॉल्यूम को अलग करें। |

## कमांड चलाएँ

`process.exec` (Python: `exec_`) एक कमांड चलाता है और उसके समाप्त होने की प्रतीक्षा करता है। कमांड चलते समय आउटपुट प्राप्त करने के लिए `onStdout` या `onStderr` (Python: `on_stdout`, `on_stderr`) पास करें, प्रति कॉल एक लाइन बिना ट्रेलिंग न्यूलाइन के; कॉल अभी भी अंत में पूर्ण परिणाम लौटाता है। शेल को छोड़ने के लिए स्ट्रिंग के बजाय एक argv ऐरे पास करें, जो किसी अविश्वसनीय टेक्स्ट को तर्क के रूप में पास करने का सुरक्षित तरीका है।

```ts
const result = await sandbox.process.exec('npm test', {
  workdir: '/app',
  envs: { NODE_ENV: 'test' },
  timeoutMs: 120_000,
  onStdout: (line) => console.log(line),
});
if (result.exitCode !== 0) throw new Error(result.stderr);

await sandbox.process.exec(['grep', '-rn', '--', userQuery, '/workspace']);
```

```python
result = sandbox.process.exec_(
    "npm test",
    workdir="/app",
    envs={"NODE_ENV": "test"},
    timeout_ms=120_000,
    on_stdout=print,
)
if result.exit_code != 0:
    raise RuntimeError(result.stderr)

sandbox.process.exec_(["grep", "-rn", "--", user_query, "/workspace"])
```

कमांड परिणामों में stdout, stderr और एग्जिट कोड शामिल होते हैं। एक गैर-शून्य एग्जिट कोड एक परिणाम है जिसे आप जांचते हैं; अनुरोध विफलताएं थ्रो करती हैं। `timeoutMs` (Python: `timeout_ms`) सेट करता है कि कोई कमांड कितने समय तक चल सकता है, 1 से 600 सेकंड तक। इसके बिना, सर्वर कमांड को 150 सेकंड के बाद रोक देता है, और TypeScript SDK 60 सेकंड के बाद प्रतीक्षा करना बंद कर देता है और `TimeoutError` नामक `DOMException` थ्रो करता है। एक मिनट से अधिक समय तक चलने वाली किसी भी कमांड के लिए `timeoutMs` पास करें। `process.exec`, `envs`, `workdir`, और `user` स्वीकार करता है; कमांड `root` के रूप में चलते हैं जब तक कि आप `user` पास न करें। क्रिएट-टाइम `envs` हर कमांड तक पहुंचते हैं।

<span id="files" />

## फ़ाइलें

टेक्स्ट या बाइट्स के लिए `fs.write` और टेक्स्ट के लिए `fs.read` का उपयोग करें। बाइनरी फ़ाइलों के लिए, बाइट्स लिखें और उन्हें `fs.readBytes` (Python: `read_bytes`) के साथ वापस पढ़ें। पूर्ण पथ का उपयोग करें। एक अनुपलब्ध पथ `NotFoundError` थ्रो करता है।

```ts
await sandbox.fs.write('/app/data.csv', 'x,y\n1,2\n');
const text = await sandbox.fs.read('/app/data.csv');
const entries = await sandbox.fs.list('/app');
const png = await sandbox.fs.readBytes('/app/chart.png');
```

```python
sandbox.fs.write("/app/data.csv", "x,y\n1,2\n")
text = sandbox.fs.read("/app/data.csv")
entries = sandbox.fs.list("/app")
png = sandbox.fs.read_bytes("/app/chart.png")
```

एक पॉज़ या एक स्नैपशॉट डिस्क पर हर फ़ाइल को रखता है, जहाँ भी आपने इसे लिखा है। स्टॉप (किल या समाप्ति) के बाद, `/workspace` पर [Persistent Volume](/sandboxes/volumes) के बाहर की फाइलें चली जाती हैं, जब तक कि आपने पहले स्नैपशॉट न लिया हो।

<span id="ports" />

## पोर्ट्स

सैंडबॉक्स के अंदर `0.0.0.0` पर एक सर्वर शुरू करें, फिर उसके पोर्ट को प्रकाशित करें। हर अनुरोध के लिए एक्सेस टोकन की आवश्यकता होती है, `X-Lizard-Access-Token` हेडर के रूप में या ब्राउज़र में `?lizard_token=` के रूप में एक बार। [प्रीव्यू यूआरएल](/sandboxes/preview-urls) देखें।

```ts
const { url, hostname, accessToken } = await sandbox.exposePort(3000);
console.log(url); // open in a browser; it carries the token
await fetch(`https://${hostname}/api`, { headers: { 'X-Lizard-Access-Token': accessToken } });
await sandbox.unexpose(3000);
```

```python
import httpx

exposed = sandbox.expose_port(3000)
print(exposed.url)  # open in a browser; it carries the token
httpx.get(f"https://{exposed.hostname}/api", headers={"X-Lizard-Access-Token": exposed.access_token})
sandbox.unexpose(3000)
```

<span id="pause-snapshot-and-fork" />

## पॉज़, स्नैपशॉट, और फोर्क

ये कॉल मेमोरी, चल रही प्रक्रियाओं और फ़ाइलों को रखते हैं। [क्विकस्टार्ट](/sandboxes/quickstart#pause-and-resume) बताता है कि प्रत्येक क्या रखता है, कौन स्नैपशॉट पुनर्स्थापित कर सकता है, पुनर्स्थापनाओं का बिल कैसे लिया जाता है, और क्या विफल रहता है।

```ts
await sandbox.pause();
await sandbox.waitForStatus('paused');
await sandbox.resume();
await sandbox.waitForStatus('running');

const saved = await sandbox.snapshot('ready-env');
const copy = await Sandbox.restore(saved.id);

for (const f of await sandbox.fork({ count: 2 })) {
  if (f.sandbox) await f.sandbox.process.exec('echo hi');
  else console.warn('fork failed:', f.error);
}
```

```python
sandbox.pause()
sandbox.wait_for_status("paused")
sandbox.resume()
sandbox.wait_for_status("running")

saved = sandbox.snapshot("ready-env")
copy = Sandbox.restore(saved["id"])

for f in sandbox.fork(count=2):
    if f.sandbox:
        f.sandbox.process.exec_("echo hi")
    else:
        print("fork failed:", f.error)
```

`fork` प्रत्येक कॉपी के लिए एक प्रविष्टि लौटाता है: नया सैंडबॉक्स, या खाता की सैंडबॉक्स सीमा जैसी त्रुटि। प्रत्येक कॉपी अपने स्रोत की तरह बिल करती है।

<span id="run-code-with-state" />

## स्टेट के साथ कोड चलाएं

`CodeSandbox` `interpreter` टेम्पलेट को बूट करता है और `runCode` (Python: `run_code`) के साथ कोड चलाता है। उस टेम्पलेट में, Python प्रत्येक संदर्भ के लिए एक स्थायी Jupyter कर्नेल में चलता है, इसलिए चर कॉलों के बीच बने रहते हैं और परिणाम में `image/png` के रूप में चार्ट शामिल हो सकते हैं। JavaScript और bash प्रत्येक कॉल पर एक ताज़ा प्रक्रिया के रूप में चलते हैं। [कोड इंटरप्रेटर](/sandboxes/code-interpreter) देखें।

<span id="volumes" />

## वॉल्यूम

`/workspace` को सैंडबॉक्स के बीच रखने के लिए नाम से एक [Persistent Volume](/sandboxes/volumes) संलग्न करें:

```ts
import { Sandbox, Volume } from '@lizard-build/sdk';

await Volume.getOrCreate('proj_123', 'agent-workdir', { sizeGb: 10 });
const sandbox = await Sandbox.create('base', { projectId: 'proj_123', volumeName: 'agent-workdir' });
```

```python
from lizard import Sandbox, Volume

Volume.get_or_create("proj_123", "agent-workdir", size_gb=10)
sandbox = Sandbox.create("base", project_id="proj_123", volume_name="agent-workdir")
```

<span id="unsupported-apis" />

## असमर्थित एपीआई

फ़ाइल देखना अभी उपलब्ध नहीं है। `sandbox.fork()` वॉल्यूम संलग्न होने पर 409 लौटाता है। `Sandbox.connect` एक पॉज़ या स्टॉप किए गए सैंडबॉक्स को फिर से शुरू नहीं करता है; पॉज़ किए गए पर `resume()` को कॉल करें। SSH प्रोटोकॉल एक्सेस उपलब्ध नहीं है; `lizard sandbox ssh` आपके सीएलआई क्रेडेंशियल्स के साथ एक इंटरैक्टिव शेल खोलता है।

<span id="errors" />

## त्रुटियाँ

एपीआई विफलताएं इन त्रुटियों को थ्रो (Python: raise) करती हैं। प्रत्येक HTTP स्थिति और, जब एपीआई एक भेजता है, एक `code` ले जाता है।

| त्रुटि | अर्थ |
|---|---|
| `PaymentRequiredError` | HTTP 402: खाते को Pro शुरू करना होगा या कुछ भी बनाने से पहले चालान का भुगतान करना होगा। `url` वह पृष्ठ है जिसे खोलना है। |
| `AuthenticationError` | HTTP 401 या 403: अमान्य कुंजी या कोई एक्सेस नहीं। परीक्षण के दौरान, स्मॉल के अलावा कोई अन्य आकार या अमेरिका के बाहर का क्षेत्र भी 403, के साथ `code` को `TRIAL_SANDBOX_SIZE` या `TRIAL_SANDBOX_REGION` पर सेट करके लौटाता है। |
| `NotFoundError` | HTTP 404: सैंडबॉक्स, फ़ाइल, या स्नैपशॉट मौजूद नहीं है या समाप्त हो गया है। |
| `ConflictError` | HTTP 409: विरोधाभासी स्थिति, जैसे वॉल्यूम के साथ सैंडबॉक्स को फोर्क करना। |
| `LimitExceededError` | HTTP 429: एक साथ बहुत सारे सैंडबॉक्स या बहुत सारे स्टार्ट। `code` बताता है कि कौन सी सीमा है, जैसे `SANDBOX_LIMIT_REACHED` या `SANDBOX_RATE_LIMITED`; `retryAfterS` (Python: `retry_after_s`) बताता है कि कब फिर से प्रयास करना है। |
| `TimeoutError` | HTTP 408 या 504. TypeScript SDK का अपना 60-सेकंड `process.exec` के लिए प्रतीक्षा `DOMException` नामक `TimeoutError` थ्रो करता है। |
| `LizardError` | अन्य एपीआई विफलताएं, जिसमें असमर्थित ऑपरेशन शामिल हैं। |

HTTP 429 के पीछे की संख्याएं [खाता सीमाओं](/platform/limits#sandbox-account-limits) में हैं।

## HTTP API

SDK Lizard के REST API को `https://lizard.build` पर कॉल करता है। अपनी API कुंजी `Authorization: Bearer liz_...` के रूप में या `X-API-Key` हेडर में भेजें।

| कॉल | अनुरोध |
|---|---|
| बनाएँ | `POST /api/sandboxes` को `template`, `projectId`, `size`, `timeoutMs`, `envs`, `metadata`, `region`, `volumeName` के साथ; 201 को `sandboxId` के साथ लौटाता है |
| स्थिति प्राप्त करें | `GET /api/sandboxes/{id}` |
| सूची | `GET /api/sandboxes`, या एक प्रोजेक्ट के लिए `GET /api/projects/{projectId}/sandboxes` |
| कमांड चलाएँ | `POST /api/sandboxes/{id}/exec` को `cmd`, `envs`, `workdir`, `user`, `timeoutMs` के साथ; `stdout`, `stderr`, `exitCode` लौटाता है |
| जीवनकाल बदलें | `POST /api/sandboxes/{id}/timeout` को `timeoutMs` के साथ |
| रोकें या फिर से शुरू करें | `POST /api/sandboxes/{id}/pause`, `POST /api/sandboxes/{id}/resume` |
| पोर्ट प्रकाशित करें | `POST /api/sandboxes/{id}/expose/{port}`; उसी पाथ पर `DELETE` इसे हटा देता है |
| मारें | `DELETE /api/sandboxes/{id}` |

```bash
curl -X POST https://lizard.build/api/sandboxes \
  -H "Authorization: Bearer $LIZARD_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"template": "base", "projectId": "proj_123", "timeoutMs": 300000}'
```

रॉ API एक सैंडबॉक्स बनाता है जिसकी कोई समाप्ति तिथि नहीं होती है जब तक कि आप `timeoutMs` पास न करें।
