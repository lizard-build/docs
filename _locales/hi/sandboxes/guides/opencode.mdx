# सैंडबॉक्स में OpenCode चलाएं

Lizard पर सैंडबॉक्स में OpenCode चलाने के लिए, `lizard agents` (एक ChatGPT सब्सक्रिप्शन, या एक Anthropic, OpenAI, OpenRouter या LLM गेटवे कुंजी) के साथ एक क्रेडेंशियल कनेक्ट करें, `opencode` टेम्प्लेट से एक सैंडबॉक्स बनाएं, और `lizard sandbox prompt <id> --agent opencode "…"` के साथ प्रॉम्प्ट भेजें। इसके बजाय OpenCode के वेब UI का उपयोग करने के लिए, सैंडबॉक्स में `opencode web --hostname 0.0.0.0 --port 4096` शुरू करें और `lizard sandbox expose` के साथ पोर्ट खोलें।

**टेस्ट स्टेटस:** कमांड Lizard CLI 4.0.42 और प्लेटफ़ॉर्म के एजेंट रनर से आते हैं 2026-10-12. तक। हमने OpenCode 1.18.34, के सोर्स से वेब UI स्टेप्स की जाँच की, जो अपने UI और API को एक ही पोर्ट से सर्व करता है, और Lizard के सैंडबॉक्स राउटर से, जो कुकी में एक्सेस टोकन रखता है और WebSockets को पास करता है। हमने अभी तक इस पेज के लिए लाइव सैंडबॉक्स में किसी भी पाथ को एंड-टू-एंड नहीं चलाया है।

<span id="before-you-start" />

## शुरू करने से पहले

- Lizard CLI, `lizard login` के साथ साइन इन किया हुआ, और एक प्रोजेक्ट: एक फ़ोल्डर में `lizard init` चलाएँ, या सैंडबॉक्स कमांड्स में `-p <project>` पास करें।
- Lizard Pro या 7-दिन का Pro ट्रायल (कार्ड आवश्यक)। Sandboxes चलने के दौरान प्रति सेकंड साइज़ के हिसाब से बिल करता है; [सीमाएं](/platform/limits#sandbox-sizes) और [मूल्य निर्धारण](https://lizard.build/pricing) देखें।

<span id="connect-credentials" />

## क्रेडेंशियल्स कनेक्ट करें

| क्रेडेंशियल | कमांड |
|---|---|
| ChatGPT सब्सक्रिप्शन | `lizard agents login chatgpt --open` |
| Anthropic API की | `lizard agents add anthropic` |
| OpenAI API की | `lizard agents add openai` |
| OpenRouter API की | `lizard agents add openrouter` |
| LLM Gateway API की | `lizard agents add llmgateway` |

OpenCode उन सभी कनेक्टेड क्रेडेंशियल्स को लेता है जिन्हें वह स्वीकार करता है ताकि उन प्रोवाइडर्स के मॉडल्स तक पहुँच सके। यह क्लॉड सब्सक्रिप्शन टोकन नहीं लेता है; उसके लिए, [Claude Code](/sandboxes/guides/claude-code) का उपयोग करें। ChatGPT लॉगिन एक शॉर्ट-लिव्ड एक्सेस टोकन के रूप में रन तक पहुँचता है, कभी भी रिफ्रेश टोकन नहीं। API कीज़ एनवायरनमेंट वेरिएबल्स जैसे `ANTHROPIC_API_KEY` के रूप में रन तक पहुँचती हैं।

OpenCode मॉडल्स को `provider/model` नाम देता है। एक डिफ़ॉल्ट सेट करें, या प्रति प्रॉम्प्ट `-m` पास करें:

```bash
lizard agents use opencode -m openrouter/anthropic/claude-sonnet-4.5
lizard agents status
```

केवल एक OpenRouter की कनेक्टेड होने और कोई मॉडल न चुने जाने पर, Lizard `openrouter/openai/gpt-5.3-codex` चलाता है।

<span id="create-a-sandbox" />

## एक सैंडबॉक्स बनाएं

```bash
lizard sandbox create -t opencode --timeout 3600000
```

प्रिंटेड आईडी को एक वेरिएबल में रखें: `SB=genuine-toddler-jasj`। CLI डिफ़ॉल्ट लाइफटाइम पाँच मिनट है, जिसके बाद Lizard सैंडबॉक्स और उसकी फाइलों को डिलीट कर देता है; `--timeout 3600000` इसे एक घंटा देता है। `opencode` टेम्प्लेट में Node.js 22, एक पिन्ड OpenCode रिलीज़, git, Python 3, ripgrep, curl, jq, unzip और Lizard CLI है।

अपने कोड को उसी तरह कॉपी करें जैसे Claude Code के लिए करते हैं:

```bash
lizard sandbox exec $SB -- git clone https://github.com/your-org/your-app /workspace/app
```

एक प्राइवेट या लोकल रिपॉजिटरी के लिए, [अपने कोड को सैंडबॉक्स में डालें](/sandboxes/guides/claude-code#put-your-code-in-the-sandbox) देखें।

<span id="send-a-prompt" />

## एक प्रॉम्प्ट भेजें

```bash
lizard sandbox prompt $SB --agent opencode --cwd /workspace/app "add input validation to the signup form"
```

हर टर्न `opencode run --auto` चलाता है, जो हर परमिशन रिक्वेस्ट को अप्रूव करता है जिसे स्पष्ट रूप से डिनाई नहीं किया गया है: OpenCode फाइलों को एडिट करता है और बिना पूछे कमांड चलाता है। `--effort <level>` OpenCode का `--variant` बन जाता है। `-c <conversation-id>` के साथ बातचीत जारी रखें, और हर फॉलो-अप पर `--agent opencode` और `--cwd` को फिर से पास करें। Ctrl-C देखना बंद कर देता है; `lizard sandbox interrupt $SB` एजेंट को रोकता है।

बदलावों को पैच के रूप में वापस पाने के लिए, [बदलावों को वापस पाएं](/sandboxes/guides/claude-code#get-the-changes-back) देखें।

<span id="open-the-opencode-web-ui" />

## OpenCode वेब UI खोलें

`opencode web` OpenCode के ब्राउज़र इंटरफ़ेस और उसके API को एक ही पोर्ट से सर्व करता है। इसे सैंडबॉक्स में चलाएं और उस पोर्ट को [प्रीव्यू URL](/sandboxes/preview-urls) के माध्यम से खोलें।

`lizard agents` से क्रेडेंशियल्स केवल `lizard sandbox prompt` रन तक पहुँचते हैं, इसलिए इस सर्वर को अपनी की की आवश्यकता है। इसे एक फ़ाइल के रूप में कॉपी करें, ताकि यह कमांड लाइन में दिखाई न दे:

```bash
printf 'export ANTHROPIC_API_KEY=%s\n' "$ANTHROPIC_API_KEY" > opencode.env
lizard sandbox files put $SB opencode.env /root/opencode.env
rm opencode.env
```

सर्वर शुरू करें और पोर्ट खोलें:

```bash
lizard sandbox exec $SB -- sh -c '. /root/opencode.env && cd /workspace/app && nohup opencode web --hostname 0.0.0.0 --port 4096 >/tmp/opencode.log 2>&1 </dev/null & echo $! > /tmp/opencode.pid'
lizard sandbox expose $SB 4096
```

`expose` द्वारा प्रिंट किए गए URL को खोलें। यह `?lizard_token=` ले जाता है; Lizard टोकन को उस होस्ट के लिए कुकी में ले जाता है और उसे उसी पेज पर रीडायरेक्ट करता है। कुकी UI के रिक्वेस्ट, इवेंट स्ट्रीम और टर्मिनल WebSockets को प्रमाणित करती है।

- आपको `--hostname 0.0.0.0` की आवश्यकता है। OpenCode डिफ़ॉल्ट रूप से `127.0.0.1` पर सुनता है, और प्रीव्यू URL तब 502 को `The sandbox is running but port is not open` के साथ जवाब देता है।
- एक फिक्स्ड `--port` दें। इसके बिना, OpenCode एक रैंडम अनयूज्ड पोर्ट चुनता है।
- URL पासवर्ड की तरह काम करता है: जिसके पास यह है वह OpenCode के माध्यम से सैंडबॉक्स में कमांड चला सकता है। पासवर्ड की भी आवश्यकता के लिए, `opencode.env` में `export OPENCODE_SERVER_PASSWORD=…` जोड़ें; यूजर का नाम `opencode` है।
- सर्वर के लॉग को `lizard sandbox exec $SB -- tail -n 50 /tmp/opencode.log` से पढ़ें। सर्वर को `lizard sandbox exec $SB -- sh -c 'kill $(cat /tmp/opencode.pid)'` से रोकें।
- UI तब रुक जाता है जब सैंडबॉक्स रुक जाता है। इसे `lizard sandbox timeout $SB 3600000` के साथ बढ़ाएं।

<span id="common-problems" />

## सामान्य समस्याएं

| संदेश या लक्षण | समाधान |
|---|---|
| `OpenCode has no credential. Connect one of: …` | `lizard agents` के साथ ऊपर दिए गए क्रेडेंशियल्स में से एक को कनेक्ट करें। |
| `Your ChatGPT login expired` | `lizard agents login chatgpt` को फिर से चलाएं। |
| आउटपुट में Codex का उल्लेख है | प्रॉम्प्ट `--agent opencode` के बिना भेजा गया था। |
| प्रीव्यू URL 401 का जवाब देता है | `expose` द्वारा प्रिंट किए गए पूरे URL को खोलें, उसके `lizard_token` के साथ। [प्रीव्यू URLs](/sandboxes/preview-urls) देखें। |
| प्रीव्यू URL 502 का जवाब देता है | सर्वर नहीं चल रहा है या `127.0.0.1` पर सुन रहा है। `/tmp/opencode.log` की जाँच करें। |
| वेब UI लोड होता है लेकिन हर मॉडल फेल हो जाता है | सर्वर के पास कोई प्रोवाइडर की नहीं है। `/root/opencode.env` को ठीक करें, सर्वर को रोकें और उसे फिर से शुरू करें। |
