# सैंडबॉक्स में Claude Code चलाएँ

Lizard पर सैंडबॉक्स में Claude Code चलाने के लिए एक बार क्रेडेंशियल कनेक्ट करें: `lizard agents add claude` (`claude setup-token` से मिला टोकन) या `lizard agents add anthropic` (API की)। फिर `claude` टेम्प्लेट से सैंडबॉक्स बनाएँ और `lizard sandbox prompt <id> --agent claude "…"` से उसे काम भेजें। Claude Code अपनी अलग Linux मशीन पर `--dangerously-skip-permissions` के साथ चलता है: वह बिना पूछे फ़ाइलें एडिट करता है और कमांड चलाता है, और उसकी आपके कंप्यूटर तक कोई पहुँच नहीं होती।

**टेस्ट स्टेटस:** इस पेज की कमांड और व्यवहार 2026-10-12 की स्थिति के अनुसार Lizard CLI 4.0.42 और प्लेटफ़ॉर्म के एजेंट रनर से लिए गए हैं; `--with-token` वाला नोट Lizard CLI 4.0.65 से है। इस पेज के लिए हमने यह पूरा वॉकथ्रू किसी लाइव सैंडबॉक्स में शुरू से आखिर तक नहीं चलाया है। `git bundle` और पैच वाले स्टेप हमने लोकल तौर पर जाँचे हैं।

<span id="before-you-start" />

## शुरू करने से पहले

- Lizard CLI, जिसमें `lizard login` से साइन इन किया गया हो, और एक प्रोजेक्ट: किसी फ़ोल्डर में `lizard init` चलाएँ, या सैंडबॉक्स कमांड में `-p <project>` पास करें।
- Lizard Pro या 7 दिन का Pro ट्रायल (कार्ड ज़रूरी)। Sandboxes का बिल चलने के दौरान साइज़ के हिसाब से प्रति सेकंड बनता है; [लिमिट](/platform/limits#sandbox-sizes) और [प्राइसिंग](https://lizard.build/pricing) देखें।
- Claude सब्सक्रिप्शन के लिए: `claude setup-token` चलाने के लिए आपके कंप्यूटर पर Claude Code।

<span id="connect-a-credential" />

## क्रेडेंशियल कनेक्ट करें

| क्रेडेंशियल | कमांड | रन को क्या मिलता है |
|---|---|---|
| Claude सब्सक्रिप्शन | `claude setup-token`, फिर `lizard agents add claude` चलाएँ और `sk-ant-oat01-…` टोकन पेस्ट करें | `CLAUDE_CODE_OAUTH_TOKEN` |
| Anthropic API की | `lizard agents add anthropic` | `ANTHROPIC_API_KEY` |
| OpenRouter API की | `lizard agents add openrouter` | OpenRouter का Anthropic-कम्पैटिबल एंडपॉइंट |

क्रेडेंशियल्स आपके Lizard अकाउंट के होते हैं, किसी प्रोजेक्ट के नहीं, और आपका शुरू किया हर सैंडबॉक्स इन्हें इस्तेमाल कर सकता है। Claude Code एक समय में एक ही क्रेडेंशियल इस्तेमाल करता है। अगर आपने कई क्रेडेंशियल्स कनेक्ट किए हैं, तो उनमें से एक चुनें। आप डिफ़ॉल्ट मॉडल भी सेट कर सकते हैं:

```bash
lizard agents use claude --credential anthropic
lizard agents use claude -m sonnet
lizard agents status
```

सभी विकल्पों के लिए [`lizard agents`](/cli/agents) देखें।

<span id="create-a-sandbox" />

## सैंडबॉक्स बनाएँ

```bash
lizard sandbox create -t claude --timeout 3600000
```

कमांड सैंडबॉक्स ID प्रिंट करती है, जैसे `genuine-toddler-jasj`। नीचे के स्टेप्स के लिए इसे एक वेरिएबल में रखें: `SB=genuine-toddler-jasj`।

- `--timeout 3600000` सैंडबॉक्स को एक घंटा देता है। CLI में डिफ़ॉल्ट पाँच मिनट है, जिसके बाद Lizard सैंडबॉक्स और उसकी फ़ाइलें डिलीट कर देता है, भले ही काम बीच में हो। चल रहे सैंडबॉक्स का समय `lizard sandbox timeout $SB 3600000` से बढ़ाएँ।
- `claude` टेम्प्लेट में Node.js 22, Claude Code का एक पिन किया हुआ रिलीज़, git, Python 3, ripgrep, curl, jq, unzip और Lizard CLI हैं। Claude Code का वर्ज़न `lizard sandbox exec $SB -- claude --version` से जाँचें।
- डिफ़ॉल्ट साइज़ Medium (4 vCPU, 8 GB) है। इसे बदलने के लिए `--size small` या `--size large` पास करें। ट्रायल के दौरान हर सैंडबॉक्स Small होता है और US रीजन में चलता है।

<span id="put-your-code-in-the-sandbox" />

## अपना कोड सैंडबॉक्स में डालें

पब्लिक रिपॉज़िटरी से:

```bash
lizard sandbox exec $SB -- git clone https://github.com/your-org/your-app /workspace/app
```

लोकल git रिपॉज़िटरी से, प्राइवेट रिपॉज़िटरी समेत:

```bash
git bundle create /tmp/app.bundle HEAD
lizard sandbox files put $SB /tmp/app.bundle /workspace/app.bundle
lizard sandbox exec $SB -- git clone -q /workspace/app.bundle /workspace/app
```

बंडल में सिर्फ़ कमिट की गई फ़ाइलें होती हैं, इसलिए `.env` और दूसरी अनट्रैक्ड फ़ाइलें आपके कंप्यूटर पर ही रहती हैं।

<span id="send-a-prompt" />

## प्रॉम्प्ट भेजें

```bash
lizard sandbox prompt $SB --agent claude --cwd /workspace/app "run the tests and fix any that fail"
```

CLI हर टूल कॉल को स्ट्रीम करता है, फिर Claude का जवाब, टोकन की संख्या और बातचीत (conversation) की ID दिखाता है। काम के फ़्लैग: `-m <model>`, `--effort <level>`, कमांड आउटपुट प्रिंट करने के लिए `-v`, और तुरंत लौटने के लिए `--no-wait`। Ctrl-C सिर्फ़ देखना बंद करता है; Claude काम करता रहता है। उसे `lizard sandbox interrupt $SB` से रोकें।

उसी Claude Code सेशन को जारी रखने के लिए बातचीत की ID पास करें:

```bash
lizard sandbox prompt $SB --agent claude -c conv_0123456789abcdef --cwd /workspace/app "now add a test for an empty list"
lizard sandbox conversations $SB
```

हर प्रॉम्प्ट में, फ़ॉलो-अप समेत, `--agent claude` और `--cwd` पास करें। `--agent` के बिना CLI Codex को रिक्वेस्ट भेजता है, और `--cwd` के बिना एजेंट `/workspace` में काम करता है।

<span id="what-claude-code-can-reach" />

## Claude Code किन चीज़ों तक पहुँच सकता है

- **अनुमतियाँ।** हर टर्न सैंडबॉक्स के अंदर root के रूप में `--dangerously-skip-permissions` के साथ `claude -p` चलाता है। Claude बिना पूछे फ़ाइलें बदलता है, पैकेज इंस्टॉल करता है और कमांड चलाता है। ये अनुमतियाँ सैंडबॉक्स के अंदर लागू होती हैं।
- **फ़ाइलें।** सैंडबॉक्स की सभी फ़ाइलों तक पहुँच है, आपके कंप्यूटर की किसी फ़ाइल तक नहीं।
- **नेटवर्क।** इंटरनेट पर बाहर जाने वाले कनेक्शन मिलते हैं, ताकि वह पैकेज डाउनलोड और API कॉल कर सके। सैंडबॉक्स की कीमत में रोलिंग 30 दिनों में [प्रति अकाउंट 2 TB](/platform/limits#sandbox-egress) तक एग्रेस शामिल है।
- **आपका क्रेडेंशियल।** रन के दौरान टोकन Claude Code के एनवायरनमेंट में `CLAUDE_CODE_OAUTH_TOKEN` या `ANTHROPIC_API_KEY` के रूप में रहता है, और उसकी चलाई कमांड को भी यह मिलता है। सब्सक्रिप्शन के लिए यह `claude setup-token` से मिला लंबे समय तक मान्य टोकन है; हर रन के लिए कम अवधि वाली कॉपी सिर्फ़ ChatGPT लॉगिन को मिलती है। मानकर चलें कि सैंडबॉक्स में चलने वाला कोड इसे पढ़ सकता है, और ज़रूरत खत्म होने पर इसे `lizard agents remove claude` से हटा दें।
- **आपका Lizard अकाउंट।** डिफ़ॉल्ट रूप से कोई पहुँच नहीं। सैंडबॉक्स के अंदर `lizard` में साइन इन करने के लिए उसे `--with-token` के साथ बनाएँ, जैसे Claude का बनाया ऐप डिप्लॉय करने के लिए। आपकी अपनी की सिर्फ़ रिक्वेस्ट को ऑथराइज़ करती है: सैंडबॉक्स को उसके प्रोजेक्ट तक सीमित एक नई की मिलती है, जो सैंडबॉक्स के साथ डिलीट हो जाती है। इसके बाद Claude उस प्रोजेक्ट को बदल सकता है, आपके अकाउंट में और कुछ नहीं; [`lizard keys`](/cli/keys) देखें।

<span id="get-the-changes-back" />

## बदलाव वापस पाएँ

```bash
lizard sandbox exec $SB -- sh -c 'cd /workspace/app && git add -A && git diff --cached > /tmp/claude.patch'
lizard sandbox files get $SB /tmp/claude.patch claude.patch
git apply claude.patch
```

कमिट करने से पहले पैच रिव्यू करें। Claude का शुरू किया हुआ वेब ऐप आज़माने के लिए उसके पोर्ट का [प्रीव्यू URL](/sandboxes/preview-urls) खोलें, जैसे `lizard sandbox expose $SB 3000`।

<span id="use-claude-code-by-hand" />

## Claude Code को मैन्युअली चलाएँ

`lizard sandbox ssh $SB` सैंडबॉक्स में शेल खोलता है। `lizard agents` के क्रेडेंशियल्स सिर्फ़ `lizard sandbox prompt` वाले रन तक पहुँचते हैं, इसलिए उस शेल में अपना `CLAUDE_CODE_OAUTH_TOKEN` या `ANTHROPIC_API_KEY` export करें, फिर `claude` चलाएँ।

<span id="pause-or-remove-the-sandbox" />

## सैंडबॉक्स को पॉज़ करें या हटाएँ

```bash
lizard sandbox pause $SB
lizard sandbox resume $SB
lizard sandbox rm $SB
```

सफल पॉज़ के बाद कंप्यूट का चार्ज रुक जाता है; Persistent Volumes के स्टोरेज का बिल बनता रहता है। रिज़्यूम करने पर सैंडबॉक्स की फ़ाइलें और प्रोसेस वापस आ जाते हैं और कंप्यूट बिलिंग फिर शुरू हो जाती है। बातचीत की स्टेट सैंडबॉक्स के अंदर `/workspace/.lizard-agent` में रहती है। सैंडबॉक्स हटाने के बाद भी फ़ाइलें रखनी हों, तो बनाते समय `--volume` से [Persistent Volume](/sandboxes/volumes) अटैच करें।

<span id="common-problems" />

## आम समस्याएँ

| मैसेज या लक्षण | समाधान |
|---|---|
| `Claude Code has no credential. Connect one of: …` | `lizard agents add claude` या `lizard agents add anthropic` चलाएँ। |
| `Claude rejected the credential (authentication_failed)` | टोकन या की अब मान्य नहीं है। नया बनाएँ और फिर से जोड़ें। |
| `create` पर Checkout लिंक के साथ HTTP 402 | ट्रायल या Pro शुरू करें: `lizard billing start`। |
| `create` पर `TRIAL_SANDBOX_SIZE` या `TRIAL_SANDBOX_REGION` के साथ HTTP 403 | ट्रायल में सिर्फ़ US रीजन में Small सैंडबॉक्स चलते हैं। `--size small` और US का कोई `--region` इस्तेमाल करें, या अभी Pro शुरू करें: `lizard billing start-now`। |
| काम के बीच में सैंडबॉक्स गायब हो गया | उसका लाइफटाइम खत्म हो गया। अगला सैंडबॉक्स `--timeout` के साथ बनाएँ, या `lizard sandbox timeout` से समय बढ़ाएँ। |
| आउटपुट में Codex का ज़िक्र है | प्रॉम्प्ट `--agent claude` के बिना भेजा गया। |
| किसी स्टेप में `installing Claude Code` दिखता है | सैंडबॉक्स `claude` टेम्प्लेट से नहीं बना था, इसलिए रनर पहले npm से Claude Code इंस्टॉल करता है। |
