# सैंडबॉक्स में Claude Code चलाएं

Lizard पर सैंडबॉक्स में Claude Code चलाने के लिए, `lizard agents add claude` (`claude setup-token` से एक टोकन) या `lizard agents add anthropic` (एक API कुंजी) के साथ एक बार क्रेडेंशियल कनेक्ट करें। फिर `claude` टेम्पलेट से एक सैंडबॉक्स बनाएँ और `lizard sandbox prompt <id> --agent claude "…"` के साथ इसे काम भेजें। Claude Code अपने स्वयं के लिनक्स मशीन पर `--dangerously-skip-permissions` पर चलता है: यह फ़ाइलों को संपादित करता है और बिना पूछे कमांड चलाता है, और इसे आपके कंप्यूटर तक पहुँच नहीं है।

**परीक्षण स्थिति:** इस पृष्ठ पर कमांड और व्यवहार Lizard CLI 4.0.42 और प्लेटफ़ॉर्म के एजेंट रनर से 2026-10-12 के अनुसार हैं; `--with-token` नोट Lizard CLI 4.0.65. से है। हमने इस वॉकथ्रू को इस पृष्ठ के लिए लाइव सैंडबॉक्स में एंड-टू-एंड नहीं चलाया है। हमने `git bundle` और पैच चरणों को स्थानीय रूप से जांचा है।

<span id="before-you-start" />

## शुरू करने से पहले

- Lizard CLI, `lizard login` के साथ साइन इन, और एक प्रोजेक्ट: एक फ़ोल्डर में `lizard init` चलाएँ, या सैंडबॉक्स कमांड को `-p <project>` पास करें।
- Lizard Pro या 7-दिन Pro परीक्षण (कार्ड आवश्यक)। Sandboxes चलने के दौरान आकार के अनुसार प्रति सेकंड बिल करते हैं; [सीमाओं](/platform/limits#sandbox-sizes) और [मूल्य निर्धारण](https://lizard.build/pricing) देखें।
- Claude सदस्यता के लिए: अपने कंप्यूटर पर Claude Code, `claude setup-token` चलाने के लिए।

<span id="connect-a-credential" />

## एक क्रेडेंशियल कनेक्ट करें

| क्रेडेंशियल | कमांड | रन क्या प्राप्त करता है |
|---|---|---|
| Claude सदस्यता | `claude setup-token`, फिर `lizard agents add claude` और `sk-ant-oat01-…` टोकन पेस्ट करें | `CLAUDE_CODE_OAUTH_TOKEN` |
| Anthropic की API कुंजी | `lizard agents add anthropic` | `ANTHROPIC_API_KEY` |
| OpenRouter API key | `lizard agents add openrouter` | OpenRouter का Anthropic-संगत एंडपॉइंट |

क्रेडेंशियल आपके Lizard खाते के हैं, किसी प्रोजेक्ट के नहीं, और आपके द्वारा शुरू किया गया प्रत्येक सैंडबॉक्स उनका उपयोग कर सकता है। Claude Code एक समय में एक क्रेडेंशियल का उपयोग करता है। यदि आप कई क्रेडेंशियल कनेक्ट करते हैं, तो एक चुनें। आप एक डिफ़ॉल्ट मॉडल भी सेट कर सकते हैं:

```bash
lizard agents use claude --credential anthropic
lizard agents use claude -m sonnet
lizard agents status
```

सभी विकल्पों के लिए [`lizard agents`](/cli/agents) देखें।

<span id="create-a-sandbox" />

## एक सैंडबॉक्स बनाएं

```bash
lizard sandbox create -t claude --timeout 3600000
```

कमांड सैंडबॉक्स आईडी प्रिंट करता है, जैसे `genuine-toddler-jasj`। इसे नीचे दिए गए चरणों के लिए एक वेरिएबल में रखें: `SB=genuine-toddler-jasj`।

- `--timeout 3600000` सैंडबॉक्स को एक घंटा देता है। CLI डिफ़ॉल्ट पांच मिनट है, जिसके बाद Lizard सैंडबॉक्स और उसकी फ़ाइलों को हटा देता है, कार्य के बीच में भी। चल रहे को `lizard sandbox timeout $SB 3600000` से बढ़ाएँ।
- `claude` टेम्प्लेट में Node.js 22, एक पिन किया हुआ Claude Code रिलीज़, git, Python 3, ripgrep, curl, jq, unzip और Lizard CLI है। Claude Code संस्करण को `lizard sandbox exec $SB -- claude --version` से जांचें।
- डिफ़ॉल्ट आकार मध्यम है (4 vCPU, 8 GB)। इसे बदलने के लिए `--size small` या `--size large` पास करें। परीक्षण के दौरान, प्रत्येक सैंडबॉक्स छोटा होता है और यूएस क्षेत्र में चलता है।

<span id="put-your-code-in-the-sandbox" />

## अपने कोड को सैंडबॉक्स में रखें

एक सार्वजनिक रिपॉजिटरी से:

```bash
lizard sandbox exec $SB -- git clone https://github.com/your-org/your-app /workspace/app
```

एक स्थानीय git रिपॉजिटरी से, निजी वाले सहित:

```bash
git bundle create /tmp/app.bundle HEAD
lizard sandbox files put $SB /tmp/app.bundle /workspace/app.bundle
lizard sandbox exec $SB -- git clone -q /workspace/app.bundle /workspace/app
```

एक बंडल केवल कमिट की गई फ़ाइलों को रखता है, इसलिए `.env` और अन्य अनट्रैक की गई फ़ाइलें आपके कंप्यूटर पर रहती हैं।

<span id="send-a-prompt" />

## एक प्रॉम्प्ट भेजें

```bash
lizard sandbox prompt $SB --agent claude --cwd /workspace/app "run the tests and fix any that fail"
```

CLI प्रत्येक टूल कॉल को स्ट्रीम करता है, फिर Claude का उत्तर, टोकन गणना और वार्तालाप आईडी। उपयोगी फ़्लैग: `-m <model>`, `--effort <level>`, `-v` कमांड आउटपुट प्रिंट करने के लिए, और `--no-wait` तुरंत वापस आने के लिए। Ctrl-C देखना बंद कर देता है; Claude काम करना जारी रखता है। इसे `lizard sandbox interrupt $SB` से रोकें।

उसी Claude Code सत्र को जारी रखने के लिए, वार्तालाप आईडी पास करें:

```bash
lizard sandbox prompt $SB --agent claude -c conv_0123456789abcdef --cwd /workspace/app "now add a test for an empty list"
lizard sandbox conversations $SB
```

प्रत्येक प्रॉम्प्ट, फॉलो-अप सहित `--agent claude` और `--cwd` पास करें। `--agent` के बिना CLI Codex के लिए पूछता है, और `--cwd` के बिना एजेंट `/workspace` में काम करता है।

<span id="what-claude-code-can-reach" />

## Claude Code क्या पहुंच सकता है

- **अनुमतियाँ।** हर टर्न में सैंडबॉक्स के अंदर root के रूप में `claude -p` को `--dangerously-skip-permissions` के साथ चलाते हैं। Claude बिना पूछे फ़ाइलें बदलता है, पैकेज इंस्टॉल करता है और कमांड चलाता है। ये अनुमतियाँ सैंडबॉक्स के अंदर लागू होती हैं।
- **फ़ाइलें।** सैंडबॉक्स की सभी फ़ाइलों तक पहुँच है, आपके कंप्यूटर की फ़ाइलों तक नहीं।
- **नेटवर्क।** इंटरनेट पर बाहर जाने वाले कनेक्शन मिलते हैं, ताकि पैकेज डाउनलोड और API कॉल कर सके। सैंडबॉक्स की कीमत में पिछले 30 दिनों में [हर खाते के लिए 2 TB](/platform/limits#sandbox-egress) तक egress शामिल है।
- **आपका क्रेडेंशियल।** रन के दौरान टोकन Claude Code के environment में `CLAUDE_CODE_OAUTH_TOKEN` या `ANTHROPIC_API_KEY` के रूप में रहता है। उसकी चलाई कमांड को भी यह मिलता है। सब्सक्रिप्शन के लिए यह `claude setup-token` का लंबे समय तक मान्य टोकन है; सिर्फ़ ChatGPT लॉगिन को हर रन के लिए कम अवधि की कॉपी मिलती है। मानकर चलें कि सैंडबॉक्स में चलने वाला कोड इसे पढ़ सकता है। ज़रूरत खत्म होने पर इसे `lizard agents remove claude` से हटाएँ।
- **आपका Lizard खाता।** डिफ़ॉल्ट रूप से कोई पहुँच नहीं मिलती। सैंडबॉक्स के अंदर `lizard` में साइन इन करने के लिए उसे `--with-token` के साथ बनाएँ, जैसे Claude का बनाया ऐप डिप्लॉय करने के लिए। आपकी अपनी कुंजी सिर्फ़ अनुरोध की अनुमति देती है: सैंडबॉक्स को उसके प्रोजेक्ट तक सीमित नई कुंजी मिलती है, जो सैंडबॉक्स के साथ हट जाती है। फिर Claude उस प्रोजेक्ट को बदल सकता है, आपके खाते में और कुछ नहीं; [`lizard keys`](/cli/keys) देखें।

<span id="get-the-changes-back" />

## परिवर्तनों को वापस प्राप्त करें

```bash
lizard sandbox exec $SB -- sh -c 'cd /workspace/app && git add -A && git diff --cached > /tmp/claude.patch'
lizard sandbox files get $SB /tmp/claude.patch claude.patch
git apply claude.patch
```

कमिट करने से पहले पैच की समीक्षा करें। Claude द्वारा शुरू किए गए वेब ऐप को आज़माने के लिए, उसके पोर्ट के लिए [पूर्वावलोकन URL](/sandboxes/preview-urls) खोलें, उदाहरण के लिए `lizard sandbox expose $SB 3000`।

<span id="use-claude-code-by-hand" />

## Claude Code का उपयोग हाथ से करें

`lizard sandbox ssh $SB` सैंडबॉक्स में एक शेल खोलता है। `lizard agents` से क्रेडेंशियल केवल `lizard sandbox prompt` रन तक पहुंचते हैं, इसलिए उस शेल में अपना `CLAUDE_CODE_OAUTH_TOKEN` या `ANTHROPIC_API_KEY` निर्यात करें, फिर `claude` चलाएं।

<span id="pause-or-remove-the-sandbox" />

## सैंडबॉक्स को रोकें या हटा दें

```bash
lizard sandbox pause $SB
lizard sandbox resume $SB
lizard sandbox rm $SB
```

एक सफल पॉज़ कंप्यूट चार्ज को रोकता है; Persistent Volumes में स्टोरेज पर बिलिंग जारी रहती है। फिर से शुरू करने से सैंडबॉक्स की फ़ाइलें और प्रक्रियाएं बहाल हो जाती हैं और कंप्यूट बिलिंग फिर से शुरू हो जाती है। वार्तालाप स्थिति `/workspace/.lizard-agent` में रहती है, सैंडबॉक्स के अंदर। सैंडबॉक्स हटाने के बाद फ़ाइलों को रखने के लिए, `--volume` के साथ बनाते समय [स्थायी वॉल्यूम](/sandboxes/volumes) संलग्न करें।

<span id="common-problems" />

## सामान्य समस्याएं

| संदेश या लक्षण | समाधान |
|---|---|
| `Claude Code has no credential. Connect one of: …` | `lizard agents add claude` या `lizard agents add anthropic` चलाएं। |
| `Claude rejected the credential (authentication_failed)` | टोकन या कुंजी अब मान्य नहीं है। एक नया बनाएं और इसे फिर से जोड़ें। |
| `create` पर चेकआउट लिंक के साथ HTTP 402 | परीक्षण या Pro शुरू करें: `lizard billing start`। |
| `create` पर `TRIAL_SANDBOX_SIZE` या `TRIAL_SANDBOX_REGION` के साथ HTTP 403 | परीक्षण केवल यूएस क्षेत्रों में छोटे सैंडबॉक्स चलाता है। `--size small` और एक यूएस `--region` का उपयोग करें, या अभी Pro शुरू करें: `lizard billing start-now`। |
| कार्य के बीच में सैंडबॉक्स चला गया | इसका जीवनकाल समाप्त हो गया। `--timeout` के साथ अगला बनाएं, या `lizard sandbox timeout` के साथ इसे बढ़ाएं। |
| आउटपुट में Codex का उल्लेख है | प्रॉम्प्ट `--agent claude` के बिना बाहर चला गया। |
| एक चरण `installing Claude Code` कहता है | सैंडबॉक्स `claude` टेम्प्लेट से नहीं बनाया गया था, इसलिए रनर पहले npm के साथ Claude Code स्थापित करता है। |
