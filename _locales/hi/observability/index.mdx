# ऑब्ज़र्वेबिलिटी

देखें कि आपकी सर्विसेज़ क्या कर रही हैं: लॉग स्ट्रीम करें, मेट्रिक्स और लागत ट्रैक करें, और डिप्लॉय और रेप्लिका का इतिहास देखें।

<span id="in-this-section" />

## इस सेक्शन में

- [लॉग](/observability/logs): लाइव और पुराने लॉग, जिनमें बिल्ड और रीस्टार्ट लॉग भी शामिल हैं।
- [मेट्रिक्स और लागत](/observability/metrics): संसाधनों का उपयोग और उसकी लागत।
- [इवेंट्स और इतिहास](/observability/events): डिप्लॉय टाइमलाइन और हर रेप्लिका की स्थिति।

CLI कमांड `--json` भी स्वीकार करती हैं, इसलिए डिप्लॉय फ़ेल होने पर कोडिंग एजेंट उनका आउटपुट पढ़ सकते हैं। [Claude Code से डिप्लॉय करना](https://lizard.build/blog/deploy-from-claude-code) देखें।
