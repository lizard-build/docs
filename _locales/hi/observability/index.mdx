# ऑब्जर्वेबिलिटी

देखें कि आपकी सेवाएँ क्या कर रही हैं: लॉग स्ट्रीम करें, मेट्रिक्स और लागत ट्रैक करें, और डिप्लॉय और रेप्लिका इतिहास की समीक्षा करें।

<span id="in-this-section" />

## इस सेक्शन में

- [लॉग्स](/observability/logs): लाइव और ऐतिहासिक लॉग, जिसमें बिल्ड और रीस्टार्ट लॉग शामिल हैं।
- [मेट्रिक्स और लागत](/observability/metrics): संसाधन उपयोग और उसकी लागत।
- [इवेंट्स और इतिहास](/observability/events): डिप्लॉय टाइमलाइन और प्रति-रेप्लिका स्थिति।

CLI कमांड `--json` को भी स्वीकार करते हैं, इसलिए कोडिंग एजेंट डिप्लॉय विफल होने पर उनके आउटपुट को पढ़ सकते हैं। [Claude Code से डिप्लॉय करना](https://lizard.build/blog/deploy-from-claude-code) देखें।
