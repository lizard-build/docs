# मेट्रिक्स और लागत

[`lizard metrics`](/cli/metrics) से या डैशबोर्ड में किसी सर्विस का CPU, मेमोरी, नेटवर्क, डिस्क और लागत देखें।

<span id="view-metrics" />

## मेट्रिक्स देखें

```bash
lizard metrics                    # CPU / memory / network / disk
lizard metrics --service api      # a specific service
lizard metrics --range 24h        # time window: 1h (default), 6h, 24h, 7d, 14d, 30d
lizard metrics --watch            # live-updating view
```

`--range` एक ही सर्विस पर लागू होता है: लिंक की गई सर्विस पर या `--service` में दी गई सर्विस पर। प्रोजेक्ट ओवरव्यू (`--all`, या ऐसा फ़ोल्डर जिससे कोई सर्विस लिंक नहीं है) सिर्फ़ मौजूदा वैल्यू दिखाता है।

<span id="include-cost" />

## लागत शामिल करें

```bash
lizard metrics --cost
```

यह कमांड मेट्रिक्स की जगह लागत दिखाती है: हर चल रहे संसाधन की प्रति घंटा कीमत, मौजूदा बिलिंग अवधि का उपयोग (एग्रेस सहित), और इस अवधि में Pro में शामिल उपयोग में से कितना खर्च हो चुका है (7-दिन के ट्रायल में ट्रायल के $5, उसके बाद हर महीने शामिल $19)। यह पूरे प्रोजेक्ट के लिए होती है, `--service` और `--range` को नज़रअंदाज़ करती है, और इसे सिर्फ़ वर्कस्पेस का मालिक देख सकता है।

<span id="dashboard" />

## डैशबोर्ड

डैशबोर्ड (`lizard open`) इन्हें **मेट्रिक्स** व्यू में चार्ट के रूप में दिखाता है, और **उपयोग** व्यू पूरे प्रोजेक्ट की खपत और बिलिंग का ब्योरा देता है। इसे ऐसे खोलें:

```bash
lizard open
```

<span id="acting-on-what-you-see" />

## आँकड़ों के आधार पर क्या करें

- CPU/मेमोरी ज़्यादा → स्केल अप करें: `lizard scale --service api --cpu 2 --memory 2048`।
- लगातार लोड → रेप्लिका जोड़ें: `lizard scale --service api --replicas 3`। Pro में ट्रायल के दौरान हर सर्विस के लिए 1 रेप्लिका और पहले भुगतान किए गए इनवॉइस के बाद 5 रेप्लिका तक की अनुमति है।
- किसी ऐडऑन की डिस्क भरने लगे → स्टोरेज बढ़ाएँ: `lizard scale --service postgres --storage 8192`।
