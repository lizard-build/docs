# मेट्रिक्स और लागत

[`lizard metrics`](/cli/metrics) या डैशबोर्ड में किसी सर्विस के CPU, मेमोरी, नेटवर्क, डिस्क और लागत की जांच करें।

<span id="view-metrics" />

## मेट्रिक्स देखें

```bash
lizard metrics                    # CPU / memory / network / disk
lizard metrics --service api      # a specific service
lizard metrics --range 24h        # time window: 1h (default), 6h, 24h, 7d, 14d, 30d
lizard metrics --watch            # live-updating view
```

`--range` एक सर्विस पर लागू होता है: लिंक की गई सर्विस या `--service`। प्रोजेक्ट ओवरव्यू (`--all`, या बिना लिंक की गई सर्विस वाला फ़ोल्डर) केवल वर्तमान मान दिखाता है।

<span id="include-cost" />

## लागत शामिल करें

```bash
lizard metrics --cost
```

यह कमांड मेट्रिक्स के बजाय लागत दिखाता है: प्रति घंटे प्रत्येक चल रहे संसाधन की कीमत, वर्तमान बिलिंग अवधि के लिए उपयोग (ईग्रेस शामिल), और इस अवधि में आपने अपने शामिल Pro उपयोग का कितना उपयोग किया है (7-दिन के परीक्षण के दौरान परीक्षण का $5, फिर हर महीने शामिल $19)। यह पूरे प्रोजेक्ट को कवर करता है, `--service` और `--range` को अनदेखा करता है, और केवल वर्कस्पेस मालिक ही इसे देख सकता है।

<span id="dashboard" />

## डैशबोर्ड

डैशबोर्ड (`lizard open`) इन्हें **मेट्रिक्स** व्यू में चार्ट के रूप में प्रस्तुत करता है, और **उपयोग** व्यू प्रोजेक्ट में खपत और बिलिंग का विवरण देता है। इसे इससे खोलें:

```bash
lizard open
```

<span id="acting-on-what-you-see" />

## जो आप देखते हैं उस पर कार्रवाई करना

- उच्च CPU/मेमोरी → स्केल अप करें: `lizard scale --service api --cpu 2 --memory 2048`।
- निरंतर लोड → रेप्लिका जोड़ें: `lizard scale --service api --replicas 3`। Pro परीक्षण के दौरान प्रति सर्विस 1 रेप्लिका और पहले भुगतान चालान के बाद 5 की अनुमति देता है।
- ऐडऑन पर डिस्क दबाव → स्टोरेज बढ़ाएं: `lizard scale --service postgres --storage 8192`।
