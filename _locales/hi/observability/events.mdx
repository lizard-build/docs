# इवेंट्स और इतिहास

`lizard events` सेवा के डिप्लॉय इतिहास और उसके रेप्लिका की लाइव स्थिति दिखाता है - क्या शिप हुआ और अभी क्या चल रहा है, इसका टाइमलाइन।

<span id="view-events" />

## इवेंट देखें

```bash
lizard events                     # deploy history + replica status
lizard events --service api       # a specific service
lizard events --limit 5           # fewer entries (default and maximum 10)
```

प्रत्येक एंट्री एक डिप्लॉय है: स्थिति, ट्रिगर, कमिट और रीस्टार्ट काउंट। डिप्लॉय के ऊपर एक रेप्लिका टेबल प्रत्येक पॉड की वर्तमान स्थिति दिखाती है; यह तब गायब रहती है जब सेवा में कोई पॉड नहीं होता है, उदाहरण के लिए जब यह पॉज़ या स्लीप मोड में हो। साथ में वे "क्या बदला, और क्या यह स्वस्थ है?" का उत्तर देते हैं। `lizard scale` से रेप्लिका परिवर्तन कोई डिप्लॉय नहीं बनाता है, इसलिए यह सूचीबद्ध नहीं है।

<span id="quick-status" />

## त्वरित स्थिति

प्रोजेक्ट में सभी सेवाओं का एक त्वरित स्नैपशॉट - स्थिति और URL - देखने के लिए, इसका उपयोग करें:

```bash
lizard ps
lizard status        # the current directory's workspace/project/service link
```

<span id="dashboard" />

## डैशबोर्ड

डैशबोर्ड (`lizard open`) में एक सेवा खोलें ताकि उसका डिप्लॉय इतिहास देखा जा सके। प्रत्येक डिप्लॉय पंक्ति उसकी ब्रांच और कमिट संदेश दिखाती है; उसके बिल्ड लॉग और रीस्टार्ट के लिए एक पर क्लिक करें। सेवा पैनल चालू और वांछित रेप्लिका दिखाता है।
