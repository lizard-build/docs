# इवेंट्स और इतिहास

`lizard events` किसी सर्विस का डिप्लॉय इतिहास और उसकी रेप्लिकाओं की लाइव स्थिति दिखाता है — क्या शिप हुआ और इस समय क्या चल रहा है, इसकी टाइमलाइन।

<span id="view-events" />

## इवेंट्स देखें

```bash
lizard events                     # deploy history + replica status
lizard events --service api       # a specific service
lizard events --limit 5           # fewer entries (default and maximum 10)
```

हर एंट्री एक डिप्लॉय है: स्थिति, ट्रिगर, कमिट और रीस्टार्ट की संख्या। डिप्लॉय की सूची के ऊपर रेप्लिका टेबल हर पॉड की मौजूदा स्थिति दिखाती है; जब सर्विस में कोई पॉड नहीं होता, जैसे जब वह पॉज़ हो या स्लीप में हो, तब यह टेबल नहीं दिखती। दोनों मिलकर बताते हैं कि "क्या बदला, और क्या सब ठीक चल रहा है?" `lizard scale` से रेप्लिका बदलने पर कोई डिप्लॉय नहीं बनता, इसलिए वह इस सूची में नहीं दिखता।

<span id="quick-status" />

## तुरंत स्थिति देखें

प्रोजेक्ट की सभी सर्विसेज़ का एक झटपट स्नैपशॉट — स्थिति और URL — देखने के लिए यह चलाएँ:

```bash
lizard ps
lizard status        # the current directory's workspace/project/service link
```

<span id="dashboard" />

## डैशबोर्ड

किसी सर्विस का डिप्लॉय इतिहास देखने के लिए उसे डैशबोर्ड (`lizard open`) में खोलें। हर डिप्लॉय की पंक्ति में उसकी ब्रांच और कमिट मैसेज दिखता है; किसी पंक्ति पर क्लिक करके उस डिप्लॉय के बिल्ड लॉग और रीस्टार्ट देखें। सर्विस पैनल में चल रही और अपेक्षित (desired) रेप्लिकाओं की संख्या दिखती है।
