# डिप्लॉय

GitHub, स्थानीय फ़ोल्डर या Dockerfile से एक सेवा परिनियोजित करें, फिर उसका रनटाइम, क्षेत्र और संसाधन सेट करें।

होस्ट की तुलना करने के लिए, ब्लॉग बताता है कि [सेवा के रूप में कंटेनर](https://lizard.build/blog/container-as-a-service) प्लेटफ़ॉर्म कैसे भिन्न होते हैं और उनकी लागत का अनुमान कैसे लगाया जाता है।

<span id="in-this-section" />

## इस सेक्शन में

- [GitHub से परिनियोजित करें](/deploy/github): एक रेपो कनेक्ट करें ताकि ट्रैक की गई ब्रांच पर पुश ऑटो-रीडिप्लॉय हो जाएं।
- [स्थानीय कोड से परिनियोजित करें](/deploy/upload): `lizard up` के साथ वर्तमान डायरेक्टरी भेजें, कोई Git आवश्यक नहीं।
- [Dockerfile से परिनियोजित करें](/deploy/dockerfile): अपना स्वयं का डॉकर कंटेनर बनाएं और होस्ट करें, या एक सार्वजनिक छवि को लपेटें।
- [रनटाइम संस्करण](/deploy/runtime-versions): `.nvmrc`, `.python-version`, `go.mod` या `.ruby-version` के साथ Node.js, Python, Go या Ruby संस्करण सेट करें।
- [बैकग्राउंड वर्कर्स](/deploy/workers): `containerPort=0` के साथ डिस्कॉर्ड बॉट](/guides/discord-bot) जैसे क्यू कंज्यूमर, पोलिंग लूप और बॉट चलाएं।
- [स्केलिंग](/deploy/scaling): प्रतिकृतियां, संसाधन और भंडारण समायोजित करें।
- [क्षेत्र](/deploy/regions): आपकी सेवाएं कहां चलती हैं।
- [समस्या निवारण](/deploy/troubleshooting/incomplete-dockerfile): सबसे आम बिल्ड और परिनियोजन समस्याओं के लिए सुधार।
