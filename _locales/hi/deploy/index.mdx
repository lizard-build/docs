# डिप्लॉय

GitHub, लोकल फ़ोल्डर या Dockerfile से सर्विस डिप्लॉय करें, फिर उसका रनटाइम, रीजन और रिसोर्स सेट करें।

होस्ट की तुलना करनी हो तो ब्लॉग में बताया गया है कि [कंटेनर-ऐज़-ए-सर्विस](https://lizard.build/blog/container-as-a-service) (CaaS) प्लेटफ़ॉर्म एक-दूसरे से कैसे अलग हैं और उनकी लागत का अनुमान कैसे लगाएँ।

<span id="in-this-section" />

## इस सेक्शन में

- [GitHub से डिप्लॉय करें](/deploy/github): रिपॉज़िटरी कनेक्ट करें, ताकि ट्रैक की गई ब्रांच पर हर पुश के बाद अपने आप रीडिप्लॉय हो।
- [लोकल कोड से डिप्लॉय करें](/deploy/upload): `lizard up` से मौजूदा डायरेक्टरी डिप्लॉय करें, Git की ज़रूरत नहीं।
- [Dockerfile से डिप्लॉय करें](/deploy/dockerfile): अपना Docker कंटेनर बिल्ड और होस्ट करें, या किसी पब्लिक इमेज को Dockerfile में रैप करें।
- [रनटाइम वर्ज़न](/deploy/runtime-versions): `.nvmrc`, `.python-version`, `go.mod` या `.ruby-version` से Node.js, Python, Go या Ruby का वर्ज़न सेट करें।
- [बैकग्राउंड वर्कर](/deploy/workers): `containerPort=0` के साथ क्यू कंज्यूमर, पोलिंग लूप और [Discord बॉट](/guides/discord-bot) जैसे बॉट चलाएँ।
- [स्केलिंग](/deploy/scaling): रेप्लिका, रिसोर्स और स्टोरेज बदलें।
- [रीजन](/deploy/regions): आपकी सर्विसेज़ कहाँ चलती हैं।
- [समस्या निवारण](/deploy/troubleshooting/incomplete-dockerfile): बिल्ड और डिप्लॉय की सबसे आम समस्याओं के समाधान।
