# Lizard Studio इंस्टॉल करें

Lizard Studio एक मुफ़्त Chrome एक्सटेंशन है, जो Claude Code या ChatGPT को उस पेज से जोड़ता है जिसे आप बना रहे हैं। पेज के बगल में चैट खोलें, कोई एलिमेंट चुनें और एजेंट से अपने लोकल प्रोजेक्ट की फ़ाइलें एडिट करने को कहें। एक्सटेंशन में पेज इंस्पेक्शन, एनोटेशन, रूलर, कलर पिकर और ब्राउज़र डीबगिंग टूल शामिल हैं।

यह गाइड आपको इंस्टॉलेशन से लेकर एक ऐसे सोर्स एडिट तक ले जाती है जो पेज रिफ़्रेश करने के बाद भी बना रहता है। डाउनलोड किया जा सकने वाला उदाहरण देखने के लिए [Claude Code विज़ुअल एडिटिंग गाइड](https://lizard.build/blog/claude-code-visual-editor) देखें।

<span id="what-you-need" />

## आपको क्या चाहिए

- macOS, Windows या Linux पर Google Chrome।
- Node.js और npm। लोकल होस्ट के लिए Node.js 18 या उससे नया वर्ज़न चाहिए; आपके चुने हुए एजेंट को इससे नया वर्ज़न चाहिए हो सकता है। Node.js का ऐसा वर्ज़न इस्तेमाल करें जो दोनों के साथ चले।
- Claude Code या ChatGPT का लोकल CLI, जिसमें आपने अपने अकाउंट से साइन इन किया हो।
- एक लोकल प्रोजेक्ट फ़ोल्डर। ब्राउज़र में सोर्स एडिट देखने के लिए उस प्रोजेक्ट का डेवलपमेंट सर्वर चलाएँ और उसका URL खोलें।

एक्सटेंशन और होस्ट मुफ़्त हैं और MIT लाइसेंस के तहत उपलब्ध हैं। मॉडल के उपयोग पर आपके प्रोवाइडर के अकाउंट की शर्तें, लिमिट और शुल्क लागू होते हैं। Lizard Studio इस्तेमाल करने के लिए Lizard अकाउंट की ज़रूरत नहीं है।

<span id="1-add-the-chrome-extension" />

## 1. Chrome एक्सटेंशन जोड़ें

Chrome Web Store में [Lizard Studio](https://chromewebstore.google.com/detail/kgbaeoalmkabpoglpjcdmppdmcipfdeh) खोलें और **Add to Chrome** चुनें। अगर आप टूलबार से एक्सटेंशन खोलना चाहते हैं, तो उसे पिन कर लें।

टूलबार में डिज़ाइन टूल होते हैं; Chrome के साइड पैनल में आपकी चैट रहती हैं। स्टोर से इंस्टॉल करने के लिए Developer mode की ज़रूरत नहीं है।

<span id="2-install-your-agent" />

## 2. अपना एजेंट इंस्टॉल करें

वह एजेंट चुनें जिसे आप इस्तेमाल करना चाहते हैं। दूसरा एजेंट आप बाद में भी जोड़ सकते हैं।

Claude Code के लिए [आधिकारिक सेटअप गाइड](https://code.claude.com/docs/en/setup) फ़ॉलो करें। टर्मिनल में इंस्टॉलेशन जाँचें:

```bash
claude --version
```

Lizard Studio में ChatGPT के लिए Codex CLI इंस्टॉल करें:

```bash
npm install -g @openai/codex
codex --version
```

Lizard Studio अपने इंटरफ़ेस में इस एजेंट को **ChatGPT** कहता है। पैकेज और टर्मिनल कमांड में इसका नाम **Codex** है। यह आपके प्रोजेक्ट से जुड़ा एक लोकल कोडिंग एजेंट है; इसमें chatgpt.com वेबसाइट एम्बेड नहीं होती।

आगे बढ़ने से पहले अपना चुना हुआ एजेंट खोलें और उसका साइन-इन पूरा करें। कनेक्शन के कौन-से तरीके सपोर्ट होते हैं, यह [Lizard Studio README](https://github.com/lizard-build/lizard-studio#setup) में देखें।

<span id="3-install-the-local-host" />

## 3. लोकल होस्ट इंस्टॉल करें

टर्मिनल में यह कमांड एक बार चलाएँ:

```bash
npx @lizard-build/lizard-studio-host install
```

होस्ट Chrome एक्सटेंशन को आपके कंप्यूटर पर चल रहे एजेंट से जोड़ता है। इंस्टॉलर होस्ट को `~/.lizard-studio/host` में कॉपी करता है और उसे ब्राउज़र में रजिस्टर करता है। Node.js इंस्टॉल रहने दें: ब्राउज़र होस्ट को शुरू करने के लिए इसी का इस्तेमाल करता है।

इंस्टॉलेशन के बाद एक्सटेंशन का साइड पैनल दोबारा खोलें। अगर आपने पहले से मौजूद होस्ट को अपडेट किया है, तो नई चैट शुरू करने से पहले पैनल दोबारा खोलें।

<span id="4-connect-the-page-to-its-project" />

## 4. पेज को उसके प्रोजेक्ट से कनेक्ट करें

अपने प्रोजेक्ट का डेवलपमेंट सर्वर उसकी सामान्य कमांड से शुरू करें। सर्वर जो URL प्रिंट करे, उसे Chrome में खोलें, फिर उसी टैब पर Lizard Studio खोलें।

चैट शुरू करें, **Claude Code** या **ChatGPT** चुनें, और वह फ़ोल्डर चुनें जिसमें इस प्रोजेक्ट का सोर्स कोड है। हर चैट का अपना प्रोजेक्ट फ़ोल्डर और अपनी अनुमतियाँ होती हैं। टैब में सही पेज खुला होने भर से एजेंट को यह पता नहीं चलता कि कौन-सी लोकल रिपॉज़िटरी बदलनी है।

एडिट माँगने से पहले रीड-ओनली रिक्वेस्ट से कनेक्शन जाँच लें:

```text
Read this page's title and inspect its main heading. Tell me which
local project folder you are using. Do not change any files yet.
```

अगर एजेंट गलत फ़ोल्डर बताता है, तो आगे बढ़ने से पहले चुना गया फ़ोल्डर ठीक करें।

<span id="5-select-an-element-and-make-one-edit" />

## 5. एलिमेंट चुनें और एक एडिट करें

पेज टूलबार में **Selector** चुनें और उस एलिमेंट पर क्लिक करें जिसे आप बदलना चाहते हैं। चुना गया एलिमेंट चैट में कॉन्टेक्स्ट जोड़ देता है। अगर विज़ुअल समस्या कई एलिमेंट्स में फैली है, तो **Annotate** से उस हिस्से को मार्क करें और स्क्रीनशॉट चैट में जोड़ें।

ऐसी रिक्वेस्ट आज़माएँ जिसका नतीजा मापा जा सके:

```text
Find the source for the selected card's action row. Set the gap
between its buttons to 24px in the project files. Keep the button
labels and colors unchanged. Show the diff, then inspect the
rendered row to check its computed gap.
```

फ़ाइलों में प्रस्तावित बदलाव पढ़ें और परमिशन कंट्रोल से सिर्फ़ वही काम अप्रूव करें जो आप चाहते हैं। आपका परमिशन मोड तय करता है कि किन कामों के लिए अलग से पूछा जाएगा।

जब डेवलपमेंट सर्वर पेज को रीलोड करे, तो नतीजा इंस्पेक्ट करें। अगर पेज अपने-आप रीलोड नहीं होता, तो Chrome में रिफ़्रेश करें।

<span id="6-check-that-the-edit-persists" />

## 6. जाँचें कि एडिट बना रहता है

DOM में किया गया अस्थायी एडिट रिफ़्रेश करने तक सही दिख सकता है। सोर्स एडिट उन फ़ाइलों को बदलता है जिन्हें आपका डेवलपमेंट सर्वर सर्व करता है।

अपने एडिटर में फ़ाइल का diff देखें या प्रोजेक्ट फ़ोल्डर से `git diff` चलाएँ। पेज रिफ़्रेश करें और उसी एलिमेंट को फिर से इंस्पेक्ट करें। ऊपर के उदाहरण में उसका कंप्यूटेड गैप अब भी `24px` होना चाहिए। बदलाव रखने से पहले डेस्कटॉप और पतली स्क्रीन, दोनों लेआउट जाँच लें।

लोकल प्रोजेक्ट एडिट करने से डिप्लॉय की गई वेबसाइट अपडेट नहीं होती। जब बदलाव लाइव करना हो, तो अलग से डिप्लॉय करें।

<span id="if-the-connection-fails" />

## अगर कनेक्शन न हो

| आपको क्या दिखता है | क्या जाँचें |
|---|---|
| साइड पैनल होस्ट तक नहीं पहुँच पाता | होस्ट इंस्टॉलर चलाएँ, पक्का करें कि Node.js उपलब्ध है, फिर पैनल दोबारा खोलें। |
| एजेंट शुरू नहीं हो पाता | टर्मिनल में `claude --version` या `codex --version` चलाकर देखें और उस एजेंट का लॉगिन पूरा करें। |
| एजेंट पेज देखता है, पर उसका कोड नहीं ढूँढ पाता | सही लोकल फ़ोल्डर चुनें और पक्का करें कि टैब उसी प्रोजेक्ट के डेवलपमेंट सर्वर से खुला है। |
| रिफ़्रेश करने पर एडिट गायब हो जाता है | diff जाँचें। अगर एजेंट ने सिर्फ़ लाइव DOM बदला है, तो सोर्स में बदलाव करने को कहें। |
| Chrome के सेटिंग्स पेज पर टूलबार नहीं दिखता | Chrome `chrome://` पेजों, New Tab पेज और Chrome Web Store पर कंटेंट स्क्रिप्ट ब्लॉक करता है। कोई सामान्य वेबसाइट खोलें। |

macOS पर होस्ट को `~/.lizard-studio/host` में रखने का एक फ़ायदा यह भी है कि Desktop, Documents या Downloads में होस्ट शुरू करते समय Chrome पर लगने वाली पाबंदियाँ लागू नहीं होतीं। ज़्यादा जानकारी के लिए [README में होस्ट से जुड़े नोट्स](https://github.com/lizard-build/lizard-studio#2-the-local-host-one-time) देखें।

<span id="where-your-data-goes" />

## आपका डेटा कहाँ जाता है

एक्सटेंशन और होस्ट आपके कंप्यूटर पर चलते हैं। आप एजेंट के ज़रिए जो रिक्वेस्ट भेजते हैं, वे चुने गए मॉडल प्रोवाइडर तक पहुँचती हैं। Lizard Studio न तो Lizard के किसी चैट सर्वर का इस्तेमाल करता है, न ही टेलीमेट्री इकट्ठा करता है। लोकल इंस्टॉलेशन का मतलब यह नहीं है कि क्लाउड मॉडल आपके प्रॉम्प्ट लोकल तौर पर प्रोसेस करता है। जिस प्रोजेक्ट के डेटा पर पाबंदियाँ हैं, उसके साथ इस्तेमाल करने से पहले [Lizard Studio की प्राइवेसी पॉलिसी](https://github.com/lizard-build/lizard-studio/blob/main/PRIVACY.md) पढ़ें।
