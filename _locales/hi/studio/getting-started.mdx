# Lizard Studio इंस्टॉल करें

Lizard Studio एक मुफ़्त Chrome एक्सटेंशन है जो Claude Code या ChatGPT को आपके द्वारा बनाए जा रहे पेज से जोड़ता है। पेज के बगल में एक चैट खोलें, एक एलिमेंट चुनें और एजेंट से अपने लोकल प्रोजेक्ट में फ़ाइलों को एडिट करने के लिए कहें। एक्सटेंशन में पेज इंस्पेक्शन, एनोटेशन, रूलर्स, एक कलर पिकर और ब्राउज़र डीबगिंग टूल शामिल हैं।

यह गाइड आपको इंस्टॉलेशन से लेकर एक सोर्स एडिट तक ले जाती है जो पेज रिफ्रेश से बच जाती है। डाउनलोड करने योग्य उदाहरण के लिए, [Claude Code विज़ुअल एडिटिंग गाइड](https://lizard.build/blog/claude-code-visual-editor) देखें।

<span id="what-you-need" />

## आपको क्या चाहिए

- macOS, Windows या Linux पर Google Chrome।
- Node.js और npm। लोकल होस्ट Node.js 18 या बाद का संस्करण घोषित करता है; आपके चुने हुए एजेंट की आवश्यकता अधिक हो सकती है। Node.js का वह संस्करण उपयोग करें जो दोनों सपोर्ट करते हों।
- Claude Code या ChatGPT के लिए लोकल CLI, अपने अकाउंट से साइन इन किया हुआ।
- एक लोकल प्रोजेक्ट फ़ोल्डर। ब्राउज़र में सोर्स एडिट देखने के लिए, उस प्रोजेक्ट के डेवलपमेंट सर्वर को चलाएं और उसका URL खोलें।

एक्सटेंशन और होस्ट मुफ़्त हैं और MIT लाइसेंस प्राप्त हैं। मॉडल का उपयोग आपके प्रदाता की अकाउंट आवश्यकताओं, सीमाओं और शुल्कों का पालन करता है। Lizard Studio का उपयोग करने के लिए आपको Lizard अकाउंट की आवश्यकता नहीं है।

<span id="1-add-the-chrome-extension" />

## 1. Chrome एक्सटेंशन जोड़ें

Chrome Web Store में [Lizard Studio](https://chromewebstore.google.com/detail/kgbaeoalmkabpoglpjcdmppdmcipfdeh) खोलें और **Add to Chrome** चुनें। यदि आप टूलबार से एक्सटेंशन तक पहुंचना चाहते हैं तो इसे पिन करें।

टूलबार डिज़ाइन टूल प्रदान करता है; Chrome साइड पैनल में आपकी चैट होती हैं। स्टोर से इंस्टॉलेशन के लिए डेवलपर मोड की आवश्यकता नहीं होती है।

<span id="2-install-your-agent" />

## 2. अपना एजेंट इंस्टॉल करें

वह एजेंट चुनें जिसे आप उपयोग करना चाहते हैं। आप बाद में दूसरा जोड़ सकते हैं।

Claude Code के लिए, [आधिकारिक सेटअप गाइड](https://code.claude.com/docs/en/setup) का पालन करें। टर्मिनल में इंस्टॉलेशन की जाँच करें:

```bash
claude --version
```

Lizard Studio में ChatGPT के लिए, Codex CLI इंस्टॉल करें:

```bash
npm install -g @openai/codex
codex --version
```

Lizard Studio इस एजेंट को अपने इंटरफ़ेस में **ChatGPT** कहता है। पैकेज और टर्मिनल कमांड **Codex** नाम का उपयोग करते हैं। यह एक लोकल कोडिंग एजेंट है जो आपके प्रोजेक्ट से जुड़ा है; इसमें chatgpt.com वेबसाइट एम्बेड नहीं है।

अपना चुना हुआ एजेंट खोलें और जारी रखने से पहले उसके साइन-इन फ्लो को पूरा करें। समर्थित कनेक्शन पाथ के लिए [Lizard Studio README](https://github.com/lizard-build/lizard-studio#setup) देखें।

<span id="3-install-the-local-host" />

## 3. लोकल होस्ट इंस्टॉल करें

एक टर्मिनल में इस कमांड को एक बार चलाएं:

```bash
npx @lizard-build/lizard-studio-host install
```

होस्ट Chrome एक्सटेंशन को आपके कंप्यूटर पर एजेंट से जोड़ता है। इंस्टॉलर होस्ट को `~/.lizard-studio/host` में कॉपी करता है और इसे ब्राउज़र के साथ रजिस्टर करता है। Node.js इंस्टॉल रखें: ब्राउज़र होस्ट शुरू करने के लिए इसका उपयोग करता है।

इंस्टॉलेशन के बाद एक्सटेंशन के साइड पैनल को फिर से खोलें। यदि आपने मौजूदा होस्ट को अपडेट किया है, तो नई चैट शुरू करने से पहले पैनल को फिर से खोलें।

<span id="4-connect-the-page-to-its-project" />

## 4. पेज को उसके प्रोजेक्ट से कनेक्ट करें

अपने प्रोजेक्ट के डेवलपमेंट सर्वर को उसके सामान्य कमांड का उपयोग करके शुरू करें। जो URL यह प्रिंट करता है उसे Chrome में खोलें, फिर उस टैब पर Lizard Studio खोलें।

एक चैट शुरू करें, **Claude Code** या **ChatGPT** चुनें, और उस फ़ोल्डर को चुनें जिसमें इस प्रोजेक्ट का सोर्स कोड है। प्रत्येक चैट अपना प्रोजेक्ट फ़ोल्डर और अनुमतियाँ रखता है। सही पेज दिखाने वाला टैब अपने आप एजेंट को यह नहीं बताता कि कौन सी लोकल रिपॉजिटरी बदलनी चाहिए।

एडिट का अनुरोध करने से पहले, केवल-पढ़ने के लिए अनुरोध के साथ कनेक्शन की जाँच करें:

```text
Read this page's title and inspect its main heading. Tell me which
local project folder you are using. Do not change any files yet.
```

यदि एजेंट गलत फ़ोल्डर का नाम बताता है, तो जारी रखने से पहले चयन को सही करें।

<span id="5-select-an-element-and-make-one-edit" />

## 5. एक एलिमेंट चुनें और एक एडिट करें

पेज टूलबार में **Selector** चुनें और उस एलिमेंट पर क्लिक करें जिसे आप बदलना चाहते हैं। चयन चैट से संदर्भ जोड़ता है। कई एलिमेंट्स तक फैले विज़ुअल इश्यू के लिए, एरिया को मार्क करने और चैट में स्क्रीनशॉट जोड़ने के लिए **Annotate** का उपयोग करें।

एक मापने योग्य परिणाम वाले अनुरोध का प्रयास करें:

```text
Find the source for the selected card's action row. Set the gap
between its buttons to 24px in the project files. Keep the button
labels and colors unchanged. Show the diff, then inspect the
rendered row to check its computed gap.
```

प्रस्तावित फ़ाइल परिवर्तनों को पढ़ें और उन परिवर्तनों को स्वीकृत करने के लिए अनुमति नियंत्रणों का उपयोग करें जो आप चाहते हैं। आपका अनुमति मोड निर्धारित करता है कि किन क्रियाओं के लिए अलग प्रॉम्प्ट की आवश्यकता होती है।

जब आपका डेवलपमेंट सर्वर पेज को रीलोड करता है, तो परिणाम का निरीक्षण करें। यदि यह स्वचालित रूप से रीलोड नहीं होता है, तो Chrome को रीफ़्रेश करें।

<span id="6-check-that-the-edit-persists" />

## 6. जांचें कि एडिट बना रहता है

एक अस्थायी DOM एडिट रिफ्रेश होने तक सही दिख सकता है। एक सोर्स एडिट उन फ़ाइलों को बदलता है जिन्हें आपका डेवलपमेंट सर्वर सर्व करता है।

अपने एडिटर में फ़ाइल डिफ़ देखें या प्रोजेक्ट फ़ोल्डर से `git diff` चलाएं। पेज को रीफ़्रेश करें और उसी एलिमेंट का फिर से निरीक्षण करें। उपरोक्त उदाहरण के लिए, इसके कंप्यूटेड गैप को `24px` होना चाहिए। परिवर्तन को रखने से पहले डेस्कटॉप और नैरो लेआउट दोनों की समीक्षा करें।

लोकल प्रोजेक्ट को एडिट करने से डिप्लॉयड वेबसाइट अपडेट नहीं होती है। जब आप बदलाव को लाइव करना चाहते हैं तो अलग से डिप्लॉय करें।

<span id="if-the-connection-fails" />

## अगर कनेक्शन फेल हो जाता है

| आप क्या देखते हैं | क्या जांचें |
|---|---|
| साइड पैनल होस्ट तक नहीं पहुंच सकता | होस्ट इंस्टॉलर चलाएं, Node.js उपलब्ध है इसकी पुष्टि करें, फिर पैनल को फिर से खोलें। |
| एजेंट शुरू नहीं हो सकता | टर्मिनल में `claude --version` या `codex --version` की जांच करें और उस एजेंट के लॉगिन को पूरा करें। |
| एजेंट पेज देखता है लेकिन उसका कोड नहीं ढूंढ पाता | सही लोकल फ़ोल्डर चुनें और पुष्टि करें कि टैब उस प्रोजेक्ट के डेवलपमेंट सर्वर का उपयोग करता है। |
| रिफ्रेश करने पर एक एडिट गायब हो जाता है | डिफ़रेंस (diff) की जांच करें। यदि एजेंट ने केवल लाइव DOM को बदला है तो सोर्स परिवर्तन के लिए पूछें। |
| क्रोम सेटिंग्स पेज पर टूलबार दिखाई नहीं देता | क्रोम `chrome://` पेजों, न्यू टैब पेज और क्रोम वेब स्टोर पर कंटेंट स्क्रिप्ट को ब्लॉक करता है। एक सामान्य वेबसाइट खोलें। |

macOS पर, `~/.lizard-studio/host` में होस्ट का स्थान उन प्रतिबंधों से भी बचता है जिनका सामना क्रोम डेस्कटॉप, डॉक्यूमेंट्स या डाउनलोड के तहत होस्ट शुरू करते समय कर सकता है। अधिक जानकारी के लिए [README के होस्ट नोट्स](https://github.com/lizard-build/lizard-studio#2-the-local-host-one-time) देखें।

<span id="where-your-data-goes" />

## आपका डेटा कहां जाता है

एक्सटेंशन और होस्ट आपके कंप्यूटर पर चलते हैं। आपके द्वारा अपने एजेंट के माध्यम से भेजे गए अनुरोधों को चयनित मॉडल प्रदाता प्राप्त करता है। Lizard Studio Lizard चैट सर्वर का उपयोग नहीं करता है या टेलीमेट्री एकत्र नहीं करता है। लोकल इंस्टॉलेशन का मतलब यह नहीं है कि क्लाउड मॉडल आपके प्रॉम्प्ट को स्थानीय रूप से प्रोसेस करता है। डेटा प्रतिबंधों वाले प्रोजेक्ट के साथ इसका उपयोग करने से पहले [Lizard Studio गोपनीयता नीति](https://github.com/lizard-build/lizard-studio/blob/main/PRIVACY.md) पढ़ें।
