# ऐप डैशबोर्ड

Lizard डैशबोर्ड Lizard CLI का विज़ुअल साथी है। `lizard …` से आप जो कुछ भी करते हैं, वह यहाँ दिखता है, और साथ में वे चीज़ें भी जो UI में आसान हैं — स्ट्रीमिंग लॉग्स, चार्ट, डेटा ब्राउज़र, Sandboxes, और टीम/बिलिंग मैनेजमेंट।

अगर आप टर्मिनल खोलना ही नहीं चाहते, तो कमांड एजेंट को चलाने दें और नतीजा यहाँ देखें — यही तरीका [Antigravity ऐप को प्रोडक्शन में डिप्लॉय करना](https://lizard.build/blog/google-antigravity-how-to-deploy-your-app-to-production#deploy-from-the-antigravity-chat) में बताया गया है, जहाँ एक ही प्रॉम्प्ट से पूरा डिप्लॉय हो जाता है।

इसे CLI से खोलें:

```bash
lizard open          # open the current project
lizard docs          # open this documentation
```

<span id="whats-in-the-dashboard" />

## डैशबोर्ड में क्या है

<span id="services" />

### सर्विसेज़

साइडबार में **Apps & databases** हर सर्विस को उसके स्टेटस बैज, जेनरेटेड डोमेन, और लॉग्स, मेट्रिक्स, सीक्रेट्स और सेटिंग्स के क्विक लिंक के साथ लिस्ट करता है। **New Service** से सर्विस बनाएँ: GitHub रिपॉज़िटरी से, आपके कंप्यूटर के किसी फ़ोल्डर से, या डेटाबेस (Managed Postgres, Managed Redis) या Managed Object Storage के रूप में।

सर्विस के **Settings** टैब में **Serverless** भी है, जिससे सर्विस आइडल होने पर स्लीप कर सकती है ([`lizard sleep`](/cli/sleep)), और **Pause**, जो कुछ भी डिलीट किए बिना उसे रोक देता है ([`lizard pause`](/cli/pause))।

<span id="deployments" />

### डिप्लॉयमेंट्स

हर सर्विस के **Overview** टैब पर उसके डिप्लॉय की लिस्ट होती है। किसी डिप्लॉय की स्थिति, ट्रिगर, सोर्स, बिल्ड लॉग और रीस्टार्ट देखने के लिए उसे खोलें। यह `lizard events` + `lizard logs --build` का विज़ुअल रूप है।

<span id="logs" />

### लॉग्स

सर्च और लेवल फ़िल्टर के साथ रनटाइम और बिल्ड लॉग्स की लाइव स्ट्रीमिंग — [`lizard logs`](/observability/logs) का UI रूप।

<span id="metrics--usage" />

### मेट्रिक्स और उपयोग

हर सर्विस के CPU, मेमोरी, नेटवर्क और डिस्क चार्ट, और साथ में **Usage** पेज, जो पूरे प्रोजेक्ट का उपयोग और खर्च अलग-अलग करके दिखाता है। यह [`lizard metrics --cost`](/observability/metrics) जैसा ही है।

<span id="variables--secrets" />

### वेरिएबल्स और सीक्रेट्स

सर्विस-स्कोप वाले सीक्रेट्स सर्विस के **Secrets** टैब में और प्रोजेक्ट-स्कोप वाले **Global Secrets** में मैनेज करें; वैल्यूज़ मास्क रहती हैं और रेफ़रेंस (`${{…}}`) सपोर्ट होते हैं। [वेरिएबल्स और सीक्रेट्स](/variables) देखें।

<span id="domains" />

### डोमेन

सर्विस के **Settings** टैब में कस्टम डोमेन जोड़ें, DNS रिकॉर्ड देखें, और वेरिफ़िकेशन और TLS की स्थिति ट्रैक करें। [नेटवर्किंग](/networking) देखें।

<span id="data-browsers" />

### डेटा ब्राउज़र

हर मैनेज्ड ऐडऑन के साथ एक डेटा ब्राउज़र आता है:

- **Managed Postgres** — डेटा क्वेरी और एडिट करने के लिए SQL/टेबल एडिटर।
- **Managed Redis** — की/वैल्यू ब्राउज़र।
- **Managed Object Storage** — बकेट और ऑब्जेक्ट ब्राउज़र, अपलोड/डाउनलोड और बकेट एक्सेस सेटिंग्स के साथ।

### Sandboxes

साइडबार में **Sandboxes**, **Volumes** (Persistent Volumes), **Templates** और **Agents** हैं। Sandboxes पेज पर **New Sandbox** से सैंडबॉक्स बनाएँ; उसके बगल की संख्या दिखाती है कि आपकी लिमिट में से कितने चल रहे हैं। ट्रायल के दौरान डायलॉग सिर्फ़ US रीजन में Small साइज़ का विकल्प देता है। [Sandboxes क्विकस्टार्ट](/sandboxes/quickstart) देखें।

<span id="github-integration" />

### GitHub इंटीग्रेशन

**New Service → GitHub Repository** से GitHub कनेक्ट करें। कनेक्ट होने के बाद रिपॉज़िटरी लिस्ट के नीचे **Configure access** GitHub App की सेटिंग्स खोलता है, जहाँ आप चुनते हैं कि Lizard किन रिपॉज़िटरी को बिल्ड कर सकता है। पब्लिक रिपॉज़िटरी उसका URL पेस्ट करके भी डिप्लॉय हो जाती है, बिना कनेक्ट किए। [GitHub से डिप्लॉय करें](/deploy/github) देखें।

<span id="settings-team--billing" />

### सेटिंग्स, टीम और बिलिंग

साइडबार में नीचे **Settings** में प्रोजेक्ट और वर्कस्पेस की सेटिंग्स, सदस्यों के इनवाइट और भूमिकाएँ (**Team**), और आपके अकाउंट की सेटिंग्स होती हैं। **Billing** अकाउंट सेटिंग्स से या डैशबोर्ड में सबसे ऊपर अपने प्लान पर क्लिक करके खोलें। यह आपका प्लान, ट्रायल, मौजूदा अवधि का उपयोग, इनवॉइस और कार्ड दिखाता है। [बिलिंग](/platform/billing) देखें।

<span id="cli--dashboard" />

## CLI ↔ डैशबोर्ड

| काम | CLI | डैशबोर्ड व्यू |
|------|-----|----------------|
| डिप्लॉय हिस्ट्री | `lizard events` | Service → Overview |
| लॉग्स स्ट्रीम करें | `lizard logs` | Logs |
| रिसोर्स चार्ट | `lizard metrics` | Metrics / Usage |
| सीक्रेट्स मैनेज करें | `lizard secrets` | Secrets / Global Secrets |
| कस्टम डोमेन | `lizard domain` | Service → Settings |
| सर्विस को पॉज़ या रिज़्यूम करें | `lizard pause` / `lizard resume` | Service → Settings |
| आइडल होने पर स्लीप करें | `lizard sleep` | Service → Settings → Serverless |
| Managed Postgres, Managed Redis या Managed Object Storage को क्वेरी करें | `lizard run --service <addon> -- <cmd>` | Data browsers |
| टीम के सदस्यों को इनवाइट करें | — | Settings → Team |

उस समय जो भी सुविधाजनक हो, उसका उपयोग करें — दोनों एक ही प्रोजेक्ट्स और सर्विसेज़ पर काम करते हैं।
