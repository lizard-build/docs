# गाइड

सेटअप के चरण, जाँच और सीमाएँ जानने के लिए नीचे कोई काम चुनें। फ़्लैग का सटीक सिंटैक्स कमांड संदर्भ में देखें।

| काम | गाइड |
|---|---|
| Claude Code, Codex या Cursor से लिखा गया ऐप डिप्लॉय करें | [कोडिंग एजेंट से डिप्लॉय करें](/guides/deploy-from-coding-agent) |
| किसी MCP क्लाइंट को रिमोट HTTPS एंडपॉइंट दें | [रिमोट MCP सर्वर होस्ट करें](/guides/deploy-mcp-server) |
| Telegram का एक लॉन्ग-पोलिंग प्रोसेस लगातार चालू रखें | [Telegram बॉट चलाएँ](/guides/telegram-bot) |
| गेटवे से जुड़ा रहने वाला Discord बॉट होस्ट करें | [Discord बॉट होस्ट करें](/guides/discord-bot) |
| HTTP लिसनर के बिना क्यू के जॉब प्रोसेस करें | [बैकग्राउंड वर्कर्स](/deploy/workers) |
| अलग Linux गेस्ट में कोड चलाएँ | [Sandboxes क्विकस्टार्ट](/sandboxes/quickstart) |
| Claude Code को उसके अपने सैंडबॉक्स में काम करने दें | [सैंडबॉक्स में Claude Code चलाएँ](/sandboxes/guides/claude-code) |
| सैंडबॉक्स में OpenCode या उसका वेब UI चलाएँ | [सैंडबॉक्स में OpenCode चलाएँ](/sandboxes/guides/opencode) |
| सैंडबॉक्स में चल रहा डेव सर्वर अपने ब्राउज़र से खोलें | [प्रीव्यू URL](/sandboxes/preview-urls) |
| PostgreSQL के साथ वेबसाइट एनालिटिक्स इकट्ठा करें | [Umami चलाएँ](/guides/umami) |
| Flowise के फ़्लो और एन्क्रिप्टेड क्रेडेंशियल PostgreSQL में रखें | [Flowise चलाएँ](/guides/flowise) |
| बाद के किसी सैंडबॉक्स में फ़ाइलें फिर से इस्तेमाल करें | [Persistent Volumes](/sandboxes/volumes) |

संसाधन चुनते समय [सीमाएँ](/platform/limits), [स्टोरेज और रिकवरी](/platform/storage-and-recovery) और [ज्ञात समस्याएँ](/platform/known-issues) देख लें।

टेस्ट किए गए वर्ज़न, क्लाउड जाँच और बाकी कमियों के लिए [सिनेरियो टेस्ट के नतीजे](/guides/validation) पढ़ें।
