# गाइड्स

सेटअप चरणों, जांचों और सीमाओं के लिए नीचे एक कार्य चुनें। कमांड संदर्भ में सटीक फ़्लैग सिंटैक्स देखें।

| कार्य | गाइड |
|---|---|
| क्लॉड कोड, कोडेक्स, या कर्सर द्वारा लिखित ऐप परिनियोजित करें | [कोडिंग एजेंट से परिनियोजित करें](/guides/deploy-from-coding-agent) |
| एम सी पी क्लाइंट को एक रिमोट एचटीटीपी एंडपॉइंट दें | [रिमोट एम सी पी सर्वर होस्ट करें](/guides/deploy-mcp-server) |
| एक टेलीग्राम लॉन्ग-पोलिंग प्रक्रिया चालू रखें | [टेलीग्राम बॉट चलाएं](/guides/telegram-bot) |
| गेटवे से जुड़ा रहने वाला डिस्कॉर्ड बॉट होस्ट करें | [डिस्कॉर्ड बॉट होस्ट करें](/guides/discord-bot) |
| एचटीटीपी श्रोता के बिना कतारबद्ध नौकरियों का उपभोग करें | [पृष्ठभूमि कार्यकर्ता](/deploy/workers) |
| एक अलग लिनक्स गेस्ट में कोड चलाएं | [Sandboxes क्विकस्टार्ट](/sandboxes/quickstart) |
| क्लॉड कोड को उसके अपने सैंडबॉक्स में काम करने दें | [सैंडबॉक्स में क्लॉड कोड चलाएं](/sandboxes/guides/claude-code) |
| सैंडबॉक्स में ओपनकोड, या इसके वेब यूआई, चलाएं | [सैंडबॉक्स में ओपनकोड चलाएं](/sandboxes/guides/opencode) |
| अपने ब्राउज़र से सैंडबॉक्स में एक देव सर्वर खोलें | [पूर्वावलोकन यूआरएल](/sandboxes/preview-urls) |
| PostgreSQL के साथ वेबसाइट एनालिटिक्स एकत्र करें | [उमामी चलाएं](/guides/umami) |
| PostgreSQL में Flowise फ्लो और एन्क्रिप्टेड क्रेडेंशियल्स रखें | [Flowise चलाएं](/guides/flowise) |
| बाद के सैंडबॉक्स में फ़ाइलों का पुनः उपयोग करें | [Persistent Volumes](/sandboxes/volumes) |

संसाधन चुनते समय [सीमाओं](/platform/limits), [भंडारण और पुनर्प्राप्ति](/platform/storage-and-recovery), और [ज्ञात समस्याओं](/platform/known-issues) की जाँच करें।

परीक्षण किए गए संस्करणों, क्लाउड जांचों और शेष अंतराल के लिए [परिदृश्य परीक्षण परिणाम](/guides/validation) पढ़ें।
