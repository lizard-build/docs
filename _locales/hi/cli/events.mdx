# lizard events

डिप्लॉय हिस्ट्री और रेप्लिका स्टेटस दिखाएँ।

<span id="usage" />

## उपयोग

```bash
lizard events [flags]
```

<span id="flags" />

## फ़्लैग्स

| फ़्लैग | विवरण |
|------|-------------|
| `-n, --limit <n>` | कितनी एंट्री दिखानी हैं (डिफ़ॉल्ट 10) |
| `-s, --service <name>` | किसी खास सर्विस के इवेंट दिखाएँ |
| `-p, --project <id>` | प्रोजेक्ट का नाम, स्लग या ID |

`-p` के बिना `events` लिंक किया गया प्रोजेक्ट इस्तेमाल करता है, और जो फ़ोल्डर लिंक नहीं है उसमें आपका डिफ़ॉल्ट प्रोजेक्ट।

## उदाहरण

<span id="show-deploy-history-and-replica-status" />

### डिप्लॉय हिस्ट्री और रेप्लिका स्टेटस दिखाएँ

```bash
lizard events
```

<span id="show-events-for-a-specific-service" />

### किसी खास सर्विस के इवेंट दिखाएँ

```bash
lizard events --service api
```

<span id="show-more-entries" />

### ज़्यादा एंट्री दिखाएँ

```bash
lizard events --limit 25
```
