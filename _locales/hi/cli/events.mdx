# lizard events

डिप्लॉय इतिहास और रेप्लिका स्थिति दिखाएं।

<span id="usage" />

## उपयोग

```bash
lizard events [flags]
```

<span id="flags" />

## फ्लैग्स

| फ्लैग | विवरण |
|------|-------------|
| `-n, --limit <n>` | दिखाने के लिए प्रविष्टियों की संख्या (डिफ़ॉल्ट 10) |
| `-s, --service <name>` | किसी विशिष्ट सेवा के लिए ईवेंट दिखाएं |
| `-p, --project <id>` | प्रोजेक्ट का नाम, स्लग, या आईडी |

`-p` के बिना, `events` लिंक किए गए प्रोजेक्ट का उपयोग करता है, या एक अनलिंक किए गए फ़ोल्डर में आपका डिफ़ॉल्ट प्रोजेक्ट।

<span id="examples" />

## उदाहरण

<span id="show-deploy-history-and-replica-status" />

### डिप्लॉय इतिहास और रेप्लिका स्थिति दिखाएं

```bash
lizard events
```

<span id="show-events-for-a-specific-service" />

### किसी विशिष्ट सेवा के लिए ईवेंट दिखाएं

```bash
lizard events --service api
```

<span id="show-more-entries" />

### अधिक प्रविष्टियां दिखाएं

```bash
lizard events --limit 25
```
