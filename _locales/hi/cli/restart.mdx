# lizard restart

वर्तमान बिल्ड का रोलिंग रीस्टार्ट — कोई रीबिल्ड नहीं।

<span id="usage" />

## उपयोग

```bash
lizard restart [nameOrId] [flags]
```

<span id="flags" />

## फ्लैग्स

| फ्लैग | विवरण |
|------|--------------|
| `-s, --service <name>` | सेवा |
| `-p, --project <id>` | प्रोजेक्ट का नाम, स्लग, या आईडी |
| `--detach` | रीस्टार्ट स्वीकार होने के बाद वापस आएं, उसकी स्थिति की जाँच किए बिना |
| `--wait` | नए रीस्टार्ट प्रयास के तैयार होने की प्रतीक्षा करें; `--json` के साथ काम करता है |
| `--timeout <seconds>` | `--wait` के साथ तत्परता प्रतीक्षा बजट; डिफ़ॉल्ट `120` |
| `--json` | स्क्रिप्ट के लिए JSON लौटाएं |

<span id="examples" />

## उदाहरण

<span id="restart-a-service" />

### एक सेवा को रीस्टार्ट करें

```bash
lizard restart --service api
```

<span id="return-without-waiting" />

### प्रतीक्षा किए बिना वापस लौटें

```bash
lizard restart --service api --detach
```

<span id="wait-before-running-the-next-check" />

### अगली जाँच चलाने से पहले प्रतीक्षा करें

```bash
lizard --json restart --service api --wait --timeout 120
```

`--wait` के बिना, JSON मोड रीस्टार्ट स्वीकार होने के बाद वापस आ जाता है। `--wait` के साथ, परिणाम में `ok`, `status`, `attemptId`, और `waitedMs` शामिल हैं। CLI एक नए रीस्टार्ट प्रयास की प्रतीक्षा करता है, इसलिए अनुरोध से पहले की अपरिवर्तित स्थिति को सफलता नहीं माना जाता है। एक विफल प्रतीक्षा या टाइमआउट एक गैर-शून्य निकास कोड देता है।

एक रुकी हुई सेवा आपको इसे [फिर से शुरू](/cli/pause) करने तक रीस्टार्ट करने से इनकार करती है।

HTTP सेवाओं के लिए, CLI सेवा डोमेन को दो बार भी जाँचता है। `containerPort=0` वाले वर्कर्स बैकएंड से तत्परता स्थिति का उपयोग करते हैं और उन्हें HTTP श्रोता की आवश्यकता नहीं होती है, भले ही उनके पास एक उत्पन्न डोमेन हो।

```bash
lizard --json restart --service worker --wait --timeout 60
```

टाइमआउट रीस्टार्ट अनुरोध के बाद तत्परता प्रतीक्षा पर लागू होता है। यह रीस्टार्ट को रद्द नहीं करता है, और नेटवर्क कॉल कमांड को कुल मिलाकर अधिक समय ले सकती हैं। जब आपके वर्कफ़्लो को प्रक्रिया तत्परता से अधिक की आवश्यकता होती है, तो कमांड के बाद एप्लिकेशन डेटा या स्वास्थ्य एंडपॉइंट की जाँच करें।
