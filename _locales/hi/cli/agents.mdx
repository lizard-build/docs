# lizard agents

सैंडबॉक्स में कोडिंग एजेंट द्वारा उपयोग किए जाने वाले क्रेडेंशियल्स को कनेक्ट करें, और प्रत्येक एजेंट के डिफ़ॉल्ट सेट करें। एजेंट को [`lizard sandbox prompt`](/cli/sandbox#coding-agents) के साथ चलाएँ।

<span id="usage" />

## उपयोग

```bash
lizard agents status
lizard agents login [chatgpt] [flags]
lizard agents add <credential> [flags]
lizard agents remove <credential>
lizard agents use <agent> [flags]
```

क्रेडेंशियल्स आपके खाते से संबंधित हैं। किसी भी सैंडबॉक्स में एजेंट रन के लिए उपयोग करने के लिए एक क्रेडेंशियल को एक बार कनेक्ट करें। ChatGPT लॉगिन के लिए, प्लेटफ़ॉर्म लॉन्ग-लिव्ड टोकन रखता है और प्रत्येक रन के लिए सैंडबॉक्स को एक शॉर्ट-लिव्ड एक्सेस टोकन देता है। Lizard प्रत्येक रन के वातावरण में एपीआई कीज़ और संग्रहीत क्लॉड सब्सक्रिप्शन टोकन को अपरिवर्तित पास करता है। उन क्रेडेंशियल्स का उपयोग करें जिन्हें आप निरस्त कर सकते हैं। ये कमांड `-p, --project` स्वीकार करते हैं लेकिन इसे अनदेखा करते हैं।

<span id="agents-and-credentials" />

## एजेंट और क्रेडेंशियल्स

| एजेंट | नाम | स्वीकार करता है |
|-------|------|---------|
| Codex | `codex` | में से एक: `chatgpt`, `openai`, `deepseek`, `openrouter` |
| Claude Code | `claude` | में से एक: `claude`, `anthropic`, `openrouter` |
| pi | `pi` | में से कोई भी: `claude`, `chatgpt`, `anthropic`, `openai`, `openrouter`, `llmgateway` |
| OpenCode | `opencode` | में से कोई भी: `chatgpt`, `anthropic`, `openai`, `openrouter`, `llmgateway` |
| Prime Agent | `prime` | में से कोई भी: `claude`, `chatgpt`, `anthropic`, `openai`, `openrouter`, `llmgateway` |

Kimi Code (`kimi`, `kimi` या `moonshot` क्रेडेंशियल्स के साथ) सूचीबद्ध है लेकिन अभी तक चल नहीं सकता है।

<span id="subcommands" />

## सबकमांड

### `lizard agents status`

दिखाएँ कि कौन से क्रेडेंशियल्स कनेक्टेड हैं और कौन से एजेंट चल सकते हैं। प्लेन `lizard agents` भी वही करता है।

### `lizard agents login [chatgpt]`

अपने ChatGPT सब्सक्रिप्शन को डिवाइस कोड के साथ कनेक्ट करें। CLI एक URL और एक कोड प्रिंट करता है; URL खोलें, साइन इन करें, और 15 मिनटों के भीतर कोड दर्ज करें। कमांड आपके अप्रूव करने तक प्रतीक्षा करता है।

| फ्लैग | विवरण |
|------|-------------|
| `--open` | अपने ब्राउज़र में साइन-इन पेज खोलें |

### `lizard agents add <credential>`

एक एपीआई की जोड़ें: `anthropic`, `openai`, `openrouter`, `llmgateway`, `deepseek`, या `moonshot`। क्लॉड सब्सक्रिप्शन के लिए, अपने मशीन पर `claude setup-token` चलाएँ और अपने टोकन को `claude` के रूप में जोड़ें।

| फ्लैग | विवरण |
|------|-------------|
| `--key <value>` | की या टोकन। इसके बिना, CLI stdin पढ़ता है, या पूछता है |

### `lizard agents remove <credential>`

एक कनेक्टेड क्रेडेंशियल (उपनाम `logout`) हटाएं।

### `lizard agents use <agent>`

किसी एजेंट का क्रेडेंशियल और डिफ़ॉल्ट सेट करें।

| फ्लैग | विवरण |
|------|-------------|
| `--credential <name>` | Codex और Claude Code के लिए: कौन सा क्रेडेंशियल उपयोग करना है |
| `-m, --model <model>` | डिफ़ॉल्ट मॉडल (`none` इसे साफ़ करता है) |
| `--effort <level>` | डिफ़ॉल्ट रीज़निंग प्रयास (`none` इसे साफ़ करता है) |

## उदाहरण

<span id="connect-chatgpt-and-run-codex" />

### ChatGPT कनेक्ट करें और Codex चलाएँ

```bash
lizard agents login chatgpt --open
lizard sandbox create -t codex
lizard sandbox prompt genuine-toddler-jasj "add a health check endpoint and test it"
```

<span id="add-a-claude-subscription-for-claude-code" />

### Claude Code के लिए एक Claude सब्सक्रिप्शन जोड़ें

```bash
claude setup-token
lizard agents add claude
lizard sandbox create -t claude
lizard sandbox prompt genuine-toddler-jasj --agent claude "fix the failing tests"
```

<span id="run-codex-on-an-openai-api-key" />

### OpenAI API की पर Codex चलाएँ

```bash
lizard agents add openai < openai.key
lizard agents use codex --credential openai --effort high
```
