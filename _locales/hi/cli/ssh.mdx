# lizard ssh

> **बंद है।** Lizard पर सर्विसेज़ में शेल एक्सेस बंद है। `lizard ssh` को HTTP 403 `Shell access to services is disabled` मिलता है और वह कोड `1` के साथ बाहर निकलती है।

यह कमांड अब भी CLI के साथ आती है, लेकिन प्लेटफ़ॉर्म हर सर्विस के लिए इसे अस्वीकार कर देता है। इसकी जगह ये कमांड इस्तेमाल करें:

| क्या जाँचना है | कमांड |
|----------|---------|
| खाली वैल्यू में रिज़ॉल्व हुए रेफ़रेंस | `lizard logs --build --service api` (बिल्ड लॉग हर खाली `${{…}}` रेफ़रेंस पर चेतावनी देता है) |
| सर्विस पर सेव की गई वैल्यूज़ | `lizard secrets list --service api --show` |
| ऐडऑन की असली कनेक्शन वैल्यूज़ के साथ कोई कमांड | `lizard run --service postgres -- <cmd>` |
| रनटाइम पर ऐप क्या प्रिंट करता है | `lizard logs --service api` |

सैंडबॉक्स में शेल के लिए [`lizard sandbox ssh <id>`](/cli/sandbox#sandbox-ssh) का उपयोग करें। यह अब भी काम करती है।

<span id="usage" />

## उपयोग

```bash
lizard ssh --service <name> -- <command>
```

| फ्लैग | विवरण |
|------|-------------|
| `-s, --service <id>` | सर्विस का नाम या ID |
| `-p, --project <id>` | प्रोजेक्ट का नाम, स्लग या ID |
