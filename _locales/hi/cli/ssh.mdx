# lizard ssh

> **बंद है।** सेवाओं तक शेल एक्सेस Lizard पर अक्षम है। `lizard ssh` HTTP 403 `Shell access to services is disabled` प्राप्त करता है और कोड `1` के साथ बाहर निकलता है।

कमांड अभी भी सीएलआई के साथ आता है, लेकिन प्लेटफ़ॉर्म इसे हर सेवा के लिए अस्वीकार कर देता है। इसके बजाय इनका उपयोग करें:

| जांचने के लिए | कमांड |
|----------|---------|
| खाली मान पर हल होने वाले संदर्भ | `lizard logs --build --service api` (बिल्ड लॉग हर खाली `${{…}}` संदर्भ के बारे में चेतावनी देता है) |
| किसी सेवा पर संग्रहीत मान | `lizard secrets list --service api --show` |
| एडऑन के वास्तविक कनेक्शन मानों वाला कमांड | `lizard run --service postgres -- <cmd>` |
| रनटाइम पर ऐप क्या प्रिंट करता है | `lizard logs --service api` |

सैंडबॉक्स में शेल के लिए, [`lizard sandbox ssh <id>`](/cli/sandbox#sandbox-ssh) का उपयोग करें। यह अभी भी काम करता है।

<span id="usage" />

## उपयोग

```bash
lizard ssh --service <name> -- <command>
```

| फ्लैग | विवरण |
|------|-------------|
| `-s, --service <id>` | सेवा का नाम या आईडी |
| `-p, --project <id>` | प्रोजेक्ट का नाम, स्लग, या आईडी |
