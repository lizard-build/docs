# lizard init

प्रोजेक्ट बनाएँ या चुनें और उसे मौजूदा डायरेक्टरी से लिंक करें।

<span id="usage" />

## उपयोग

```bash
lizard init [flags]
```

<span id="flags" />

## फ़्लैग्स

| फ़्लैग | विवरण |
|------|-------------|
| `-n, --name <name>` | प्रोजेक्ट का नाम (मौजूद न हो तो बना दिया जाता है) |
| `-w, --workspace <ws>` | वर्कस्पेस की ID, स्लग या नाम |
| `--force` | पहले से लिंक होने पर भी दोबारा लिंक करें |

<span id="examples" />

## उदाहरण

<span id="link-the-current-directory-interactively" />

### मौजूदा डायरेक्टरी को इंटरैक्टिव तरीके से लिंक करें

```bash
lizard init
```

`--name` के बिना `init` पूछता है कि कौन-सा प्रोजेक्ट इस्तेमाल करना है। नॉन-इंटरैक्टिव शेल में यह फ़ेल हो जाता है, इसलिए वहाँ `--name` पास करें।

<span id="link-explicitly-in-ci" />

### CI में स्पष्ट रूप से लिंक करें

लिंक न की गई डायरेक्टरी से चलाया गया `lizard up` आपके अकाउंट के डिफ़ॉल्ट प्रोजेक्ट में डिप्लॉय करता है। CI में किसी खास नाम वाले प्रोजेक्ट में डिप्लॉय करने के लिए पहले उसे लिंक करें:

```bash
export LIZARD_TOKEN=liz_xxx
lizard init --name my-project
lizard up --ci --service api   # creates api on the first run
```

<span id="relink-a-directory-thats-already-linked" />

### पहले से लिंक की गई डायरेक्टरी को दोबारा लिंक करें

```bash
lizard init --name my-project --force
```
