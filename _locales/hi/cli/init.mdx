# lizard init

एक प्रोजेक्ट बनाएं या चुनें और उसे वर्तमान डायरेक्टरी से लिंक करें।

<span id="usage" />

## उपयोग

```bash
lizard init [flags]
```

<span id="flags" />

## फ्लैग्स

| फ्लैग | विवरण |
|------|-------------|
| `-n, --name <name>` | प्रोजेक्ट का नाम (यदि मौजूद नहीं है तो बनाएं) |
| `-w, --workspace <ws>` | वर्कस्पेस आईडी, स्लग, या नाम |
| `--force` | पहले से लिंक होने पर भी फिर से लिंक करें |

<span id="examples" />

## उदाहरण

<span id="link-the-current-directory-interactively" />

### वर्तमान डायरेक्टरी को इंटरैक्टिव रूप से लिंक करें

```bash
lizard init
```

`--name` के बिना, `init` पूछता है कि कौन सा प्रोजेक्ट उपयोग करना है। एक नॉन-इंटरैक्टिव शेल में यह विफल हो जाता है, इसलिए `--name` पास करें।

<span id="link-explicitly-in-ci" />

### CI में स्पष्ट रूप से लिंक करें

एक अनलिंक्ड `lizard up` आपके खाते के डिफ़ॉल्ट प्रोजेक्ट में डिप्लॉय होता है। CI में एक नामित प्रोजेक्ट में डिप्लॉय करने के लिए, पहले उसे लिंक करें:

```bash
export LIZARD_TOKEN=liz_xxx
lizard init --name my-project
lizard up --ci --service api   # creates api on the first run
```

<span id="relink-a-directory-thats-already-linked" />

### पहले से लिंक डायरेक्टरी को फिर से लिंक करें

```bash
lizard init --name my-project --force
```
