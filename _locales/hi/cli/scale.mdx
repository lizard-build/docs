# lizard scale

एक सर्विस को स्केल करें (रेप्लिका / CPU / मेमोरी / स्टोरेज)।

<span id="usage" />

## उपयोग

```bash
lizard scale [service] [flags]
```

<span id="flags" />

## फ्लैग्स

| फ्लैग | विवरण |
|------|-------------|
| `-s, --service <name>` | सर्विस का नाम या आईडी (डिफ़ॉल्ट: लिंक्ड सर्विस; `service` आर्गुमेंट के समान) |
| `-p, --project <id>` | प्रोजेक्ट का नाम, स्लग, या आईडी |
| `--replicas <n>` | रेप्लिका (ऐप्स), आपके प्लान की [सीमा](/platform/limits#applications) तक: `1` पहले पेड Pro इनवॉइस तक (इसलिए ट्रायल के दौरान), `5` उसके बाद और एंटरप्राइज पर |
| `--cpu <cores>` | `1`, `2`, `3`, या `4` |
| `--memory <mb>` | `128`–`8192` MB |
| `--storage <mb>` | ऐडऑन वॉल्यूम साइज़, केवल-ग्रो: `512`, `1024`, `2048`, `4096`, `8192`, या `16384` |

<span id="examples" />

## उदाहरण

<span id="scale-replicas-horizontally" />

### रेप्लिका को हॉरिजॉन्टली स्केल करें

```bash
lizard scale --service api --replicas 5
```

प्रत्येक रेप्लिका लोड बैलेंसर के पीछे अपना पॉड होता है। सुनिश्चित करें कि आपका ऐप स्टेटलेस है ताकि रेप्लिका इंटरचेंजेबल हों। एक से अधिक रेप्लिका वाला ऐप [निष्क्रिय होने पर स्लीप नहीं करता](/cli/sleep)। [पॉज़](/cli/pause) किए गए ऐप पर, `--replicas` गिनती को सेव करता है, और यह रिज्यूम होने पर लागू होता है।

<span id="scale-cpu-and-memory-vertically" />

### CPU और मेमोरी को वर्टिकली स्केल करें

```bash
lizard scale --service api --cpu 4 --memory 8192
```

<span id="grow-addon-storage" />

### ऐडऑन स्टोरेज को बढ़ाएं

```bash
lizard scale --service postgres --storage 8192
```

ऐडऑन डेटा वॉल्यूम केवल-ग्रो होते हैं — आप स्टोरेज बढ़ा सकते हैं लेकिन घटा नहीं सकते।
