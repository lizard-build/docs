# lizard secrets

प्रोजेक्ट या सर्विस के सीक्रेट्स (एनवायरनमेंट वेरिएबल्स) मैनेज करें।

<span id="usage" />

## उपयोग

```bash
lizard secrets <subcommand> [args] [flags]
```

<span id="subcommands" />

## सबकमांड

### `lizard secrets set <K=V>...`

एक या ज़्यादा सीक्रेट्स सेट करें (एक साथ कई दे सकते हैं)। डिफ़ॉल्ट स्कोप सर्विस है; `--global` प्रोजेक्ट को टारगेट करता है।

| फ्लैग | विवरण |
|------|-------------|
| `--global` | प्रोजेक्ट स्कोप |
| `-s, --service <name>` | सर्विस स्कोप |
| `-p, --project <id>` | प्रोजेक्ट का नाम, स्लग या ID |

### `lizard secrets list`

स्कोप के सीक्रेट्स लिस्ट करें।

| फ्लैग | विवरण |
|------|-------------|
| `--show` | वैल्यूज़ दिखाएँ |
| `--ref` | इस स्कोप में उपलब्ध `${{…}}` रेफ़रेंस लिस्ट करें |
| `--global` | प्रोजेक्ट स्कोप |
| `-s, --service <name>` | सर्विस स्कोप |
| `-p, --project <id>` | प्रोजेक्ट का नाम, स्लग या ID |

### `lizard secrets delete <K>...`

एक या ज़्यादा सीक्रेट्स डिलीट करें (एक साथ कई दे सकते हैं, उपनाम `rm`)। यह पुष्टि माँगता है; TTY के बिना `-y` दें।

| फ्लैग | विवरण |
|------|-------------|
| `-y, --yes` | पुष्टि छोड़ दें |
| `--global` | प्रोजेक्ट स्कोप |
| `-s, --service <name>` | सर्विस स्कोप |
| `-p, --project <id>` | प्रोजेक्ट का नाम, स्लग या ID |

### `lizard secrets import`

stdin से `KEY=value` लाइनें इम्पोर्ट करें। यह खाली लाइनों और `#` से शुरू होने वाली लाइनों को छोड़ देता है। कोट्स वैल्यू का हिस्सा बने रहते हैं; अगर `export ` प्रीफ़िक्स हों तो पहले उन्हें हटा दें।

| फ्लैग | विवरण |
|------|-------------|
| `--global` | प्रोजेक्ट स्कोप |
| `-s, --service <name>` | सर्विस स्कोप |
| `-p, --project <id>` | प्रोजेक्ट का नाम, स्लग या ID |

## उदाहरण

<span id="set-secrets-on-the-linked-service" />

### लिंक की गई सर्विस पर सीक्रेट्स सेट करें

```bash
lizard secrets set DATABASE_URL=postgres://… LOG_LEVEL=info
lizard secrets set API_KEY=sk_live_… --service api
```

<span id="set-a-project-wide-secret" />

### पूरे प्रोजेक्ट के लिए सीक्रेट सेट करें

```bash
lizard secrets set NODE_ENV=production --global
```

<span id="list-and-reveal-secrets" />

### सीक्रेट्स लिस्ट करें और उनकी वैल्यूज़ दिखाएँ

```bash
lizard secrets list
lizard secrets list --show
```

<span id="delete-secrets" />

### सीक्रेट्स डिलीट करें

```bash
lizard secrets delete OLD_KEY ANOTHER_KEY
lizard secrets delete OLD_KEY --yes   # in CI or a script
```

<span id="import-a-env-file" />

### `.env` फ़ाइल इम्पोर्ट करें

```bash
lizard secrets import < .env
```
