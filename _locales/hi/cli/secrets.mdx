# lizard secrets

प्रोजेक्ट या सर्विस के सीक्रेट्स (एनवायरनमेंट वेरिएबल्स) को मैनेज करें।

<span id="usage" />

## उपयोग

```bash
lizard secrets <subcommand> [args] [flags]
```

<span id="subcommands" />

## सबकमांड

### `lizard secrets set <K=V>...`

एक या अधिक सीक्रेट्स सेट करें (वेरिएटिक)। डिफ़ॉल्ट स्कोप सर्विस है; `--global` प्रोजेक्ट को टारगेट करता है।

| फ्लैग | विवरण |
|------|-------------|
| `--global` | प्रोजेक्ट स्कोप |
| `-s, --service <name>` | सर्विस स्कोप |
| `-p, --project <id>` | प्रोजेक्ट का नाम, स्लग, या आईडी |

### `lizard secrets list`

स्कोप में सीक्रेट्स लिस्ट करें।

| फ्लैग | विवरण |
|------|-------------|
| `--show` | वैल्यूज़ रिवील करें |
| `--ref` | इस स्कोप में उपलब्ध `${{…}}` रेफरेंस को लिस्ट करें |
| `--global` | प्रोजेक्ट स्कोप |
| `-s, --service <name>` | सर्विस स्कोप |
| `-p, --project <id>` | प्रोजेक्ट का नाम, स्लग, या आईडी |

### `lizard secrets delete <K>...`

एक या अधिक सीक्रेट्स डिलीट करें (variadic, alias `rm`). यह कन्फर्मेशन पूछता है; TTY के बिना, `-y` पास करें।

| फ्लैग | विवरण |
|------|-------------|
| `-y, --yes` | पुष्टि छोड़ें |
| `--global` | प्रोजेक्ट स्कोप |
| `-s, --service <name>` | सर्विस स्कोप |
| `-p, --project <id>` | प्रोजेक्ट का नाम, स्लग, या आईडी |

### `lizard secrets import`

`KEY=value` लाइन्स को stdin से इम्पोर्ट करें। यह खाली लाइन्स और `#` से शुरू होने वाली लाइन्स को स्किप करता है। कोट्स वैल्यू का हिस्सा बने रहते हैं; पहले कोई भी `export ` प्रीफिक्स हटा दें।

| फ्लैग | विवरण |
|------|-------------|
| `--global` | प्रोजेक्ट स्कोप |
| `-s, --service <name>` | सर्विस स्कोप |
| `-p, --project <id>` | प्रोजेक्ट का नाम, स्लग, या आईडी |

## उदाहरण

<span id="set-secrets-on-the-linked-service" />

### लिंक्ड सर्विस पर सीक्रेट्स सेट करें

```bash
lizard secrets set DATABASE_URL=postgres://… LOG_LEVEL=info
lizard secrets set API_KEY=sk_live_… --service api
```

<span id="set-a-project-wide-secret" />

### प्रोजेक्ट-वाइड सीक्रेट सेट करें

```bash
lizard secrets set NODE_ENV=production --global
```

<span id="list-and-reveal-secrets" />

### सीक्रेट्स लिस्ट और रिवील करें

```bash
lizard secrets list
lizard secrets list --show
```

<span id="delete-secrets" />

### सीक्रेट्स डिलीट करें

```bash
lizard secrets delete OLD_KEY ANOTHER_KEY
lizard secrets delete OLD_KEY --yes   # in CI or a script
```

<span id="import-a-env-file" />

### एक `.env` फ़ाइल इम्पोर्ट करें

```bash
lizard secrets import < .env
```
