# lizard run

प्रोजेक्ट और सेवा रहस्यों को इंजेक्ट करके स्थानीय रूप से एक कमांड चलाएं।

<span id="what-run-injects" />

## `run` क्या इंजेक्ट करता है

`lizard run` प्रोजेक्ट के रहस्यों को लोड करता है, फिर उसके ऊपर सेवा के रहस्यों को लोड करता है, और उन्हें अपने वातावरण में आपकी मशीन पर चलाता है।

- ऐप सेवा के लिए, यह संग्रहीत मानों को इंजेक्ट करता है। `${{postgres.DATABASE_URL}}` जैसे संदर्भ उस शाब्दिक पाठ के रूप में आते हैं, न कि हल किए गए मान के रूप में। `PORT` और `LIZARD_*` जैसे प्लेटफ़ॉर्म चर इंजेक्ट नहीं किए जाते हैं।
- एडऑन (`--service postgres`, `--service redis`, `--service s3`) के लिए, यह एडऑन के वास्तविक कनेक्शन मानों को इंजेक्ट करता है, जैसे `DATABASE_URL`।

स्थानीय रूप से माइग्रेशन या डेटाबेस क्लाइंट चलाने के लिए, एडऑन को `--service` पर इंगित करें, न कि उस ऐप पर जो इसे संदर्भित करता है।

Lizard `lizard ssh` को चल रही सेवाओं में चलने से रोकता है (API 403 "सेवाओं तक शेल एक्सेस अक्षम है" का जवाब देता है)। यह जांचने के लिए कि चल रहा ऐप क्या प्राप्त करता है, इसका उपयोग करें:

| जाँच | कमांड |
|-------|---------|
| खाली संदर्भ | `lizard logs --build --service api` (बिल्ड लॉग हर `${{…}}` संदर्भ के बारे में चेतावनी देता है जो एक खाली मान में हल हुआ) |
| संग्रहीत मान | `lizard secrets list --service api --show` |
| एडऑन के वास्तविक कनेक्शन मान | `lizard run --service postgres -- printenv DATABASE_URL` |

<span id="usage" />

## उपयोग

```bash
lizard run [flags] -- <command>
```

<span id="flags" />

## फ्लैग्स

| फ्लैग | विवरण |
|------|-------------|
| `-s, --service <name>` | सेवा जिसका env इंजेक्ट करना है (डिफ़ॉल्ट रूप से लिंक की गई सेवा) |
| `--no-service` | सेवा env इंजेक्ट न करें, केवल प्रोजेक्ट सीक्रेट्स |
| `-p, --project <id>` | प्रोजेक्ट का नाम, स्लग, या आईडी (डिफ़ॉल्ट रूप से लिंक किए गए प्रोजेक्ट, या एक अनलिंक फ़ोल्डर में आपके डिफ़ॉल्ट प्रोजेक्ट के लिए) |

एक अनलिंक फ़ोल्डर में, `lizard run --service postgres` आपके व्यक्तिगत वर्कस्पेस में सबसे पुराने प्रोजेक्ट, `postgres` एडऑन को पढ़ता है। किसी अन्य प्रोजेक्ट के डेटाबेस का उपयोग करने के लिए `-p` पास करें।

<span id="examples" />

## उदाहरण

<span id="run-a-migration-against-managed-postgres" />

### Managed Postgres के विरुद्ध माइग्रेशन चलाएं

```bash
lizard run --service postgres -- node scripts/migrate.js
```

<span id="print-an-injected-environment-variable" />

### इंजेक्ट किए गए पर्यावरण चर को प्रिंट करें

```bash
lizard run --service postgres -- printenv DATABASE_URL
```

<span id="run-a-local-tool-with-an-apps-stored-secrets" />

### ऐप के संग्रहीत रहस्यों के साथ एक स्थानीय टूल चलाएं

```bash
lizard run --service api -- node scripts/report.js
```
