# lizard run

प्रोजेक्ट और सर्विस के सीक्रेट्स इंजेक्ट करके लोकली कोई कमांड चलाएँ।

<span id="what-run-injects" />

## `run` क्या इंजेक्ट करता है

`lizard run` पहले प्रोजेक्ट के सीक्रेट्स लोड करता है, फिर उनके ऊपर सर्विस के सीक्रेट्स, और आपकी कमांड को इन्हीं वैल्यूज़ वाले एनवायरनमेंट के साथ आपकी मशीन पर चलाता है।

- ऐप सर्विस के लिए यह सेव की गई वैल्यूज़ इंजेक्ट करता है। `${{postgres.DATABASE_URL}}` जैसे रेफ़रेंस वैसे ही टेक्स्ट के रूप में आते हैं, रिज़ॉल्व की गई वैल्यू के रूप में नहीं। `PORT` और `LIZARD_*` जैसे प्लेटफ़ॉर्म वेरिएबल्स इंजेक्ट नहीं होते।
- ऐडऑन (`--service postgres`, `--service redis`, `--service s3`) के लिए यह ऐडऑन की असली कनेक्शन वैल्यूज़ इंजेक्ट करता है, जैसे `DATABASE_URL`।

लोकली माइग्रेशन या डेटाबेस क्लाइंट चलाने के लिए `--service` में ऐडऑन का नाम दें, उस ऐप का नहीं जो उसे रेफ़र करता है।

Lizard चल रही सर्विसेज़ में `lizard ssh` की अनुमति नहीं देता (API 403 और संदेश "Shell access to services is disabled" लौटाता है)। चल रहे ऐप को क्या मिलता है, यह जाँचने के लिए इनका उपयोग करें:

| जाँच | कमांड |
|-------|---------|
| खाली रेफ़रेंस | `lizard logs --build --service api` (बिल्ड लॉग हर उस `${{…}}` रेफ़रेंस पर चेतावनी देता है जो खाली वैल्यू में रिज़ॉल्व हुआ) |
| सेव की गई वैल्यूज़ | `lizard secrets list --service api --show` |
| ऐडऑन की असली कनेक्शन वैल्यूज़ | `lizard run --service postgres -- printenv DATABASE_URL` |

<span id="usage" />

## उपयोग

```bash
lizard run [flags] -- <command>
```

<span id="flags" />

## फ्लैग्स

| फ्लैग | विवरण |
|------|-------------|
| `-s, --service <name>` | वह सर्विस जिसका env इंजेक्ट करना है (डिफ़ॉल्ट: लिंक की गई सर्विस) |
| `--no-service` | सर्विस का env इंजेक्ट न करें, सिर्फ़ प्रोजेक्ट के सीक्रेट्स |
| `-p, --project <id>` | प्रोजेक्ट का नाम, स्लग या ID (डिफ़ॉल्ट: लिंक किया गया प्रोजेक्ट, या अनलिंक्ड फ़ोल्डर में आपका डिफ़ॉल्ट प्रोजेक्ट) |

अनलिंक्ड फ़ोल्डर में `lizard run --service postgres` आपके डिफ़ॉल्ट प्रोजेक्ट (आपके पर्सनल वर्कस्पेस का सबसे पुराना प्रोजेक्ट) का `postgres` ऐडऑन पढ़ता है। किसी दूसरे प्रोजेक्ट का डेटाबेस इस्तेमाल करने के लिए `-p` दें।

<span id="examples" />

## उदाहरण

<span id="run-a-migration-against-managed-postgres" />

### Managed Postgres पर माइग्रेशन चलाएँ

```bash
lizard run --service postgres -- node scripts/migrate.js
```

<span id="print-an-injected-environment-variable" />

### इंजेक्ट किया गया एनवायरनमेंट वेरिएबल प्रिंट करें

```bash
lizard run --service postgres -- printenv DATABASE_URL
```

<span id="run-a-local-tool-with-an-apps-stored-secrets" />

### ऐप के सेव किए गए सीक्रेट्स के साथ कोई लोकल टूल चलाएँ

```bash
lizard run --service api -- node scripts/report.js
```
