# lizard metrics

CPU / मेमोरी / नेटवर्क / डिस्क और लागत दिखाएं।

<span id="usage" />

## उपयोग

```bash
lizard metrics [flags]
```

<span id="flags" />

## फ्लैग्स

| फ्लैग | विवरण |
|------|-------------|
| `-s, --service <id>` | Service (डिफ़ॉल्ट रूप से लिंक्ड सर्विस पर) |
| `-p, --project <id>` | प्रोजेक्ट का नाम, स्लग, या आईडी |
| `--all` | प्रोजेक्ट में सभी सर्विसेज़, लिंक्ड सर्विस को अनदेखा करते हुए; `-s` के साथ संयुक्त नहीं किया जा सकता |
| `-r, --range <range>` | टाइम विंडो: `1h` (डिफ़ॉल्ट), `6h`, `24h`, `7d`, `14d`, या `30d` |
| `-w, --watch` | लाइव व्यू, हर 3 सेकंड में रीफ़्रेश होता है; `--json` के साथ संयुक्त नहीं किया जा सकता |
| `--cost` | रनिंग रिसोर्सेज, प्रति घंटा लागत, इस बिलिंग अवधि का उपयोग, और इस महीने का Pro उपयोग। केवल वर्कस्पेस मालिक |

लिंक्ड सर्विस या `-s` के बिना, `metrics` प्रोजेक्ट में हर सर्विस का अवलोकन दिखाता है।

<span id="examples" />

## उदाहरण

<span id="view-metrics-for-the-current-service" />

### वर्तमान सर्विस के लिए मेट्रिक्स देखें

```bash
lizard metrics
```

<span id="view-metrics-for-a-specific-service" />

### एक विशिष्ट सर्विस के लिए मेट्रिक्स देखें

```bash
lizard metrics --service api
```

<span id="watch-metrics-live" />

### मेट्रिक्स को लाइव देखें

```bash
lizard metrics --watch
```

<span id="include-cost" />

### लागत शामिल करें

```bash
lizard metrics --cost
```
