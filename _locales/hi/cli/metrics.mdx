# lizard metrics

CPU / मेमोरी / नेटवर्क / डिस्क और लागत दिखाएँ।

<span id="usage" />

## उपयोग

```bash
lizard metrics [flags]
```

<span id="flags" />

## फ़्लैग्स

| फ़्लैग | विवरण |
|------|-------------|
| `-s, --service <id>` | सर्विस (डिफ़ॉल्ट रूप से लिंक की गई सर्विस) |
| `-p, --project <id>` | प्रोजेक्ट का नाम, स्लग या ID |
| `--all` | प्रोजेक्ट की सभी सर्विसेज़, लिंक की गई सर्विस को अनदेखा करते हुए; `-s` के साथ इस्तेमाल नहीं किया जा सकता |
| `-r, --range <range>` | टाइम विंडो: `1h` (डिफ़ॉल्ट), `6h`, `24h`, `7d`, `14d` या `30d` |
| `-w, --watch` | लाइव व्यू, हर 3 सेकंड में रीफ़्रेश होता है; `--json` के साथ इस्तेमाल नहीं किया जा सकता |
| `--cost` | चल रहे रिसोर्स, प्रति घंटा लागत, इस बिलिंग अवधि का उपयोग और इस महीने का Pro उपयोग। सिर्फ़ वर्कस्पेस के मालिक के लिए |

लिंक की गई सर्विस या `-s` के बिना `metrics` प्रोजेक्ट की हर सर्विस का ओवरव्यू दिखाता है।

<span id="examples" />

## उदाहरण

<span id="view-metrics-for-the-current-service" />

### मौजूदा सर्विस के मेट्रिक्स देखें

```bash
lizard metrics
```

<span id="view-metrics-for-a-specific-service" />

### किसी खास सर्विस के मेट्रिक्स देखें

```bash
lizard metrics --service api
```

<span id="watch-metrics-live" />

### मेट्रिक्स लाइव देखें

```bash
lizard metrics --watch
```

<span id="include-cost" />

### लागत भी दिखाएँ

```bash
lizard metrics --cost
```
