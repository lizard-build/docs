# lizard upgrade

CLI को लेटेस्ट वर्ज़न पर अपग्रेड करें।

<span id="usage" />

## उपयोग

```bash
lizard upgrade [flags]
```

अपग्रेड कैसे होता है, यह इस पर निर्भर करता है कि आपने CLI कैसे इंस्टॉल किया था:

- **macOS या Linux पर इंस्टॉल स्क्रिप्ट:** लेटेस्ट रिलीज़ डाउनलोड करती है और बाइनरी को बदल देती है।
- **npm:** आपके लिए `npm install -g @lizard-build/cli@<version>` चलाता है। अगर npm फ़ेल हो जाए, जैसे ग्लोबल फ़ोल्डर में लिखने की अनुमति न होने पर, तो CLI `npm install -g @lizard-build/cli@latest` प्रिंट करता है; इसे उन अनुमतियों के साथ चलाएँ जो npm को चाहिए।
- **Windows:** बाइनरी खुद को नहीं बदल सकती। इंस्टॉलर दोबारा चलाएँ: `irm https://lizard.build/api/cli/install.ps1 | iex`।

macOS और Linux पर इंस्टॉल स्क्रिप्ट से आई बाइनरी बैकग्राउंड में खुद को अपडेट भी करती है: सिर्फ़ इंटरैक्टिव टर्मिनल में, हर 6 घंटे में ज़्यादा से ज़्यादा एक बार, और `CI` या `LIZARD_NO_UPDATE` सेट होने पर कभी नहीं। इसके बाद अगली कमांड `lizard auto-updated: v<old> → v<new>` प्रिंट करती है। npm से इंस्टॉल किया गया CLI और Windows बाइनरी बैकग्राउंड में अपडेट नहीं होते।

<span id="flags" />

## फ्लैग्स

| फ्लैग | विवरण |
|------|-------------|
| `--check` | इंस्टॉल किए बिना नया वर्ज़न जाँचें |

`--json` के साथ `lizard upgrade --check` `{ currentVersion, latestVersion, updateAvailable }` लौटाता है।

<span id="examples" />

## उदाहरण

<span id="update-to-the-latest-version" />

### लेटेस्ट वर्ज़न पर अपडेट करें

```bash
lizard upgrade
```

<span id="check-for-updates-without-installing" />

### इंस्टॉल किए बिना अपडेट जाँचें

```bash
lizard upgrade --check
```
