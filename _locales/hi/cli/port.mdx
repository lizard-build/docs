# lizard port

किसी सर्विस का कंटेनर पोर्ट दिखाएँ या बदलें। बिना आर्गुमेंट के चलाने पर मौजूदा पोर्ट प्रिंट होता है (पोर्ट `0` होने पर `worker mode`)। नया पोर्ट अगले डिप्लॉय पर लागू होता है; उसे लागू करने के लिए [`lizard redeploy`](/cli/redeploy) चलाएँ।

<span id="usage" />

## उपयोग

```bash
lizard port [value] [flags]
```

<span id="flags" />

## फ़्लैग्स

| फ़्लैग | विवरण |
|------|-------------|
| `-s, --service <name>` | कौन-सी सर्विस |
| `-p, --project <id>` | प्रोजेक्ट का नाम, स्लग या ID |

<span id="examples" />

## उदाहरण

<span id="show-the-current-port" />

### मौजूदा पोर्ट दिखाएँ

```bash
lizard port
```

<span id="set-the-port-for-a-specific-service" />

### किसी खास सर्विस का पोर्ट सेट करें

```bash
lizard port 0 -s worker
```

<span id="check-the-port-on-a-worker-service" />

### वर्कर सर्विस का पोर्ट जाँचें

```bash
lizard port --service worker
```
