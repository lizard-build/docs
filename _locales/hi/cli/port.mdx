# lizard port

किसी सेवा के लिए कंटेनर पोर्ट दिखाएं या बदलें। कोई आर्गुमेंट वर्तमान पोर्ट प्रिंट करता है (जब यह `0` हो तो `worker mode`)। नया पोर्ट अगले डिप्लॉय पर प्रभावी होता है; इसे लागू करने के लिए [`lizard redeploy`](/cli/redeploy) चलाएं।

<span id="usage" />

## उपयोग

```bash
lizard port [value] [flags]
```

<span id="flags" />

## फ्लैग्स

| फ्लैग | विवरण |
|------|-------------|
| `-s, --service <name>` | लक्षित सेवा |
| `-p, --project <id>` | प्रोजेक्ट का नाम, स्लग, या आईडी |

<span id="examples" />

## उदाहरण

<span id="show-the-current-port" />

### वर्तमान पोर्ट दिखाएं

```bash
lizard port
```

<span id="set-the-port-for-a-specific-service" />

### किसी विशिष्ट सेवा के लिए पोर्ट सेट करें

```bash
lizard port 0 -s worker
```

<span id="check-the-port-on-a-worker-service" />

### वर्कर सेवा पर पोर्ट जांचें

```bash
lizard port --service worker
```
