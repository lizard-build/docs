# lizard ps

स्थिति और URL के साथ प्रोजेक्ट में सभी सेवाओं को सूचीबद्ध करें।

<span id="usage" />

## उपयोग

```bash
lizard ps [flags]
```

<span id="flags" />

## फ्लैग्स

| फ्लैग | विवरण |
|------|-------------|
| `-p, --project <id>` | प्रोजेक्ट का नाम, स्लग, या आईडी |

`-p` के बिना, `ps` लिंक किए गए प्रोजेक्ट का उपयोग करता है, या अनलिंक किए गए फ़ोल्डर में आपका डिफ़ॉल्ट प्रोजेक्ट।

<span id="examples" />

## उदाहरण

<span id="list-services-in-the-linked-project" />

### लिंक किए गए प्रोजेक्ट में सेवाएं सूचीबद्ध करें

```bash
lizard ps
```

<span id="list-services-in-another-project" />

### दूसरे प्रोजेक्ट में सेवाएं सूचीबद्ध करें

```bash
lizard ps -p my-project
```
