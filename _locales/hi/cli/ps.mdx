# lizard ps

प्रोजेक्ट की सभी सर्विसेज़ को उनकी स्थिति और URL के साथ लिस्ट करें।

<span id="usage" />

## उपयोग

```bash
lizard ps [flags]
```

<span id="flags" />

## फ्लैग्स

| फ्लैग | विवरण |
|------|-------------|
| `-p, --project <id>` | प्रोजेक्ट का नाम, स्लग या ID |

`-p` के बिना `ps` लिंक किए गए प्रोजेक्ट का उपयोग करता है, और अनलिंक्ड फ़ोल्डर में आपके डिफ़ॉल्ट प्रोजेक्ट का।

<span id="examples" />

## उदाहरण

<span id="list-services-in-the-linked-project" />

### लिंक किए गए प्रोजेक्ट की सर्विसेज़ लिस्ट करें

```bash
lizard ps
```

<span id="list-services-in-another-project" />

### किसी दूसरे प्रोजेक्ट की सर्विसेज़ लिस्ट करें

```bash
lizard ps -p my-project
```
