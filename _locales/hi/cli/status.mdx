# lizard status

वर्तमान डायरेक्टरी के लिए लिंक किए गए वर्कस्पेस, प्रोजेक्ट और सेवा दिखाएं। इसके लिए साइन-इन की आवश्यकता नहीं है।

एक अनलिंक किए गए फ़ोल्डर में यह `Not linked` प्रिंट करता है। वहां कमांड आपके खाते के डिफ़ॉल्ट प्रोजेक्ट का उपयोग करते हैं, और `lizard up` फ़ोल्डर को उससे लिंक करता है।

<span id="usage" />

## उपयोग

```bash
lizard status
```

<span id="examples" />

## उदाहरण

<span id="check-the-current-directorys-link" />

### वर्तमान डायरेक्टरी के लिंक की जाँच करें

```bash
lizard status
```

<span id="read-the-link-from-a-script" />

### स्क्रिप्ट से लिंक पढ़ें

```bash
lizard status --json
```

एक लिंक किया गया फ़ोल्डर `cwd`, `linked: true`, `workspace`, `workspaceId`, `project`, `projectId`, `service` और `serviceId` देता है। एक अनलिंक किया गया फ़ोल्डर `{"cwd": "…", "linked": false}` देता है।
