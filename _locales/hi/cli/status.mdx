# lizard status

मौजूदा डायरेक्टरी से लिंक किया गया वर्कस्पेस, प्रोजेक्ट और सर्विस दिखाएँ। इसके लिए साइन-इन ज़रूरी नहीं है।

अनलिंक्ड फ़ोल्डर में यह `Not linked` प्रिंट करता है। वहाँ कमांड आपके अकाउंट के डिफ़ॉल्ट प्रोजेक्ट का उपयोग करती हैं, और `lizard up` फ़ोल्डर को उसी से लिंक कर देता है।

<span id="usage" />

## उपयोग

```bash
lizard status
```

<span id="examples" />

## उदाहरण

<span id="check-the-current-directorys-link" />

### मौजूदा डायरेक्टरी का लिंक जाँचें

```bash
lizard status
```

<span id="read-the-link-from-a-script" />

### स्क्रिप्ट से लिंक पढ़ें

```bash
lizard status --json
```

लिंक किया गया फ़ोल्डर `cwd`, `linked: true`, `workspace`, `workspaceId`, `project`, `projectId`, `service` और `serviceId` देता है। अनलिंक्ड फ़ोल्डर `{"cwd": "…", "linked": false}` देता है।
