# lizard git

अपने Lizard अकाउंट को GitHub से कनेक्ट करें, देखें कि किसी प्रोजेक्ट की सर्विसेज़ किन रिपॉज़िटरी से डिप्लॉय होती हैं, और किसी सर्विस को दूसरी ब्रांच पर स्विच करें। GitHub App कनेक्शन आपके Lizard अकाउंट से जुड़ा होता है, किसी एक प्रोजेक्ट से नहीं।

`lizard git` के बाकी सबकमांड Lizard Git का हिस्सा हैं, जिसके बारे में यह पेज नहीं है।

<span id="usage" />

## उपयोग

```bash
lizard git connect
lizard git status [flags]
lizard git checkout <service> <branch> [flags]
```

`-p` के बिना `status` और `checkout` लिंक किया गया प्रोजेक्ट इस्तेमाल करते हैं, और जो फ़ोल्डर लिंक नहीं है उसमें आपका डिफ़ॉल्ट प्रोजेक्ट।

<span id="subcommands" />

## सबकमांड

### `lizard git connect`

प्राइवेट रिपॉज़िटरी का एक्सेस पाने के लिए GitHub App कनेक्ट करें। कमांड ऐप इंस्टॉल करने के लिए GitHub खोलता है, आपके Enter दबाने का इंतज़ार करता है, फिर कनेक्शन जाँचता है। अगर ऐप पहले से कनेक्ट है, तो कमांड यही बता देता है। `--json` के साथ या टर्मिनल न होने पर यह इसके बजाय इंस्टॉल URL प्रिंट करता है: `{ installed: false, installUrl }`।

### `lizard git status`

दिखाएँ कि GitHub App कनेक्ट है या नहीं, और प्रोजेक्ट की हर सर्विस किस रिपॉज़िटरी और ब्रांच से डिप्लॉय होती है।

| फ़्लैग | विवरण |
|------|-------------|
| `-p, --project <id>` | प्रोजेक्ट का नाम, स्लग या ID |

### `lizard git checkout <service> <branch>`

सर्विस को दूसरी ब्रांच पर स्विच करें और रीडिप्लॉय करें।

| फ़्लैग | विवरण |
|------|-------------|
| `--detach` | लॉग स्ट्रीम न करें |
| `-p, --project <id>` | प्रोजेक्ट का नाम, स्लग या ID |

## उदाहरण

<span id="connect-the-github-app" />

### GitHub App कनेक्ट करें

```bash
lizard git connect
```

<span id="check-connection-and-repository-status" />

### कनेक्शन और रिपॉज़िटरी का स्टेटस जाँचें

```bash
lizard git status
```

<span id="switch-a-service-to-a-different-branch" />

### सर्विस को दूसरी ब्रांच पर स्विच करें

```bash
lizard git checkout api staging
```

<span id="switch-branches-without-streaming-logs" />

### लॉग स्ट्रीम किए बिना ब्रांच स्विच करें

```bash
lizard git checkout api staging --detach
```
