# lizard git

अपने Lizard खाते को GitHub से कनेक्ट करें, देखें कि किसी प्रोजेक्ट की सेवाएं किन रिपॉजिटरी से डिप्लॉय होती हैं, और किसी सेवा को किसी अन्य ब्रांच में स्विच करें। GitHub ऐप कनेक्शन आपके Lizard खाते से संबंधित है, न कि किसी एक प्रोजेक्ट से।

अन्य `lizard git` सबकमांड Lizard Git से संबंधित हैं, जिसे यह पृष्ठ कवर नहीं करता है।

<span id="usage" />

## उपयोग

```bash
lizard git connect
lizard git status [flags]
lizard git checkout <service> <branch> [flags]
```

`-p` के बिना, `status` और `checkout` लिंक किए गए प्रोजेक्ट का उपयोग करते हैं, या एक अनलिंक किए गए फ़ोल्डर में आपका डिफ़ॉल्ट प्रोजेक्ट।

<span id="subcommands" />

## सबकमांड

### `lizard git connect`

निजी रिपॉजिटरी तक पहुंचने के लिए GitHub ऐप कनेक्ट करें। कमांड ऐप को इंस्टॉल करने के लिए GitHub खोलता है, आपके Enter दबाने की प्रतीक्षा करता है, फिर कनेक्शन की जांच करता है। यदि ऐप पहले से कनेक्टेड है, तो यह ऐसा कहता है। `--json` के साथ या बिना टर्मिनल के, यह इसके बजाय इंस्टॉल URL प्रिंट करता है: `{ installed: false, installUrl }`।

### `lizard git status`

दिखाएं कि GitHub ऐप कनेक्टेड है या नहीं, और प्रोजेक्ट में प्रत्येक सेवा किस रिपॉजिटरी और ब्रांच से डिप्लॉय होती है।

| फ्लैग | विवरण |
|------|-------------|
| `-p, --project <id>` | प्रोजेक्ट का नाम, स्लग, या आईडी |

### `lizard git checkout <service> <branch>`

किसी सेवा को किसी भिन्न ब्रांच में स्विच करें और रीडिप्लॉय करें।

| फ्लैग | विवरण |
|------|-------------|
| `--detach` | लॉग स्ट्रीमिंग छोड़ें |
| `-p, --project <id>` | प्रोजेक्ट का नाम, स्लग, या आईडी |

## उदाहरण

<span id="connect-the-github-app" />

### GitHub ऐप कनेक्ट करें

```bash
lizard git connect
```

<span id="check-connection-and-repository-status" />

### कनेक्शन और रिपॉजिटरी स्थिति जांचें

```bash
lizard git status
```

<span id="switch-a-service-to-a-different-branch" />

### किसी सेवा को किसी भिन्न ब्रांच में स्विच करें

```bash
lizard git checkout api staging
```

<span id="switch-branches-without-streaming-logs" />

### लॉग स्ट्रीमिंग के बिना ब्रांच स्विच करें

```bash
lizard git checkout api staging --detach
```
