# lizard s3

एक [Managed Object Storage](/addons/storage) बकेट में ऑब्जेक्ट अपलोड और लिस्ट करें, और अस्थायी डाउनलोड लिंक प्रिंट करें।

<span id="usage" />

## उपयोग

```bash
lizard s3 upload <file> [flags]
lizard s3 list [flags]
lizard s3 url <key> [flags]
```

तीनों कमांड प्रोजेक्ट के एकमात्र S3 ऐडऑन और उसके `default` बकेट पर काम करते हैं जब तक कि आप `--addon` और `--bucket` पास नहीं करते। पहले `lizard add s3` के साथ ऐडऑन जोड़ें।

<span id="subcommands" />

## सबकमांड

### `lizard s3 upload <file>`

एक लोकल फ़ाइल अपलोड करें। बकेट पब्लिक होने पर की (key), ETag, साइज़ और URL प्रिंट करता है। `default` बकेट प्राइवेट है; डैशबोर्ड में S3 ब्राउज़र से बकेट को पब्लिक बनाएँ।

`upload` फ़ाइल को Lizard API के माध्यम से एक ही रिक्वेस्ट में भेजता है, 150 MB तक। बड़ी फ़ाइलों के लिए, ऐडऑन के क्रेडेंशियल्स के साथ S3 क्लाइंट का उपयोग करें; [Managed Object Storage](/addons/storage) देखें।

| फ्लैग | विवरण |
|------|-------------|
| `--addon <name>` | S3 ऐडऑन का नाम या ID (डिफ़ॉल्ट: प्रोजेक्ट का एकमात्र S3 ऐडऑन) |
| `--bucket <name>` | टारगेट बकेट (डिफ़ॉल्ट `default`) |
| `--key <key>` | ऑब्जेक्ट की (डिफ़ॉल्ट: फ़ाइल का नाम) |
| `--content-type <type>` | Content-Type हेडर (डिफ़ॉल्ट: फ़ाइल एक्सटेंशन से अनुमानित) |
| `-p, --project <id>` | प्रोजेक्ट का नाम, स्लग, या आईडी |

### `lizard s3 url <key>`

किसी ऑब्जेक्ट के लिए एक अस्थायी डाउनलोड लिंक प्रिंट करें। लिंक वाला कोई भी व्यक्ति ऑब्जेक्ट को तब तक डाउनलोड कर सकता है जब तक वह एक्सपायर न हो जाए, प्राइवेट बकेट से भी, बिना किसी क्रेडेंशियल के। `--json` के साथ यह `url`, `key`, `bucket`, `expiresIn` और `expiresAt` प्रिंट करता है।

| फ्लैग | विवरण |
|------|-------------|
| `--addon <name>` | S3 ऐडऑन का नाम या ID (डिफ़ॉल्ट: प्रोजेक्ट का एकमात्र S3 ऐडऑन) |
| `--bucket <name>` | बकेट (डिफ़ॉल्ट `default`) |
| `--expires <seconds>` | लिंक कितने समय तक काम करता है, सेकंड में (डिफ़ॉल्ट `3600`, अधिकतम `604800` = 7 दिन) |
| `-p, --project <id>` | प्रोजेक्ट का नाम, स्लग, या आईडी |

### `lizard s3 list`

बकेट में ऑब्जेक्ट लिस्ट करें (उपनाम `ls`)।

| फ्लैग | विवरण |
|------|-------------|
| `--addon <name>` | S3 ऐडऑन का नाम या ID |
| `--bucket <name>` | लिस्ट करने के लिए बकेट (डिफ़ॉल्ट `default`) |
| `--prefix <prefix>` | केवल इस प्रीफ़िक्स के अंतर्गत कीज़ |
| `-p, --project <id>` | प्रोजेक्ट का नाम, स्लग, या आईडी |

प्रत्येक अकाउंट अपने ऐडऑन में 16 GiB तक स्टोर कर सकता है। स्टोरेज को $0.0135 प्रति GB-माह की दर से स्टोर किए गए बाइट्स के अनुसार बिल किया जाता है।

<span id="examples" />

## उदाहरण

<span id="upload-a-file" />

### एक फ़ाइल अपलोड करें

```bash
lizard s3 upload ./logo.png --key assets/logo.png
```

<span id="share-a-private-file-for-a-day" />

### एक दिन के लिए प्राइवेट फ़ाइल शेयर करें

```bash
lizard s3 url assets/logo.png --expires 86400
```

<span id="list-objects-under-a-prefix" />

### एक प्रीफ़िक्स के तहत ऑब्जेक्ट लिस्ट करें

```bash
lizard s3 list --prefix assets/
```

<span id="use-a-second-s3-addon" />

### एक दूसरा S3 ऐडऑन उपयोग करें

```bash
lizard s3 upload ./backup.tar.gz --addon s3-autumn-bear
```
