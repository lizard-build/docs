# lizard whoami

वह खाता दिखाएँ जिसमें आप साइन इन हैं और, एक लिंक किए गए फ़ोल्डर में, लिंक किया गया प्रोजेक्ट और उसका वर्कस्पेस दिखाएँ।

<span id="usage" />

## उपयोग

```bash
lizard whoami
```

<span id="what-it-shows" />

## यह क्या दिखाता है

- एक खाते के रूप में साइन इन: आपका यूज़रनेम, क्या GitHub ऐप कनेक्टेड है, और ब्रैकेट में लिंक किया गया प्रोजेक्ट उसके वर्कस्पेस के साथ। एक अनलिंक्ड फ़ोल्डर में यह `Project: none` दिखाता है; वहाँ कमांड आपके खाते के डिफ़ॉल्ट प्रोजेक्ट का उपयोग करते हैं।
- एक स्कोप्ड API कुंजी के साथ साइन इन: `Scoped API key (account details are not visible)`, फिर प्रत्येक प्रोजेक्ट या वर्कस्पेस जिस तक कुंजी पहुँचती है। यह कभी भी कुंजी के पीछे का खाता नहीं दिखाता है।

`whoami` एक सक्रिय वर्कस्पेस नहीं दिखाता है। अपने वर्कस्पेस को सूचीबद्ध करने के लिए, [`lizard workspace list`](/cli/workspace) चलाएँ।

`--json` के साथ, या जब आउटपुट एक टर्मिनल नहीं है, तो यह आपके खाते के फ़ील्ड के साथ `project` प्रिंट करता है। एक स्कोप्ड कुंजी के लिए यह `{ "scoped": true, "scopes": [...], "project": ... }` प्रिंट करता है।
