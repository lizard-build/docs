# lizard whoami

वह अकाउंट दिखाएँ जिससे आप साइन इन हैं, और लिंक किए गए फ़ोल्डर में लिंक किया गया प्रोजेक्ट और उसका वर्कस्पेस भी।

<span id="usage" />

## उपयोग

```bash
lizard whoami
```

<span id="what-it-shows" />

## यह क्या दिखाता है

- अकाउंट से साइन इन होने पर: आपका यूज़रनेम, GitHub App कनेक्ट है या नहीं, और लिंक किया गया प्रोजेक्ट, ब्रैकेट में उसके वर्कस्पेस के साथ। अनलिंक्ड फ़ोल्डर में यह `Project: none` दिखाता है; वहाँ कमांड आपके अकाउंट के डिफ़ॉल्ट प्रोजेक्ट का उपयोग करती हैं।
- स्कोप्ड API की से साइन इन होने पर: `Scoped API key (account details are not visible)`, फिर हर वह प्रोजेक्ट या वर्कस्पेस जिस तक की पहुँचती है। यह कभी नहीं दिखाता कि की किस अकाउंट की है।

`whoami` कोई एक्टिव वर्कस्पेस नहीं दिखाता। अपने वर्कस्पेस लिस्ट करने के लिए [`lizard workspace list`](/cli/workspace) चलाएँ।

`--json` के साथ, या जब आउटपुट टर्मिनल पर न जा रहा हो, यह आपके अकाउंट के फ़ील्ड और `project` प्रिंट करता है। स्कोप्ड की के लिए यह `{ "scoped": true, "scopes": [...], "project": ... }` प्रिंट करता है।
