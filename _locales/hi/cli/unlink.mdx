# lizard unlink

मौजूदा डायरेक्टरी को उसके प्रोजेक्ट से अलग करें। प्रोजेक्ट में खुद कोई बदलाव नहीं होता। इसके बाद इस फ़ोल्डर में कमांड आपके अकाउंट के डिफ़ॉल्ट प्रोजेक्ट का उपयोग करती हैं, और `lizard up` फ़ोल्डर को फिर से उसी से लिंक कर देता है।

<span id="usage" />

## उपयोग

```bash
lizard unlink
```
