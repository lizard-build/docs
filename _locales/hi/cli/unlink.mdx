# lizard unlink

वर्तमान डायरेक्टरी को किसी भी प्रोजेक्ट से अलग करें। प्रोजेक्ट स्वयं नहीं बदलता है। उसके बाद, इस फ़ोल्डर में कमांड आपके खाते के डिफ़ॉल्ट प्रोजेक्ट का उपयोग करते हैं, और `lizard up` फ़ोल्डर को उससे फिर से लिंक करता है।

<span id="usage" />

## उपयोग

```bash
lizard unlink
```
