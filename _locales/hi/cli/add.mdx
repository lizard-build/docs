# lizard add

प्रोजेक्ट में डेटाबेस, सर्विस या रेपो जोड़ें।

<span id="usage" />

## उपयोग

```bash
lizard add [types...] [flags]
```

`add` वर्तमान डायरेक्टरी से लिंक किए गए प्रोजेक्ट पर काम करता है; एक अनलिंक्ड फ़ोल्डर में यह आपके खाते के डिफ़ॉल्ट प्रोजेक्ट का उपयोग करता है। `add` में कोई `--project` फ्लैग नहीं है: दूसरे प्रोजेक्ट में जोड़ने के लिए, पहले फ़ोल्डर को [`lizard link --project <name>`](/cli/link) या [`lizard init`](/cli/init) के साथ लिंक करें।

<span id="flags" />

## फ्लैग्स

| फ्लैग | विवरण |
|------|-------------|
| `-r, --repo <owner/repo>` | GitHub रेपो से सर्विस बनाएं |
| `-s, --service <name>` | एक खाली सर्विस बनाएं |
| `-a, --addon <type...>` | प्रबंधित एडऑन जोड़ें (`postgres` / `redis` / `s3`) |
| `-n, --name <name>` | `${{name.KEY}}` संदर्भों में प्रयुक्त नाम |
| `-v, --variables <K=V>` | एक env var को सीड करें (दोहराया जा सकता है) |
| `--region <code>` | प्रोविज़न करने के लिए क्षेत्र (डिफ़ॉल्ट `us-east-1`) |
| `--no-deploy` | रेपो अटैच करें लेकिन पहली बिल्ड छोड़ दें |
| `--list` | उपलब्ध डेटाबेस प्रकार दिखाएं |

<span id="examples" />

## उदाहरण

<span id="create-a-service-from-a-github-repo" />

### GitHub रेपो से सर्विस बनाएं

```bash
lizard add -r your-org/your-app
```

यह एक `github`-स्रोत सर्विस बनाता है और पहली बिल्ड शुरू करता है, जो रेपो को क्लोन करता है और स्टैक का स्वतः पता लगाता है। कमांड सर्विस के मौजूद होने पर वापस आ जाता है; `lizard logs --build` के साथ बिल्ड का पालन करें।

<span id="provision-addons" />

### एडऑन प्रोविज़न करें

```bash
lizard add postgres            # one addon
lizard add postgres redis s3   # several at once
lizard add --list              # show available types
```

<span id="create-an-empty-service" />

### एक खाली सर्विस बनाएं

```bash
lizard add -s worker
```

<span id="name-a-service-and-seed-variables" />

### एक सर्विस का नाम दें और वेरिएबल्स को सीड करें

```bash
lizard add -r your-org/monorepo -n api -v NODE_ENV=production -v LOG_LEVEL=info
```
