# lizard config

प्रोजेक्ट पर `lizard-config.json` फ़ाइल लागू करें।

<span id="usage" />

## उपयोग

```bash
lizard config apply [flags]
```

<span id="subcommands" />

## सबकमांड

### `lizard config apply`

प्रोजेक्ट पर `lizard-config.json` फ़ाइल लागू करें।

| फ़्लैग | विवरण |
|------|-------------|
| `-f, --file <path>` | कॉन्फ़िग फ़ाइल (डिफ़ॉल्ट `lizard-config.json`) |
| `-p, --project <id>` | प्रोजेक्ट का नाम, स्लग या ID |
| `--dry-run` | पार्स की गई फ़ाइल और टारगेट प्रोजेक्ट प्रिंट करें, लागू किए बिना। यह मौजूदा कॉन्फ़िग से तुलना नहीं करता |

<span id="examples" />

## उदाहरण

<span id="apply-the-default-config-file" />

### डिफ़ॉल्ट कॉन्फ़िग फ़ाइल लागू करें

```bash
lizard config apply
```

<span id="apply-a-config-file-from-a-custom-path" />

### कस्टम पाथ से कॉन्फ़िग फ़ाइल लागू करें

```bash
lizard config apply -f ./configs/prod.json
```

<span id="preview-changes-without-applying-them" />

### बदलाव लागू किए बिना उन्हें पहले देखें

```bash
lizard config apply --dry-run
```
