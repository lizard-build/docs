# ऐप क्विकस्टार्ट

यह क्विकस्टार्ट कुछ ही मिनटों में Lizard पर एक ऐप डिप्लॉय करता है। Lizard CLI इंस्टॉल करें: इंस्टॉलर आपका साइन-इन करवाता है और 7-दिन का Pro ट्रायल ऑफ़र करता है। फिर GitHub रिपॉज़िटरी के लिए `lizard add -r owner/repo` या लोकल फ़ोल्डर के लिए `lizard up` चलाएँ। Lizard ऐप को अपने सर्वर पर बिल्ड करता है, लोकल Docker की ज़रूरत नहीं होती, और उसे `onlizard.com` पर एक HTTPS URL देता है। पहली बार साइन इन करने पर Lizard आपका अकाउंट बना देता है।

<span id="1-install-the-cli" />

## 1. CLI इंस्टॉल करें

macOS या Linux पर इंस्टॉल स्क्रिप्ट चलाएँ:

```bash
curl -fsSL https://lizard.build/install.sh | bash
```

यह `lizard` बाइनरी को `~/.lizard/bin` में रखती है, `~/.zshrc` या `~/.bashrc` में उस फ़ोल्डर को आपके `PATH` में जोड़ती है, और `lizard` को ऐसे फ़ोल्डर में लिंक करती है जो पहले से आपके `PATH` में है, इसलिए यह इसी टर्मिनल में तुरंत काम करने लगता है। इसके बाद बाइनरी अपने-आप अपडेट होती रहती है (CI को छोड़कर)। अगर स्क्रिप्ट बताए कि `lizard` शायद न मिले, तो नया टर्मिनल खोलें। वर्ज़न जाँचें:

```bash
lizard --version
```

Windows पर PowerShell में यह चलाएँ:

```powershell
irm https://lizard.build/api/cli/install.ps1 | iex
```

दोनों इंस्टॉल स्क्रिप्ट आख़िर में [`lizard login`](/cli/login) चलाती हैं, जो आपके लिए चरण 2 और 3 पूरे कर देता है: यह आपका साइन-इन करवाता है और Pro ट्रायल ऑफ़र करता है। इसे छोड़ने के लिए `LIZARD_NO_LOGIN=1` सेट करें; CI में स्क्रिप्ट इसे अपने-आप छोड़ देती हैं।

**या npm से इंस्टॉल करें** (Node.js 20 या उसके बाद का वर्ज़न ज़रूरी है)। npm से इंस्टॉल करने पर साइन-इन नहीं होता, इसलिए चरण 2 पर आगे बढ़ें:

```bash
npm install -g @lizard-build/cli
```

> **`npx` का उपयोग न करें।** हमेशा ग्लोबली इंस्टॉल की गई `lizard` बाइनरी का उपयोग करें। `npx @lizard-build/cli` चलाने से एक अस्थायी कॉपी डाउनलोड होती है, जिसका वर्ज़न प्लेटफ़ॉर्म से अलग हो सकता है। बाद में npm इंस्टॉल को अपग्रेड करने के लिए `npm install -g @lizard-build/cli@latest` चलाएँ।

> **अनुमति की त्रुटि (EACCES)?** `sudo` का इस्तेमाल न करें। ऊपर दी गई इंस्टॉल स्क्रिप्ट चलाएँ, जिसे admin अधिकारों की ज़रूरत नहीं होती, या npm के लिए ऐसा prefix सेट करें जो आपके यूज़र का हो:
> ```bash
> mkdir -p ~/.npm-global
> npm config set prefix ~/.npm-global
> echo 'export PATH=~/.npm-global/bin:$PATH' >> ~/.zshrc && source ~/.zshrc
> npm install -g @lizard-build/cli
> ```

<span id="2-log-in" />

## 2. लॉग इन करें

अगर इंस्टॉल स्क्रिप्ट ने आपका साइन-इन करवा दिया है, तो यह चरण छोड़ दें। नहीं तो चलाएँ:

```bash
lizard login
```

यह पूछता है कि आप GitHub से साइन इन करेंगे या Google से, ब्राउज़र में वह पेज खोलता है और तब तक इंतज़ार करता है जब तक आप मंज़ूरी नहीं देते। अगर आपका अकाउंट पहले से है, तो वही तरीका चुनें जिससे आपने साइन अप किया था: दूसरा तरीका एक दूसरा, खाली अकाउंट खोल देता है, जब तक कि दोनों में एक ही वेरिफ़ाइड ईमेल न हो। `--github` या `--google` देने पर यह सवाल नहीं पूछा जाता। जिस मशीन पर पहले से साइन इन है, वहाँ `lizard login` इसके बजाय मौजूदा अकाउंट दिखाता है, इसलिए इसे दोबारा चलाना सुरक्षित है।

आप `lizard login` को छोड़ भी सकते हैं: टर्मिनल में चलाया गया कोई भी कमांड पहले इसी तरह साइन इन करवाता है, फिर आगे बढ़ता है।

CI या दूसरे नॉन-इंटरैक्टिव एनवायरनमेंट में इसके बजाय टोकन से ऑथेंटिकेट करें:

```bash
export LIZARD_TOKEN=liz_xxx
# or
lizard login --token liz_xxx
```

API की `liz_` से शुरू होती हैं। `lizard keys create <name>` से नई की बनाएँ। `LIZARD_TOKEN` की जगह `LIZARD_API_KEY` भी काम करता है। `lizard login --token-stdin` की को पाइप से पढ़ता है, जिससे वह आपकी शेल हिस्ट्री में नहीं जाती।

आप किस अकाउंट से साइन इन हैं, यह कभी भी जाँचें:

```bash
lizard whoami
```

<span id="3-start-the-pro-trial" />

## 3. Pro ट्रायल शुरू करें

नए अकाउंट पर कोई प्लान नहीं होता, और डिप्लॉय के लिए प्लान ज़रूरी है। साइन इन होने के बाद `lizard login` 7-दिन का Pro ट्रायल ऑफ़र करता है। हाँ कहें, तो यह Stripe Checkout खोलता है, जहाँ आप एक कार्ड जोड़ते हैं। ट्रायल में $5 का उपयोग शामिल है, और ट्रायल ख़त्म होने तक कोई चार्ज नहीं लगता। जिस अकाउंट का ट्रायल पहले हो चुका है, उसे इसके बजाय $19 प्रति माह पर Pro ऑफ़र किया जाता है।

अगर आपने मना कर दिया था, तो इसे बाद में शुरू करें:

```bash
lizard billing start
```

जब तक कोई प्लान शुरू नहीं होता, कुछ भी बनाने की कोशिश पर HTTP 402 के साथ एक Checkout लिंक लौटता है। [बिलिंग](/platform/billing) और [`lizard billing`](/cli/billing) देखें।

<span id="4-deploy" />

## 4. डिप्लॉय करें

वह तरीका चुनें जो इस पर निर्भर हो कि आपका कोड कहाँ है।

<span id="option-a--deploy-a-github-repo-recommended" />

### विकल्प A — GitHub रिपॉज़िटरी से डिप्लॉय करें (सुझाया गया)

अगर आपका कोड GitHub पर है, तो सीधे रिपॉज़िटरी से सर्विस बनाएँ। Lizard उसे क्लोन करता है, स्टैक पहचानता है और पहला बिल्ड शुरू करता है:

```bash
lizard add -r your-org/your-app
```

सर्विस बनते ही कमांड लौट आता है; बिल्ड चलता रहता है। [चरण 5](#5-watch-it-build-and-run) में देखें कि बिल्ड को कैसे फ़ॉलो करें और URL कहाँ मिलेगा।

प्राइवेट रिपॉज़िटरी के लिए, और ट्रैक की गई ब्रांच पर पुश होने पर ऐप को रीडिप्लॉय करवाने के लिए, पहले [`lizard git`](/cli/git) से Lizard GitHub App कनेक्ट करें:

```bash
lizard git connect
```

<span id="option-b--deploy-local-code" />

### विकल्प B — लोकल कोड डिप्लॉय करें

अपनी प्रोजेक्ट डायरेक्टरी के अंदर से मौजूदा फ़ोल्डर को अपलोड और डिप्लॉय करें (`.gitignore` को ध्यान में रखा जाता है):

```bash
lizard up
```

पहली बार यह सर्विस का नाम पूछता है; डिफ़ॉल्ट रूप से फ़ोल्डर का नाम लिया जाता है। फिर यह बिल्ड को फ़ॉलो करता है और ऐप लाइव होते ही `https://your-app-x1y2z.onlizard.com` जैसा URL प्रिंट करता है।

अगर फ़ोल्डर अभी किसी प्रोजेक्ट से लिंक नहीं है, तो `lizard add` और `lizard up` आपके डिफ़ॉल्ट प्रोजेक्ट का उपयोग करते हैं और यह बताते भी हैं। डिफ़ॉल्ट प्रोजेक्ट आपके पर्सनल वर्कस्पेस का सबसे पुराना प्रोजेक्ट है; नए अकाउंट में यह साइन-अप के समय ही बन जाता है। `lizard up` फ़ोल्डर को इससे लिंक भी कर देता है, इसलिए अगला `lizard up` उसी सर्विस को अपडेट करता है। किसी दूसरे प्रोजेक्ट में डिप्लॉय करने के लिए पहले `lizard init --name my-project` चलाएँ। CI में भी ऐसा ही करें, ताकि डिप्लॉय वहीं हो जहाँ आप उम्मीद करते हैं।

Lizard ज़्यादातर स्टैक अपने-आप पहचान लेता है। अपने फ्रेमवर्क का सटीक बिल्ड कमांड, स्टार्ट कमांड और पोर्ट जानने के लिए [Next.js](/framework-guides/nextjs), [React](/framework-guides/react), [Vue](/framework-guides/vue), [Astro](/framework-guides/astro), [SvelteKit](/framework-guides/sveltekit), [Node.js](/framework-guides/nodejs), [Django](/framework-guides/django), [FastAPI](/framework-guides/fastapi), [Rails](/framework-guides/rails) या [Go](/framework-guides/go) की गाइड देखें। जिस ऐप का अपना Dockerfile है, उसके लिए [Dockerfile के साथ डिप्लॉय करें](/deploy/dockerfile) देखें।

<span id="5-watch-it-build-and-run" />

## 5. बिल्ड और रन होते हुए देखें

```bash
lizard ps               # services in the project, with status + URL
lizard logs             # stream runtime logs (Ctrl+C to stop)
lizard logs --tail 100  # print the last 100 lines and exit
lizard logs --build     # the most recent build's logs
lizard open             # open the project in the dashboard
```

[`lizard open`](/cli/open) वही प्रोजेक्ट [डैशबोर्ड](/dashboard) में दिखाता है। मेट्रिक्स, लागत और डिप्लॉय हिस्ट्री के लिए [ऑब्ज़र्वेबिलिटी](/observability) देखें।

<span id="6-add-a-database-optional" />

## 6. डेटाबेस जोड़ें (वैकल्पिक)

Managed Postgres प्रोविज़न करें। अगले डिप्लॉय पर प्रोजेक्ट की हर सर्विस को उसका पब्लिक `DATABASE_URL` मिल जाता है; इसके बजाय प्राइवेट नेटवर्क से कनेक्ट करने के लिए अपनी सर्विस में उसका रेफ़रेंस दें:

```bash
lizard add postgres
lizard secrets set DATABASE_URL='${{postgres.DATABASE_PRIVATE_URL}}' --service your-app
lizard redeploy --service your-app
```

Lizard डिप्लॉय के समय `${{postgres.DATABASE_PRIVATE_URL}}` को resolve करता है, ताकि सर्विस प्रोजेक्ट के प्राइवेट नेटवर्क से कनेक्ट हो। रेफ़रेंस ऐडऑन के मौजूदा नाम से जुड़ा होता है, इसलिए ऐडऑन का नाम बदलने पर रेफ़रेंस भी अपडेट करें। क्रेडेंशियल्स अपने-आप रोटेट नहीं होते; नई वैल्यू सर्विस को अगले डिप्लॉय पर मिलती हैं। [Managed Addons](/addons) देखें।

## होस्टिंग की लागत

Pro की कीमत $19 प्रति माह है, जिसमें हर महीने $19 के क्रेडिट शामिल हैं। इससे ज़्यादा उपयोग का बिल प्रकाशित दरों पर pay as you go आधार पर लगता है। Pro की शुरुआत 7-दिन के ट्रायल और $5 के ट्रायल क्रेडिट से होती है; ट्रायल शुरू करने के लिए आप एक कार्ड जोड़ते हैं। [बिलिंग](/platform/billing) और [प्राइसिंग](https://lizard.build/pricing) देखें, और डिप्लॉय करने से पहले अपनी [सीमाएँ](/platform/limits) जाँच लें।
