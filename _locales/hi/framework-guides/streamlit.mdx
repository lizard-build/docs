# एक Streamlit ऐप परिनियोजित करें

Lizard आपके द्वारा स्थानीय रूप से उपयोग किए जाने वाले कमांड, `streamlit run app.py` के साथ एक Streamlit ऐप चलाता है। इसे `--server.address 0.0.0.0` और `8501` जैसे एक निश्चित पोर्ट के साथ एक Procfile `web:` लाइन में रखें, फिर `lizard up --port 8501` के साथ परिनियोजित करें। Procfile के बिना, lizardpack `python app.py` शुरू करता है, जो ऐप परोसने के बजाय एक चेतावनी प्रिंट करता है और बाहर निकल जाता है।

**स्थिति का परीक्षण करें:** नीचे दिए गए नमूने को स्थानीय रूप से Streamlit 1.65.0, और PostgreSQL 14. के विरुद्ध psycopg 3.3.5 के साथ डेटाबेस संस्करण के साथ चलाया गया था। हमने lizardpack के साथ इसकी बिल्ड योजना की जाँच की, बिल्ड प्लानर Lizard चलता है। हमने अभी तक इसे एंड-टू-एंड परिनियोजित नहीं किया है। ब्राउज़र Streamlit के लिए एक WebSocket खुला रखता है, और हमने अभी तक Lizard की रूटिंग के माध्यम से उस कनेक्शन की जाँच नहीं की है।

<span id="before-you-start" />

## शुरू करने से पहले

- ऐप का परीक्षण करने के लिए अपने कंप्यूटर पर पायथन 3।
- Lizard CLI, `lizard login` के साथ साइन इन, Pro या 7-दिन Pro ट्रायल (कार्ड आवश्यक) पर। [मूल्य निर्धारण](https://lizard.build/pricing) देखें।

<span id="a-minimal-app" />

## एक न्यूनतम ऐप

`app.py`:

```python
import streamlit as st

st.title("Hello from Streamlit on Lizard")
name = st.text_input("Your name", "world")
st.write(f"Hello, {name}!")
```

`requirements.txt`:

```text
streamlit==1.65.0
```

`.python-version`:

```text
3.13
```

`Procfile`:

```text
web: streamlit run app.py --server.port 8501 --server.address 0.0.0.0
```

इसे स्थानीय रूप से चलाएँ:

```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

Streamlit `http://localhost:8501` पर खुलता है। `.gitignore` में `.venv/`, `.env` और `.streamlit/secrets.toml` जोड़ें।

<span id="what-lizardpack-builds" />

## lizardpack क्या बनाता है

| चरण | क्या होता है |
|---|---|
| पहचान | `requirements.txt`, `pyproject.toml`, `Pipfile` या कोई भी `.py` फ़ाइल |
| पायथन संस्करण | `.python-version`, फिर `.tool-versions`, फिर `pyproject.toml` में `requires-python`; केवल प्रमुख और लघु, `python:<x.y>-slim` पर। डिफ़ॉल्ट `3.13`। |
| स्थापित करें | `pip install -r requirements.txt`; uv, Poetry या Pipenv जब उनकी लॉक या कॉन्फ़िगरेशन फ़ाइल मौजूद हो |
| प्रारंभ करें | Procfile `web:` लाइन |
| रनटाइम | `PYTHONUNBUFFERED=1`, ताकि `print` आउटपुट तुरंत लॉग तक पहुँचे |

सेवा पोर्ट को `--server.port` से मिलान करने के लिए `--port` के साथ सेट करें। नियम और उनके एज केस के लिए [रनटाइम संस्करण](/deploy/runtime-versions) देखें।

<span id="deploy" />

## डिप्लॉय

ऐप के फ़ोल्डर से:

```bash
lizard init --name streamlit-app
lizard add --service web
lizard up --service web --port 8501
```

`lizard up` फ़ोल्डर को अपलोड करता है, Lizard पर बनाता है और URL प्रिंट करता है। गिट रिपॉजिटरी के अंदर यह `.gitignore` द्वारा सूचीबद्ध को छोड़ देता है; गिट के बाहर यह `.env` फ़ाइलों को अपलोड करता है। git push to deploy के लिए, [एक GitHub रिपॉजिटरी कनेक्ट करें](/deploy/github) और `lizard port 8501 --service web` के साथ पोर्ट सेट करें।

<span id="secrets-and-settings" />

## सीक्रेट्स और सेटिंग्स

`st.secrets`, `.streamlit/secrets.toml` को पढ़ता है, एक फ़ाइल जिसे आपको अपलोड नहीं करना चाहिए। Lizard पर, सीक्रेट्स को सर्विस वेरिएबल्स के रूप में स्टोर करें और उन्हें एनवायरनमेंट से पढ़ें:

```bash
lizard secrets set OPENAI_API_KEY=sk-... --service web
```

```python
import os

api_key = os.environ["OPENAI_API_KEY"]
```

एक वेरिएबल परिवर्तन ऐप को बिना रीबिल्ड के रीस्टार्ट करता है। [वेरिएबल्स और सीक्रेट्स](/variables) देखें।

<span id="add-managed-postgres" />

## Managed Postgres जोड़ें

```bash
lizard add postgres
lizard secrets set DATABASE_URL='${{postgres.DATABASE_PRIVATE_URL}}' --service web
```

सिंगल कोट्स `${{…}}` को आपके शेल से दूर रखते हैं; Lizard डिप्लॉय टाइम पर [रेफरेंस](/variables/references) को रिजॉल्व करता है। `psycopg[binary]==3.3.5` को `requirements.txt` में जोड़ें और प्रति सर्वर प्रोसेस एक कनेक्शन खोलें:

```python
import os

import psycopg
import streamlit as st


@st.cache_resource
def get_conn():
    return psycopg.connect(os.environ["DATABASE_URL"], autocommit=True)


with get_conn().cursor() as cur:
    cur.execute("SELECT now()")
    st.write("Database time:", cur.fetchone()[0])
```

`st.cache_resource` कनेक्शन को रीरन और ब्राउज़र सेशन में बनाए रखता है। डेटा को [Managed Postgres](/addons/postgres) या [Managed Object Storage](/addons/storage) में रखें: कंटेनर के अंदर ऐप द्वारा लिखी गई फ़ाइलें अगले डिप्लॉय पर खो जाती हैं।

<span id="check-that-it-works" />

## जांचें कि यह काम करता है

```bash
lizard logs --service web --tail 100
lizard domain --service web
curl https://<your-domain>/_stcore/health
```

लॉग `You can now view your Streamlit app in your browser` दिखाता है, और हेल्थ URL `ok` का जवाब देता है। ऐप के URL को खोलें और टेक्स्ट बॉक्स बदलें: ग्रीटिंग अपडेट होना चाहिए।

<span id="common-problems" />

## सामान्य समस्याएं

| लक्षण | समाधान |
|---|---|
| लॉग कहता है `to view this Streamlit app on a browser, run it with the following command` | Procfile गायब है या उसमें `web:` लाइन नहीं है, इसलिए lizardpack ने `python app.py` चलाया। |
| डिप्लॉय कभी हेल्दी नहीं होता | सर्विस पोर्ट और `--server.port` अलग हैं। `lizard port --service web` चलाएं। [सर्विस कभी हेल्दी नहीं](/deploy/troubleshooting/service-never-healthy) देखें। |
| `ModuleNotFoundError` | पैकेज को `requirements.txt` में जोड़ें और फिर से डिप्लॉय करें। |
| सीक्रेट के लिए `KeyError` | वेरिएबल `web` सर्विस पर गायब है: `lizard secrets list --service web`। |
| पेज एक कनेक्टिंग मैसेज दिखाता है और कभी लोड नहीं होता | ब्राउज़र `/_stcore/stream` पर अपना WebSocket नहीं रख सकता। ब्राउज़र कंसोल में उस विफल रिक्वेस्ट को देखें, और `lizard logs` में एरर के लिए देखें। |
