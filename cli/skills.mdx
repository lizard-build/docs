# lizard skills

Read the embedded agent skills shipped with this CLI version. Alias: `lizard skill`.

## Usage

```bash
lizard skills list
lizard skills get core
lizard skills path
```

## Subcommands

### `lizard skills list`

List the available embedded skills.

### `lizard skills get core`

Read the core guide — the authoritative usage guide for the platform, versioned with the CLI. With `--json` it returns `{ name, path, frontmatter, content }`, where `content` is the complete guide (build pipeline, env precedence, addons, discovery, exit codes).

### `lizard skills path [name]`

Print where a skill comes from. Skills are built into the CLI, so this prints `embedded://skills` unless `LIZARD_SKILLS_DIR` points the CLI at a directory on disk.

## Examples

### Load the core guide as an agent

```bash
lizard skills get core --json
```

### List available embedded skills

```bash
lizard skills list
```
