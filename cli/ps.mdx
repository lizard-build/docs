# lizard ps

List all services in the project with status and URL.

## Usage

```bash
lizard ps [flags]
```

## Flags

| Flag | Description |
|------|-------------|
| `-p, --project <id>` | Project name, slug, or ID |

Without `-p`, `ps` uses the linked project, or your default project in an unlinked folder.

## Examples

### List services in the linked project

```bash
lizard ps
```

### List services in another project

```bash
lizard ps -p my-project
```
