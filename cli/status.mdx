# lizard status

Show the linked workspace, project, and service for the current directory.

## Usage

```bash
lizard status
```

## Examples

### Check the current directory's link

```bash
lizard status
```

## See also

- [lizard init](/cli/init) — create or select a project and link it to the current directory
- [lizard link](/cli/link) — associate the current directory with an existing project
- [lizard whoami](/cli/whoami) — show the current user, active workspace, and linked project
