# lizard status

Show the linked workspace, project, and service for the current directory. It needs no sign-in.

In an unlinked folder it prints `Not linked`. Commands there use your account's default project, and `lizard up` links the folder to it.

## Usage

```bash
lizard status
```

## Examples

### Check the current directory's link

```bash
lizard status
```

### Read the link from a script

```bash
lizard status --json
```

A linked folder gives `cwd`, `linked: true`, `workspace`, `workspaceId`, `project`, `projectId`, `service` and `serviceId`. An unlinked one gives `{"cwd": "…", "linked": false}`.
