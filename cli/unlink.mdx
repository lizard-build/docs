# lizard unlink

Disassociate the current directory from any project. The project itself does not change. After that, commands in this folder use your account's default project, and `lizard up` links the folder to it again.

## Usage

```bash
lizard unlink
```

## Examples

### Unlink the current directory

```bash
lizard unlink
```
