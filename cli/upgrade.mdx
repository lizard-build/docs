# lizard upgrade

Upgrade the CLI to the latest version.

## Usage

```bash
lizard upgrade [flags]
```

How it upgrades depends on how you installed the CLI:

- **Install script on macOS or Linux:** downloads the latest release and replaces the binary.
- **npm:** runs `npm install -g @lizard-build/cli@<version>` for you. If npm fails, for example because it lacks write access to the global folder, the CLI prints `npm install -g @lizard-build/cli@latest` for you to run with the rights npm needs.
- **Windows:** the binary can't replace itself. Run the installer again: `irm https://lizard.build/api/cli/install.ps1 | iex`.

The binary from the install script on macOS and Linux also updates itself in the background: only in an interactive terminal, at most once every 6 hours, and never when `CI` or `LIZARD_NO_UPDATE` is set. The next command then prints `lizard auto-updated: v<old> → v<new>`. npm installs and the Windows binary do not update in the background.

## Flags

| Flag | Description |
|------|-------------|
| `--check` | Check for a newer version without installing |

With `--json`, `lizard upgrade --check` returns `{ currentVersion, latestVersion, updateAvailable }`.

## Examples

### Update to the latest version

```bash
lizard upgrade
```

### Check for updates without installing

```bash
lizard upgrade --check
```
