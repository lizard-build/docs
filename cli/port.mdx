# lizard port

Show or change the container port for a service. No argument prints the current port (`worker mode` when it's `0`). A new port takes effect on the next deploy; run [`lizard redeploy`](/cli/redeploy) to apply it.

## Usage

```bash
lizard port [value] [flags]
```

## Flags

| Flag | Description |
|------|-------------|
| `-s, --service <name>` | Service to target |
| `-p, --project <id>` | Project name, slug, or ID |

## Examples

### Show the current port

```bash
lizard port
```

### Set the port for a specific service

```bash
lizard port 0 -s worker
```

### Check the port on a worker service

```bash
lizard port --service worker
```
