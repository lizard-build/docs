# lizard project

List, create, pause, resume, or delete projects.

## Usage

```bash
lizard project list [flags]
lizard project create <name> [flags]
lizard project pause [project]
lizard project resume [project]
lizard project delete <project> [flags]
```

## Subcommands

### `lizard project list`

List your projects across all workspaces, or in one workspace with `-w`.

| Flag | Description |
|------|-------------|
| `-w, --workspace <ws>` | Only this workspace (id, slug, or name) |

### `lizard project create <name>`

Create a project. It does not link the current directory; use [`lizard init`](/cli/init) for that.

| Flag | Description |
|------|-------------|
| `-w, --workspace <ws>` | Workspace to create the project in |

### `lizard project pause [project]`

Pause every app and database in the project, and its running sandboxes. Services keep their URLs, passwords, settings and data. See [`lizard pause`](/cli/pause).

### `lizard project resume [project]`

Resume the apps and databases you paused in the project, and the sandboxes that `project pause` paused.

### `lizard project delete <project>`

Move a project to trash (alias `rm`). Only the project owner can delete it. Its services and databases stop; you can restore them from the trash in the dashboard for 3 days, after which Lizard deletes them for good.

> **Warning:** Sandboxes have no trash. `project delete` deletes the project's sandboxes, their volumes and their snapshots at once, and you can't get them back.

`delete` needs the project named. It never falls back to the folder's linked project or your account's default project. Without an argument, `pause` and `resume` use the project linked to this folder or, in an unlinked folder, your account's default project.

| Flag | Description |
|------|-------------|
| `-y, --yes` | Skip confirmation (required without a TTY) |

## Examples

### List projects

```bash
lizard project list
lizard project list --workspace my-team
```

### Create a new project

```bash
lizard project create my-project
lizard project create my-project --workspace my-team
```

### Pause and resume a project

```bash
lizard project pause my-project
lizard project resume my-project
```

### Delete a project

```bash
lizard project delete my-project --yes
```
