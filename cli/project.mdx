# lizard project

List or create projects in a workspace.

## Usage

```bash
lizard project list
lizard project create
```

## Subcommands

### `lizard project list`

List all projects in the workspace.

### `lizard project create`

Create a new project.

## Examples

### List projects in the workspace

```bash
lizard project list
```

### Create a new project

```bash
lizard project create
```
