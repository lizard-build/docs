# lizard workspace

Create, list, and delete workspaces.

## Usage

```bash
lizard workspace list
lizard workspace create <name>
lizard workspace rm <name-or-id> [flags]
```

## Subcommands

### `lizard workspace list`

List the workspaces you belong to, with your role and project count (alias `ls`).

### `lizard workspace create <name>`

Create a workspace. Add projects to it with `lizard project create <name> --workspace <slug>`.

### `lizard workspace rm <name-or-id>`

Delete a workspace (alias `delete`). Only the owner can delete it, and only when it has no projects or sandboxes left. You can't delete your personal workspace.

| Flag | Description |
|------|-------------|
| `-y, --yes` | Skip confirmation |

## Examples

### List your workspaces

```bash
lizard workspace list
```

### Create a workspace

```bash
lizard workspace create my-team
```

### Delete an empty workspace

```bash
lizard workspace rm my-team --yes
```
