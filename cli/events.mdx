# lizard events

Show deploy history and replica status.

## Usage

```bash
lizard events [flags]
```

## Flags

| Flag | Description |
|------|-------------|
| `-n, --limit <n>` | Number of entries to show (default 10) |
| `-s, --service <name>` | Show events for a specific service |
| `-p, --project <id>` | Project name, slug, or ID |

Without `-p`, `events` uses the linked project, or your default project in an unlinked folder.

## Examples

### Show deploy history and replica status

```bash
lizard events
```

### Show events for a specific service

```bash
lizard events --service api
```

### Show more entries

```bash
lizard events --limit 25
```
