# lizard login

Log in to Lizard.

## Usage

```bash
lizard login [flags]
```

By default this opens the sign-in page in your browser, prints its URL, and exits. After you sign in, run your next command (for example `lizard whoami`); it finishes the login and saves your credentials. With `--json`, `login` prints `{ "status": "pending", "authUrl": "…" }` and does not open a browser.

## Flags

| Flag | Description |
|------|-------------|
| `--token <token>` | Authenticate with an API key (`liz_…`) |

## Examples

### Log in via browser

```bash
lizard login
```

### Log in with an API key

Create a key with [`lizard keys create <name>`](/cli/keys), then:

```bash
lizard login --token liz_xxx
```

### Log in non-interactively in CI

In CI or other non-interactive environments, set `LIZARD_TOKEN` (or `LIZARD_API_KEY`) in the environment instead of running `login`:

```bash
export LIZARD_TOKEN=liz_xxx
```
