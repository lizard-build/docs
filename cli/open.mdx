# lizard open

Open the project in the browser.

## Usage

```bash
lizard open [flags]
```

## Flags

| Flag | Description |
|------|-------------|
| `-p, --project <id>` | Project name, slug, or ID |

Without `-p`, `open` uses the linked project, or your default project in an unlinked folder. With `--json` it prints `{ url, opened: false }` and does not open a browser.

## Examples

### Open the current project's dashboard

```bash
lizard open
```

### Print the dashboard URL

```bash
lizard open --json
```
