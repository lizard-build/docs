# lizard init

Create or select a project and link it to the current directory.

## Usage

```bash
lizard init [flags]
```

## Flags

| Flag | Description |
|------|-------------|
| `-n, --name <name>` | Project name (create if missing) |
| `-w, --workspace <ws>` | Workspace id, slug, or name |
| `--force` | Relink even if already linked |

## Examples

### Link the current directory interactively

```bash
lizard init
```

Without `--name`, `init` asks which project to use. In a non-interactive shell it fails instead, so pass `--name`.

### Link explicitly in CI

An unlinked `lizard up` deploys into your account's default project. To deploy into a named project in CI, link it first:

```bash
export LIZARD_TOKEN=liz_xxx
lizard init --name my-project
lizard up --ci --service api   # creates api on the first run
```

### Relink a directory that's already linked

```bash
lizard init --name my-project --force
```
