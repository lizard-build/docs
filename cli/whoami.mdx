# lizard whoami

Show the account you are signed in with and, in a linked folder, the linked project and its workspace.

## Usage

```bash
lizard whoami
```

## What it shows

- Signed in as an account: your username, whether the GitHub App is connected, and the linked project with its workspace in brackets. In an unlinked folder it shows `Project: none`; commands there use your account's default project.
- Signed in with a scoped API key: `Scoped API key (account details are not visible)`, then each project or workspace the key reaches. It never shows the account behind the key.

`whoami` does not show an active workspace. To list your workspaces, run [`lizard workspace list`](/cli/workspace).

With `--json`, or when the output is not a terminal, it prints your account's fields plus `project`. For a scoped key it prints `{ "scoped": true, "scopes": [...], "project": ... }`.

## Examples

### Check who you're logged in as

```bash
lizard whoami
```
