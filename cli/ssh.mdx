# lizard ssh

> **Turned off.** Shell access to services is disabled on Lizard. `lizard ssh` gets HTTP 403 `Shell access to services is disabled` and exits with code `1`.

The command still ships with the CLI, but the platform refuses it for every service. Use these instead:

| To check | Command |
|----------|---------|
| References that resolved to an empty value | `lizard logs --build --service api` (the build log warns about every empty `${{…}}` reference) |
| The values stored on a service | `lizard secrets list --service api --show` |
| A command with an addon's real connection values | `lizard run --service postgres -- <cmd>` |
| What the app prints at runtime | `lizard logs --service api` |

For a shell in a sandbox, use [`lizard sandbox ssh <id>`](/cli/sandbox#sandbox-ssh). It still works.

## Usage

```bash
lizard ssh --service <name> -- <command>
```

| Flag | Description |
|------|-------------|
| `-s, --service <id>` | Service name or ID |
| `-p, --project <id>` | Project name, slug, or ID |
