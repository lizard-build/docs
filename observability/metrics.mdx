# Metrics & Cost

Check a service's CPU, memory, network, disk and cost with [`lizard metrics`](/cli/metrics) or in the dashboard.

## View metrics

```bash
lizard metrics                    # CPU / memory / network / disk
lizard metrics --service api      # a specific service
lizard metrics --range 24h        # time window: 1h (default), 6h, 24h, 7d, 14d, 30d
lizard metrics --watch            # live-updating view
```

`--range` applies to one service: the linked one or `--service`. The project overview (`--all`, or a folder with no linked service) shows current values only.

## Include cost

```bash
lizard metrics --cost
```

This command shows cost instead of metrics: each running resource's price per hour, usage for the current billing period (egress included), and how much of your plan's included usage you have used this period (the trial's $5 during the 7-day trial, then the amount your plan includes each month: $19, $99 or $499). It covers the whole project, ignores `--service` and `--range`, and only the workspace owner can see it.

## Dashboard

The dashboard (`lizard open`) renders these as charts in the **Metrics** view, and the **Usage** view breaks down consumption and billing across the project. Open it with:

```bash
lizard open
```

## Acting on what you see

- High CPU/memory → scale up: `lizard scale --service api --cpu 2 --memory 2048`.
- Sustained load → add replicas: `lizard scale --service api --replicas 3`. Your plan allows 1 replica per service during the trial and 5 after the first paid invoice.
- Disk pressure on an addon → grow storage: `lizard scale --service postgres --storage 8192`.

See [Scaling](/deploy/scaling).
