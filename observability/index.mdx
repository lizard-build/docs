# Observability

See what your services are doing: stream logs, track metrics and cost, and review deploy and replica history.

## In this section

- [Logs](/observability/logs): live and historical logs, including build and restart logs.
- [Metrics & Cost](/observability/metrics): resource usage and what it costs.
- [Events & History](/observability/events): deploy timeline and per-replica status.

The CLI commands also accept `--json`, so coding agents can read their output when a deploy fails. See [deploying from Claude Code](https://lizard.build/blog/deploy-from-claude-code).
